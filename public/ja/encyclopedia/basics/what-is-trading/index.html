トレードとは？

トレードとは、価格の変動から利益を得ることを目的に、金融資産を売買することです。期間は通常、数秒から数か月です。長期投資とは異なり、トレーダーのリターンは主にタイミングと他の市場参加者に勝てるかどうかで決まり、企業や経済のゆるやかな成長によって決まるわけではありません。そのためトレードは実際のコストを伴う競争であり、データを見ると、挑戦した個人トレーダーの大半がお金を失っています。その理由を理解することが、賢くトレードを行うための、あるいはやらないと決めるための第一歩です。

要点

  • トレードは短期から中期の価格変動から利益を得ようとするもので、投資は生産的な資産を保有することで長期的なリターンを得ようとするものです。
  • トレードの対象となる市場の多くは、コストを差し引く前の時点でほぼゼロサムです。そのため手数料、スプレッド、税金を支払うと、トレーダー全体としてはマイナスサムになります。
  • トレーダーにはエッジ、つまりコスト控除後にプラスの結果を期待できる再現性のある理由が必要ですが、トレードを始める人の大半はそれを持っていません。
  • 個人デイトレーダーに関する大規模な研究や、規制当局が義務付けたブローカーの開示を見ると、一貫して過半数がお金を失っています。
  • 生き残れるかどうかは、完璧なエントリーを見つけることよりも、リスク管理、コストへの意識、規律にかかっています。

トレードとは実際に何をすることか

最も単純に言えば、取引とは交換です。他の誰かと合意した価格で、現金を渡して資産を受け取るか、資産を渡して現金を受け取ります。トレーダーはポジション（相場によって価値が変わるものを保有している、または負っている状態）を建て、後でそれを決済します。損益は、エントリー価格と決済価格の差からコストを引いたものです。

先に買って後で売れば、価格の上昇から利益を得られます。これをロング（買い）と呼びます。先に売って後で買い戻せば、価格の下落からも利益を得られます。これをショート（売り）と呼びます。どちらもロングとショートのポジションで解説しています。

トレードは、企業の株式、通貨、先物、オプション、暗号資産、コモディティ、債券、そして予測市場のイベントコントラクトなど、多くの市場で行われています。それぞれについては金融市場の全体像で説明しています。仕組みは異なりますが、核となる考え方はどこでも同じです。売る価格より安く買い、その差がコストを賄えるだけ大きいことを確かめることです。

トレード、投資、ギャンブルの違い

人はこの3つの活動を混同しがちです。重なる部分もありますが、時間軸、リターンの源泉、そして平均的な参加者が期待できる結果が異なります。

なぜ投資はプラスの期待値を持ちやすいのか

幅広い株式のバスケットを何年も保有すれば、企業の利益と配当の分け前を受け取ることになります。歴史的に見ると、多くの国の株式市場全体は長い期間でプラスの実質リターンをもたらしてきました。ただし途中で大きな下落もあり、将来の保証はありません。平均的な投資家は、低コストで市場全体を保有するだけで市場のリターンを得ることができます。

なぜトレードは違うのか

1日や1週間という期間では、ほとんどの資産価格の期待される上昇幅（ドリフト）は、ランダムな値動きの大きさに比べてごくわずかです。したがって短期トレーダーは、成長の恩恵をほとんど受けていません。その成績は、取引相手よりも有利な価格で売買できるかどうかにほぼ完全にかかっています。それは競争であり、どんな競争にも敗者がいます。

トレードとギャンブルの境界

エッジがなく、ポジションサイズが計画ではなく興奮によって決まり、期待値がプラスである理由をトレーダー自身が説明できないとき、トレードはギャンブルと区別がつかなくなります。満期までの期間が非常に短いオプション、高レバレッジの暗号資産ポジション、新しく発行されたミームコインは、この一線を越えやすい分野です。トレードがやめられない衝動のように感じられたり、損失を取り返そうと追いかけている自分に気づいたりしたら、多くの国では無料で秘密が守られる相談窓口など、ギャンブル依存の支援を受けられます。

ゼロサムとマイナスサムの市場

ゼロサムの市場では、一方の利益がそのまま他方の損失になります。最もわかりやすい例が先物とオプションです。あるトレーダーが別のトレーダーから100で先物を買い、その後価格が110で決済されれば、買い手は10ポイントの利益、売り手は10ポイントの損失です。何も生み出されてはおらず、お金がある口座から別の口座に移動しただけです。

株式は企業が利益を生むため、長期的には厳密なゼロサムではありません。しかし短い時間軸では、その利益による上昇はあまりに小さいため、短期の株式トレードはほぼゼロサムゲームのように振る舞います。

ここにコストを加えましょう。どのトレードも何かを支払っています。手数料、ビッド・アスク・スプレッド、取引所手数料、資金調達コスト、あるいはネットワークのガス代です。こうした支払いはトレーダーの資金プールから出ていき、ブローカー、取引所、マーケットメイカーの手に渡ります。手数料のかかるゼロサムゲームは、プレイヤー全体にとってはマイナスサムのゲームです。トレーダー全体が損益トントンになるには、誰か別の人がトレーダーにお金を失っていなければなりませんが、短い時間軸ではそうした取り分の源泉はほとんどありません。

計算例：コストはどう積み重なるか

$20,000の口座を持つデイトレーダーが、1日10回の往復取引（往復取引とは1回の買いと1回の売りのこと）をするとします。手数料、スプレッド、わずかなスリッページを合わせて、往復1回あたり平均$4のコストがかかります。

  • 1日のコスト：10 x $4 = $40
  • 1年の取引日数：約250日
  • 年間コスト：$40 x 250 = $10,000
  • 口座資金に対するコストの割合：$10,000 / $20,000 = 50%

このトレーダーは何かを稼ぐ前に、損益トントンにするためだけで年50%の粗利益を上げなければなりません。それができる人はごくわずかです。取引コストと手数料の記事で、各コストを詳しく分解しています。

トレーダーはどうやって稼ぐのか

利益を出しているトレーダーにはエッジ（優位性）があります。市場の仕組みに根ざした、自分のトレードが平均してコスト以上の価値を持つはずだという理由です。よくある源泉は次のとおりです。

  • 情報や分析。 中央銀行の決定が通貨にどう影響するか、予測市場がどう決着するかといったことを、価格に織り込まれるよりも正確に、あるいは早く理解すること。
  • 流動性の提供。 マーケットメイカーは、在庫リスクを引き受ける代わりに、常に売買に応じる準備をすることでスプレッドを稼ぎます。市場参加者をご覧ください。
  • 他者が手放したいリスクを引き受ける。 ヘッジャーが手放したいポジションを持つことや、保険のようなポジションを提供することで、平均して対価を得ているトレーダーもいます。こうした戦略は、まれな出来事で大きな損失を被ることがあります。
  • 行動パターン。 特定の時間軸におけるモメンタムなど、一部の価格パターンは学術研究で報告されており、その一因は人々のニュースへの反応の仕方にあるとされることが多いものです。ただし、こうしたパターンは弱く、混み合っていて、一貫性に欠ける傾向があります。
  • スピードとテクノロジー。 プロの業者は高速な執行に多額の投資をしています。個人トレーダーはこの点では太刀打ちできません。

エッジが確実ということは決してありません。本当に利益の出る手法でも長い連敗はありますし、エッジは見つける人が増えるほど縮小していく傾向があります。

トレーダーはなぜお金を失うのか

損失の大半は、限られた原因から生じています。

  • エッジがない。 勘、噂、検証されていないパターンに基づいてトレードしているため、結果は取引コスト分のマイナスに近づいていきます。
  • コスト。 上の例が示すとおり、頻繁な取引は小さなコストを大きなコストに膨らませます。
  • 逆選択（アドバースセレクション）。 自分より情報を持つ相手と取引すると、まさに自分に不利に動くトレードで約定しがちです。
  • レバレッジ。 借りたお金は利益と同じだけ損失も拡大させ、1回の値動きで口座を吹き飛ばすことがあります。レバレッジと証拠金をご覧ください。
  • 行動。 利益を早く確定しすぎる、損失を長く持ちすぎる、負けた後のリベンジトレード、勝った後のポジションの過大化。これらは心理のセクションで取り上げています。
  • お粗末なリスク管理。 1回のトレードでリスクを取りすぎると、普通の連敗が致命的な連敗になります。

個人トレーダーに関するデータが示すこと

複数のデータが同じ方向を指しています。

  • 台湾。 ブラッド・バーバー、李怡宗（Yi-Tsung Lee）、劉玉珍（Yu-Jane Liu）、テランス・オディーンによる研究は、台湾証券取引所の全取引記録を使い、デイトレーダーの大多数がお金を失っていたこと、そして手数料控除後に毎年予測可能な利益を上げられたのは1%未満だったことを明らかにしました。
  • ブラジル。 フェルナンド・シャギ、ロドリゴ・デ＝ロッソ、ブルーノ・ジョヴァネッティは、ブラジルのミニ指数先物を少なくとも300日間デイトレードした個人を調査しました。約97%がお金を失い、その活動からブラジルの最低賃金を上回る収入を得ていたのはわずか約1%でした。
  • CFDブローカーの開示。 欧州証券市場監督局（ESMA）が導入し各国の規制当局が採用したルールのもと、EUで個人顧客に差金決済取引（CFD）を提供するブローカーは、損失を出している個人口座の割合を表示しなければなりません。ブローカーが公表している数値は一般に70%から80%、あるいはそれ以上で、英国にも同様の要件があります。

これらは、利益の出るトレードが不可能だと証明するものではありません。示しているのは、何もしなければ損失が標準的な結果であること、頻繁な取引やレバレッジをかけた取引ほど損失が大きいこと、そして安定して勝ち続けるごく少数の人を、短期的には運の良い人と見分けるのが難しいということです。

よくある間違い

  • 連勝をスキルの証拠だと考える。 数週間うまくいったくらいでは、十分に運の範囲内です。
  • レバレッジから始める。 レバレッジは、他のあらゆる失敗をするまでの時間を短くします。
  • コストを無視する。 チャート上では利益が出ているように見える戦略の多くも、スプレッドと手数料を含めると損失になります。
  • 大きすぎるサイズで取引する。 1回のトレードで口座資金の10%以上をリスクにさらすと、そこそこの戦略でも破産する可能性が高くなります。
  • 宣伝から学ぶ。 講座やシグナルを売っている人の多くは、トレードよりも顧客から多くを稼いでいます。講座、自称カリスマ、シグナルをご覧ください。

よくある質問

トレードはギャンブルと同じですか？

必ずしもそうではありません。検証済みのエッジ、管理されたポジションサイズ、文書化された計画を持って行うトレードはスキルに基づく活動です。しかし、エッジがなく興奮に駆られて行うトレードは、ギャンブルと同じく期待値がマイナスです。

トレードで生計を立てることはできますか？

ごく一部の人はそうしていますが、台湾とブラジルの個人デイトレーダーに関する研究では、安定して利益を上げていたのは約1%にすぎませんでした。挑戦する人の大半はお金を失うため、長く検証された実績がない限り、トレードを主な収入源として当てにすべきではありません。

なぜほとんどのトレーダーはお金を失うのですか？

短期トレードはコスト控除前でほぼゼロサム、コスト控除後はマイナスサムであるため、平均的なトレーダーはおおよそ取引コスト分を失います。レバレッジ、オーバートレード、感情的な判断によって、多くのトレーダーはその平均を大きく下回ります。

トレードと投資の違いは何ですか？

投資とは、生産的な資産を何年も保有して、その長期的な成長の恩恵を受けることです。トレードとは、価格の変動から利益を得るために短い期間で売買することであり、他の参加者を上回る成績を上げられるかどうかにかかっています。

教育目的のコンテンツです。本サイトの内容は、金融・投資・法律・税務に関する助言ではありません。トレードには大きな損失リスクがあり、レバレッジ商品では入金額を超える損失が生じることがあります。ルール、手数料、プラットフォームの条件は変わります。取引の前に、ご利用の証券会社、取引所、規制当局で最新の条件をご確認ください。
