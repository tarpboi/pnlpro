トレードの始め方

賢くトレードを始めるとは、市場の仕組みを学び、1つの市場とスタイルを選び、実際のお金を使わずに練習し、そのうえで厳格なリスク上限を設けて少額で取引しながら、すべてのトレードを記録して振り返ることです。最初の1年の目標は、お金持ちになることではありません。生き残り、学び、自分に優位性（エッジ）があるのかを正直に見極めることです。トレードを始めた人の大半はお金を失います。だからこそ最も安全な道は、ゆっくり、低コストで、資金を守ることを中心に組み立てることです。

要点

  • トレードにはリスク資金だけを使いましょう。リスク資金とは、全額失っても生活費、借金の返済、貯蓄目標に影響しないお金のことです。
  • 最初は1つの市場と1つのスタイルに絞り、その仕組みとコストを深く学びましょう。
  • デモトレード（ペーパートレード）でプラットフォームや手順に慣れることはできますが、本物の感情や約定は再現できません。
  • 実際の資金で取引を始めたら、1回のトレードで口座資金の小さな一定割合（多くの場合1%以下）だけをリスクにさらし、すべてのトレードを日誌に記録しましょう。
  • ロットを増やすのは、意味のある数のトレードでコスト控除後の成績がプラスだと示されてからにしましょう。

ステップ1：基礎を学ぶ

トレードを始める前に、用語と仕組みを理解しておきましょう。少なくとも次のことは説明できるようにしておくべきです。

  • 注文の種類の仕組み、特に成行注文、指値注文、逆指値注文。
  • ビッド・アスク・スプレッドとは何か、往復取引にいくらかかるか。
  • レバレッジと証拠金が損失をどう拡大させるか、いつロスカット（強制決済）が起きるか。
  • 取引する予定の市場にどんな取引コストと手数料がかかるか。
  • ポジションサイズの決め方や損切りの置き方を含め、リスク管理がどう機能するか。

この事典の「トレードの基礎」と「リスク管理・資金管理」のセクションの記事で、これらを順番に解説しています。質の高い無料の教材はたくさんあります。収入を約束する高額な講座には注意してください。講座、自称カリスマ、シグナルをご覧ください。

ステップ2：1つの市場と1つのスタイルを選ぶ

市場ごとに取引時間、コスト、レバレッジ、ルール、値動きの特徴が異なります。複数の市場に少しずつ手を出すより、1つの市場をしっかり学ぶほうがうまくいく傾向があります。次の点を考えましょう。

  • スケジュール。 ある市場の主要な取引時間に仕事をしているなら、時間軸の長いスタイルを選ぶか、自分の空いている時間に活発な市場を選びましょう。市場の取引時間とセッションをご覧ください。
  • 資金。 取引単位や口座ルールなど、事実上の最低必要資金がある市場もあります。
  • シンプルさ。 レバレッジをかけない株式やETFは、オプション、無期限先物、ミームコインよりも理解しやすいものです。

自分の時間と気質に合ったトレードスタイルを選びましょう。多くの初心者は、デイトレードやスキャルピングよりも、ペースが遅くコストも低いスイングトレードのほうがうまくいきます。

ステップ3：シンプルな計画を書く

トレードを始める前に、次のことを書き出しておきましょう。

  • 何を、いつ取引するか。
  • どのセットアップで入るか、具体的なエントリールール。
  • 損切りをどこに置くか、利益の出ているポジションをどう手仕舞うか。
  • 1回のトレードでいくらリスクを取るか、そして1日または1週間でいくら負けたら取引をやめるか。

計画は完璧である必要はありませんが、漠然とした意図を検証可能なルールに変えてくれます。トレード計画の書き方をご覧ください。

ステップ4：デモトレードをする

デモトレード（ペーパートレード）とは、ブローカーのデモ口座やスプレッドシートを使って、実際のお金を使わずに取引をシミュレーションすることです。次の点で役立ちます。

  • プラットフォームの操作を覚え、高くつく誤発注を防ぐ。
  • 計画のルールを一貫して守れるかを確認する。
  • 各セットアップがどう機能するかについて、最初の大まかなサンプルを集める。

ただし限界もはっきりあります。デモの約定は実際の約定よりも有利になりがちで、特に薄い市場での成行注文ではその傾向が強くなります。さらに重要なのは、何も懸かっていなければ恐怖も欲もないということです。デモの成績は手順のテストとして扱い、利益が出せる証拠とは考えないでください。通常は数週間から数か月、あるいは数十回のトレードを経れば、少額の実弾トレードに移るには十分です。

ステップ5：少額で実際の取引を始める

本物のお金が懸かると行動が変わります。その市場で可能な最小のポジションサイズから始め、1回のトレードで口座資金の小さな一定割合だけをリスクにさらしましょう。

計算例：リスク資金の予算を立てる

ある人が$50,000の貯蓄を持っているとします。そのうち生活費6か月分の$18,000を緊急資金として確保し、$26,000を住宅購入の頭金として取り分けています。全額失っても生活が変わらないお金は$3,000だと判断しました。これがその人のトレード口座になります。

  • 1回あたりのリスクを1%とすると：$3,000 x 1% = $30。
  • 損切りをエントリー価格の2%下に置く株式トレードなら、ポジションサイズ = $30 / 0.02 = $1,500。
  • 株価が$50なら、$1,500 / $50 = 30株。
  • 損切りにかかった場合の損失は、30 x ($50 x 0.02) = 30 x $1 = $30で、これにコストが加わります。

1回あたり1%のリスクなら、10連敗しても損失は約$300、口座資金の10%です。痛手ではありますが生き残れますし、健全な戦略でもその程度の連敗は起こります。1回あたり10%のリスクを取っていた場合、同じ連敗で元の$3,000のうち残るのは約$1,046です。ポジションサイズの決め方はポジションサイジングで解説しています。

このトレーダーはもう1つルールを決めています。口座資金が$2,400（20%のドローダウン）を下回ったら実弾トレードをやめ、振り返りとデモトレードに戻るというものです。

ステップ6：トレード日誌をつける

すべてのトレードを記録しましょう。日付、市場、セットアップ、エントリー、損切り、利益目標、決済、ポジションサイズ、コスト控除後の結果、そしてなぜそのトレードをしたのか、どう感じたのかについての短いメモです。エントリー時と決済時のチャートのスクリーンショットも役に立ちます。日誌がなければ、実力と運を見分けることも、繰り返している失敗を見つけることもほぼ不可能です。トレード日誌をご覧ください。

ステップ7：定期的に振り返る

週に1回、日誌を見直しましょう。役立つ問いは次のとおりです。

  • すべてのトレードでルールを守ったか？ 守らなかったなら、どのルールをなぜ破ったのか？
  • どのセットアップがコスト控除後に利益を生み、どれが損失を出したか？
  • 平均利益、平均損失、勝率はいくらか？ 1トレードあたりの期待値はいくらか？ リスクリワードと期待値をご覧ください。
  • 負けた後や勝った後に、取引回数が増えていないか？

一度に変えるのは1つだけにし、それぞれの変更を判断できるだけのトレード数を確保しましょう。

ステップ8：ゆっくり規模を拡大する

ロットを増やすのは、根拠がそれを裏付けているときだけにしましょう。妥当な基準は、同じルールに従った実弾トレードが少なくとも50〜100回あり、コスト控除後の成績がプラスで、ドローダウンが自分の上限内に収まっていることです。それでも倍にするのではなく、1回あたりのリスクを0.5%から0.75%に上げるといった小刻みな引き上げにとどめましょう。ポジションが大きくなると感情の揺れが強まり、流動性が制約になるため、成績は悪化しがちです。

現実的な期待値

  • トレードに挑戦した人の大半はお金を失います。台湾とブラジルの個人デイトレーダーを対象とした大規模な研究では、安定して利益を上げていたのはわずか約1%でした。
  • 利益を出しているトレーダーでも、長い負けの期間があります。
  • 自分にエッジがあるかどうかわかるまでに、1年以上学ぶのはごく普通のことです。
  • トレードがやめられない衝動のように感じられたり、損失を隠したり、より大きな賭けで取り返そうとしたりし始めたら、それはギャンブル依存の警告サインです。多くの国では、無料で秘密が守られる相談窓口など、支援を受けられる場所があります。損失とティルトへの対処をご覧ください。

詐欺を避ける

初心者はトレード詐欺の主な標的です。よくある警告サインは次のとおりです。

  • SNSやメッセージアプリで、見知らぬ人が教えてあげる、代わりに取引してあげると持ちかけてくる。
  • 元本保証、または異常に高く安定したリターン。
  • 入金は簡単なのに、出金の前に手数料や「税金」を要求するプラットフォーム。
  • 自分たちのプラットフォームへの入金を求めるシグナルグループや「AIボット」。
  • 前払い手数料と引き換えに、失ったお金を取り戻してあげると持ちかける人。

確立した法域で規制を受けている業者を利用し、規制当局自身の登録簿でライセンスを確認しましょう。ブローカーと取引所とトレード詐欺をご覧ください。

よくある間違い

  • レバレッジや複雑な商品から始める。 オプション、無期限先物、ミームコインは、最初の市場としては不向きです。
  • 必要なお金を入金する。 家賃や借りたお金でトレードすると、プレッシャーから誤った判断をしがちです。
  • 日誌をつけない。 記録がなければ、自分のトレードから学ぶことはできません。
  • たまたま勝ちが続いた後にロットを増やす。 数回の勝ちはエッジがある証拠ではありません。
  • 戦略をころころ変える。 どんな戦略にも負けが続く時期があります。そのたびに乗り換えていては学びが得られません。
  • 税金を忘れる。 税務のために、すべてのトレードの記録を残しておきましょう。トレードの税金の概要をご覧ください。

よくある質問

トレードはいくらから始められますか？

技術的には、多くのブローカーが非常に少額の口座を認めています。それより大事なのは、そのお金が全額失っても困らないリスク資金であること、そして選んだ市場でコストを差し引いたうえで妥当なポジションサイズが取れるだけの口座規模があることです。

初心者はデモ口座を使うべきですか？

デモ口座は、プラットフォームの操作を覚えたり、ルールを守れるかを試したりするのに役立ちます。ただし本物の感情や約定は再現できないため、手順が習慣になったら少額の実弾トレードに移りましょう。

トレードを身につけるにはどのくらいかかりますか？

ほとんどのトレーダーは、自分に再現性のあるエッジがあるかを知るまでに、少なくとも何か月も、多くの場合は1年以上、学習と練習と実弾トレードを重ねる必要があります。結局エッジを見つけられない人も大勢います。

1回のトレードで口座資金の何%をリスクにさらすべきですか？

多くのトレーダーは、1回のトレードで口座資金の1%以下しかリスクにさらしません。そうすれば、学んでいる間に普通の連敗が起きても深刻なダメージを受けずに済みます。

教育目的のコンテンツです。本サイトの内容は、金融・投資・法律・税務に関する助言ではありません。トレードには大きな損失リスクがあり、レバレッジ商品では入金額を超える損失が生じることがあります。ルール、手数料、プラットフォームの条件は変わります。取引の前に、ご利用の証券会社、取引所、規制当局で最新の条件をご確認ください。
