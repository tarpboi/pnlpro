ビッド・アスク・スプレッドと流動性

ビッド・アスク・スプレッド（bid-ask spread）とは、買い手が支払ってもよい最も高い価格（ビッド、買い気配）と、売り手が受け入れる最も安い価格（アスク、売り気配）の差のことです。流動性とは、ある資産を価格を大きく動かさずに、まとまった量で売買できる度合いを指します。この2つは取引コストの大部分を左右し、手数料より大きくなることも珍しくありません。特に短期トレーダーにとっては、スプレッドとスリッページを理解しておくことが、その戦略でそもそも利益が出せるのかを判断するうえで欠かせません。

要点

  • アスクで買ってビッドで売る以上、どの往復取引もスプレッド分の損失からスタートします。
  • スプレッドはセント、pips、ティック、あるいは仲値に対するパーセンテージで表され、パーセンテージで見ると異なる市場同士を比較できます。
  • 流動性にはいくつかの側面があります。スプレッドの狭さ、各価格帯の板の厚さ、そして大口取引の後にどれだけ早く回復するかです。
  • 注文が大きいとき、市場が薄いとき、価格が急変しているときは、スプレッドに加えてスリッページとマーケットインパクトのコストが上乗せされます。
  • スプレッドはニュースの前後、取引の開始時と終了時、流動性の低い時間帯、そして市場が混乱しているときに広がります。

ビッド、アスク、スプレッド、仲値

  • ビッド（買い気配）： 現時点で誰かが買ってもよいと提示している最良の価格です。すぐに売る場合は、ビッドで売ることになります。
  • アスク（オファー、売り気配）： 現時点で誰かが売ってもよいと提示している最良の価格です。すぐに買う場合は、アスクで買うことになります。
  • スプレッド： アスクからビッドを引いた値です。
  • 仲値（ミッドプライス）： 両者の中間点で、(bid + ask) / 2 で求めます。チャートや気配値には仲値や直近の約定価格が表示されることが多いものの、通常は仲値で取引することはできません。

これらの価格は、取引所の板（オーダーブック）から、あるいはFXのような店頭（OTC）市場ではディーラーの提示レートから生まれます。

スプレッドは流動性を提供する側、典型的にはマーケットメイカーへの対価です。マーケットメイカーは常にビッドで買い、アスクで売る用意をしています。平均するとスプレッド分を稼ぎますが、抱えている在庫に対して価格が不利に動くリスクを負っています。詳しくは市場参加者をご覧ください。

スプレッドの測り方

スプレッドの表示単位は市場によって異なるため、仲値に対するパーセンテージやベーシスポイント（1ベーシスポイントは0.01%）に換算すると比較しやすくなります。

市場の例 ビッド アスク スプレッド 仲値に対するスプレッドの割合
大型株 $25.00 $25.05 $0.05 約0.20%
小型株 $2.00 $2.10 $0.10 約4.9%
EUR/USD 1.08500 1.08510 1 pip 約0.009%
予測市場のコントラクト $0.42 $0.45 $0.03 約6.9%

計算式：0.05 / 25.025 = 0.20%、0.10 / 2.05 = 4.88%、0.0001 / 1.08505 = 0.0092%、0.03 / 0.435 = 6.90%。数値は説明用であり現在の気配値ではありませんが、傾向としては典型的です。主要通貨や大型株は低コストで取引できる一方、小型株、流動性の低いトークン、ニッチなコントラクトでは往復で数パーセントのコストがかかることがあります。

計算例：往復取引のコスト

あるトレーダーが上の表の大型株を1,000株買い、数分後に価格が変わらないまま売却したとします。

  • アスクで買う：1,000 x $25.05 = $25,050
  • ビッドで売る：1,000 x $25.00 = $25,000
  • スプレッドによる損失：$50
  • 片道$1の手数料を加えると、合計コストは$52

これはポジション金額の0.21%にあたり、相場がまったく動かなかった取引で支払ったコストです。これを1日10回繰り返すトレーダーは、1日あたり$520を支払うことになります。250営業日では、一度に$25,000を回転させるポジションに対して、年間$130,000のコストになります。

同じ計算はFXにも当てはまります。EUR/USDの1スタンダードロット（100,000ユーロ）は1 pipあたり$10の価値があるため、1 pipのスプレッドは往復で$10のコストとなり、これに手数料が加わります。暗号資産や予測市場ではスプレッドがさらに広いことが多く、そのうえ取引所手数料もかかります。コストの全体像は取引コストと手数料にまとめています。

流動性

流動性の高い市場では、直近の価格に近い値段で、ある程度の量を素早く取引できます。トレーダーは流動性を次の3つの側面で捉えるのが一般的です。

  • タイトネス（狭さ）： スプレッドがどれだけ狭いか。
  • デプス（厚み）： 最良気配とその近辺にどれだけの数量があるか。
  • レジリエンス（回復力）： 大口取引で流動性が消費された後、板がどれだけ早く埋まり直すか。

スプレッドは狭いのに板は薄い、という市場もあります。たとえばスプレッドは1セントでも、売り買いそれぞれに100株しか並んでいないケースです。10,000株を売買する必要があるトレーダーにとっては、表示されているスプレッドよりも板の厚みのほうが重要です。

流動性は時間によっても変わります。同じ資産でも、メインセッションの寄り付きでは非常に流動性が高く、夜間や祝日、パニック時には極端に薄くなることがあります。

スリッページとマーケットインパクト

スリッページとは、想定していた価格と実際に約定した価格の差のことです。主な原因は3つあります。

  1. 板を食う。 最良気配の数量を上回る注文は、複数の価格帯にまたがって約定します。注文の種類の計算例をご覧ください。
  2. レイテンシ（遅延）。 クリックしてから注文が届くまでの間に価格が動きます。動きの速い相場では特に顕著です。
  3. 窓（ギャップ）。 夜間や週末をまたいで窓を開けた後に発動した逆指値は、最初に取引可能な価格で約定します。

マーケットインパクトとは、自分の売買そのものが価格に与える、より広い意味での影響です。大口注文は、分割して出したとしても需要の存在を知らせることになり、価格を自分にとって不利な方向へ押しやることがあります。プロのトレーダーは執行アルゴリズムを使ってこれを抑えます。流動性の高い市場での個人投資家サイズの取引であればインパクトは小さいものの、小型株、時価総額の小さいトークン、薄いイベントコントラクトでは、ほどほどの注文でも価格が目に見えて動くことがあります。

スプレッドが広がる理由

マーケットメイカーは、気配を出すリスクが高まるとスプレッドを広げます。よくある原因は次のとおりです。

  • 予定されたニュース。 中央銀行の政策決定や重要な経済指標の発表前後には、ディーラーが気配を引っ込めたり広げたりします。ニューストレードと経済指標カレンダーをご覧ください。
  • 流動性の低い時間帯。 夜間セッション、FXの日次ロールオーバー、暗号資産の週末は参加者が少なくなります。市場の取引時間とセッションをご覧ください。
  • 寄り付きと引け。 セッション開始直後の数分間は、価格が探られている最中のためスプレッドが広がりがちです。
  • ボラティリティと市場の混乱。 価格が激しく上下すると在庫を抱えるリスクが急増するため、気配が広がったり消えたりします。
  • 関心の低さ。 知名度の低い銘柄、新しいトークン、ニッチなコントラクトは、そもそも気配を出す参加者が少ないのです。

よくある間違い

  • ビッドとアスクではなくチャート上の価格を見てしまう。 多くのチャートは仲値やビッドを描いているため、実際に支払う価格とは異なることがあります。
  • 手数料ゼロだからとスプレッドのコストを無視する。 手数料無料の取引でも、スプレッド分のコストはかかります。
  • 薄い市場で成行注文を使う。 広いスプレッドと薄い板が重なると、大きなスリッページが生じることがあります。
  • スプレッドの拡大を考慮せずにニュース前後で取引する。 一時的なスプレッドの急拡大で逆指値が発動することがあります。
  • 出来高だけで流動性を判断する。 一部の暗号資産取引所では、公表される出来高に仮装売買（ウォッシュトレード）が含まれていることがあり、出来高は今この瞬間に利用できる板の厚みを教えてくれません。

よくある質問

良いスプレッドの目安はどのくらいですか？

市場によって異なります。主要通貨ペアや最大級の銘柄は、スプレッドが数百分の1パーセント程度で取引されることが多い一方、小型株、流動性の低いトークン、ニッチなコントラクトでは数パーセントに達することもあります。1回の取引で見込む利益とスプレッドを比べてみてください。

スプレッドのパーセンテージはどう計算しますか？

アスクからビッドを引き、仲値で割って100を掛けます。ビッドが$25.00、アスクが$25.05なら、0.05 / 25.025 x 100で、約0.20%になります。

スリッページはなぜ起こるのですか？

スリッページは、注文が想定より不利な価格で約定したときに発生します。主な原因は、注文が最良気配の数量より大きいこと、注文が届く前に価格が動いたこと、あるいは相場が窓を開けて逆指値の水準を飛び越えたことです。

なぜ夜間はスプレッドが広がるのですか？

メインセッション以外の時間帯は、活動しているトレーダーやマーケットメイカーが少ないため、狭い気配を出そうとする競争が弱まり、1つひとつの気配が抱えるリスクも大きくなります。スプレッドはニュースの前後やFXの日次ロールオーバーの時間帯にも広がりやすくなります。
