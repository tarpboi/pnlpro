インプライド・ボラティリティ

インプライド・ボラティリティ（IV）とは、市場がオプションに織り込んでいる将来のボラティリティの水準で、オプション価格から価格モデルを使って逆算したものです。年率のパーセンテージで表され、同じ権利行使価格・同じ満期のオプションでも、時期によって価格が大きく異なる主な理由になっています。IVは不確実なイベントの前に上昇し、イベント後に低下するため、オプション取引で利益が出るかどうかは、原資産の方向と同じくらいIVで決まることがよくあります。

要点

  • インプライド・ボラティリティは将来を見たもので、オプション価格から求めます。ヒストリカル・ボラティリティは過去を見たもので、実際の値動きから求めます。
  • IVランクとIVパーセンタイルは、現在のIVがその銘柄の過去のレンジと比べて高いか低いかを示します。
  • IVは決算などの予定されたイベントの前に上昇し、イベント後に急落する傾向があります。これをIVクラッシュと呼びます。
  • 権利行使価格ごとにIVは異なり、ボラティリティ・スキューやスマイルを形づくります。これはプロテクションへの需要や予想される値動きの形を反映しています。
  • 予想変動幅（エクスペクテッド・ムーブ）の計算式を使うと、IVを一定期間のおおよその1標準偏差の価格レンジに変換できます。

ヒストリカル・ボラティリティとインプライド・ボラティリティ

ヒストリカル・ボラティリティ（HV） は実現ボラティリティとも呼ばれ、過去の一定期間に価格が実際にどれだけ動いたかを測ります。通常は日次リターンの標準偏差を年率換算して計算します。

インプライド・ボラティリティ は、オプション価格モデルに入力したときにオプションの現在の市場価格と一致するボラティリティの値です。市場のコンセンサス予想に、売り手がリスクを引き受ける対価として求める上乗せ分を加えたものです。

計算例：ヒストリカル・ボラティリティを年率換算する

ある株の過去1か月の日次リターンの標準偏差が1.5%だったとします。1年の取引日はおよそ252日で、ボラティリティは時間の平方根に比例して大きくなります。

  • 252の平方根 = 約15.87
  • 年率換算したHV = 1.5% x 15.87 = 約23.8%

この株のオプションがIV 35%で値付けされているなら、市場は最近の実際の値動きよりも大きな変動をこの先に見込んでいることになります。イベントが控えているのかもしれません。歴史的に、指数オプションのIVは平均するとその後の実現ボラティリティを上回る傾向がありました。この差はボラティリティ・リスク・プレミアムと呼ばれ、オプションの売り戦略が長期間で平均的に利益を上げてきた理由の1つです。ただし、ときに大きな損失も被っています。

ブラック・ショールズの考え方

1973年にフィッシャー・ブラックとマイロン・ショールズが発表し、ロバート・マートンの関連研究もあるブラック・ショールズ・モデルは、6つの入力値からヨーロピアン・オプションの価格を算出します。

  1. 原資産価格
  2. 権利行使価格
  3. 満期までの期間
  4. 金利
  5. 配当
  6. ボラティリティ

最初の5つはわかっていますが、ボラティリティはわかりません。そこでトレーダーは、モデルを使って価格を求めるのではなく、市場価格を出発点にして、モデルがその価格と一致するボラティリティを逆算します。その数値がインプライド・ボラティリティです。

このモデルは、ボラティリティが一定であること、リターンが滑らかな釣鐘型の分布に従うことなどを前提としています。現実の市場にはジャンプや暴落、変化するボラティリティがあり、そのため権利行使価格ごとにIVが異なる結果になります。IVは完璧な予測というより、オプション価格を表示するための共通の単位と考えるのが適切です。

IVが高いほど、コールでもプットでもオプション価格は高くなります。IV 1ポイントあたりの価格変化を測るのが、オプションのグリークスの1つであるベガです。

IVランクとIVパーセンタイル

IVが40%の株が割安か割高かは、その銘柄にとって何が普通かによって変わります。IVを文脈の中で捉えるための一般的な指標が2つあり、通常は過去1年間で見ます。

  • IVランク = (現在のIV - 52週安値のIV) / (52週高値のIV - 52週安値のIV)
  • IVパーセンタイル = 過去1年の取引日のうち、IVが現在の水準を下回っていた日の割合

計算例

ある株のIVは過去1年間に20%から60%の範囲で推移し、現在は30%です。

  • IVランク = (30 - 20) / (60 - 20) = 10 / 40 = 25%。
  • 直近252取引日のうち160日でIVが30%を下回っていたなら、IVパーセンタイル = 160 / 252 = 約63%。

この2つは大きく異なることがあります。60%への一度の急騰があると、IVランクは1年間押し下げられますが、IVパーセンタイルは1つの外れ値の影響を受けにくいのです。多くのトレーダーは、これらの数値が高いときにプレミアムを売り、低いときに買うことを好みますが、IVが高いのには往々にしてもっともな理由があります。

予想変動幅の計算式

IVはおおよその価格レンジに変換できます。ある期間の1標準偏差の予想変動幅は次のとおりです。

予想変動幅 = 価格 x IV x (満期までの日数 / 365) の平方根

暦日と365を使うのが一般的な慣習ですが、取引日と252を使うトレーダーもいます。

計算例

株価$200、IV 40%の株について、今後7日間の予想変動幅を求めます。

  • 日数の比率：7 / 365 = 0.01918
  • 平方根：約0.1385
  • 予想変動幅 = $200 x 0.40 x 0.1385 = 約$11.08

市場は、この1週間に上下どちらかへ約$11、つまり5.5%動くことが、おおよそ1標準偏差の結果だと織り込んでいることになります。モデルの釣鐘型の前提のもとでは、株価が約68%の確率でこのレンジ内に収まります。現実のリターン分布はテールが厚いため、大きな値動きは釣鐘型の曲線が示すよりも頻繁に起こります。

市場価格に基づく手早い代替手段として、アット・ザ・マネーのストラドル（同じ権利行使価格のコールとプットの組み合わせ）の価格があります。これは満期までに予想される値動きの大きさの近似値になります。ストラドルとストラングルと決算トレードを参照してください。

IVクラッシュ

インプライド・ボラティリティは、決算、新製品の発表、治験結果、中央銀行の会合など、既知のイベントを前に上昇することがよくあります。大きな値動きが起こり得るからです。ニュースが出るとその不確実性は消え、IVは数分のうちに急落することがあります。この低下をIVクラッシュと呼びます。

計算例：方向は正しいのに損失

決算前日、株価は$50です。その週の後半に満期を迎える$50のコールは、IVが90%に上昇しているため$2.10で、そのほぼすべてが時間価値です。決算発表後、株価は$51.50に上がり、IVは35%に急落します。

  • コールの価値は、本質的価値$1.50に、残った時間価値を仮に$0.25とすると、約$1.75です。
  • 損失 = $2.10 - $1.75 = 1株あたり$0.35、1枚あたり$35。

トレーダーは方向を正しく予測しましたが、値動きはオプション価格が織り込んでいたよりも小さく、IVの低下が利益を帳消しにしました。イベント前にオプションを買うなら、すでに織り込まれている以上の値動きが必要です。売り手はクラッシュの恩恵を受けますが、値動きが予想をはるかに上回るリスクを負います。

ボラティリティ・スキューとスマイル

ブラック・ショールズが完全に正しければ、同じ満期のすべての権利行使価格で同じIVになるはずです。実際には、権利行使価格に対してIVをプロットすると、たいてい曲線になります。

形状 説明 よく見られる市場
プット・スキュー（スマーク） 低い権利行使価格ほど、高い権利行使価格よりIVが高い 株価指数とほとんどの大型株
スマイル ディープOTMのプットとコールの両方がATMよりIVが高い 通貨、一部の個別株、ときに暗号資産
コール・スキュー 高い権利行使価格ほどIVが高い 一部のコモディティ、買収やスクイーズの可能性がある株

株価指数のプット・スキューは、1987年10月の暴落以降に顕著になりました。ポートフォリオの保険としてプットを買う投資家からの安定した需要と、市場は上昇するより速く下落する傾向があることを反映しています。その結果、指数のOTMプットは、同じだけ離れたOTMコールよりもIVベースで割高になるのが普通です。

IVは満期によっても異なります。IVの期間構造（ターム・ストラクチャー）は平穏な市場では通常右上がりですが、危機時には逆転し、期近のIVが期先のIVを上回ることがあります。VIX指数はS&P 500の30日インプライド・ボラティリティを測ります。ボラティリティとVIXを参照してください。

よくある間違い

  • IVを確認せずに決算直前にオプションを買う。 価格にはすでに大きな値動きが織り込まれているかもしれません。
  • IVが高いという理由だけでオプションを売る。 IVが高いのは、大きな値動きが起こりそうだからであることが多いのです。高いプレミアムは現実のリスクへの対価です。
  • 文脈なしに銘柄間でIVを比べる。 50%のIVは小型のバイオ株なら普通でも、公益株なら極端です。IVランクかIVパーセンタイルを使ってください。
  • 予想変動幅を境界線として扱う。 これは1標準偏差の推定値であり、それを超える値動きはごく普通に起こります。
  • 権利行使価格を選ぶときにスキューを無視する。 指数のOTMプットは相対的に割高で、OTMコールは相対的に割安です。

よくある質問

インプライド・ボラティリティが高いのは良いことですか、悪いことですか？

それ自体はどちらでもありません。IVが高いとオプションは割高になり、売り手に有利、買い手に不利になりがちですが、通常は市場がより大きな値動きを予想していることを示しています。

IVクラッシュはなぜ起こるのですか？

IVクラッシュは、決算発表などの予定されたイベントが過ぎ、それに伴う不確実性が消えたときに起こります。株価が動いても、IVの低下とともにオプション価格は下がります。

インプライド・ボラティリティから予想変動幅はどう計算しますか？

株価にIVを掛け、さらに満期までの日数を365で割った値の平方根を掛けます。IV 40%の$200の株なら、7日間の予想変動幅は約$11です。

IVランクとIVパーセンタイルの違いは何ですか？

IVランクは、現在のIVが52週の安値と高値の間のどこにあるかを示します。IVパーセンタイルは、過去1年のうち、IVが現在より低かった日の割合を示します。
