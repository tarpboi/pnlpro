アイアン・コンドルとバタフライ

アイアン・コンドルとバタフライは、満期まで原資産が一定の範囲内にとどまれば利益になる、リスク限定型のオプション戦略です。アイアン・コンドルはブル・プット・スプレッドとベア・コール・スプレッドを組み合わせ、広い範囲でクレジットを受け取ります。バタフライは3つの権利行使価格のオプションを組み合わせ、価格が1つの目標付近で満期を迎えたときに利益が最大になります。どちらも静かなレンジ相場や、インプライド・ボラティリティが高いときに人気がありますが、利益には上限があり、1回の急な値動きで想定リスクの全額を失うこともあります。

要点

  • アイアン・コンドルはプット・スプレッドの売りとコール・スプレッドの売りを組み合わせたもので、最大利益は受け取ったクレジットに等しくなります。
  • バタフライは3つの権利行使価格を使い、原資産がちょうど真ん中の権利行使価格で満期を迎えたときに最も大きな利益になります。
  • どちらの戦略も最大損失と損益分岐点が決まっており、エントリー前に計算できます。
  • これらはショート・ボラティリティのトレードです。タイム・ディケイとインプライド・ボラティリティの低下から恩恵を受け、大きな値動きで損失を被ります。
  • 満期時に売り側の権利行使価格付近で生じるピン・リスクによって想定外の株式ポジションが残ることがあるため、多くのトレーダーは満期前に手仕舞います。

アイアン・コンドルの組み方

アイアン・コンドルは4つのレッグから成り、すべて同じ満期です。

  1. アウト・オブ・ザ・マネーのプットを売る。
  2. さらにアウト・オブ・ザ・マネーのプットを買う（保護用の「ウイング」）。
  3. アウト・オブ・ザ・マネーのコールを売る。
  4. さらにアウト・オブ・ザ・マネーのコールを買う。

レッグ1と2でブル・プット・スプレッド、レッグ3と4でベア・コール・スプレッドになります。どちらもバーティカル・スプレッドで解説しています。このポジションでは純クレジットを受け取ります。

計算例：アイアン・コンドル

株価は$100です。オプション価格は説明用のもので、1枚はそれぞれ100株分です。

レッグ 権利行使価格 価格 キャッシュフロー
プットの売り $90 $1.20 +$1.20
プットの買い $85 $0.50 -$0.50
コールの売り $110 $1.10 +$1.10
コールの買い $115 $0.40 -$0.40
純クレジット +$1.40
  • 最大利益： 満期時に株価が$90から$110の間なら$1.40、つまり$140。
  • 最大損失： 片側の幅 - クレジット = $5.00 - $1.40 = $3.60、つまり$360。株価が$85を下回るか$115を上回ると発生します。株価が両側に同時に存在することはないので、満期時に損失が出るのは片側だけです。
  • 下側の損益分岐点： $90 - $1.40 = $88.60。
  • 上側の損益分岐点： $110 + $1.40 = $111.40。
満期時の株価 プット・スプレッドの価値 コール・スプレッドの価値 損益
$80 $5.00 $0 -$360
$88.60 $1.40 $0 $0
$95 $0 $0 +$140
$105 $0 $0 +$140
$111.40 $0 $1.40 $0
$120 $0 $5.00 -$360

損益は、$1.40のクレジットから、満期時にイン・ザ・マネーになっている側のスプレッドの価値を引き、100を掛けたものです。このトレードは$140を得るために$360のリスクを取っています。この比率は典型的なもので、アイアン・コンドルは負けるより勝つことのほうが多い傾向がありますが、1回の損失は1回の利益より大きくなります。

バタフライの組み方

ロング・コール・バタフライは、等間隔の3つの権利行使価格を使います。

  1. 低い権利行使価格のコールを1枚買う。
  2. 真ん中の権利行使価格のコールを2枚売る。
  3. 高い権利行使価格のコールを1枚買う。

同じ形はプットでも組めます。このポジションは通常、小さなデビットで建てられます。

計算例：ロング・コール・バタフライ

株価$100のとき：

レッグ 権利行使価格 価格 キャッシュフロー
コールを1枚買う $95 $7.00 -$7.00
コールを2枚売る $100 各$4.00 +$8.00
コールを1枚買う $105 $2.00 -$2.00
純デビット -$1.00
  • 最大損失： 株価が$95以下、または$105以上なら$1.00、つまり$100。
  • 最大利益： 片側のウイングの幅 - デビット = $5.00 - $1.00 = $4.00、つまり$400。満期時に株価がちょうど$100の場合です。
  • 下側の損益分岐点： $95 + $1.00 = $96.00。
  • 上側の損益分岐点： $105 - $1.00 = $104.00。

満期時に$100なら、$95のコールの価値は$5.00で、他のコールは無価値なので、$1.00のコストに対してポジションの価値は$5.00になります。$102なら、$95のコールの価値は$7.00、売っている2枚の$100のコールはそれぞれ$2.00（合計$4.00）のマイナス、$105のコールは無価値なので、$7.00 - $4.00 = $3.00となり、$2.00の利益です。利益は真ん中の権利行使価格から離れるにつれて、両側で着実に減っていきます。

バタフライは最大利益に比べて安く建てられますが、最大利益に達するのは狭い範囲だけなので、満期まで保有したバタフライの多くは満額に届かずに終わります。

アイアン・バタフライ

アイアン・バタフライは、売りプットと売りコールが同じ権利行使価格（通常はアット・ザ・マネー）を共有するアイアン・コンドルです。

計算例

株価$100のとき、$100のコールを$4.00で売り、$100のプットを$3.80で売り、$110のコールを$1.00で買い、$90のプットを$1.00で買います。

  • 純クレジット：$4.00 + $3.80 - $1.00 - $1.00 = $5.80、つまり$580。
  • 最大利益：株価がちょうど$100で満期を迎えれば$580。
  • 最大損失：$90を下回るか$110を上回ると、$10.00 - $5.80 = $4.20、つまり$420。
  • 損益分岐点：$100 - $5.80 = $94.20と、$100 + $5.80 = $105.80。

アイアン・コンドルと比べると、アイアン・バタフライははるかに多くのクレジットを受け取り、リスクに対するリワードの比率も良好ですが、利益が出る範囲は狭く、利益のピークは1つの価格だけです。

ブロークン・ウイング・バタフライ

ブロークン・ウイング・バタフライは左右のウイングの幅を不均等にし、リスクを片側に寄せます。小さなクレジットで建てられることが多く、その場合は株価が一方向に離れていっても損失は出ません。

計算例：コールのブロークン・ウイング・バタフライ

$95のコールを$7.00で買い、$100のコールを各$4.00で2枚売り、$110のコールを$0.80で買います。

  • 差し引き：-$7.00 + $8.00 - $0.80 = +$0.20のクレジット、つまり$20。
  • $95未満： すべてのコールが無価値で満期を迎え、利益は$20のクレジットです。
  • $100の場合： $95のコールの価値は$5.00で、利益 = $5.00 + $0.20 = $5.20、つまり$520。
  • $110超： ポジションの価値は(S - 95) - 2 x (S - 100) + (S - 110) = -$5.00で、損失 = $5.00 - $0.20 = $4.80、つまり$480。
  • 上側の損益分岐点： $100から$110の間ではポジションの価値は$105 - Sなので、損益分岐点は$105 - S + $0.20 = 0となる点、つまり$105.20です。

このトレードには満期時の下方向のリスクはありませんが、強い上昇相場では標準的なバタフライより損失が大きくなります。プット版では、リスクが下方向に移ります。

これらの戦略が使われる場面

状況 コンドルやバタフライが向いている理由
レンジ相場 利益は価格が一定の範囲内にとどまることにかかっている
高いインプライド・ボラティリティ 売りオプションでより多くのプレミアムを受け取れ、IVの低下も追い風になる
イベント後 IVが高く、イベントリスクが過ぎた時点でコンドルを売るトレーダーもいる
具体的な目標価格 バタフライで価格の着地点についての見方を表現できる

これらは、売り側の権利行使価格付近でマイナスのガンマとプラスのセータを持つショート・ボラティリティのポジションです。オプションのグリークスとインプライド・ボラティリティを参照してください。

ポジションの管理

  • 利益目標： 多くのトレーダーは、リスクが高いまま最後の数セントを待つのではなく、クレジットのうち決めた割合を確保した時点でアイアン・コンドルを手仕舞います。
  • 損失の上限： たとえば損失がクレジットの一定倍数に達したら手仕舞うなど、あらかじめ決めておきます。
  • 調整： よくある調整の1つは、攻められていない側を価格に近づけるようにロールして、追加のクレジットを得ることです。調整にはコストがかかり、リスクを拡大させることもあるので、ルールが必要です。
  • 満期前の手仕舞い： 最後の数日間は、残っているプレミアムに対してガンマのリスクが最も大きくなります。

ピン・リスク

満期時に株価が売り側の権利行使価格ちょうど、またはそのごく近くで引けると、そのオプションが権利行使されるかどうか確信が持てません。売りオプションが割り当てられる一方で保護用の買いオプションは無価値で満期を迎え、週末をまたいで株式のロングまたはショートのポジションが残る可能性があります。時間外の値動きによって、これが大きなコストになることがあります。オプションの満期と割り当てを参照してください。

よくある間違い

  • 高い勝率を安全性と取り違える。 ほとんどの月で勝つコンドルでも、1回の損失で何か月分もの利益を吐き出すことがあります。
  • 手数料を節約するためにウイングを狭くしすぎる、またはクレジットを増やすために広くしすぎる。 幅が最大損失を直接決めます。
  • 決算や重要ニュースをまたいで保有する。 ギャップによって、一晩で株価がウイングの外側まで動くことがあります。
  • ビッド・アスク・スプレッドを無視する。 4つのレッグがあるということは、エントリーとエグジットのたびに4つのスプレッドを越えなければならないということです。
  • 計画なしに調整する。 ロールを繰り返すと、リスク限定のトレードがはるかに大きなものに変わることがあります。

よくある質問

アイアン・コンドルはどうやって利益を出すのですか？

アウト・オブ・ザ・マネーのプット・スプレッドとコール・スプレッドを売ってクレジットを受け取ります。満期まで株価が売り側の権利行使価格の間にとどまれば、すべてのオプションが無価値で満期を迎え、トレーダーはクレジットを全額手元に残せます。

アイアン・コンドルとアイアン・バタフライの違いは何ですか？

アイアン・コンドルは売り側の権利行使価格が離れているため、平らで広い利益ゾーンができます。アイアン・バタフライは2つの売りオプションを同じ権利行使価格で売るため、より多くのクレジットを受け取れますが、利益のピークは1つの価格だけです。

アイアン・コンドルの最大損失はいくらですか？

片側のスプレッドの幅から受け取った純クレジットを引き、100を掛けた額です。幅$5のアイアン・コンドルを$1.40で売った場合、最大損失は1枚あたり$360です。

アイアン・コンドルはいつ手仕舞うべきですか？

多くのトレーダーは、クレジットの目標割合を確保した時点か、あらかじめ決めた損失に達した時点で、満期よりかなり前に手仕舞います。最後の数日まで保有すると、ガンマとピン・リスクが高まります。

教育目的のコンテンツです。本サイトの内容は、金融・投資・法律・税務に関する助言ではありません。トレードには大きな損失リスクがあり、レバレッジ商品では入金額を超える損失が生じることがあります。ルール、手数料、プラットフォームの条件は変わります。取引の前に、ご利用の証券会社、取引所、規制当局で最新の条件をご確認ください。
