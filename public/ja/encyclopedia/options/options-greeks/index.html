オプションのグリークス

グリークスとは、他の条件を一定にしたまま1つの要素だけが変化したとき、オプション価格がどれだけ変わると見込まれるかを表す指標群です。デルタは原資産価格への感応度、ガンマはデルタ自体の変化の速さ、セータは時間の経過による価値の減少、ベガはインプライド・ボラティリティへの感応度、ローは金利への感応度を測ります。これらを組み合わせることで、オプションは宝くじのようなものから、リスクを測定・比較・管理できるポジションに変わります。

要点

  • デルタは、原資産が$1動いたときにオプション価格がおおよそどれだけ動くかを示し、株数換算のエクスポージャーとしても使えます。
  • ガンマはデルタの変化率で、満期間近のアット・ザ・マネーのオプションで最大になります。
  • セータはオプションを保有する1日あたりのコストで、満期が近づくほど加速します。
  • ベガはインプライド・ボラティリティの変化に対するエクスポージャーを測ります。株価が動かなくても、オプション価格はIVで動くことがあります。
  • すべてのポジションのグリークスを合計したものがポジション・グリークスで、ポートフォリオが実際に何にさらされているかを最もわかりやすく要約してくれます。

基準となるオプション

以下の例では、同じオプションを使い続けます。株価は$100です。権利行使価格$100、残存30日のコールの価格は$3.50で、インプライド・ボラティリティは約30%です。オプション価格モデルで算出した場合のおおよそのグリークス（四捨五入済み）は次のとおりです。

グリークス 値 平たく言うと
デルタ 0.52 株価が$1上がると、コールは1株あたり約$0.52上がる
ガンマ 0.046 株価が$1上がると、デルタは約0.046上がる
セータ -0.06 タイム・ディケイにより、コールは1日あたり1株約$0.06下がる
ベガ 0.11 インプライド・ボラティリティが1ポイント上がると、コールは1株あたり約$0.11上がる
ロー 0.04 金利が1ポイント上がると、コールは1株あたり約$0.04上がる

米国の標準的な株式オプションは100株分なので、1枚あたりの金額への影響を見るには各数値に100を掛けます。セータ-0.06は、1枚あたり1日約$6を意味します。グリークスはモデルによる推定値で、常に変化し続けます。契約の仕組みについてはオプションの基本を参照してください。

デルタ

デルタは、原資産が$1変化したときのオプション価格の予想変化額です。コールのデルタは0から1の間のプラス、プットのデルタは0から-1の間のマイナスです。

デルタからわかること

  • 価格感応度： デルタ0.52なら、株価が$1上がるとコールは約$0.52、1枚あたり$52上がります。
  • 株数換算： デルタ0.52のオプション1枚は、小さな値動きに対しておよそ52株と同じように振る舞います。
  • おおよその確率： トレーダーはデルタを、オプションがイン・ザ・マネーで満期を迎える確率の大まかな目安としてよく使います。デルタ0.30のオプションなら、おおむね30%の確率と読まれることが多いです。これは経験則であり、正確な確率ではありません。
マネーネス コールの典型的なデルタ プットの典型的なデルタ
ディープ・イン・ザ・マネー 1.00に近い -1.00に近い
アット・ザ・マネー 約0.50 約-0.50
ディープ・アウト・オブ・ザ・マネー 0に近い 0に近い

ガンマ

ガンマは、原資産が$1変化したときのデルタの変化量です。オプションの買いポジションは、コールでもプットでも常にプラスのガンマを持ち、売りポジションはマイナスのガンマを持ちます。

計算例：デルタとガンマを組み合わせる

株価が$100から$101に上がったとします。

  • 新しいデルタは約0.52 + 0.046 = 0.566です。
  • 値動きの途中でデルタが増えているので、価格変化は平均デルタで見積もるほうが正確です：0.52 + (0.5 x 0.046) = 0.543。
  • 新しいコール価格は約$3.50 + $0.543 = $4.04です。

逆に株価が$1下がった場合、デルタは約0.474に下がり、コールは約0.52 - 0.023 = $0.497下がって約$3.00になります。プラスのガンマとは、同じ幅の値動きなら、コールは上昇時に得る額のほうが下落時に失う額よりわずかに大きいということです。オプションの売り手はその逆で、株価が不利な方向に動くと損失が加速します。

ガンマの変化

ガンマはアット・ザ・マネーのオプションで最も高く、満期が近づくと急激に大きくなります。当日満期のアット・ザ・マネーのオプションでは、わずかな値動きでデルタが約0.50から1近く、あるいは0近くまで振れることがあります。0DTEオプションが非常に敏感なのはこのためであり、ガンマ・エクスポージャーとディーラーのヘッジで解説するように、ディーラーのガンマヘッジが原資産市場に影響を与え得るのもこのためです。

セータ

セータは、他の条件がすべて同じまま1日が経過したときのオプション価格の変化です。オプションの買いポジションはマイナスのセータ、売りポジションはプラスのセータを持ちます。セータは、オプションが与えてくれる権利を保有するためのコストです。

計算例

株価が横ばいでボラティリティも変わらないまま、基準のコールを5日間保有すると、コストは約5 x $0.06 = 1株あたり$0.30、1枚あたり$30で、コールは約$3.50から約$3.20になります。実際にはセータは一定ではなく、満期が近づくほど大きくなります。

セータの変化

  • 時間： アット・ザ・マネーのオプションの時間価値は、最初はゆっくり減り、最後の数週間で速く減ります。残存90日のオプションは1日数セントしか減らないかもしれませんが、同じ権利行使価格で残り1週間になると、その数倍減ることがあります。
  • マネーネス： 金額ベースのセータは、時間価値を最も多く持つアット・ザ・マネーのオプションで最大になります。ディープ・イン・ザ・マネーやディープ・アウト・オブ・ザ・マネーのオプションは、失う時間価値がそもそも少ないのです。

オプションの売り手はセータの獲得を狙います。売り手がその対価を得られるのは、マイナスのガンマ、つまり大きな値動きのリスクも同時に引き受けているからです。

ベガ

ベガは、インプライド・ボラティリティが1ポイント変化したときのオプション価格の変化です。オプションの買いポジションはプラスのベガ、売りポジションはマイナスのベガを持ちます。

計算例

決算発表の前に、株価は変わらないまま、基準のコールのインプライド・ボラティリティが30%から36%に上がったとします。コールは約6 x $0.11 = $0.66上がり、約$4.16になります。発表後にインプライド・ボラティリティが30%に戻れば、株価がほとんど動かなくても、その$0.66は消えてしまいます。これをIVクラッシュと呼びます。

ベガの変化

ベガはアット・ザ・マネーのオプションと、満期の長いオプションで最大になります。ボラティリティが効いてくる時間が長いからです。同じ権利行使価格でも、残存1年のオプションは残存1週間のオプションよりはるかに大きなベガを持ちます。

ロー

ローは、金利が1ポイント変化したときのオプション価格の変化です。コールのローはプラス、プットのローはマイナスです。金利が高いほど、株を現物で買うよりコールを持つほうが相対的に有利になるためです。満期の短いオプションではローは小さく、個人トレーダーにとっては通常最も重要度の低いグリークスですが、LEAPSのような長期オプションでは無視できません。

グリークスの連動

グリークス アット・ザ・マネー ディープ・イン・ザ・マネー ディープ・アウト・オブ・ザ・マネー 満期接近時（ATM）
デルタ 約±0.50 ±1.00付近 0付近 ±0.50付近にとどまるが不安定になる
ガンマ 最大 小さい 小さい 急上昇
セータ 減少が最大 小さい 小さい 減少が加速
ベガ 最大 小さい 小さい 低下

ポジション・グリークス

ポジション・グリークスとは、すべてのオプションと株式のポジションについて、各グリークスに枚数と乗数を掛けて合計したものです。株式のデルタは1株あたり1で、ガンマ、セータ、ベガはありません。

計算例：小さなポートフォリオ

あるトレーダーが次のポジションを持っています。

  • 基準のコールを5枚買い（デルタ0.52、ガンマ0.046、セータ-0.06、ベガ0.11）
  • 同じ銘柄の株を200株売り
グリークス コール：5 x 100 x グリークス 株式 ポジション合計
デルタ 5 x 100 x 0.52 = +260 -200 +60株
ガンマ 5 x 100 x 0.046 = +23 0 $1あたり+23
セータ 5 x 100 x -0.06 = -$30 0 1日あたり-$30
ベガ 5 x 100 x 0.11 = +$55 0 ボラティリティ1ポイントあたり+$55

読み方：このポジションは、現時点では60株の買いと同じように振る舞います。株価が$1上がれば、デルタは約+83に増えます。何も起きなければ1日約$30を失い、インプライド・ボラティリティが1ポイント上がるごとに約$55を得ます。これはロング・ガンマ、ロング・ベガのポジションで、その特権の対価としてセータを支払っています。ほとんどの証券会社のプラットフォームはポジション・グリークスを表示しており、取引の前後に毎回確認するのは良い習慣です。

よくある間違い

  • デルタを固定値として扱う。 デルタは価格、時間、ボラティリティによって変わります。今ニュートラルなポジションも、値動きの後にはそうでなくなっているかもしれません。
  • オプションの買いでセータを無視する。 方向の見立てが正しくても、動きが来るのが遅すぎれば損失になり得ます。
  • イベント前後のベガを忘れる。 インプライド・ボラティリティが高いときにオプションを買い、その後IVが崩れるのを眺めることになるのは、見立てが正しいのに損をする典型的なパターンです。
  • ショート・ガンマを甘く見る。 満期間近のオプションを売れば速いペースでセータを得られますが、急な値動き1つで短時間に大きな損失が出ることがあります。
  • モデルのグリークスを鵜呑みにする。 グリークスは前提条件を持つモデルから算出されます。大きな値動き、ギャップ、ボラティリティの急変は、まさにそれが最も重要な場面でグリークスを不正確にすることがあります。

よくある質問

オプションを買うのに適したデルタはいくつですか？

唯一の正解はありません。デルタの高いイン・ザ・マネーのオプションは株式に近い動きをし、率で見たタイム・ディケイも小さくなります。一方、デルタの低いアウト・オブ・ザ・マネーのオプションは安いものの、イン・ザ・マネーで満期を迎える可能性は低くなります。

なぜ満期が近づくとセータが大きくなるのですか？

時間価値は満期時にゼロにならなければなりません。アット・ザ・マネーのオプションでは、残った時間価値をどんどん少ない日数で失っていくため、満期が近づくほど1日あたりの減少額が大きくなります。

マイナスのガンマとはどういう意味ですか？

マイナスのガンマはオプションを売ることで生じ、原資産が動くたびにデルタが不利な方向に変化することを意味します。価格が下がるほどロングが増え、上がるほどショートが増えます。大きな値動きでは損失が加速することがあります。

どのグリークスが最も重要ですか？

戦略によって異なります。方向性のトレーダーはデルタ、短期満期のトレーダーはガンマとセータ、決算などのイベント前後でトレードする人はベガを最も注意深く見ています。
