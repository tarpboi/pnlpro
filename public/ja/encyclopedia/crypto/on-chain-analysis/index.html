オンチェーン分析とは、送金、ウォレット残高、コインが最後に動いたときの価格など、公開ブロックチェーンに記録されたデータを調べて、保有者がどう行動しているかを把握する手法です。ビットコインやイーサリアムのトランザクションはすべて公開されているため、トレーダーは取引所へ流れ込むコインを監視したり、大口ウォレットを追跡したり、市場の平均取得コストを推定したりできます。株式市場にはない視点を得られますが、データの解釈には注意が必要で、正確なタイミングのシグナルが得られることはほとんどありません。

要点

  • ブロックチェーンは公開台帳なので、ウォレットと取引所の間のフローは直接測定できますが、ウォレットの所有者は推測するしかありません。
  • 取引所への流入は売りの可能性、流出は買い集めと読まれることが多いですが、取引所内部の資金移動がどちらもゆがめることがあります。
  • 実現価格は市場の平均取得コストを推定するもので、MVRVは時価総額をその取得コストと比較するものです。
  • SOPRは、使われた（動かされた）コインが平均して利益と損失のどちらの状態で動いているかを示します。
  • オンチェーン指標は、短期のトレードのきっかけとしてではなく、サイクル上の位置を知る文脈として使うのが最も効果的です。

オンチェーンデータとは

公開ブロックチェーン上のトランザクションには、送信元アドレス、受信先アドレス、金額、タイムスタンプが記録されます。分析会社はこの生データを処理し、ウォレットラベルを付けます。これは、そのアドレスを誰が管理しているか（取引所、ファンド、マイナー、ブリッジ、既知のハッカーなど）についての推測です。ラベルは、公開情報、入金テスト、クラスタリングのヒューリスティクス（一緒に使われるアドレスは同じ主体が管理していることが多い）、そして調査活動から得られます。

オンチェーン分析は、暗号資産に特有のファンダメンタル分析の一種です。価格ベースのツールや、資金調達率などのデリバティブのデータを補完します。

取引所フロー

流入（インフロー）とは、取引所の入金アドレスとしてラベル付けされたウォレットにコインが移動することです。流出（アウトフロー）とは、コインが取引所から出ていくことです。

一般的な読み方は次のとおりです。

  • BTCやETHの大量流入は、保有者が売る準備をしていることを意味する場合があります。
  • 継続的な流出は、保有者がコインを長期保管に移しており、取引所の売り側の供給が減っていることを意味する場合があります。
  • 取引所のステーブルコイン残高の増加は、買い余力が流れ込んできていることを意味する場合があります。

ただし、注意点が重要です。取引所はホットウォレットとコールドウォレットの間で資金を移したり、入金をまとめたり、コインをカストディアンに移したりします。現物ETFのカストディウォレット、OTCデスク、ラップドトークンのブリッジも、売買ではない大きなフローを生み出します。取引所に送られたコインは、売られるのではなく、デリバティブの担保として使われることもあります。1回の大口送金は弱い証拠にすぎず、多くのウォレットにわたる継続的な傾向のほうが意味があります。

クジラの追跡

「クジラ」とは、非常に大量のコインを保有する人のことです。トレーダーはクジラのウォレットの大きな動きを監視しており、アラートサービスは大口送金をリアルタイムで公開しています。

役に立つ習慣：

  • ラベルを確認しましょう。「クジラ」の送金とされるものの多くは、取引所が自社の資金を動かしているだけです。
  • 送金先を見ましょう。長く動いていなかったウォレットから取引所への送金は、2つのコールドウォレット間の送金よりも多くの情報を含んでいます。
  • 洗練されたプレイヤーは、自分が監視されていることを知っています。送金を分割したり、OTCデスクを使ったり、相手を欺くためにわざと目立つ動きをしたりすることがあります。

小型トークンでのウォレットのコピーについては、成功しているように見えるウォレットが罠になりうることを解説したウォレットのコピートレードを参照してください。

保有者分布

保有者分布は、供給がアドレス間にどう分散しているかを示します。ビットコインでは、アナリストはアドレスを残高の規模や保有期間でグループ分けします。長期保有者（一部の分析プロバイダーの慣例では、155日以上動いていないコインであることが多い）と短期保有者です。

小型トークンでは、保有の集中はリスクのシグナルです。取引所やコントラクト以外の上位10ウォレットが供給の大半を保有していれば、少数の売り手で価格が暴落する可能性があります。集中度を判断する前に、必ず取引所のウォレット、流動性プール、ベスティングのコントラクト、バーンアドレスを除外しましょう。トークノミクスとトークンアンロックを参照してください。

実現価格、MVRV、SOPR

この3つの指標は、各コイン（厳密には各未使用トランザクション出力、UTXO）が最後に動いたときの価格を持っているという、ビットコインのモデルから生まれたものです。

実現時価総額と実現価格

  • 時価総額 = 現在の価格 × 流通供給量。
  • 実現時価総額（realized cap）= 各コインが最後に動いたときの価格で評価した価値の合計。
  • 実現価格（realized price）= 実現時価総額 / 供給量。すべての保有者の平均取得コストの近似値です。

MVRV

MVRV = 時価総額 / 実現時価総額。

  • 1を上回る：平均的な保有者は含み益の状態です。
  • 1を下回る：平均的な保有者は含み損の状態で、これは歴史的に大きな弱気相場の底付近で起きてきました。
  • 非常に高い値は歴史的にサイクルの天井付近で現れてきましたが、ピークの水準はサイクルを重ねるごとに低くなっています。

計算例

4枚のコインしかない小さなブロックチェーンを想像してみましょう。

コイン枚数 最後に動いたときの価格 実現価値
1 $20,000 $20,000
2 $40,000 $80,000
1 $80,000 $80,000
4 $180,000
  • 実現時価総額 = $180,000。実現価格 = $180,000 / 4 = $45,000。
  • 市場価格が$60,000なら、時価総額 = 4 × $60,000 = $240,000。
  • MVRV = $240,000 / $180,000 = 1.33。平均的な保有者は約33%の含み益です。

最後に$80,000で動いたコインが$60,000で売られれば、損失が実現します。$40,000のコインのうち1枚が$60,000で売られれば、利益が実現します。

SOPR

SOPR（spent output profit ratio、使用済み出力利益率）= コインが使われたときの価値 / そのコインが最後に動いたときの価値。

  • $40,000で買って$50,000で売ったコインのSOPRは、50,000 / 40,000 = 1.25です。
  • 日次のSOPRは、その日に使われたすべてのコインを平均したものです。
  • 1を上回れば、コインは平均して利益の出る状態で売られており、1を下回れば損失の出る状態で売られています。

強気相場では、SOPRが1に向かって下がってから反発する動きは、保有者が損益トントンでは売ろうとしない表れと読まれてきました。弱気相場では、SOPRが1の上を維持できないことは、保有者が戻り局面で取得コストで逃げようと売っていることを示唆します。ノイズを減らすため、保有期間でフィルタリングした派生指標もあります。

ステーブルコインのフロー

ステーブルコインは暗号資産における現金の役割を果たしています。トレーダーは次のものを追跡しています。

  • ステーブルコインの総供給量。 増加は新しいドルが暗号資産に入ってきていることを、減少は資金が出ていっていることを意味する場合があります。
  • 発行体によるミントとバーン。 大口プレイヤーが法定通貨を出し入れしていることを示します。
  • チェーンごとのフロー。 特定のチェーンへブリッジされるステーブルコインは、投機的な活動の向かう先を示すシグナルになることがあります。
  • 取引所のステーブルコイン準備高。 すぐに投入できる買い余力の大まかな目安です。

オンチェーンデータの限界

  • 帰属は確率的なものです。 ラベルは間違っていたり、欠けていたりすることがあります。
  • オフチェーンの活動は見えません。 中央集権型取引所内での取引、ETFの持ち分の売買、OTCの取引はオンチェーンに現れません。取引高の大部分は一度もチェーンに触れません。
  • 失われたコインが供給をゆがめます。 何年も前に失われたコインも、供給量や実現時価総額に含まれています。
  • 構造変化。 ETF、カストディアン、レイヤー2ネットワークによってフローの意味が変わったため、過去のしきい値が当てはまらない可能性があります。
  • チェーンが違えばモデルも違います。 ビットコインの出力（UTXO）モデル向けにつくられた指標は、イーサリアムやソラナのようなアカウントベースのチェーンにはうまく当てはまりません。
  • データベンダーによって違います。 ラベルや手法が異なるため、2つのプロバイダーが「同じ」指標で異なる値を示すことがあります。
  • チャートの後知恵。 「すべての天井を当てた」指標は、後知恵で調整されていることが多く、これはオーバーフィッティングの一種です。

よくある間違い

  • ラベルや送金先を確認せずに、 1件のクジラアラートに反応すること。
  • 取引所への流入を確実な売りとみなすこと。
  • MVRVやSOPRのしきい値を、正確なエントリーやエグジットのポイントとして使うこと。
  • 需要を判断する際に、 特にETFのフローなど、オフチェーンの活動を無視すること。
  • 取引所やコントラクトのウォレットを除外せずに、 保有の集中度を判断すること。

よくある質問

暗号資産のオンチェーン分析とは何ですか？

トランザクション、残高、取引所フローなどの公開ブロックチェーンデータを分析して、保有者や大口プレイヤーがどう行動しているかを把握することです。トレーダーは価格チャートやデリバティブのデータと合わせて使います。

MVRVレシオとは何ですか？

MVRVは、時価総額を実現時価総額で割ったものです。実現時価総額は、各コインを最後に動いたときの価格で評価します。1を上回れば平均的な保有者は含み益の状態にあり、1を下回る水準は歴史的に深い弱気相場と結びついてきました。

SOPRとはどういう意味ですか？

SOPR（spent output profit ratio、使用済み出力利益率）は、コインが使われたときの価値を、最後に動いたときの価値と比較するものです。1を上回ればコインは平均して利益の出る状態で売られており、1を下回れば損失の出る状態で売られていることを意味します。

取引所への流入は弱気のサインですか？

大量の流入は売りの意図を示すことがありますが、取引所内部の送金、担保の入金、カストディアンの移動からも生じます。1回の送金よりも、継続的な傾向のほうが意味があります。
