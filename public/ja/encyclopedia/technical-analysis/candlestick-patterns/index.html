ローソク足のパターン

ローソク足パターンとは、価格チャート上の連続する1〜3本のローソク足が作る、名前の付いた形のことです。トレーダーはこれを使って、下落後の長い下ヒゲや、直前のローソク足を飲み込む大きなローソク足など、買い圧力や売り圧力が変化したように見える瞬間を表現します。テクニカル分析で最も広く教えられているツールの一つですが、単独ではシグナルとして弱く、その有用性は、どこに現れたか、その後に何が続いたかに大きく左右されます。

要点

  • ローソク足パターンは、1〜3期間にわたる買い手と売り手の力関係の短期的な変化を表します。
  • 同じパターンでも、レンジの中ほどではほとんど意味がなく、トレーダーがすでに注目している水準では意味が大きくなります。
  • 多くのトレーダーは、次のローソク足がパターンの高値や安値を抜けるといった確認（コンファメーション）を待ってから行動します。
  • ローソク足パターンの体系的な検証では、特に取引コストを考慮すると、予測力は弱いか一貫しないという結果が一般的です。
  • パターンの最も実用的な使い方は、トレードが間違っていたと判断する地点を決めることであり、それが損切りを置く論理的な位置になります。

このガイドの読み方

以下の各パターンは、ローソク足チャートの見方で説明したローソク足の各部分、つまり実体（始値から終値まで）とヒゲ（実体を超えた極値）から構成されています。定義は書籍やソフトウェアによって異なるため、以下の比率は決まったルールではなく一般的な慣習として捉えてください。

ここでいう「強気」「弱気」は、そのパターンが伝統的に示唆するとされている内容を表すもので、予測ではありません。

1本のローソク足のパターン

十字線（doji）

十字線は、始値と終値が同じかごく近く、実体が細い線になっているローソク足です。期間中に価格は動いたものの、始まった位置で終わったことを示します。

  • 通常の十字線： 上下のヒゲが短い。
  • 足長十字線： 上下のヒゲが長い。値幅は大きいが、正味の値動きはない。
  • トンボ（dragonfly doji）： 下ヒゲが長く、上ヒゲはほとんどないか、まったくない。
  • トウバ（gravestone doji）： 上ヒゲが長く、下ヒゲはほとんどないか、まったくない。

十字線は通常、迷いとして読まれます。強い上昇や下落の後に現れると勢いの鈍化を示唆することもありますが、十字線は閑散とした相場ではよく現れ、何の意味もないことも少なくありません。

カラカサ（ハンマー）と首吊り線

どちらも値幅の上端近くに小さな実体があり、下ヒゲが実体の長さの少なくとも約2倍あり、上ヒゲはほとんどないか、まったくありません。

  • カラカサ（ハンマー） は下落の後に現れます。売り手が価格を押し下げ、買い手が引けまでに押し戻したと読まれます。
  • 首吊り線は、上昇の後に現れる同じ形です。終値は持ちこたえたものの、期間中に売りが出たことへの警告と読まれます。

流れ星（シューティングスター）と逆カラカサ

こちらは鏡像の形で、値幅の下端近くに小さな実体があり、長い上ヒゲがあります。

  • 流れ星（シューティングスター） は上昇の後に現れ、買い手が高値を維持できなかったと読まれます。
  • 逆カラカサ（インバーテッドハンマー） は下落の後に現れ、買い意欲の初期の兆候と読まれます。

ピンバー

「ピンバー」（ピノキオ・バーに由来）は、片側に長いヒゲがあり、反対側の端に小さな実体があるローソク足全般を指すプライスアクションの用語です。カラカサも流れ星もピンバーです。この用語を使うトレーダーは、名前よりも、長いヒゲが重要な水準を超えて試した後に押し戻されたかどうかを重視します。プライスアクション・トレードをご覧ください。

丸坊主（marubozu）

丸坊主は、実体が大きく、上下どちらにもヒゲがほとんどないか、まったくないローソク足です。価格が一方の極値で始まり、もう一方の極値で引けたことを意味します。その期間、一方の勢力が完全に主導権を握っていたことを示します。

2本のローソク足のパターン

強気の包み足と弱気の包み足

  • 強気の包み足（陽の包み足）： 陰線の後に陽線が現れ、その実体が1本目の実体を完全に包み込むもの。
  • 弱気の包み足（陰の包み足）： 陽線の後に陰線が現れ、その実体が1本目の実体を包み込むもの。

例。 1日目は45.00ドルで始まり44.00ドルで引けました（陰線）。2日目は43.80ドルで始まり45.40ドルで引けました。2日目の実体は43.80ドルから45.40ドルまでで、1日目の実体（44.00ドルから45.00ドル）を完全に含んでいます。これが強気の包み足です。

FXや暗号資産のような24時間市場では、各ローソク足は通常、前の終値の近くで始まるため、窓（ギャップ）を伴う厳密な「包み足」はまれです。そのため、多くのトレーダーはこれらの市場では定義を緩めて使っています。

はらみ線

はらみ線は包み足の逆で、大きなローソク足の後に、実体が1本目の実体の内側に収まる小さなローソク足が現れるものです。「はらみ（孕み）」は日本語で妊娠を意味し、その形を表しています。勢いが一服したと読まれます。2本目が十字線のはらみ線は、はらみ寄せ線（harami cross）と呼ばれます。

毛抜き天井と毛抜き底

2本のローソク足の高値がそろう（毛抜き天井）か、安値がそろう（毛抜き底）、あるいはほぼそろう形です。価格が同じ水準を2回試し、それを超えられなかったと読まれます。

3本のローソク足のパターン

明けの明星と宵の明星

  • 明けの明星： 大陰線の後に実体の小さなローソク足が現れ（株式市場では窓を開けて下落することが多い）、続いて1本目の実体の深くまで食い込んで引ける大陽線が現れる形です。売りが出尽くし、買い手が主導権を握ったと読まれます。
  • 宵の明星： その弱気版の鏡像で、上昇の後に現れます。

赤三兵と黒三兵

  • 赤三兵（three white soldiers）： 3本連続する大陽線で、それぞれが前の実体の中で始まり、高値付近で引けるもの。
  • 黒三兵（three black crows）： 3本連続する大陰線で、それぞれが安値付近で引けるもの。

これらは一方向への持続的な圧力を表します。ただし、大きく動いた後に現れると、短期的な行き過ぎ（出尽くし）を示すこともあり、これが単独では信頼できない理由の一つです。

形よりも文脈が重要

横ばいのレンジの中ほどに現れたカラカサには、ほとんど情報がありません。長い下落の後、これまで何度も反転してきた水準で、普段より大きな出来高を伴って現れた同じカラカサは、まったく別の状況です。トレーダーは通常、次の点を検討します。

  • 位置： パターンはサポートやレジスタンス、移動平均線、過去のスイングポイントにあるか？
  • トレンド： より大きなトレンドと一致しているか、それとも逆らっているか？
  • 出来高： シグナルとなったローソク足で参加者が増えたか？出来高分析をご覧ください。
  • 時間足： 日足のパターンは、1分足のパターンよりもはるかに多くの取引を反映しています。

計算例：リスクを定めてカラカサでトレードする

ある株が24ドルから19.50ドル前後まで下落し、昨年2回反発した水準に近づいています。翌日の日足は、始値20.10ドル、高値20.25ドル、安値19.20ドル、終値20.20ドルでした。

  • 実体 = 20.20ドル − 20.10ドル = 0.10ドル
  • 下ヒゲ = 20.10ドル − 19.20ドル = 0.90ドル（実体の9倍）
  • 上ヒゲ = 20.25ドル − 20.20ドル = 0.05ドル

これはサポート付近のカラカサの条件を満たしています。トレーダーは次のような計画を立てるかもしれません。

  • エントリー： 翌日にカラカサの高値を上回って20.26ドルで取引された場合にのみ買う（確認）。
  • 損切り： カラカサの安値のすぐ下、19.19ドル。
  • 1株あたりのリスク： 20.26ドル − 19.19ドル = 1.07ドル。
  • 目標： 過去のレジスタンスである22.40ドル。リワードは22.40ドル − 20.26ドル = 2.14ドル。
  • リスクリワード比： 2.14ドル / 1.07ドル = 2.0。

翌日に20.26ドルを上回る取引がなければ、トレードはしません。上回った後に19.19ドルまで下落すれば、1株あたり1.07ドルの損失になります。これはかなりの頻度で起こりうる、想定内の結果です。パターンが反発を予測したわけではなく、損失額のわかった、具体的で検証可能な計画を与えてくれたのです。この1.07ドルを基にポジションサイズを決める方法はポジションサイジングで解説しています。

研究が示す根拠

ローソク足パターンは、株式、先物、通貨市場を対象に、学術研究と実務家の研究の両方で何度も検証されてきました。全体像としては、取引コストと多重検定を考慮すると、ほとんどのパターンには一貫した予測力がほぼないか、まったくなく、ある市場や期間で強く見えた結果も別の市場や期間では通用しないことがよくあります。特定の条件下で一部のパターンにわずかな効果があったと報告する研究もいくつかありますが、確実に機能するパターンのリストについて合意は存在しません。

難しさの一部は定義にあります。検証するには「小さな実体」や「長いヒゲ」を正確な数値に置き換える必要があり、しきい値が少し違うだけで結果が変わります。あるパターンに頼りたいなら、正確に定義したうえで、自分が取引する市場と時間足で、現実的なコストを織り込んでバックテストしてください。

よくある間違い

  • 文脈を無視してパターンだけでトレードする。 ローソク足の形よりも、位置とトレンドのほうが重要です。
  • ローソク足が確定する前に行動する。 日中の途中ではカラカサに見えても、引けてみればただの陰線ということがあります。
  • 確認を省く。 パターンだけでエントリーすると、その後続かないトレードを数多く抱えることになります。
  • 何十ものパターンを暗記する。 名前の付いたパターンの多くは、ある価格帯が否定された、あるいは一方の勢力が主導権を握った、という同じ考え方のバリエーションです。
  • 損切りを近くに置きすぎる。 長いヒゲのほんの数セント先に置いた損切りは、通常のノイズで引っかかることがあります。損切り戦略をご覧ください。

よくある質問

最も信頼できるローソク足パターンは何ですか？

市場や期間を問わず確実に予測力があると示されたローソク足パターンはありません。パターンを使うトレーダーは、包み足やピンバーのような少数の単純なパターンに絞り、重要な価格水準で現れたものだけを、確認してから行動に移す傾向があります。

カラカサ（ハンマー）のローソク足は何を意味しますか？

カラカサは、上端近くに小さな実体があり、長い下ヒゲを持つローソク足で、下落の後に現れます。期間中に売り手が価格を押し下げたものの、引けまでに買い手が押し戻したことを示します。

十字線とコマの違いは何ですか？

どちらも迷いを示します。十字線は始値と終値が事実上同じであるのに対し、コマ（スピニングトップ）は小さいながらも目に見える実体があり、上下にヒゲがあります。

ローソク足パターンは暗号資産やFXでも機能しますか？

同じ形はどの市場にも現れますが、24時間取引ではローソク足に窓がほとんど開かないため、包み足や明けの明星のようなパターンの形成のされ方が変わります。暗号資産やFXでも、ほかの市場より根拠が強いわけではないので、どのパターンも自分が取引する市場で検証してください。
