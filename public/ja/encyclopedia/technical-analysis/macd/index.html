MACD（移動平均収束拡散法）

MACD（Moving Average Convergence Divergence、移動平均収束拡散法）は、価格の2本の指数平滑移動平均線（EMA）の差から作られる、トレンド系とモメンタム系を兼ねた指標です。MACD線、それを平滑化したシグナル線、そして両者の差を示すヒストグラムの3つの要素からなります。1970年代後半にジェラルド・アペルが考案したMACDは、トレンドの方向と勢いを1つのパネルにまとめられるため、最も広く使われている指標の一つです。もとになっている移動平均線と同様、価格に遅行し、すでに始まった値動きを表します。

要点

  • MACD線は12期間EMAから26期間EMAを引いたもの、シグナル線はMACD線の9期間EMA、ヒストグラムはMACDからシグナルを引いたものです。
  • MACD線がゼロより上にあるのは、短期の移動平均線が長期の移動平均線より上にあることを意味し、上昇トレンドと整合的です。
  • シグナル線とのクロスは頻繁でノイズが多く、ゼロラインとのクロスは遅く、移動平均線のクロスと同じ意味を持ちます。
  • ヒストグラムはMACDとシグナル線の差が広がっているか縮まっているかを示し、トレーダーはこれを勢いの強まりや衰えとして読みます。
  • MACDは価格の単位で表されるため、価格水準の異なる資産の間でその値を直接比較することはできません。

MACDの作り方

MACDは3つの計算を使い、標準設定は12、26、9です。

  1. MACD線 = 終値の12期間EMA − 終値の26期間EMA
  2. シグナル線 = MACD線の9期間EMA
  3. ヒストグラム = MACD線 − シグナル線

名前は、MACD線が追跡するもの、つまり2本の移動平均線が収束する（近づく）ことと拡散する（離れる）ことを表しています。価格が着実に上昇すると、速い12期間EMAが遅い26期間EMAの上に離れていき、MACDのプラス幅が大きくなります。上昇が鈍ると、2本の移動平均線は収束し、MACDはゼロに向かって縮小します。

ヒストグラムは当初の設計には含まれておらず、後にほかのアナリストが追加したものですが、現在ではほとんどのプラットフォームで標準になっています。

3つの要素の読み方

要素 示すもの 一般的な読み方
MACDがゼロより上 12 EMAが26 EMAより上 中期に対して短期のトレンドが上向き
MACDがゼロより下 12 EMAが26 EMAより下 短期のトレンドが下向き
MACDが上昇 移動平均線が上方向に拡散、または下から収束 上昇の勢いが増している
MACDがシグナルを上抜け 直近の勢いが上向きに転換 短期的な強気シグナル
MACDがシグナルを下抜け 直近の勢いが下向きに転換 短期的な弱気シグナル
ヒストグラムが拡大 MACDとシグナルの差が広がっている 勢いが加速している
ヒストグラムが縮小 差が縮まっている 勢いが鈍化している。クロスが続く可能性

計算例

ある日、ある株の12日EMAが105.40ドル、26日EMAが103.90ドルでした。前日のシグナル線は1.20でした。

  • MACD = 105.40 − 103.90 = 1.50
  • シグナル線の平滑化係数は k = 2 /（9 + 1）= 0.2 です。
  • シグナル = 1.20 + 0.2 ×（1.50 − 1.20）= 1.20 + 0.06 = 1.26
  • ヒストグラム = 1.50 − 1.26 = 0.24

翌日、上昇が鈍り、MACDは1.40に低下しました。

  • シグナル = 1.26 + 0.2 ×（1.40 − 1.26）= 1.26 + 0.028 = 1.288
  • ヒストグラム = 1.40 − 1.288 = 0.112

その翌日、MACDは1.20に低下しました。

  • シグナル = 1.288 + 0.2 ×（1.20 − 1.288）= 1.288 − 0.0176 = 1.2704
  • ヒストグラム = 1.20 − 1.2704 = −0.0704

ヒストグラムがマイナスに転じました。MACDがシグナル線を下抜けたのです。しかしMACD自体はまだゼロを大きく上回っており、12日移動平均線は26日移動平均線より上にあり、中期のトレンドはまだ上向きです。トレーダーはこれを、下降トレンドの確定ではなく、上昇トレンドの中での勢いの衰えと読むでしょう。2日目のヒストグラムの縮小は、クロスよりも早く警告を発していました。

資産間で値を比較できない理由

MACDは価格の単位で表されます。104ドルの株でMACDが1.50であることは、10.40ドルの株でMACDが0.15であることと、比率としては同じ差です。資産を比較するために、EMAの差を遅いほうのEMAで割るPPO（Percentage Price Oscillator） を使うトレーダーもいます。この例では、PPO = 1.50 / 103.90 × 100 で、約1.44% です。同じ理由で、価格が大きく変化した資産について、何年も前のMACDの値を現在の値と直接比較することはできません。

トレーダーによるMACDの使い方

シグナル線とのクロス

最も一般的な使い方は、MACDがシグナル線を上抜けたら買い、下抜けたら売りというものです。これらのシグナルは頻繁に出て反応も速いのですが、横ばいの相場ではダマシ（ウィップソー）が多発します。多くのトレーダーは、より大きなトレンドの方向のクロスだけを採用します。たとえば、MACDがゼロより上にあるとき、または価格が200日移動平均線より上にあるときだけ、強気のクロスを採用するといった具合です。

ゼロラインとのクロス

MACDがゼロをクロスするとき、12 EMAが26 EMAをクロスしています。これはまさに移動平均線のクロスであり、シグナル線とのクロスより遅い反面、ダマシは少なくなります。ゼロラインを売買のトリガーではなく、トレンドのフィルターとして使うトレーダーもいます。

ヒストグラムによる勢いの把握

ヒストグラムは、クロスが起こる前に向きを変えます。ヒストグラムがピークをつけるのは、MACDとシグナルの差の拡大が止まったことを意味します。ヒストグラムの転換を早めの手仕舞いや損切りの引き上げに使うトレーダーもいます。シグナルが早いほど、ダマシも増えます。

ダイバージェンス

RSIと同様に、ダイバージェンスとは価格と指標の食い違いのことです。

  • 弱気のダイバージェンス： 価格は高値を更新したのに、MACD（またはそのヒストグラム）の高値は切り下がっている。
  • 強気のダイバージェンス： 価格は安値を更新したのに、MACDの安値は切り上がっている。

ダイバージェンスは勢いの衰えを示します。反転の前によく現れますが、続いていくトレンドの最中にも繰り返し現れます。MACDには上限・下限がなく価格水準に依存するため、長い期間や大きな価格変化をまたいだダイバージェンスはゆがむことがあります。ほとんどのトレーダーは、たとえばブレイク・オブ・ストラクチャーなどで価格が確認するのを待ちます。

設定

12/26/9という標準設定は、この指標が初期に日足で使われていた頃からの慣習です。ほとんどのプラットフォームでは、どの時間足にもそのまま適用されます。

設定 効果
短め（例：5/35/5や8/17/9） シグナルが速く、ノイズが多い
標準の12/26/9 広く使われている。ほかのトレーダーが見ているものとシグナルがそろう
長め（例：19/39/9） 滑らかで、シグナルは少なく遅い

どの設定も普遍的に優れているという証拠はありません。3つのパラメーターを過去のデータに合わせて調整すると、簡単にオーバーフィッティングに陥ります。オーバーフィッティングとデータスヌーピングをご覧ください。

遅行性の問題

MACDは移動平均線から作られ、そのシグナル線は移動平均線の差の、さらに平均です。層が重なるごとに遅れが加わります。

  • ゼロラインとのクロスは、12 EMAが26 EMAに追いつき、追い越した後にしか起こらず、その頃には価格は通常かなり動いています。
  • シグナル線とのクロスはそれより速いものの、やはり価格の転換の後に続きます。
  • ニュース後の急落のような速い反転では、MACDが値動きの底付近で売りシグナルを出すことがあります。

この遅れは平滑化の代償です。そのためMACDは、正確な転換点を捉えるよりも、持続的な値動きを見極めてそれに乗り続けることに向いています。もみ合いの横ばい相場では、遅れと頻繁なクロスが重なって、小さな損失が繰り返されます。

研究が示す根拠

MACDのルールは多くの市場で検証されてきましたが、結果はまちまちです。MACDは本質的に、平滑化を加えた移動平均線のクロスのシステムなので、同じ特性を受け継いでいます。持続的なトレンドは捉えられます（トレンドフォローの研究によれば、そうしたトレンドは過去に多くの市場で存在してきました）が、レンジでは利益を吐き出します。単一の資産に対する単独のシグナル線クロス・システムは、一般にコスト控除後に安定した利益を示していません。MACDは、それ自体で優位性を生む源泉というより、トレンドと勢いを描写する方法として捉えるほうがよいでしょう。

よくある間違い

  • シグナル線とのクロスのたびにトレードする。 レンジでは、ほとんどのクロスはノイズです。
  • 資産間や時代間でMACDの値を比較する。 比較が重要なら、PPOのようなパーセントベースの指標を使ってください。
  • MACDとRSIを2つの確認として数える。 どちらも同じ終値から作られています。
  • MACDに天井や底を当てることを期待する。 MACDは遅行するように設計されており、転換が始まった後にそれを確認するものです。
  • ゼロラインを忘れる。 強い上昇トレンドの中、ゼロを大きく上回った位置での弱気のクロスは、ゼロより下でのクロスとは意味が異なります。

よくある質問

MACDの設定12、26、9は何を意味しますか？

MACD線は12期間EMAから26期間EMAを引いたもので、シグナル線はMACD線の9期間EMAです。これらの標準設定はMACDが初期に日足で使われていた頃にさかのぼり、現在もほとんどのプラットフォームで標準となっています。

MACDのクロスとは何ですか？

シグナル線とのクロスとは、MACD線がシグナル線を横切ることで、上抜けは強気、下抜けは弱気と読まれます。ゼロラインとのクロスとは、MACDがゼロを横切ることで、12 EMAが26 EMAをクロスするのと同じです。

MACDのヒストグラムは何を示していますか？

ヒストグラムは、MACD線とシグナル線の差を示します。ヒストグラムの拡大はその方向への勢いの加速を、縮小は勢いの衰えを意味し、その後クロスが起こる可能性があります。

MACDは先行指標ですか、遅行指標ですか？

MACDは過去の価格の移動平均線から作られるため、遅行指標です。ヒストグラムやダイバージェンスはより早いヒントを与えることがありますが、その分ダマシも増えます。
