ボリンジャーバンドは、3本の線からなるボラティリティ系の指標です。中央に移動平均線があり、その上下に一定の標準偏差分だけ離した上部バンドと下部バンドがあります。価格のボラティリティが高まるとバンドは広がり、落ち着くと狭まるため、価格が直近の平均に対してどこにあるかと、相場の現在のボラティリティの両方がわかります。1980年代にジョン・ボリンジャーが開発したもので、逆張り（平均回帰）とブレイクアウトの両方のトレードに使われます。この2つのアプローチは、同じバンドへの接触を正反対に読みます。バンドへの接触は価格がどこにあるかを表すものであって、それ自体はシグナルではありません。

要点

  • 標準設定は、20期間の単純移動平均線と、その上下2標準偏差のバンドです。
  • バンドの幅はボラティリティを反映します。バンドが狭まる「スクイーズ」は異常に低いボラティリティを表し、その後に大きな値動きが続くことがよくありましたが、方向は予測できません。
  • 強いトレンドでは、価格が何本も続けて上部または下部のバンドちょうど、あるいはその近くで引ける「バンドウォーク」が起こることがあります。
  • %Bは価格がバンドの中のどこにあるかを示し、バンド幅（バンドウィズ）は中心線に対してバンドがどれだけ広いかを測ります。
  • ケルトナーチャネルは標準偏差の代わりにATR（アベレージ・トゥルー・レンジ）を使うため、より滑らかで、単一の大きなバーへの反応が小さくなります。

ボリンジャーバンドの作り方

標準設定では次のようになります。

  • 中心線（ミドルバンド） = 終値の20期間単純移動平均線（SMA）
  • 上部バンド = 中心線 + 2 × 終値の20期間標準偏差
  • 下部バンド = 中心線 − 2 × 20期間標準偏差

標準偏差は、直近20本の終値がその平均の周りにどれだけ散らばっているかを測ります。終値が狭い範囲に集まっていれば、標準偏差は小さく、バンドは中心線に近づきます。終値が大きく振れれば、バンドは広がります。標準偏差の計算でNで割るかN − 1で割るかはプラットフォームによってわずかに異なりますが、20期間ではその差は小さなものです。

2標準偏差のバンドの中に価格の約95%が収まる、と言われることがあります。この数字は正規分布に由来するものですが、価格は正規分布に従っておらず、しかもこの計算はリターンではなく価格の移動窓を使っています。実際には、バンドの外側で引けることはこの数字が示すよりも多く、その割合は市場や期間によって異なります。

%Bとバンド幅

2つの派生指標が、バンドを数値に変換します。

  • %B =（価格 − 下部バンド）/（上部バンド − 下部バンド）。値が1なら価格は上部バンド上、0なら下部バンド上、0.5なら中心線上にあります。1を超えるか0を下回る値は、価格がバンドの外側にあることを意味します。
  • バンド幅 =（上部バンド − 下部バンド）/ 中心線。バンドの幅を価格に対する比率で表すため、時期や資産をまたいで比較できます。

%Bは、価格がどれだけ「行き過ぎて」いるかを1つの数値で必要とするシステムで役立ちます。バンド幅は、スクイーズを見つけるための標準的な方法です。

計算例

ある株の直近20日の終値の平均が50.00ドル、標準偏差が1.50ドルだとします。

  • 中心線 = 50.00ドル
  • 上部バンド = 50.00 + 2 × 1.50 = 53.00ドル
  • 下部バンド = 50.00 − 2 × 1.50 = 47.00ドル
  • バンド幅 =（53.00 − 47.00）/ 50.00 = 6.00 / 50.00 = 0.12、つまり12%

今日の終値が52.40ドルなら、

  • %B =（52.40 − 47.00）/（53.00 − 47.00）= 5.40 / 6.00 = 0.90。価格は上部バンドの近くにあります。

代わりに53.60ドルで引けたなら、

  • %B =（53.60 − 47.00）/ 6.00 = 6.60 / 6.00 = 1.10。価格は上部バンドの外側で引けました。

スクイーズ。 数週間後、この株は静かな値動きを続け、20日標準偏差は0.50ドルまで低下しました。平均はまだ50.00ドル付近です。

  • 上部バンド = 50.00 + 2 × 0.50 = 51.00ドル、下部バンド = 50.00 − 2 × 0.50 = 49.00ドル
  • バンド幅 = 2.00 / 50.00 = 4%

バンド幅は12%から4%へと、以前の3分の1に低下しました。4%が過去数か月で最も低いバンド幅の水準に近ければ、トレーダーはこれをスクイーズと呼ぶでしょう。

スクイーズ

ボラティリティには集中する傾向（ボラティリティ・クラスタリング）があります。静かな期間の後には静かな期間が、活発な期間の後には活発な期間が続きやすいのですが、時間がたつとボラティリティは長期的な水準に回帰する傾向もあります。スクイーズは、異常にボラティリティが低い期間を浮き彫りにします。スクイーズに注目するトレーダーは、いずれボラティリティが拡大し、どちらかの方向に大きな値動きが起こることを期待しています。

難しいのは、スクイーズが方向については何も語らないことと、スクイーズからの最初の動きが反転するダマシになることがある点です。トレーダーは通常、スクイーズを別の要素と組み合わせて方向を選びます。

  • より大きなトレンドの方向。
  • 近くのサポートやレジスタンスの水準を超えた終値。
  • ブレイクアウト時の出来高の増加。出来高分析をご覧ください。

スクイーズは予想よりはるかに長く続くこともあり、バンドが何週間も狭いままのこともあります。

バンドウォーク

強い上昇トレンドでは、価格が何本も続けて上部バンドちょうど、あるいはその上で引けることがあり、中心線は押し目で買い手が現れる価格帯として機能します。強い下降トレンドでは、下部バンドに沿って逆のことが起こります。これをバンドウォークと呼びます。

バンドウォークこそが、上部バンドに触れるたびに売ることが危険である主な理由です。トレンド中に上部バンドの外側で引けるのは、差し迫った反転よりも強さを反映していることが多いのです。ボリンジャー自身も、バンドに触れること自体は買いや売りのシグナルではないと強調していました。

逆張り（平均回帰）での使い方とブレイクアウトでの使い方

価格がバンドの外側で引けるという同じ出来事も、アプローチによって正反対に読まれます。

アプローチ 上部バンドを上回る終値の読み方 最も機能する場面 主なリスク
平均回帰 価格が行き過ぎている。中心線への戻りを期待する レンジ、もみ合い相場 トレンドが始まり、価格がバンドウォークする
ブレイクアウト／トレンド ボラティリティと勢いが上方向に拡大している。乗ることを検討する 発生しつつあるトレンド、スクイーズ後のブレイクアウト ブレイクアウトが失敗し、価格がバンド内に戻る

平均回帰のトレーダーは、バンドへの接触をRSIなどのオシレーターや、強いトレンドに逆らうトレードを避けるフィルターと組み合わせることがよくあります。ブレイクアウトのトレーダーは、事前のスクイーズと重要な水準を超えた終値を条件にすることがよくあります。どちらのアプローチもあらゆる状況で正しいわけではありません。難しいのは相場がどの局面にあるかを判断することで、その判断は後になって初めてはっきりすることが多いのです。

平均回帰戦略は勝率が高い反面、ときどき大きな損失を出す傾向があり、ブレイクアウト戦略は勝率が低い反面、ときどき大きな利益を上げる傾向があります。どちらもコスト控除後に損失になる可能性があり、だからこそ勝率よりも期待値が重要なのです。

ボリンジャーバンドとケルトナーチャネルの比較

ケルトナーチャネルは見た目は似ていますが、ボラティリティの測り方が異なります。ほとんどのプラットフォームで標準となっている現代版では、次のものを使います。

  • 中心線： 指数平滑移動平均線。20期間が多い。
  • 上下の線： 中心線にATR（アベレージ・トゥルー・レンジ）の倍数を加減したもの。一般的には1.5倍か2倍。
特徴 ボリンジャーバンド ケルトナーチャネル
中心線 20 SMA EMA（20が多い）
ボラティリティの尺度 終値の標準偏差 ATR（窓やバー内の値幅を含む）
単一の大きなバーへの反応 バンドが急激に広がる 滑らかで、徐々に広がる
典型的な形 膨らんだりくびれたりする 安定していて、より平行

標準偏差は大きな値動きに強く反応するため、ボリンジャーバンドのほうが劇的に拡大・収縮します。ボリンジャーバンドがケルトナーチャネルの内側に収縮した瞬間をスクイーズと定義するトレーダーもいます。

例。 上の株で、20期間EMAが約50.00ドル、ATRが1.20ドルだとします。ATRの2倍のケルトナーチャネルは50.00 ± 2.40、つまり47.60ドルと52.40ドルにあり、幅は4.80ドルです。以前のボラティリティが高い期間には、ボリンジャーバンド（47.00ドルから53.00ドル、幅6.00ドル）はケルトナーチャネルの外側にありました。スクイーズの間、ボリンジャーバンド（49.00ドルから51.00ドル、幅2.00ドル）はその内側にあり、こうしたトレーダーはこれをスクイーズと呼びます。実際には静かな期間にATRもある程度縮小しているはずですが、標準偏差がATRより速く低下する限り、この比較は成り立ちます。

研究が示す根拠

ボリンジャーバンドは、ボラティリティと、価格が直近の平均からどれだけ離れているかを測る方法であり、これらの量は実在し、損切りの設定やポジションサイズの決定に役立ちます。下部バンドで買い上部バンドで売る、あるいはすべてのブレイクアウトでトレードするといった単純なルールは、公表された検証で結果がまちまちであり、成績は市場、期間、コストに大きく左右されます。ボラティリティ・クラスタリングそのものは金融市場のリターンで十分に裏付けられており、スクイーズの考え方を支持していますが、だからといって次の値動きの方向が予測できるわけではありません。

よくある間違い

  • バンドへの接触をシグナルとみなす。 接触は、直近のボラティリティに対して価格がどこにあるかを示すにすぎません。
  • 強いトレンドに逆張りする。 バンドウォーク中に上部バンドで売るのは、損失を繰り返すよくあるパターンです。
  • 95%がバンド内に収まると思い込む。 価格は正規分布に従っておらず、バンドの外側で引けることはよくあります。
  • スクイーズの方向を当てようとする。 スクイーズが表すのは低いボラティリティであって、価格がどちらにブレイクするかではありません。
  • 設定を最適化しすぎる。 過去のデータに合わせて期間や倍率を変えても、将来のデータで役立つ可能性は低いでしょう。

よくある質問

ボリンジャーバンドの最適な設定は何ですか？

20期間の移動平均線と2標準偏差という標準設定が圧倒的に広く使われており、妥当な出発点です。期間を短くするとバンドの反応が速くなります。変更する場合は、取引する市場と時間足で検証してください。

ボリンジャーバンドのスクイーズは何を意味しますか？

スクイーズとは、バンドが異常に狭い幅まで縮まり、ボラティリティが低い期間を示している状態です。こうした期間の後には大きな値動きが続くことがよくありましたが、スクイーズは値動きの方向を示すものではありません。

価格が上部のボリンジャーバンドに触れたら売りシグナルですか？

それだけではシグナルになりません。レンジでは価格が上部バンドから戻ることがよくありますが、強い上昇トレンドでは、価格が何本も続けて上部バンドちょうど、あるいはその上で引けることがあります。

ボリンジャーバンドとケルトナーチャネルの違いは何ですか？

ボリンジャーバンドは単純移動平均線の周りに終値の標準偏差を使い、ケルトナーチャネルは指数平滑移動平均線の周りにATRを使います。ケルトナーチャネルのほうが滑らかで、ボリンジャーバンドのほうが急激に拡大・収縮します。
