チャートパターンとは、ヘッドアンドショルダー、ダブルトップ、三角保ち合い、フラッグなど、価格が多数のバーにわたって描く繰り返し現れる形のことです。トレーダーはこれを、トレンドの終わりを示すとされる反転パターンと、トレンド途中の一服を示すとされる継続パターンに分類します。各パターンには、慣習的なエントリーポイント（通常は境界線のブレイクアウト）と、「値幅観測（メジャードムーブ）」による目標値があります。トレードを組み立てるのには役立ちますが、失敗することも多く、後から見れば簡単に見つかり、厳密な検証による裏付けも限られています。

要点

  • チャートパターンは、ヘッドアンドショルダーのネックラインのような、パターンを定義する境界線を価格がブレイクするまで完成しません。
  • 値幅観測による目標値は、パターンの高さをブレイクアウト地点から投影したもので、予測ではなくおおまかな目安です。
  • 多くのパターンは、サポートとレジスタンスとトレンド構造の組み合わせに名前を付けたものです。
  • パターンの失敗はよくあることで、失敗したパターンが逆方向への急激な値動きを生むこともあります。
  • パターンは主観的なものなので、自分にとって付加価値があるかを知るには、正確に定義して検証するしかありません。

チャートパターンのトレード方法

ほとんどのパターンは、同じトレードの論理を共有しています。

  1. スイングハイとスイングローを使い、形成中の形を見つける。
  2. 通常はパターンの境界線（ネックライン、トレンドライン、レンジの端）を超えてローソク足が確定するまで、確認を待つ。ブレイク前は、パターンの候補にすぎません。
  3. ブレイクアウト時、またはブレイクした境界線へのリテスト時にエントリーする。
  4. ブレイクアウトの見立てが明らかに間違っていたとわかる、パターンの内側に損切りを置く。
  5. 値幅観測で目標値を設定し、近くの価格水準に合わせて調整する。

出来高は補助的な確認としてよく使われます。古典的な教科書では、パターンの形成中に出来高が減少し、ブレイクアウト時に増加すると説明されています。出来高分析をご覧ください。

反転パターン

ヘッドアンドショルダー（三尊）

ヘッドアンドショルダー・トップ（三尊天井）は上昇トレンドの後に形成されます。左肩、それより高い山（頭）、それより低い右肩という3つの山があります。山と山の間の安値を結んだ線がネックラインです。価格がネックラインを下回って引けたときにパターンが完成します。

構造的に見ると、右肩は切り下がった高値であり、ネックラインのブレイクは切り下がった安値です。これはブレイク・オブ・ストラクチャーにあたります。逆ヘッドアンドショルダー（逆三尊） は、下降トレンドの終わりに現れるその鏡像です。

ダブルトップ・ボトムとトリプルトップ・ボトム

ダブルトップは、ほぼ同じ価格にある2つの山と、その間の谷からなります。価格が谷を下回って引けたときに完成します。ダブルボトムはその逆です。トリプルトップとトリプルボトムは、3回目の試しが加わったものです。いずれも、価格が同じ水準で繰り返し跳ね返された後、レンジの反対側をブレイクする動きを表しています。

ソーサーボトム（ラウンディングボトム）

下落から上昇へと、ゆっくりU字型に移行する形です。ほとんどのパターンよりも主観的で、通常は何週間から何か月にもわたります。

継続パターン

フラッグとペナント

フラッグは、ほぼ垂直の急激な値動き（ポール）の後に現れます。その後、価格は値動きと逆方向に傾いた小さな長方形の中で推移します。ペナントも考え方は同じで、長方形の代わりに小さな対称三角形を描きます。ポールの方向へのブレイクアウトは、トレンドの再開を示すとされます。これらは短期のパターンで、日足では通常数日間続きます。

レクタングル（ボックス）

価格が水平なサポートとレジスタンスの間で横ばいに推移する形です。レクタングルは単なるレンジですが、パターンとして見る場合は、ブレイクアウトが起こり、それは直前のトレンドの方向であることが多い、という見通しが加わります。

カップ・アンド・ハンドル

丸みを帯びた下落と、直前の高値付近までの回復（カップ）の後に、浅い押し（ハンドル）が続き、その後カップの縁を上抜ける形です。成長株のトレーダーに人気があります。

どちらにも動きうるパターン

三角保ち合い（トライアングル）

  • 上昇三角形（アセンディング・トライアングル）： 水平なレジスタンスと切り上がる安値。買い手が徐々に高い位置で買いを入れ続けるため、強気と読まれることが多い形です。
  • 下降三角形（ディセンディング・トライアングル）： 水平なサポートと切り下がる高値。弱気と読まれることが多い形です。
  • 対称三角形（シンメトリカル・トライアングル）： 切り下がる高値と切り上がる安値が収束していく形。ブレイクするまで方向ははっきりしません。

三角保ち合いはボラティリティの縮小を反映しています。ブレイクアウトの方向は名前から想像されるほど予測しやすくなく、だからこそトレーダーはブレイクを待ちます。

ウェッジ

2本の境界線が同じ方向に傾きながら収束する形です。

  • 上昇ウェッジ（ライジング・ウェッジ）： 高値も安値も切り上がるものの、安値の切り上がりのほうが速い形。勢いが衰えているため、伝統的に弱気と読まれます。
  • 下降ウェッジ（フォーリング・ウェッジ）： 伝統的に強気と読まれます。

計算例：値幅観測

ヘッドアンドショルダー・トップ

ある株が、54ドルで左肩、60ドルで頭、54.50ドルで右肩を形成しました。ネックラインは50ドルで水平です。

  • パターンの高さ = 頭 − ネックライン = 60ドル − 50ドル = 10ドル
  • 値幅観測による目標値 = ネックライン − 高さ = 50ドル − 10ドル = 40ドル

49.60ドルの終値で空売りをエントリーするトレーダーは、右肩の上の55.00ドルに損切りを置くかもしれません。リスク = 55.00ドル − 49.60ドル = 5.40ドル。目標値40ドルまでのリワード = 49.60ドル − 40ドル = 9.60ドル。リスクリワード比 = 9.60ドル / 5.40ドルで、約1.8です。

ネックラインのすぐ上、たとえば51.50ドルに損切りを置けばリスクは1.90ドルに減りますが、価格がネックラインをリテストした場合（よくあることです）に損切りにかかる可能性がはるかに高くなります。

ダブルボトム

安値が30.00ドルと30.20ドルで、その間の山が34.50ドルです。

  • 高さ = 34.50ドル − 30.00ドル = 4.50ドル
  • 目標値 = 34.50ドル + 4.50ドル = 39.00ドル

強気のフラッグ

ポールが20ドルから26ドルまで、6ドル分上昇しました。フラッグは24.80ドルまで下がり、価格は25ドルでブレイクアウトしました。

  • 目標値 = 25ドル + 6ドル = 31ドル

これらの目標値は慣習にすぎません。価格は過去のレジスタンス水準で手前に止まることが多く、逆にはるかに先まで進むこともあります。多くのトレーダーは、値幅観測の地点で一部を利益確定し、残りはトレーリングストップで追いかけます。

失敗率と確認

チャートパターンは頻繁に失敗します。「失敗」とは通常、価格がブレイクアウトした後すぐに境界線の内側へ反転して戻るか、目標値に届かないことを指します。何千ものパターンを集計した実務家の研究では、失敗率はパターン、市場、そして「失敗」の定義によって大きく異なり、多くのパターンが値幅観測の期待値を下回ると報告されています。

次の点については広く意見が一致しています。

  • 確認されていないパターンは推測にすぎない。 ダブルトップの候補の多くは、価格が中間の谷をブレイクしないまま、上昇トレンドの中の普通の押し目に終わります。
  • 失敗したパターンにも情報がある。 多くの人が注目するヘッドアンドショルダーがネックラインをブレイクした後に急反発すると、ブレイクで売ったトレーダーが買い戻しを迫られ、その値動きを加速させることがあります。こうした失敗を意図的に狙うトレーダーもいます。プライスアクション・トレードをご覧ください。
  • トレンドの文脈が重要。 上位足の強いトレンドと同じ方向の継続パターンは、それに逆らう反転パターンよりも信頼性が高いと一般に考えられています。

研究が示す根拠

Lo, Mamaysky and Wang（2000）は、米国株の価格からヘッドアンドショルダー、ダブルトップ・ボトム、三角保ち合い、レクタングルなどのパターンを検出するアルゴリズムを構築しました。その結果、いくつかのパターンにはその後のリターンについてわずかな追加情報が含まれており、形が純粋なノイズではないことが示唆されました。ただし、この研究はパターンを売買してコスト控除後に利益が出ることを示したわけではありません。ほかの研究ではまちまち、あるいは否定的な結論が出ており、結果はパターンの定義の仕方に左右されます。

最大の障害は主観性です。同じチャートを見ても、パターンが存在するのか、ネックラインはどこか、いつブレイクしたのかについて、2人のトレーダーの意見が分かれることはよくあります。パターンを正確なルールに落とし込んでバックテストすることが測定する唯一の方法であり、それをうまく行うにはオーバーフィッティングを避ける注意が必要です。

よくある間違い

  • ブレイクアウト前にトレードする。 パターンを先読みすると、結局完成しない形で多くのトレードをすることになります。
  • ランダムなデータにパターンを見いだす。 ランダムな価格系列からも、それらしいヘッドアンドショルダーや三角保ち合いが頻繁に生まれます。
  • 目標値を約束とみなす。 値幅観測はおおまかな目安であり、近くの価格水準のほうが重要なことがよくあります。
  • 損切りを近くに置きすぎる。 ブレイクアウト水準へのリテストはよくあることで、境界線ぎりぎりに置いた損切りはよく引っかかります。
  • 大きなトレンドを無視する。 週足の強い上昇トレンドの中にある小さな弱気パターンは、主要な流れに逆らっています。
  • 失敗した後にパターンを引き直す。 パターンの失敗を認めないためにネックラインを引き直すのは、確証バイアスの一種です。

よくある質問

最も信頼できるチャートパターンは何ですか？

単独で信頼できるパターンはありません。どのパターンも失敗率は無視できず、市場や定義によって異なります。トレーダーは一般に、境界線を超えた終値で確認され、上位足のトレンドと一致し、出来高の増加を伴ってブレイクしたパターンをより信頼します。

チャートパターンの目標価格はどう計算しますか？

ほとんどのパターンでは値幅観測を使います。頭からネックラインまで、あるいはフラッグのポールなど、パターンの高さを測り、それをブレイクアウト地点から投影します。結果はおおまかな目安として扱い、近くのサポートやレジスタンスと照らし合わせてください。

ヘッドアンドショルダーは強気ですか、弱気ですか？

上昇トレンドの終わりに現れる通常のヘッドアンドショルダーは、ネックラインをブレイクすると伝統的に弱気と読まれます。下降トレンドの終わりに現れる逆ヘッドアンドショルダーは強気と読まれます。

フラッグとペナントの違いは何ですか？

どちらも急激な値動きの後の短い一服です。フラッグは傾いた小さな長方形の中で保ち合い、ペナントは収束する小さな三角形の中で保ち合います。

教育目的のコンテンツです。本サイトの内容は、金融・投資・法律・税務に関する助言ではありません。トレードには大きな損失リスクがあり、レバレッジ商品では入金額を超える損失が生じることがあります。ルール、手数料、プラットフォームの条件は変わります。取引の前に、ご利用の証券会社、取引所、規制当局で最新の条件をご確認ください。
