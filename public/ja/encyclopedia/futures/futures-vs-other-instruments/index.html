先物と株式、CFD、無期限先物の比較

約8分で読めます · 更新日 2026年11月23日

先物、株式、CFD、仮想通貨の無期限先物（パーペチュアル）は、いずれも同じ市場へのエクスポージャーを得る手段になりえますが、レバレッジ、コスト、取引を誰が保証するか、どう規制されているか、どう課税されるかが異なります。たとえばS&P 500へのエクスポージャーを得たいトレーダーにとって、指数ETF、指数CFD、E-mini先物、仮想通貨取引所の無期限先物は、同じ保有期間でもまったく違う振る舞いをすることがあります。適切な金融商品の選択は、どれが「最善」かではなく、目的に合うかどうかの問題です。

要点

  • 取引所で取引される先物は中央清算されるため、CFDやオフショアの仮想通貨デリバティブに見られるカウンターパーティリスクの大部分が取り除かれます。
  • 先物のレバレッジは契約自体に組み込まれており、日々の資金調達手数料はなく、通常は株式の信用取引で認められるよりはるかに高い水準です。
  • 米国では、規制下の先物は一般に1256条の60/40ルールに基づいて課税され、株式のパターン・デイトレーダー規制の対象外です。
  • CFDは柔軟で米国外では広く利用できますが、資金調達コストとディーラーのカウンターパーティリスクを伴い、米国の個人トレーダーには提供されていません。
  • 仮想通貨の無期限先物には満期がありませんが、保有者はファンディングを支払うか受け取ることになり、清算や保険に関する取引所独自のルールが重要になります。

各列の背後にある仕組みは、先物取引の基礎、CFDとスプレッドベッティング、無期限先物で解説しています。

レバレッジと証拠金

株式の場合、レバレッジは借入れから生まれます。米国の信用取引口座では、レギュレーションTにより当初の借入れは一般に株式購入額の50パーセントまでに制限されており、オーバーナイトでは約2対1のレバレッジになります。要件を満たす口座では、日中の買付余力がそれより高くなることがあります。

先物の場合、契約そのものにレバレッジがかかっています。想定元本のごく一部にあたる履行保証金を差し入れるだけで、残りの部分について利息を払うことはありません。資金調達コストがなくなるわけではありませんが、株価指数先物で説明しているように、ベーシスとして先物価格に織り込まれています。

CFDでは、現地の規則の範囲内でブローカーがレバレッジを設定します。欧州連合（EU）では、規制当局が個人向けCFDのレバレッジに上限を設けており、たとえば主要通貨ペアでは30対1、主要株価指数では20対1です。また、ブローカーには損失を出している個人口座の割合を開示するよう義務づけています。こうした開示では、通常、個人のCFD口座の大半が損失を出していることが示されています。

仮想通貨の無期限先物は、一部の取引所で非常に高いレバレッジを提供しています。レバレッジが高いと、ロスカット（強制清算）までの距離がわずかな値動きにまで縮まります。

コスト

計算例：$50,000のエクスポージャーを30日間保有する

あるトレーダーが、株価指数に対して約$50,000のロングエクスポージャーを30日間持ちたいとします。以下の数字は説明のためのもので、実際の料率はブローカー、取引所、市場環境によって異なります。

  • 先物： 指数水準5,000でMESを2枚持てば、2 x 5,000 x $5 = $50,000のエクスポージャーになります。コストは、1枚あたりの往復手数料と取引所手数料（多くは数ドル）にスプレッドを加えたものです。資金調達コストは、別項目として請求されるのではなく、ベーシスに組み込まれています。
  • CFD： ブローカーが基準金利に2.5パーセントを上乗せし、年7パーセントを課すとします。30日間の資金調達コストは$50,000 x 7% x 30 / 365 = 約$287.67で、これにスプレッドが加わります。
  • 仮想通貨の無期限先物： ファンディングが8時間ごとに平均0.01パーセントで、ロング側が支払うとします。これは1回あたり$50,000 x 0.0001 = $5で、1日3回なので1日$15、30日間で$450となり、これに取引手数料が加わります。ファンディングは常に変動しマイナスになることもあるため、この数字はずっと高くも低くもなりえます。ファンディングレートをご覧ください。

重要な違いは、CFDの資金調達コストと無期限先物のファンディングが明示的で継続的にかかる費用であるのに対し、先物はキャリーコストを取引価格そのものに織り込んでいる点です。短い保有期間では、通常スプレッドと手数料が最も重要です。長い保有期間では、資金調達コストが支配的になります。取引コストと手数料をご覧ください。

清算とカウンターパーティリスク

規制下の先物を取引する場合、清算機関が契約の履行を保証します。清算機関はすべての清算参加者から証拠金を徴収し、日々ポジションを値洗いし、デフォルト・ファンド（清算基金）を保有しています。米国の規制下の先物ブローカーでは、顧客資金は分別管理口座で保管しなければなりません。

CFDの場合、取引相手はブローカーです。ブローカーが破綻すれば、資金を取り戻せるかどうかは現地の顧客資産保護ルールや補償制度次第です。仮想通貨取引所の場合は、2022年のFTXの破綻が示したように、取引所の支払能力と誠実さに頼ることになります。無期限先物の取引所では、保険基金で吸収しきれない損失を補うために利益の出ているポジションを決済する、自動デレバレッジ（ADL）を使うこともあります。

米国のパターン・デイトレーダー規制

米国では、FINRAのパターン・デイトレーダー（PDT）規制により、5営業日以内に4回以上のデイトレードを行った信用取引口座は、少なくとも$25,000の資産を維持することが求められていました。FINRAは2026年6月4日付でこれを日中証拠金の基準に置き換えており、ブローカーは2027年10月までかけて段階的に移行できるため、利用しているブローカーの現行ルールを確認しましょう。いずれにせよ、これは証券に関するルールです。先物口座には適用されず、それが少額の口座を持つ米国のデイトレーダーがマイクロ株価指数先物に向かう理由の一つになっています。株式のデイトレードをご覧ください。

米国の課税：1256条

米国の納税者が取引する規制下の先物の大半は、内国歳入法上の「1256条契約」です。一般的な言葉で説明すると次のとおりです。

  • 60/40の扱い： 損益は、ポジションの保有期間にかかわらず、60パーセントが長期、40パーセントが短期のキャピタルゲインとして扱われます。
  • 年末の時価評価： 未決済のポジションは、その年の最終営業日に公正市場価格で売却したものとして扱われます。

計算例

ある米国のトレーダーが、数分単位で保有する先物のデイトレードで差し引き$10,000の利益を上げたとします。1256条のもとでは、$6,000が長期、$4,000が短期として扱われます。説明のために連邦税の長期と通常所得の最高税率として20パーセントと37パーセントを使うと、合成された最高税率は0.6 x 20% + 0.4 x 37% = 12% + 14.8% = 26.8パーセントとなり、全額が短期だった場合の37パーセントと比べて低くなります。実際の税率は、所得、申告区分、州税、そして現行法によって異なります。

保有期間が1年以下の株式は、短期のキャピタルゲインとして課税されます。CFD、スプレッドベッティング、仮想通貨デリバティブの税務上の扱いは国によって異なり、時とともに変わります。たとえば英国のスプレッドベッティングは、歴史的にほとんどの個人にとってキャピタルゲイン税の対象外とされてきました。このセクションは一般的な情報であり、税務上の助言ではありません。トレードの税金の概要を参照し、資格のある専門家に相談してください。

よくある間違い

  • 想定元本ではなく証拠金で比較する。 証拠金が低いということはレバレッジが高いということであり、リスクが低いということではありません。
  • CFDや無期限先物の資金調達コストを無視する。 日々の費用は、数週間、数か月と積み重なります。
  • 「先物」はすべて同じだと思い込む。 規制下のCMEの契約とオフショアの無期限先物では、清算、監督、顧客保護が異なります。
  • 税制を記憶に頼る。 ルールは国によって異なり、変わることもあります。それを前提に計画を立てる前に、現行法を確認しましょう。
  • レバレッジだけで金融商品を選ぶ。 高いレバレッジを使う個人トレーダーの大半は損失を出しています。レバレッジは、トレーダーが持つ優位性も、優位性のなさも、等しく増幅します。

よくある質問

先物はCFDより優れていますか？

一般論としてどちらが優れているということはありません。先物には中央清算、透明性の高い取引所での価格形成、明示的な資金調達手数料がないという利点があります。一方、CFDはより小さなサイズで取引でき、1つの口座で多くの市場にアクセスできますが、ブローカーのカウンターパーティリスクと日々の資金調達コストを伴います。

パターン・デイトレーダー規制は先物にも適用されますか？

いいえ。米国のPDTルールは証券の信用取引口座に適用されるもので、CFTCとNFAが規制する先物口座には適用されません。

先物の60/40ルールとは何ですか？

米国の1256条のもとでは、規制下の先物の損益は、保有期間にかかわらず、60パーセントが長期、40パーセントが短期のキャピタルゲインとして扱われます。税制は変わるため、現行法を確認し、専門家の助言を求めましょう。

先物と無期限先物の違いは何ですか？

従来の先物には満期日があり、満期時に現物価格へ収束します。無期限先物には満期がなく、ロングとショートの間で定期的にファンディングを支払い合うことで、価格を現物の近くに保ちます。
