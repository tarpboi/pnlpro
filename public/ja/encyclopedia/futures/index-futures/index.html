株価指数先物

約8分で読めます · 更新日 2026年11月23日

株価指数先物とは、S&P 500、ナスダック100、ダウ工業株30種平均、DAX、日経225などの株価指数に価値が連動する先物契約です。ほぼ24時間、中央清算のもと、高いレバレッジで、1回の取引で市場全体に対する見方をポジションにできます。CMEのE-miniとマイクロE-miniは世界で最も活発に取引されている先物の一つで、デイトレーダーによく選ばれています。

要点

  • 株価指数先物は差金決済で、E-mini S&P 500なら1ポイントあたり$50というように、固定のドル建て乗数を通じて指数に連動します。
  • マイクロE-miniはE-miniの10分の1のサイズで、小さな口座でもポジションサイズをずっと調整しやすくなります。
  • 先物価格は通常、金利と予想配当によって決まる額だけ現物指数より上か下に位置し、これを理論価格（フェアバリュー）と呼びます。
  • 平日はほぼ24時間取引されているため、米国株の取引時間外に出た重大ニュースは、まず先物に織り込まれます。
  • デイトレーダーを引きつけるレバレッジこそが、損失を速く大きくするものでもあります。

米国の主な株価指数先物

最も広く取引されている米国の契約はCME Groupに上場されています。「E-mini」とは、かつての大型の立会場取引の契約に取って代わった、電子取引の契約を指します。2019年にCMEが導入した「マイクロE-mini」は、E-miniの10分の1のサイズです。

契約 シンボル 乗数 ティックサイズ ティックバリュー
E-mini S&P 500 ES $50 x 指数 0.25ポイント $12.50
Micro E-mini S&P 500 MES $5 x 指数 0.25ポイント $1.25
E-mini Nasdaq-100 NQ $20 x 指数 0.25ポイント $5.00
Micro E-mini Nasdaq-100 MNQ $2 x 指数 0.25ポイント $0.50
E-mini Dow ($5) YM $5 x 指数 1ポイント $5.00
Micro E-mini Dow MYM $0.50 x 指数 1ポイント $0.50
E-mini Russell 2000 RTY $50 x 指数 0.10ポイント $5.00
Micro E-mini Russell 2000 M2K $5 x 指数 0.10ポイント $0.50

いずれも3月（H）、6月（M）、9月（U）、12月（Z）の四半期限月が上場されており、差金決済です。取引要綱は変更されることがあるため、取引前に取引所のサイトで確認しましょう。契約の一般的な仕組みについては、先物取引の基礎をご覧ください。

想定元本

想定元本とは、指数の水準に乗数を掛けたものです。差し入れる証拠金がどれほど少なくても、これがポジションの実際の大きさです。

契約 指数水準の例 想定元本
ES 5,000 $250,000
MES 5,000 $25,000
NQ 18,000 $360,000
MNQ 18,000 $36,000

これらの水準では、NQの乗数のほうが小さいにもかかわらず、NQを1枚保有するトレーダーはESを1枚保有するトレーダーより大きな指数エクスポージャーを持つことになります。ナスダック100の指数の数値のほうがずっと大きいからです。また、ナスダック100はパーセンテージで見ても値動きが大きい傾向があるため、NQのポジションは通常、1日あたりのドル建ての振れ幅が大きくなります。

海外の株価指数先物

主要な市場のほとんどに株価指数先物があります。

  • DAX（ドイツ）： Eurexは、指数1ポイントあたり€25の通常サイズのDAX先物と、指数1ポイントあたり€5のミニDAX先物を上場しています。
  • ユーロ・ストックス50（ユーロ圏）： Eurexのユーロ・ストックス50先物は指数1ポイントあたり€10、ティックは1ポイントで、欧州で最も取引されている株価指数先物の一つです。
  • 日経225（日本）： 大阪取引所は円建ての日経225先物を複数のサイズで上場しており、CMEは円建てと米ドル建ての両方の日経平均先物を上場しています。米ドル建てには指数の$5倍の契約もあります。
  • その他： FTSE 100先物はICE Futures Europeで、ハンセン指数先物は香港取引所で取引されており、その他多くの国の指数にもそれぞれ独自の契約があります。

これらの契約は、ヘッジのために現物指数と組み合わせて使われることが多く、現地の株式市場が開く前の値付けにも役立ちます。指数の構成とウェイトの付け方については、株価指数トレードで解説しています。

取引時間と夜間セッション

CMEの株価指数先物は、Globex電子取引プラットフォーム上で、米国時間の日曜日夕方から金曜日午後まで取引されており、毎日米国東部時間の午後5:00から1時間の休止があります。米国の株式市場の取引時間（米国東部時間の午前9:30〜午後4:00）に対応する時間帯は、レギュラー・トレーディング・アワー（RTH）と呼ばれることがよくあります。それ以外の時間帯は、夜間セッション、またはエレクトロニック・トレーディング・アワー（ETH）と呼ばれます。

夜間セッションが重要な理由は3つあります。

  1. ニュースにはまず先物が反応する。 引け後に発表される決算、海外の中央銀行の決定、地政学的な出来事は、米国株の取引開始の何時間も前にESやNQに織り込まれます。
  2. 流動性が薄い。 ESのスプレッドは通常それでも1ティックですが、板の枚数が少ないため、大口の注文は価格をより大きく動かすことがあります。スプレッドと流動性をご覧ください。
  3. ギャップは現物市場で起きるが、先物で起きるとは限らない。 先物が夜間にその値動きを徐々にこなしていた一方で、株価指数が寄り付きで「窓をあける」ことがあります。

Eurexと大阪取引所には、夜間の延長取引時間を含むそれぞれ独自のセッションがあります。セッションの詳細は変わるため、取引所の最新のスケジュールを確認し、概要については取引時間とセッションをご覧ください。

理論価格と現物指数

先物価格は指数の水準と同じではありません。両者の差はベーシスと呼ばれます。理論上、先物は理論価格（フェアバリュー）で取引されるはずで、これは今日指数の全銘柄を買って満期まで保有するコストを反映したものです。

  • 株を買う資金を調達するために金利を払うので、理論価格は指数より上に押し上げられます。
  • 保有している間は配当を受け取るので、理論価格は指数より下に押し下げられます。

簡略化した計算式は次のとおりです。

Fair value = Index x (1 + (interest rate - dividend yield) x days to expiry / 365)

（理論価格 = 指数 ×（1 +（金利 − 配当利回り）× 満期までの日数 / 365））

計算例

S&P 500の現物指数が5,000、短期金利が年4.5パーセント、指数の配当利回りが1.3パーセント、満期まで90日だとします。

  • ネットのキャリー率：4.5% - 1.3% = 3.2%
  • 期間の比率：90 / 365 = 0.2466
  • キャリー：3.2% x 0.2466 = 0.789%
  • 理論価格：5,000 x 1.00789 = 約5,039.45

したがって、先物は5,039.45付近、つまり現物指数より約39.45ポイント上で取引される「はず」です。先物が理論価格を大きく上回って取引されれば、裁定取引業者は先物を売って現物株を買うことができ、大きく下回ればその逆ができます。このインデックス裁定取引によって、ベーシスはほとんどの時間、理論価格の近くに保たれています。ベーシスは満期が近づくにつれてゼロに向かって縮小するため、次の四半期限月は期近限月とは異なる価格で取引されます。限月間のロールについてはコンタンゴ、バックワーデーション、ロールオーバーで解説しています。

取引開始前のテレビ報道で「先物は20ポイント高」と言うとき、それは先物価格そのものを指す場合もあれば、理論価格に対する先物の位置を指す場合もあります。満期まで数か月ある場合、この2つの数字は数十ポイント異なることがあります。

満期と決済

米国の株価指数先物は四半期ごとに満期を迎え、差金決済されます。E-mini S&P 500の最終清算価格は、限月の第3金曜日における指数構成銘柄の始値から算出される、指数の特別気配値（特別清算指数、いわゆるSQ）に基づきます。ほとんどのトレーダーは、出来高が新しい期近限月に移る満期の約1週間前に、次の限月へロールします。

デイトレーダーが株価指数先物を好む理由

特徴 実際の意味
厚い流動性 ESとNQは、米国の取引時間中は通常1ティックのスプレッドで取引される
ほぼ24時間アクセス可能 欧州やアジアのトレーダーも、自国の日中に米国の指数を取引できる
パターン・デイトレーダー規制がない 米国のPDTルールは株式の信用取引口座に適用され、先物口座には適用されない
中央清算 契約の履行がディーラー自身のバランスシートに依存しない
サイズを調整しやすい マイクロ契約なら、S&Pの1ポイントあたり$5刻みでサイズを決められる
米国での税務上の扱い 利益は一般に1256条の60/40ルールに基づいて課税される。先物と他の金融商品の比較を参照

同じ特徴には代償もあります。上記の水準では、ES 1枚は25万ドル分の指数エクスポージャーに相当し、一部のブローカーのデイトレード証拠金は取引所の当初証拠金をはるかに下回ります。多くの日にはごく普通に起きるESの20ポイントの逆行は、1枚あたり$1,000の損失です。複数の国の個人デイトレーダーを対象とした研究では、その大多数が長期的に損失を出していることが一貫して示されており、レバレッジはその結果をより早く招きます。

計算例：ESの代わりにMESでサイズを決める

$10,000の口座を持つトレーダーが、1トレードあたりのリスクを1パーセント、つまり$100以内に抑えたいと考えています。ストップはエントリーから8ポイントです。

  • ESの場合：8ポイント x $50 = 1枚あたり$400のリスク。1枚でもリスク上限の4倍になります。
  • MESの場合：8ポイント x $5 = 1枚あたり$40のリスク。2枚でリスクは$80となり、上限内に収まります。

これがマイクロ契約が存在する主な理由です。一般的な方法についてはポジションサイジングをご覧ください。

よくある間違い

  • ポイントとティックを混同する。 ESの1ポイントは4ティックです。ESの「10ティックのストップ」はわずか2.5ポイント、つまり$125です。
  • NQをESと同じように扱う。 NQは指数水準もボラティリティも高いため、1枚あたりのドル建ての振れ幅が大きくなります。
  • 満期を迎える契約を取引する。 ロール後は古い契約から流動性が抜けていくため、スプレッドとスリッページが悪化します。
  • 予定されたニュースを無視する。 CPI、雇用統計、中央銀行の決定は、株価指数先物を数秒で数十ポイント動かすことがあります。ニューストレードと経済指標カレンダーをご覧ください。
  • 計画なしに週末をまたいで保有する。 市場は金曜日の午後から日曜日の夕方まで閉まっており、金曜日の終値から大きく離れた価格で始まることがあります。

よくある質問

ESとMESの違いは何ですか？

どちらもS&P 500に連動し、ティックは同じ0.25ポイントですが、ESは指数1ポイントあたり$50、MESは指数1ポイントあたり$5です。MES 1枚は、サイズ、リスク、証拠金のいずれもES 1枚の10分の1です。

NQの1ポイントはいくらですか？

E-mini Nasdaq-100（NQ）の1ポイントは$20で、0.25ポイントの1ティックは$5です。Micro E-mini Nasdaq-100（MNQ）では、1ポイントが$2、1ティックが$0.50です。

なぜ先物価格はS&P 500指数と違うのですか？

先物価格には、満期まで指数構成銘柄を保有するための資金調達コストから、それらの銘柄が支払う配当を差し引いたものが含まれているからです。理論価格またはベーシスと呼ばれるこの差は、満期にはゼロに縮小します。

E-mini先物はいつ取引されていますか？

CMEの株価指数先物は、米国時間の日曜日夕方から金曜日午後まで、ほぼ24時間取引されており、毎日米国東部時間の午後5:00から1時間の休止があります。祝日のスケジュールは取引所で確認しましょう。
