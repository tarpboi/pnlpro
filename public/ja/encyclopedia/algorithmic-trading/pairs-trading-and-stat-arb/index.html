ペアトレードと統計的裁定取引

ペアトレードとは、密接に関連する2つの資産の価格関係が異常に大きく開いたときに、一方を買い、もう一方を空売りして、その差が縮まることに賭けるマーケットニュートラル戦略です。統計的裁定取引（スタットアーブ）は、この考え方を、統計モデルで選んだ多数のポジションからなる大規模なポートフォリオに拡張したものです。どちらも、単一の価格ではなく相対的な価格に適用した平均回帰の一形態であり、弱まったり崩れたりしうる関係に依存しています。

要点

  • ペアトレードは、市場全体の方向ではなく、2つの資産の間のスプレッドの変化から利益を得ます。
  • 相関よりも重要なのは共和分、つまりスプレッドそのものが安定した水準に戻る傾向があることです。
  • ヘッジ比率は、スプレッドが釣り合うようにそれぞれの資産をどれだけ取引するかを決めます。
  • エントリーとエグジットは通常、スプレッドの zスコアで定義され、関係が崩れた場合に備えてストップも設定します。
  • 公表されているペアトレードの利益は時とともに減少しており、2007年8月のように、混雑した統計的裁定のポジションが激しく巻き戻されることがあります。

ペアトレードの仕組み

典型的な例は、大手石油会社2社、決済ネットワーク2社、同じ企業の2種類の株式クラスなど、同じ業種で事業内容の似た2社です。それらの価格は多くの共通の要因によって動きます。明確な理由なく一方が他方に比べて急騰したとき、ペアトレーダーは値上がりしたほうを空売りし、出遅れたほうを買います。関係が維持されれば差は縮まり、市場全体が上昇しても下落しても、この取引は利益を生みます。

ペアトレードの起源は、1980年代のウォール街のトレーディングデスクにあったクオンツチームにさかのぼるとされることが多く、Morgan Stanley のチームがその功労者としてよく挙げられます。広く引用されている2006年の研究で、Gatev、Goetzmann、Rouwenhorst は、米国株で単純なルールを検証しました。正規化した価格が最も近い動きをする銘柄同士を組み合わせ、それらが乖離したときに取引するというものです。過去の超過リターンは確認されましたが、サンプルの後半ほど利益が小さくなっていることもわかり、その後の研究でも同じパターンが報告されています。

相関と共和分

相関と共和分はよく混同されますが、その違いは重要です。

概念 測るもの ペアトレードに有用か
相関 2つの系列のリターンが期間ごとに一緒に上下するかどうか それだけでは不十分。相関の高い2銘柄でも、恒久的に離れていくことがある
共和分 2つの価格系列の何らかの組み合わせ（スプレッド）が定常的、つまり安定した平均に戻る傾向があるかどうか 有用。ペアトレードが実際に賭けているのはこれ

2つの銘柄の日次リターンの相関が高くても、一方が何年にもわたってもう一方より少しずつ速く成長することがあります。その場合スプレッドはトレンドを描き、「割高な」ほうを空売りしたトレーダーは着実に損をします。逆に、共和分の関係にある系列は、日次の相関はそれほど高くなくても、長期的には安定した関係を保つことがあります。

一般的な検定方法は、1987年に Engle と Granger が導入した Engle-Granger の2段階法です。一方の価格をもう一方の価格に回帰させて関係を推定し、次に残差のスプレッドが定常かどうかを検定します。3つ以上の資産を扱う場合はヨハンセン検定を使います。ポートフォリオ全体で相関がどう振る舞うかについては、相関とポートフォリオのリスクを参照してください。

スプレッドの作り方

ヘッジ比率

ヘッジ比率 β は、資産 A の1単位を相殺するのに資産 B が何単位必要かを表します。多くの場合、一定の計算期間にわたって A の価格を B の価格（または対数価格）に回帰させて推定します。

Spread = Price_A − β × Price_B

ドルニュートラルのペアは、買いと売りを同じ金額で持ちます。ベータニュートラルのペアは、市場に対する感応度の違いを調整します。ヘッジ比率は変化していくため、多くのトレーダーはローリングウィンドウで再推定するか、カルマンフィルターを使って継続的に更新します。

半減期

半減期は、スプレッドが平均からの乖離の半分を埋めるのに通常どれくらいかかるかを推定したものです。スプレッドの変化をその前の水準に回帰させて求めます。半減期が5日から20日ならスイングトレードに向いています。半減期が数か月だと資金が拘束され、先に関係が崩れてしまう可能性が高まります。

import numpy as np
import statsmodels.api as sm
from statsmodels.tsa.stattools import coint

def pair_stats(a: np.ndarray, b: np.ndarray):
    """a, b：時点をそろえた価格の配列（対数価格がよく使われる）。"""
    beta = sm.OLS(a, sm.add_constant(b)).fit().params[1]
    spread = a - beta * b
    coint_p = coint(a, b)[1]          # Engle-Granger 検定。p が小さければ共和分の可能性
    lagged = spread[:-1]
    delta = np.diff(spread)
    lam = sm.OLS(delta, sm.add_constant(lagged)).fit().params[1]
    half_life = -np.log(2) / lam if lam < 0 else np.inf
    return beta, coint_p, half_life

エントリーとエグジットのルール

ほとんどのペアトレードのシステムは、スプレッドの zスコア、つまりローリング平均からの距離を標準偏差の個数で表したものを使って取引します。

  • エントリー： z が約+2を上回ったらスプレッドを売り（A を空売りし、B を β 単位買う）、z が約−2を下回ったらスプレッドを買います。
  • エグジット： z が0付近に戻ったら決済します。
  • ストップ： z が±4などの極端な値に達した場合、または取引が半減期の数倍以上続いた場合に決済します。
  • 再検定： 直近のデータで共和分の検定が通らなくなったら、そのペアの取引を停止します。

ペアトレードから統計的裁定へ

統計的裁定は、同じロジックを大規模に適用するものです。1組のペアではなく、統計的裁定のファンドは何百、何千もの小さな買いと売りのポジションを保有することがあります。一般的な手法には次のものがあります。

  • 各銘柄を、同じセクターの同業他社のバスケットに対して取引する。
  • ファクターモデルや主成分分析を使って市場やセクターの動きを取り除き、回帰が見込まれる残差リターンを取引する。Avellaneda と Lee は2010年の論文で、米国株に対するこの手法を説明しました。
  • 回帰のシグナルを、注文フローや出来高の情報と組み合わせた短期モデル。

名前に反して、統計的裁定は、裁定取引戦略で説明している無リスクという意味での裁定ではありません。多数のポジション全体で平均的に成り立つ確率に依存しているのです。

劣化と混雑

エッジの劣化

似たようなモデルを運用するトレーダーが増えるにつれ、狙われるスプレッドはより速く縮まり、機会は小さくなります。最もきれいなシグナルは、より速い競争相手が取ってしまいます。かつては何週間もポジションを保有していた戦略が、今では数分で動かなければならなかったり、まったく機能しなくなったりしていることもあります。

2007年8月のクオンツ・クエイク

2007年8月6日の週、多くのクオンツ型の株式マーケットニュートラル・ファンドが、突然の大きな損失に見舞われました。よく知られた分析で、Khandani と Lo は、おそらく資金の確保や他の部分でのリスク削減のために、1つまたは複数の大手ファンドが急速にポジションを巻き戻したことが引き金になった可能性が高いと論じました。多くのファンドが似たような買いと売りのポジションを持っていたため、強制的な売りがすべてのファンドにとって同時に不利な方向に価格を動かし、さらなるリスク削減を引き起こしたのです。損失の多くは数日のうちに戻りましたが、底値でポジションを削減したファンドは損失を確定させてしまいました。教訓は、戦略がマーケットニュートラルであっても、集中した混雑リスクを抱えうるということです。

計算例

2つの銘柄の推定ヘッジ比率が1.2だとします。過去のスプレッド A − 1.2 × B の平均は2.00ドル、標準偏差は0.50ドルでした。

  • 今日、A は51.50ドル、B は40.00ドルで取引されています。スプレッド = 51.50 − 1.2 × 40.00 = 51.50 − 48.00 = 3.50ドル。
  • z = (3.50 − 2.00) / 0.50 = 3.0 で、エントリー水準の+2を上回っているため、トレーダーはスプレッドを売ります。A を1,000株空売りし（51,500ドル）、B を1,200株買います（48,000ドル）。
  • 2週間後、A は51.00、B は40.75です。スプレッド = 51.00 − 48.90 = 2.10ドル、z = 0.2 となったので、トレーダーは決済します。
  • A の空売りの利益：(51.50 − 51.00) × 1,000 = 500ドル。B の買いの利益：(40.75 − 40.00) × 1,200 = 900ドル。合計1,400ドル。
  • 検算：スプレッドは3.50から2.10へと1.40ドル縮小し、スプレッド1,000単位分を掛けると1,400ドルです。

ここから、4つのレッグの売買手数料、それぞれで支払うスプレッド、空売りした株式の貸株料を差し引きます。空売りの仕組みとコストについては空売りで解説しています。

よくある間違い

  • 相関だけでペアを選ぶ。 相関が高くても、スプレッドが回帰するとは限りません。
  • 何千ものペアを掘り起こして、バックテストの成績が最も良いものを取引する。 候補が十分に多ければ、偶然に共和分の関係があるように見えるペアが出てきます。オーバーフィッティングとデータスヌーピングを参照してください。
  • 構造的な変化を無視する。 合併、スピンオフ、新たな規制、事業構成の変化によって、関係が恒久的に崩れることがあります。
  • スプレッドにストップを置かない。 崩れたペアは、何か月も乖離し続けることがあります。
  • 空売り側のコストを過小評価する。 貸株料、貸株の返還要求（リコール）、空売り規制によって、薄いエッジは消えてしまうことがあります。

よくある質問

ペアトレードは無リスクですか？

いいえ。2つの資産の関係は崩れることがあり、スプレッドは縮まる前にさらに広がることがあり、混雑したポジションは突然巻き戻されることがあります。ペアトレードは市場の方向へのエクスポージャーを減らしますが、別のリスクを加えます。

共和分と相関の違いは何ですか？

相関は、2つの資産のリターンが期間ごとに一緒に動くかどうかを測るものです。共和分は、両者の価格の組み合わせが安定した平均に戻る傾向のあるスプレッドを形成することを意味し、ペアトレードが依拠しているのはこちらです。

ペアトレードではどの zスコアを使うべきですか？

多くのトレーダーは±2前後でエントリーし、0付近でエグジットし、±4などより大きな値にストップを置きます。最適な閾値はコスト、スプレッドの半減期、ペアそのものによって異なり、アウトオブサンプルで検証すべきです。

ペアトレードは今でも通用しますか？

学術研究によれば、戦略が広く知られるにつれて、単純なペアトレードのルールのリターンは時とともに減少しました。機会は今でも存在しますが、以前より小さく、速く、競争が激しくなる傾向があります。
