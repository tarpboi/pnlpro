トレードにおけるオーバーフィッティングとデータスヌーピング

オーバーフィッティング（過剰最適化）とは、トレード戦略を過去データにあまりにも細かく合わせた結果、再現性のあるパターンではなくランダムなノイズを捉えてしまうことです。データスヌーピングはそれに関連する問題で、同じデータで多くのアイデアを試して最も良かったものを残すことにより、運が実力のように見えてしまうことです。この2つが、見事なバックテストを持つ戦略の多くが実運用を始めた途端にお金を失う理由を説明しています。

要点

  • ルール、フィルター、パラメーターを1つ追加するたびに、戦略がノイズに合わせられる自由度が増えます。
  • ランダムな戦略を十分な数だけ試せば、純粋に偶然だけで優れて見えるものが出てきます。
  • 頑健な戦略は幅広いパラメーター値でそれなりの成績を上げます。脆い戦略は鋭いピークの一点でしか機能しません。
  • デフレーテッド・シャープレシオやより厳格な有意水準は、実施した試行の回数に応じて結果を補正します。
  • 最善の防御策は、パラメーターを少なくすること、経済的な根拠を持つこと、手つかずのアウトオブサンプルデータを残すこと、そしてすべての検証を正直に記録することです。

オーバーフィッティングの典型的な姿

市場価格には、わずかなシグナルと大量のノイズが含まれています。十分に柔軟なモデルなら過去のどんな価格の経路でも完璧に説明できますが、説明しているものの大半はノイズであり、ノイズは繰り返されません。

カーブフィッティングされた戦略の典型的な兆候は次のとおりです。

  • 「RSI が27を下回り、出来高が平均の1.3倍で、火曜日で、17日平均が上昇しているときに買う」のように、条件が多い。
  • 最も良いスコアが出たから選ばれたことが明らかな、不自然なパラメーター値。
  • パラメーターをわずかに動かすと崩れてしまう成績。
  • インサンプルでは滑らかな資産曲線が、アウトオブサンプルでは横ばいか右肩下がりになる。
  • 少数の大きな取引によって結果が左右されている。

簡単な経験則として、戦略の自由度（パラメーター、フィルター、ルールの選択）が多いほど、それを正当化するためにより多くの取引とより長い過去データが必要になります。

多重検定とデータスヌーピング

本物のエッジをまったく持たない戦略を100個検証するとします。標準的な5%の有意水準を使えば、純粋に偶然だけで約5個が統計的に有意に見えると予想されます。その5個だけを報告すれば、存在しないエッジを5つ「発見」したことになります。

これは悪意がなくても起こります。あるリサーチャーが移動平均線のクロスオーバーを、短期10通り・長期10通りの期間（100通りの組み合わせ）で試し、ストップロスの設定を3通り（300通り）、市場を2つ（600通り）加えたとします。最終報告に載るのが最も良いものだけだとしても、その一つひとつが別々の検定です。

データスヌーピングは人をまたいでも起こります。何千人ものトレーダーが、同じ人気のデータセットを掘り返しています。書籍やフォーラムで公開されている戦略は、多くの場合、膨大で目に見えない探索を生き残ったものです。

運はどこまで大きくなりうるか

バックテストから推定したシャープレシオにはノイズが多く含まれます。本当のエッジを持たない戦略の場合、推定された年率シャープレシオの標準誤差はおよそ 1 / √(データの年数) です。5年分の日次データなら、約 1 / 2.24 ≈ 0.45 になります。

エッジがゼロの独立した N 個の戦略のうち、最良の結果の期待値は N とともに大きくなります。100回の試行では、標準正規分布から100回引いたときの最大値の期待値は標準偏差約2.5個分なので、最良のバックテストはおよそ 2.5 × 0.45 ≈ 1.1 のシャープレシオを示すことになります。1,000回の試行では、最大値の期待値は標準偏差約3.2個分で、シャープレシオはおよそ1.45になります。1.1から1.5のシャープレシオは多くのトレーダーが喜んで実運用に移す数字ですが、ここでは純粋なノイズから生まれています。

自分で確かめることもできます。

import numpy as np

rng = np.random.default_rng(0)
years, n_strategies = 5, 100
# 真のエッジがゼロで、日次ボラティリティ1%の日次リターン
daily = rng.normal(0.0, 0.01, size=(n_strategies, 252 * years))
sharpes = np.sqrt(252) * daily.mean(axis=1) / daily.std(axis=1, ddof=1)
print(f"Best Sharpe among {n_strategies} random strategies: {sharpes.max():.2f}")
print(f"Median Sharpe: {np.median(sharpes):.2f}")

実際の戦略のバリエーションは互いに独立ではなく相関しているため、実質的な試行回数は減りますが、原理は変わりません。

パラメーターの安定性

頑健な戦略は、ある一点だけでなく、パラメーターの近傍で機能するはずです。よく使われる確認方法は、2つのパラメーターにわたる成績のヒートマップです。たとえば移動平均線の戦略なら、一方の軸に短期の期間、もう一方の軸に長期の期間を取ります。

ヒートマップのパターン 解釈
まずまずの結果が広い台地状に広がっている アイデアが何か本物を捉えている可能性が高い。台地の中央の値を選ぶ
成績の悪い領域に囲まれた明るいピークが1つだけ ノイズの可能性が高い。「最良」の設定は偶然の産物
隣り合うセルの間で結果の符号が反転する 戦略とパラメーターの間に安定した関係がない

時期や市場をまたいだ安定性も重要です。トレンドシステムが同じ設定で20の先物市場のうち15で機能するなら、1つの市場で専用の設定でしか機能しないシステムよりはるかに説得力があります。

統計的な補正

より厳格な閾値

戦略の平均リターンの t統計量は、おおよそ年率シャープレシオに √(年数) を掛けたものです。5年間でシャープレシオが1.0なら t ≈ 2.24 となり、約2という伝統的な閾値をクリアします。ファクター研究に関する2016年の論文で、Harvey、Liu、Zhu は、これまでに非常に多くのファクターが検証されてきたため、新しいファクターは約3の t統計量をクリアすべきだと論じました。シャープレシオ1.0の場合、それには約9年分のデータが必要です（√9 = 3）。

デフレーテッド・シャープレシオ

Bailey と López de Prado は2014年にデフレーテッド・シャープレシオを提案しました。その考え方は次の問いを立てることです。いくつの戦略を試したか、試行の間でどれだけばらつきがあったか、バックテストの期間はどれだけか、リターンの歪度と裾の厚さはどうか、を踏まえたとき、観測された最良のシャープレシオが選択の運ではなく本物のエッジを反映している確率はどれくらいか。この補正は、試行回数が増えるほどハードルを引き上げます。これを正直に使うには、検証したバリエーションの数を記録しておく必要があり、それ自体が価値ある規律です。同じ著者らと共著者は、多数のデータ分割にわたってインサンプルとアウトオブサンプルの順位を比較することに基づく、バックテスト・オーバーフィッティング確率（PBO）と呼ばれる指標も提案しています。

オーバーフィッティングを避ける方法

  1. 理由から始める。 経済的または行動的な説明に裏づけられた戦略は、統計的な偶然である可能性が低くなります。
  2. シンプルに保つ。 キリのよい、理にかなった値を持つ少数のパラメーターを選びましょう。
  3. すべての検証を記録する。 失敗したものも含めて、試行の回数を数えましょう。
  4. データを取っておく。 アウトオブサンプルの期間を確保し、最後に一度だけ使いましょう。
  5. 再調整が必要な戦略にはウォークフォワード検証を使う。
  6. 市場や期間をまたいで検証する。 本物の効果は、通常、関連する銘柄にも現れます。
  7. 結果に負荷をかける。 コストを2倍にする、エントリーを1バー遅らせる、上位5%の取引を取り除くなどして、何が生き残るかを確かめましょう。
  8. ペーパートレードを経て、少額で取引する。 実運用の成績こそが最後のアウトオブサンプル検証です。

機械学習では、柔軟なモデルがノイズを非常に効率よく記憶してしまうため、オーバーフィッティングのリスクはさらに大きくなります。心理的な側面もあります。確証バイアスによって、リサーチャーは望んでいた結果が見つかった時点で探索をやめてしまうのです。

計算例

あるトレーダーが、1つの株価指数先物で8年分のデータを使い、トレンドフォローのブレイクアウト・システムを検証します。エントリーの計算期間を10日から100日まで5日刻み（19通り）、エグジットの計算期間を5日から50日まで5日刻み（10通り）で試し、合計190通りの組み合わせになります。最良の組み合わせであるエントリー65・エグジット15は、1.3のシャープレシオを示しました。

  • 8年分のデータでは、エッジがゼロの場合のシャープレシオの標準誤差は約 1 / √8 ≈ 0.35 です。
  • この190回の試行が独立したコイン投げのように振る舞うとすれば、最良の結果の期待値は標準誤差約2.7個分、つまり運だけでシャープレシオ約0.95になります。
  • 観測された1.3はそれを上回っており、やや心強い結果ですが、試行は独立ではなく、結果は1つの市場から得られたものです。

次にトレーダーはヒートマップを確認し、65日の単独のピークを除けば、40日から90日のエントリーではシャープレシオが0.6から1.0の間に収まること、そして同じ設定が他のいくつかの指数先物でも機能することを確認します。現実的な期待値は1.3のピークではなく、この台地です。台地の中央の値を選び、実運用ではシャープレシオ0.5から0.8程度を見込むほうが、より誠実な計画です。

よくある間違い

  • うまくいったバリエーションだけを報告する。 試行の回数も結果の一部です。
  • 小数点以下2桁まで最適化する。 パラメーターの微調整はノイズに合わせることになります。
  • 過去の負けトレードを取り除くためにフィルターを追加する。 特定の損失を解消するフィルターは、いずれも過去データに合わせている可能性が高いです。
  • アウトオブサンプルのデータを再利用できると考える。 見た後でルールを調整すれば、それはインサンプルです。
  • シャープレシオの高い短期間のバックテストを信用する。 サンプルが短いと、極端な推定値が簡単に出てしまいます。

よくある質問

トレードにおけるカーブフィッティングとは何ですか？

カーブフィッティングとは、戦略のルールとパラメーターを過去の価格にぴったり合うまで調整することです。強力なバックテストが得られますが、戦略が再現性のあるパターンではなくノイズを学習してしまっているため、通常は実運用で失敗します。

自分の戦略がオーバーフィッティングしているかどうかは、どうすればわかりますか？

警告サインには、パラメーターが多いこと、パラメーターを少し変えるだけで成績が崩れること、インサンプルとアウトオブサンプルの結果の差が大きいこと、結果が少数の取引に依存していることがあります。手つかずのデータや他の市場で検証するのが、最も直接的な確認方法です。

デフレーテッド・シャープレシオとは何ですか？

Bailey と López de Prado が提案した統計量で、観測されたシャープレシオを、試した戦略の数、バックテストの期間、リターンの非正規性に応じて補正します。結果が選択の運ではなく本物のエッジを反映している確率を推定するものです。

最適化は常に悪いことですか？

いいえ。妥当なパラメーターを選ぶことは、どんな戦略の構築にも含まれるプロセスです。問題なのは、自由な選択肢が多すぎてデータが少なすぎる状態での過度な最適化と、いくつのバリエーションを検証したかを考慮しないことです。
