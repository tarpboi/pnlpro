トレンドフォローとは、価格が上昇している資産を買い、価格が下落している資産を売る（または空売りする）システマティックな戦略で、トレンドが続く限りポジションを保有し続けます。アルゴリズム取引の中でも最も古く、最もよく研究されている手法の一つで、多くのマネージド・フューチャーズ・ファンドが採用しています。小さな損失を頻繁に出し、ときどき大きな利益を上げる傾向があるため、ある時期には利益を生む一方、別の時期には心理的に続けるのが難しい戦略です。

要点

  • トレンドフォローの土台は時系列モメンタムです。過去の実績では、資産自身の過去のリターンが近い将来の方向を予測するのに役立ってきました。
  • 典型的なシステムは、価格のブレイクアウトや移動平均線を使い、ボラティリティに基づくポジションサイジングと多数の市場への分散を組み合わせます。
  • リターンは正の歪度（ポジティブスキュー）を持つ傾向があります。小さな損失が多く、大きな利益が少数です。
  • 何年も続くこともある長い横ばいや損失の期間は、この戦略にとって普通の特徴です。
  • トレンドフォローは、長期化した危機の一部では過去に好成績を上げてきましたが、急激で突然の暴落に対する信頼できるヘッジではありません。

時系列モメンタム

研究には2種類のモメンタムが登場します。クロスセクション・モメンタムは資産同士を比較して相対的な勝ち組を買うもので、1993年に Jegadeesh と Titman が米国株で実証しました。これについてはモメンタムトレードで取り上げています。時系列モメンタムは各資産を単独で見るもので、過去数か月のリターンがプラスなら買い、マイナスなら売ります。

2012年の論文で、Moskowitz、Ooi、Pedersen は、株価指数、通貨、商品、債券を含む数十の先物市場で時系列モメンタムを実証しました。過去12か月のリターンは翌月のリターンを予測する傾向があり、その効果はより長い時間軸では一部反転することがわかりました。提示されている説明には、投資家がニュースに最初は過小反応し、その後に過剰反応すること、さらにヘッジやリスク管理のためのフローが長期間にわたって価格を同じ方向に押すことなどがあります。

CTA とマネージド・フューチャーズ

プロのトレンドフォロワーの多くは、顧客のために先物取引を運用する登録業者である商品投資顧問業者（CTA）です。この業界はマネージド・フューチャーズとも呼ばれます。典型的な分散型のトレンドプログラムは次のようなものです。

  • 株価指数、国債、金利、通貨、エネルギー、金属、農産物など、流動性の高い先物とFXの幅広い市場で取引する。
  • 買いと売りの両方のポジションを取るため、上昇相場だけでなく下落相場でも利益を上げられる。
  • 各ポジションのサイズをボラティリティで決めるため、値動きの穏やかな債券先物と値動きの激しい原油先物が、おおむね同等のリスクを担う。
  • ポジションを数週間から数か月保有する。

分散が中心的な役割を果たします。単一の市場がトレンドを描くのはときどきにすぎませんが、50以上の市場を見れば、たいていどこかでトレンドが出ています。トレンドフォロー・ファンド全体としては、2008年や2022年など、長期化した弱気相場やインフレショックの一部で利益を上げており、この戦略が「クライシス・アルファ」と呼ばれることがあるのはそのためです。しかし2010年代の大半は、多くのトレンドフォロワーにとって苦しい時期でしたし、事前にトレンドのない突然の暴落は彼らに打撃を与えることがあります。

代表的なトレンドシステム

ブレイクアウト・システム

ブレイクアウト・システムは、価格が過去 N 日間の最高値を上回ったら買い、過去 N 日間の最安値を下回ったら空売りします。最高値と最安値を結んだ線は、システマティックなトレンドトレードの初期の先駆者である Richard Donchian にちなんで、ドンチャン・チャネルと呼ばれます。手仕舞いには、反対方向のより短いチャネルやトレーリングストップを使います。

移動平均線システム

移動平均線のシステムは、短期の平均が長期の平均を上回っているとき（たとえば50日線が200日線より上）に買い、下回っているときに売ります。単一の平均線に対する価格の位置や、平均線の傾きを使う変形版もあります。

リターンに基づくシグナル

過去3か月、6か月、12か月のリターンの符号をそのまま使うシステムもあり、多くの場合、特定の期間への依存を減らすために複数の計算期間を組み合わせます。

ブレイクアウトのロジックは数行で書けます。チャネルを1バーずらして、シグナルが現在のバー自身の高値や安値を決して使わないようにし、各日のポジションは翌日のリターンに適用します。

import pandas as pd

def donchian_positions(close: pd.Series, entry=55, exit=20) -> pd.Series:
    upper = close.rolling(entry).max().shift(1)
    lower = close.rolling(entry).min().shift(1)
    exit_high = close.rolling(exit).max().shift(1)
    exit_low = close.rolling(exit).min().shift(1)
    pos, out = 0, []
    for px, up, lo, xh, xl in zip(close, upper, lower, exit_high, exit_low):
        if pos == 0 and px > up:
            pos = 1
        elif pos == 0 and px < lo:
            pos = -1
        elif pos == 1 and px < xl:
            pos = 0
        elif pos == -1 and px > xh:
            pos = 0
        out.append(pos)
    return pd.Series(out, index=close.index)

タートルズ

トレンドフォローで最も有名な逸話は、シカゴの成功した先物トレーダーである Richard Dennis と、そのパートナーの William Eckhardt にまつわるものです。1980年代初め、2人はトレードを教えることができるかどうかで意見が分かれました。Dennis は新聞広告で訓練生を募集し、ルールに基づくトレンドシステムを短期間で教え込み、取引用の資金を与えました。訓練生たちはタートルズとして知られるようになりました。

後に元タートルズが公表した記録によれば、そのシステムは、ドンチャン・ブレイクアウト（20日版と55日版）、反対方向のより短いブレイクアウトでの手仕舞い、直近のボラティリティの数倍の距離に置くストップ、そして各市場の典型的な1日の値動きが資産の小さな一定割合になるように調整したポジションサイズで構成されていました。訓練生の何人かは、その後自分のファンドを運用するようになりました。この出来事は、規律あるシステムが直感より重要であることの証拠としてよく引用されますが、有名な成功談の常として、語り継がれ方には生存者バイアスも影響しています。

正の歪度と長い横ばい期間

トレンドフォローの勝率は通常、低くなります。多くのブレイクアウトはすぐに失敗し、小さな損失で決済されます。利益は、大きく持続的な値動きを捉えた少数の取引からもたらされます。

このパターンは正の歪度、つまりリターンの分布に長い右側の裾を生み出します。勝つことが多く、ときどき大きく負ける傾向のある平均回帰とは正反対です。

代償は心理面にあります。小さな損失が長く続くのは普通のことで、戦略が何年も資産の最高値を更新できないこともあります。多くのトレーダーは、まさにそうした時期、次の大きなトレンドの直前にトレンドシステムを放棄してしまいます。

計算例

勝率が低い場合の期待値

あるトレンドシステムの勝率は35%です。平均的な勝ちトレードは3R、平均的な負けトレードは1R の損失で、R は1取引あたりのリスク額です。

  • 期待値 = 0.35 × 3R − 0.65 × 1R = 1.05R − 0.65R = 1取引あたり0.40R。
  • 1取引あたり1,000ドルをリスクにさらすなら、多数の取引を通じて平均で1取引あたり400ドルになります。
  • ある特定の10回連続の取引がすべて負けになる確率は 0.65^10 ≈ 1.3% です。数百回の取引を重ねれば、どこかでそれほど長い連敗が起きる可能性は高くなります。

ボラティリティに基づくサイジング

100,000ドルの口座で、1取引あたり1%、つまり1,000ドルをリスクにさらすとします。ある株式は50ドルで取引されており、ATR（アベレージ・トゥルー・レンジ）は1.25ドルです。ストップは2 ATR 離れた位置、つまり2.50ドル先に置きます。

  • ポジションサイズ = 1,000 / 2.50 = 400株で、金額にして20,000ドルです。
  • ATR が0.50ドルの値動きの穏やかな株式なら、ストップは1.00ドル先になり、同じリスク額で1,000株のポジションになります。

これで、値動きが穏やかでも激しくても、各ポジションが同程度のリスクを担うことになります。

よくある間違い

  • 1つの市場だけで取引する。 分散がなければ、長い横ばい期間がさらに長くなります。
  • 損失の後にシステムを無視する。 次のシグナルを見送ると、連敗を取り返してくれるはずの取引を逃すことがよくあります。
  • 計算期間を精密に最適化する。 トレンドのシグナルは幅広い計算期間で頑健です。微調整はほとんどの場合ノイズに合わせているだけです。
  • ロールのコストとギャップを無視する。 先物はロールが必要で、ストップは一夜のうちにギャップで飛び越えられることがあります。先物取引の基礎を参照してください。
  • 滑らかな資産曲線を期待する。 プロのトレンドプログラムでも、20%以上のドローダウンはよくあることでした。

よくある質問

トレンドフォローは今でも通用しますか？

トレンドフォローには、多くの市場と数十年にわたる長い実績がありますが、成績は時期によって大きく異なり、何年も低調なリターンが続く期間もあります。将来の結果は誰にも約束できず、コストや混雑がリターンを押し下げることもあります。

トレンドフォローとモメンタムの違いは何ですか？

トレンドフォロー、つまり時系列モメンタムは、各資産自身の過去のリターンを見ます。クロスセクション・モメンタムは資産同士を順位づけし、たとえすべてが下落していても相対的な勝ち組を買います。

トレンドフォロワーの勝率が低いのはなぜですか？

多くのブレイクアウトはすぐに反転するため、システムは頻繁に小さな損失を出します。利益は、典型的な損失よりはるかに大きく伸びる少数の大きなトレンドからもたらされ、それによって勝率が50%を下回っていても全体の結果はプラスになりえます。

トレンドフォローに最適な市場はどこですか？

プロのトレンドフォロワーは通常、流動性の高い先物と通貨の分散されたポートフォリオで取引します。流動性はコストを低く抑え、分散はどの時点でもいずれかの市場でトレンドが出ている可能性を高めます。
