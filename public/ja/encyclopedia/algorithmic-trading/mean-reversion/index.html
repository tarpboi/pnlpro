平均回帰トレード

平均回帰（ミーンリバージョン）とは、直近の平均から大きく離れた価格やスプレッドが、平均に向かって戻っていく傾向のことです。平均回帰戦略は、異常に急な下落の後に買い、異常に急な上昇の後に売ることで、その動きが行き過ぎや一時的な需給の偏りだったことに賭けます。勝つことが多く、負けることはまれでも負けるときは大きいという特徴があるため、穏やかな相場では魅力的ですが、トレンドが定着すると危険です。

要点

  • 平均回帰は短期的な価格の極端な動きが一部戻ることに賭け、トレンドフォローはその逆に賭けます。
  • zスコアは、価格が平均から標準偏差何個分離れているかを測るもので、「極端」を定義する標準的な方法です。
  • ボリンジャーバンドや短い期間設定の RSI を使ったシステムは、同じ考え方を個人向けにした人気の手法です。
  • リターンは通常、負の歪度（ネガティブスキュー）を持ちます。勝率は高いものの、ときどき大きな損失が出ます。
  • 主なリスクは相場局面（レジーム）の変化で、行き過ぎた価格が戻らずにそのまま進み続けることです。

価格が回帰する理由

短い時間軸で価格を平均に押し戻すメカニズムはいくつかあります。

  • 流動性の需要。 急いで手仕舞う必要のある大口の売り手は、価格を適正価値より下に押し下げます。その売りを吸収するトレーダーは対価を求め、それは価格が回復したときに得られます。
  • 過剰反応。 トレーダーはニュース、センチメント、急な値動きに過剰に反応することがあり、価格は一部修正されます。
  • ビッド・アスク・バウンス。 約定はビッドとアスクの間を行き来するため、記録された価格に統計的なリバーサルが生じますが、これを実際に利益として取ることはできません。約定価格でのバックテストは、これを取引可能なエッジと勘違いすることがあります。
  • 構造的なアンカー。 密接に関連する2つの資産の価格差など、一部のスプレッドは経済的な理由で結びついています。これがペアトレードの基盤です。

短期リバーサル

Jegadeesh や Lehmann の研究をはじめとする1990年頃の学術研究は、過去1週間または1か月のリターンが最も悪かった米国株は、その後の1週間または1か月でアウトパフォームする傾向があり、最も好成績だった銘柄は出遅れる傾向があることを見出しました。この短期リバーサル効果は、3か月から12か月の勝ち組が勝ち続ける傾向にあった中期のモメンタムと並存しています。両者は矛盾しません。異なる時間軸で働いているのです。

研究における短期リバーサルの利益の多くは、小型で流動性の低い株式から生じており、取引コストに敏感です。現実的なコストを差し引くと、単純な形の戦略は、生の数字が示すよりもはるかに魅力が薄れます。

「行き過ぎ」の測り方：zスコア

zスコアは、現在の価格が直近の推移に比べてどれだけ異常かを表します。

z = (Price − Moving average) / Standard deviation of price over the same window

（価格から移動平均を引き、同じ期間の価格の標準偏差で割ったもの）

zスコアが−2なら、価格が平均より標準偏差2個分下にあることを意味します。典型的なルールは次のとおりです。

  • z が−2を下回ったら買いで入り、z が+2を上回ったら売りで入る。
  • z が0（平均）に戻ったら、または時間切れのストップ（タイムストップ）で手仕舞う。
  • 必要に応じて、z が±4などの極端な値に達したらストップを置く。
import pandas as pd

def zscore_positions(close: pd.Series, lookback=20, entry=2.0, exit=0.0) -> pd.Series:
    mean = close.rolling(lookback).mean()
    std = close.rolling(lookback).std()
    z = (close - mean) / std
    pos, out = 0, []
    for zt in z:
        if pos == 0 and zt < -entry:
            pos = 1
        elif pos == 0 and zt > entry:
            pos = -1
        elif pos == 1 and zt >= -exit:
            pos = 0
        elif pos == -1 and zt <= exit:
            pos = 0
        out.append(pos)
    return pd.Series(out, index=close.index)

ポジションは終値から計算されるため、バックテストで説明しているとおり、先読みバイアスを避けるには次のバーのリターンに適用する必要があります。

個人トレーダーに人気のシステム

ボリンジャーバンドの回帰

ボリンジャーバンドは、移動平均線と、その上下に標準偏差2個分のバンドを描いたものです。下のバンドで買って中央のバンドで手仕舞うのは、本質的に、−2でエントリーし0で手仕舞う zスコアのシステムと同じです。

短い期間設定の RSI

RSIは通常14期間を使いますが、平均回帰のトレーダーははるかに短い設定を使うことがよくあります。トレーダーで著述家の Larry Connors が広めた2期間 RSI は、ごく短期的な極端な動きを示します。よくあるパターンは、価格が200日平均を上回っている状態で2期間 RSI が10を下回ったら買い、RSI が回復するか、価格が短期の移動平均線を上回って引けたら手仕舞うというものです。長期のフィルターは、上昇トレンドの押し目だけを買うことで、「落ちてくるナイフ」をつかむリスクを減らそうとするものです。

トレンドフィルターとタイムストップ

多くの回帰システムは、強いトレンドに逆らう取引を避けるフィルターと、期待した反発が数本のバーのうちに起きなければ手仕舞うタイムストップを加えています。すぐに回帰しない取引は、状況が変わったサインであることが多いからです。

負の歪度

平均回帰戦略は通常、勝率が高くなります。行き過ぎた価格の大半は少しは反発するからです。しかし負けトレードは、価格が動き続けたケースです。悪材料で10%下落した後にさらに30%下落する株式や、長いレンジを抜け出した通貨などです。

このパターンは負の歪度、つまりまれな大損失という長い左側の裾（テール）を生みます。資産曲線は何年も滑らかに見えた後、数か月分の利益を数日で吐き出すことがあります。これはトレンドフォローの鏡像です。

平均回帰が失敗するとき

  • 相場局面の変化。 レンジ相場がトレンド相場に変わるもので、多くはファンダメンタルズに関わるショックの後に起こります。
  • ニュース主導の値動き。 決算サプライズ、買収、不正の発覚、中央銀行の方針転換は、資産の価格を恒久的に修正することがあります。過剰反応に見えるものが、実は市場が新しい情報に適応している過程かもしれません。
  • 流動性危機。 広範な売りの局面では、多くの資産が一緒に行き過ぎたままになり、普段は流動性を供給しているトレーダーも売りを強いられます。
  • ギャップ。 価格は一夜でどんなストップも飛び越えることがあります。
  • 混雑。 多くのファンドが似たような回帰戦略を運用していると、彼らが一斉に手仕舞うことで行き過ぎがさらに悪化することがあります。2007年8月に株式マーケットニュートラル・ファンドに起きたのがそれです。

計算例

zスコアのトレード

ある株式の20日間の平均終値が100ドル、20日間の標準偏差が2ドルだとします。今日の終値は95ドルです。

  • z = (95 − 100) / 2 = −2.5 で、エントリーの閾値である−2を下回っているため、システムは翌日の寄り付きで200株を、たとえば95.20ドルで買います。
  • 4日後、終値は平均に近い99.80ドルになります（平均と標準偏差が変わらないと仮定すると z ≈ −0.1）。そのためポジションは保有したままです。
  • 翌日の終値は100.30ドルで z がプラスに転じ、ポジションはその次の寄り付きの100.10ドルで売却されます。
  • 粗利益 = (100.10 − 95.20) × 200 = 980ドル（コスト控除前）。

負の歪度の罠

ある回帰システムの勝率は75%、平均利益は1%、平均損失は2.5%です。

  • 期待値 = 0.75 × 1% − 0.25 × 2.5% = 0.75% − 0.625% = 1取引あたり+0.125%。
  • ストップのない取引が1回、ギャップで15%の損失を出すと、15 / 0.125 = 120回分の平均的な取引の期待利益が吹き飛びます。

平均回帰では、ほとんどの戦略よりもポジションサイズの上限とギャップリスクへの備えが重要になるのはこのためです。

よくある間違い

  • 際限なくナンピンする。 負けている回帰トレードに買い増しすると、小さな損失が壊滅的な損失に変わることがあります。
  • ストップもタイムストップもない。 「必ず戻るはずだ」はリスク管理計画ではありません。
  • ごく小さな目標で約定価格を使ってバックテストする。 ビッド・アスク・バウンスとスプレッドのせいで、無価値なシグナルが利益を生むように見えることがあります。
  • ニュースを無視する。 重要な発表の後に行き過ぎた価格は、材料のない行き過ぎとはまったく別物です。
  • 勝率で判断する。 80%の勝率も、損失の大きさがわからなければ何も語りません。

よくある質問

トレードにおける平均回帰とは何ですか？

平均回帰とは、平均から大きく離れた価格は平均に向かって戻る傾向がある、という考え方です。トレーダーは、急落の後に買い、急騰の後に売ることでこれを利用し、通常は手仕舞いのルールを明確に定めておきます。

平均回帰はトレンドフォローより優れていますか？

一般的にどちらが優れているということはありません。平均回帰はレンジ相場で、トレンドフォローはトレンド相場で機能する傾向があり、リターンのパターンも異なります。平均回帰は小さな勝ちが頻繁でまれに大きな負けがあり、トレンドフォローはその逆です。

平均回帰ではどの zスコアを使うべきですか？

エントリーの閾値は標準偏差±2個分程度、手仕舞いはゼロ付近が一般的です。適切な値は市場、計算期間、コストによって異なり、細かく最適化するのではなく、アウトオブサンプルで検証すべきです。

平均回帰戦略が破綻するのはなぜですか？

トレンド、危機、ニュースによるショックの最中に、さらに逆行するポジションを抱え続けることが多いからです。レバレッジやナンピンと組み合わさると、そうした取引が数回あるだけで何年分もの小さな利益が消えてしまいます。
