バリュエーション指標

バリュエーション指標とは、企業の株価（時価）を、利益、売上高、簿価、キャッシュフローといった事業の尺度と比べるものです。ある株が、その銘柄自身の過去、競合他社、あるいは市場全体と比べて割安に見えるか割高に見えるかを、手早く判断する方法になります。ただし指標は近道であって答えではありません。低い指標はお買い得を示すこともあれば衰退中の事業を示すこともあり、高い指標は急成長を示すこともあれば行き過ぎた楽観を示すこともあります。

要点

  • 各指標は株価をそれぞれ異なるファンダメンタルズと比べるため、それぞれに死角があります。アナリストは複数の指標を組み合わせて使います。
  • 企業価値（EV）ベースの指標は負債と現金を考慮するため、財務状況の異なる企業を比べる際にはPERより優れています。
  • 指標は文脈の中でしか意味を持ちません。企業は市場全体ではなく、同じセクターや自社の過去と比べましょう。
  • 低い指標は本当の問題（「バリュートラップ」）を反映していることがあり、高い指標は力強い成長によって正当化されることがあります。
  • バリュエーションは短期のタイミングについてはほとんど何も教えてくれません。割高な資産が何年もさらに割高になることがあります。

主な指標

以下の表では、全体を通して1つの例の企業を使います。

  • 株価：$50.00、発行済株式数：1億株、したがって時価総額は50億ドル。
  • 過去12か月のEPS：$2.50（純利益2億5,000万ドル）。アナリストによる来年度のEPS予想：$3.00。
  • 予想される年間EPS成長率：15%。
  • 売上高：20億ドル。簿価（株主資本）：25億ドル。
  • 負債：15億ドル。現金：5億ドル。
  • EBITDA：6億ドル。フリーキャッシュフロー：2億5,000万ドル。年間配当：1株あたり$1.00。

（表中のbnは10億ドルを表します。）

指標 計算式 計算例 結果
PER（実績） 株価 / 過去12か月のEPS 50.00 / 2.50 20.0倍
予想PER 株価 / 来年度の予想EPS 50.00 / 3.00 16.7倍
PEG PER / 予想EPS成長率（%） 20.0 / 15 1.33
PSR（株価売上高倍率） 時価総額 / 売上高 5.0bn / 2.0bn 2.5倍
PBR（株価純資産倍率） 時価総額 / 簿価 5.0bn / 2.5bn 2.0倍
EV/EBITDA (時価総額 + 負債 − 現金) / EBITDA (5.0 + 1.5 − 0.5)bn / 0.6bn = 6.0 / 0.6 10.0倍
FCF利回り フリーキャッシュフロー / 時価総額 0.25bn / 5.0bn 5.0%
配当利回り 1株あたり年間配当 / 株価 1.00 / 50.00 2.0%

株価収益率（PER）

PERは、投資家が年間利益1ドルに対して何ドルを支払っているかを示します。PERが20なら、市場はその企業を現在の利益の20年分と評価しているということです。その逆数である益利回り（ここでは1 / 20 = 5%）を使えば、株式を債券利回りとおおまかに比べることができます。PERは利益がマイナスのときには意味をなさず、利益が一時的に落ち込んだり膨らんだりしているときにはゆがみます。

予想PERは、過去の利益ではなくアナリストの予想を使います。市場は将来を織り込むため、より的を射た指標ですが、その信頼性は予想の信頼性を超えず、先の年度の予想ほど楽観的になる傾向があります。

PEGレシオ

PEGはPERを予想成長率で割ったもので、PERが高くても急成長している企業が妥当に見えることがあります。PEGが1前後なら適正だとよくいわれますが、これは経験則であって法則ではありません。PEGは実現しないかもしれない成長予想に大きく依存し、負債やリスクを無視しています。

株価売上高倍率（PSR）

PSRは時価総額を売上高と比べるものです。まだ利益の出ていない若い企業や、利益率が一時的に落ち込んでいる事業に役立ちます。弱点は、売上高は利益ではないことです。利益率の薄い企業は、利益率の厚い企業よりもはるかに低いPSRが妥当です。

株価純資産倍率（PBR）

PBRは時価総額を会計上の株主資本と比べるものです。銀行、保険会社、製造業のように、資産の大きな事業で最も役に立ちます。こうした事業では、貸借対照表が事業の価値をそれなりに反映しているからです。ソフトウェアや消費者ブランドではあまり役に立ちません。主な資産であるコード、顧客、評判の大部分が貸借対照表に載らないからです。

EV/EBITDA倍率

企業価値（EV）とは、株主と債権者を合わせた事業全体の価値で、時価総額に負債を足し、現金を引いたものです。EBITDAは利払い・税金・償却前利益のことで、営業上の現金利益のおおまかな代わりになります。EV/EBITDAは、負債の水準や税務状況が異なる企業の比較や、買収の分析で広く使われています。EBITDAは設備投資を無視するため、通信会社や航空会社のように絶えず再投資が必要な事業を実態より良く見せてしまいます。

フリーキャッシュフロー利回り

FCF利回りは、事業がその時価総額に対してどれだけのフリーキャッシュを生み出しているかを示します。利回り5%とは、企業が毎年時価総額の5%に相当する現金を生み出しているということで、それを配当、自社株買い、負債の削減に充てることができます。現金は会計上の利益より調整しにくいため、多くの投資家はPERより正直な尺度だと考えています。フリーキャッシュフローの計算方法は決算と財務諸表を参照してください。

配当利回り

配当利回りは、年間配当を株価で割ったものです。高い利回りは、成熟して現金の豊富な事業を意味することもあれば、市場が減配を予想して株価が暴落したことを意味することもあります。フリーキャッシュフローで配当をまかなえているかを確認しましょう。

計算例：負債が重要な理由

例の企業を、時価総額もEBITDAも同じで、負債がはるかに多い競合他社と比べてみましょう。

例の企業 競合他社
時価総額 $5.0bn $5.0bn
負債 $1.5bn $4.0bn
現金 $0.5bn $0.0bn
企業価値 $6.0bn $9.0bn
EBITDA $0.6bn $0.6bn
EV/EBITDA 10.0倍 15.0倍

両社の純利益が同じなら、PERも同じになり、PERによるスクリーニングでは同じくらい割安と評価されるでしょう。しかし実際には、競合他社の事業全体を買うには50%多くのコストがかかります。買い手は30億ドル多い純有利子負債（40億ドル対10億ドル）を引き受けることになるからです。また、債権者が先に支払いを受けるため、競合他社の株主はより大きなリスクを負っています。だからこそ、財務状況が異なる場合、アナリストはEVベースの指標を好むのです。

セクターの文脈

成長率、利益率、必要な設備投資、リスクが異なるため、典型的な指標の水準は業種によって大きく異なります。

セクターの種類 アナリストが重視する指標 理由
銀行・保険 PBR、PER、配当利回り 貸借対照表そのものが事業
ソフトウェア・高成長テック PSR、EV/売上高、予想PER、FCF利回り 利益が小さいか、再投資に回されていることがある
公益・通信 配当利回り、EV/EBITDA 安定したキャッシュフローと多額の負債
エネルギー・鉱業 EV/EBITDA、FCF利回り、景気サイクル全体でのPBR 利益がコモディティ価格とともに大きく変動する
不動産投資信託（REIT） 株価/FFO（運用から得られる資金）倍率、配当利回り 減価償却が純利益をゆがめる

景気敏感株では、利益がピークにあるサイクルの天井でPERが最も低く見え、利益が落ち込んでいる底で最も高く見えることがよくあります。PERが低いからといって景気敏感株を買うのは、歴史的に見て、天井付近で買ってしまうよくあるパターンでした。

国や指数の文脈も重要です。米国のようにテクノロジー企業の多い市場は、欧州の大部分、英国、香港のように銀行、エネルギー、資本財に偏った市場よりも、平均的に高い指標で取引される傾向がありました。その差の一部は、「割安さ」ではなくセクター構成の違いを反映しています。

バリュエーションはタイミングの道具としては不十分

バリュエーションは、ファンダメンタルズ分析全般と同じく、長期の期待リターンが高くなりそうか低くなりそうかは教えてくれますが、今後数週間から数か月に何が起こるかについては、歴史的に頼りにならない指針でした。経済学者のロバート・シラーが広めた景気循環調整後PER（CAPE、シラーPER）のような市場全体の尺度は、10年以上のリターンとはある程度の関係を示してきましたが、市場はこうした尺度で見て「割高」や「割安」なまま何年も推移してきました。割高に見えるという理由で空売りしたトレーダーは、市場が上がり続ける間に大きな損失を被ることがあります。

トレードでは、多くの人がバリュエーションをフィルターとして使います。たとえば一定のEV/EBITDAを超える企業を避けたうえで、タイミングについてはプライスアクション、カタリスト、テクニカル分析に頼るのです。株式スクリーナーを使えば、こうした絞り込みを簡単に行えます。

よくある間違い

  • 無関係なセクター同士で指標を比べる。 たとえば銀行のPERとソフトウェア企業のPERを比べることです。
  • 低い指標を自動的に割安とみなす。 利益の減少、多額の負債、縮小する業界によって、低い指標が正当化されることがあります。
  • 利益がマイナスのときや、一時的な項目でゆがんでいるときにPERを使う。
  • 予想値をうのみにする。 予想は、その期間が近づくにつれて下方修正されることがよくあります。
  • バリュエーションを短期のタイミングに使ったり、 割高に見えるというだけで株を空売りしたりする。

よくある質問

適正なPERはどれくらいですか？

唯一の適正なPERはありません。企業の成長率、リスク、セクター、そして金利の水準によって変わるため、類似企業や、その企業自身の過去と比べましょう。

PERとEV/EBITDAの違いは何ですか？

PERは株価を1株あたり純利益と比べるもので、企業がどれだけ負債を抱えているかを無視します。EV/EBITDAは、負債を含み現金を差し引いた事業全体の価値を、償却前の営業利益と比べるもので、財務状況の異なる企業の比較に適しています。

PERの低い株は常に買いですか？

いいえ。低いPERは、予想される利益の減少、多額の負債、法的な問題、あるいは市場の縮小を反映していることがあります。正当な理由があって割安に見える株は、バリュートラップと呼ばれます。

PEGレシオが1とはどういう意味ですか？

PERが予想年間利益成長率と等しいことを意味し、適正価値のおおまかな目安としてよく使われます。ただし、外れる可能性のある成長予想に大きく依存しています。
