ファンダメンタルズ分析

ファンダメンタルズ分析とは、資産価格の背後にある経済的な要因を研究することです。企業なら利益とキャッシュフロー、通貨なら金利と経済成長、コモディティなら需給がそれに当たります。その中心にある考え方は、資産にはこうした要因から推定できる価値があり、市場価格は時間とともにその価値に向かっていく傾向がある、というものです。トレーダーにとって重要なのは、数週間から数年にわたる最も大きく持続的な値動きが、たいていファンダメンタルズの変化、あるいはファンダメンタルズに対する市場の予想の変化にさかのぼるからです。

要点

  • ファンダメンタルズ分析では、資産の根底にある要因からその資産の本来の価値を推定し、その推定値を市場価格と比べます。
  • 価格が動くのは、新しい情報とすでに織り込まれていた予想とのギャップによるものであり、ニュースが絶対的に良いか悪いかによるものではありません。
  • 重要なファンダメンタルズは資産によって異なります。株式ならキャッシュフロー、通貨なら金利、コモディティなら在庫、暗号資産なら普及度とトークンの供給量です。
  • バリュエーションの推定は前提に非常に敏感なため、割引率や成長率がわずかに変わるだけで「適正価値」が大きく動くことがあります。
  • ファンダメンタルズは、それだけではタイミングを計る道具としては不十分です。だからこそ多くのトレーダーは、テクニカル分析や厳格なリスクルールと組み合わせています。

本質的価値と価格

資産の価格とは、直近の買い手と売り手が合意した値段のことです。本質的価値とは、その資産が生み出すもの、あるいはその希少性に基づいて推定した、資産の価値のことです。両者は長期間にわたって乖離することがあります。ファンダメンタルズのアナリストは、ギャップが大きく、しかもそれが縮まる理由があるケースを探します。

事業の価値は、その事業が将来オーナーにもたらす現金を現在の価値に割り引いたものから生まれます。10年後に受け取る1ドルは、今日の1ドルより価値が低くなります。今あるお金は利息を生むことができ、また将来は不確実だからです。将来のキャッシュフローを縮めるのに使う率を割引率といい、金利が上がったり、キャッシュフローのリスクが高く見えたりすると上昇します。

計算例：「適正価値」はどれほど敏感か

ディスカウント・キャッシュフロー（DCF）モデルの簡易版に、成長永久年金の公式があります。

価値 = 翌年の1株あたりフリーキャッシュフロー / (割引率 − 成長率)

ある企業が翌年に1株あたり$5.00のフリーキャッシュフローを生み、それが永久に年4%で成長すると予想され、投資家が9%のリターンを求めるとします。

シナリオ 割引率 成長率 1株あたりの価値
基本ケース 9% 4% $5.00 / 0.05 = $100.00
金利が1ポイント上昇 10% 4% $5.00 / 0.06 = $83.33
成長率が1ポイント上昇 9% 5% $5.00 / 0.04 = $125.00

前提を1つ1ポイント変えるだけで、推定値は約17%下がったり、25%上がったりします。ファンダメンタルズの推定値が幅を持って示される理由、キャッシュフローが遠い将来にあるグロース株が金利上昇時に大きく下落する理由、そして慎重な2人のアナリストの意見が大きく食い違うことがある理由は、ここにあります。

トップダウンとボトムアップ

ファンダメンタルズの分析を組み立てる方法は、大きく分けて2つあります。

トップダウン分析は、世界経済から始めて範囲を絞り込んでいきます。アナリストはまず成長率、インフレ、金利がどこに向かっているかを考え、次にどの国や通貨が恩恵を受けるか、さらにどのセクターか、そして最後に個別の資産を考えます。トップダウンのトレーダーなら、欧州のインフレ鈍化によって欧州中央銀行（ECB）が利下げすると結論づけ、その見方を債券、ユーロ、金利に敏感な株式を通じて表現するかもしれません。

ボトムアップ分析は、1つの企業や資産から始めて外側へと広げていきます。ボトムアップの銘柄選択者は、企業の財務諸表、競争上の地位、経営陣を調べ、事業が割安に見えれば、経済環境にかかわらずその銘柄を保有することもあります。

トップダウン ボトムアップ
出発点 世界のマクロ経済：成長、インフレ、金利 1つの企業または資産
主なツール 経済指標、中央銀行の政策、資本フロー 財務諸表、バリュエーション指標、業界分析
主な利用者 マクロファンド、FXや金利のトレーダー、アセットアロケーター 銘柄選択者、バリュー投資家とグロース投資家
主なリスク マクロの見立ては当たったのに、間違った商品を選ぶ 下落相場で良い企業を保有している

ほとんどの実務家は両方を組み合わせています。純粋な銘柄選択者であっても、市場全体の価格を見直させるほど金利が動いているときは、それを把握しておく必要があります。

資産クラスによるファンダメンタルズの違い

株式

株式のファンダメンタルズは最も発達しています。アナリストは売上高、利益率、キャッシュフロー、負債、成長率を調べ、PER（株価収益率）などの指標を使って株価をそれらの数字と比較します。国によって四半期ごとまたは半期ごとに行われる決算発表が、主な予定イベントです。長期的には、株式のリターンは歴史的に利益成長と配当に連動してきており、その間にバリュエーションの変化が大きな振れをもたらしてきました。

通貨

通貨には利益がないため、そのファンダメンタルズはマクロ経済的なものです。最も重要なのは、その通貨の中央銀行が設定する金利の他の中央銀行に対する水準で、そのほかにインフレ、経済成長、貿易と資本フロー、危機時の安全資産需要があります。FX市場は、経済指標や中央銀行の決定によって将来の金利の道筋に対する予想が変わるときに最も大きく動く傾向があります。全体の一覧は為替を動かす要因を参照してください。

コモディティ

コモディティのファンダメンタルズは、生産、天候、在庫、保管コスト、先物カーブの形状といった物理的な需給に関するものです。米国の週次原油在庫統計や月次の作物収穫予想といった定期的な発表は、価格を大きく動かすことがあります。これらの要因についてはコモディティ取引の記事で詳しく解説しています。

債券

債券価格は、金利、インフレ期待、発行体の信用力に左右されます。大きな経済圏の国債は、主に中央銀行の政策とインフレ指標に反応します。債券と金利の取引を参照してください。

暗号資産

ほとんどの暗号資産はキャッシュフローを生まないため、伝統的なバリュエーションはそのままでは当てはまりません。代わりにアナリストは、ネットワークの利用状況、手数料、トークンの供給量とアンロックのスケジュール、ブロックチェーン上で見える保有者の行動、流動性の状況を見ます。暗号資産においてファンダメンタルズ分析に最も近いものは、トークノミクスとオンチェーン分析です。暗号資産が主流のポートフォリオに組み入れられるようになってからは、世界的な流動性と金利も重要な要因になっています。

ニュースそのものより予想が重要

市場は先を見ています。ニュースが発表される頃には、トレーダーはたいていその内容について見方を固めており、価格にはすでにその見方が織り込まれています。価格を動かすのはサプライズ、つまり実際の数字と予想との差です。

だからこそ、企業が過去最高益を発表しても株価が下がることがあり、雇用統計が弱くても懸念されていたほど弱くなければ通貨が上昇することがあるのです。ファンダメンタルズのトレーダーは、2つのことを問わなければなりません。何が起こるのか、そして市場はすでに何が起こると考えているのか、です。エッジが存在するのは、2つ目の問いに対する市場の答えが間違っている場合だけです。

ファンダメンタルズとテクニカル分析の組み合わせ

ファンダメンタルズ分析は、何が誤った価格をつけている可能性があるかを教えてくれます。しかし、その誤りがいつ修正されるかを教えてくれることはめったになく、市場は、レバレッジをかけたトレーダーが資金を持ちこたえられる期間よりも長く「間違った」ままでいることがあります。テクニカル分析は、価格と出来高を研究してタイミングとトレンドを判断します。

よくある組み合わせ方は次のとおりです。

  1. ファンダメンタルズを使って方向性や候補リストを決めます。たとえば、市場の予想より速いペースで中央銀行が利上げしそうな通貨などです。
  2. プライスアクションやトレンドのツールを使ってエントリーのタイミングを計り、市場がその見方を裏付け始めるのを待ちます。
  3. トレードのアイデアが明らかに間違っていたとわかる位置に損切りを置き、損失が許容範囲に収まるようにポジションのサイズを決めます。

逆の順序で取り組むトレーダーもいます。テクニカルのセットアップでトレードしつつ、重要な発表をまたいでポジションを持たないように経済指標カレンダーを確認するのです。

データが示すこと

学術研究の結果はまちまちですが、それ自体が示唆に富んでいます。大規模で流動性の高い市場で一貫して勝ち続けるのは難しく、アクティブファンドのマネージャーの大半は、歴史的に長期間で見ると、手数料控除後に低コストのインデックスファンドを下回ってきました。その一方で、研究者たちはファンダメンタルズに関連した長続きするリターンのパターンを報告しています。たとえば、割安な株（バリュー）や収益性の高い企業が非常に長い期間ではアウトパフォームする傾向です。ただし、こうした効果には長い不振の時期がつきものです。ファンダメンタルズに基づく短期トレードはさらに難しくなります。プロのデスクは予定されたニュースを数ミリ秒で処理するからです。

個人トレーダーにとっての実践的な教訓は、あらゆるデータで機関投資家を分析で上回ることを期待するのではなく、主に市場が動く理由を理解し、大きな転換の際に間違った側に立たないためにファンダメンタルズを使うことです。

よくある間違い

  • 適正価値を目標株価として扱う。 上の例が示すように、推定値は大きく外れうる前提の上に成り立っています。
  • 予想を無視する。 すでに何が織り込まれていたかを確認せずに、見出しだけでトレードする（「好材料だから買い」）。
  • ファンダメンタルズを短期のタイミングに使う。 割安な資産が何年もさらに割安になり続けることがあります。
  • 多くの暗号資産トークンのように、キャッシュフローのない資産に株式型のバリュエーションを無理に当てはめる。
  • 1つのストーリーにとらわれる。 金利のような1つの変数に基づくシナリオは、景気後退や信用イベントといった別の要因に押し流されることがあります。

よくある質問

ファンダメンタルズ分析はテクニカル分析より優れていますか？

どちらかが常に優れているということはありません。ファンダメンタルズ分析は長い時間軸や価格が動く理由の理解に役立ち、テクニカル分析はタイミングとリスク管理に使われることが多く、多くのトレーダーは両方を組み合わせています。

ファンダメンタルズ分析はデイトレードに使えますか？

限られた形でしか使えません。デイトレーダーは主に経済指標カレンダーや決算カレンダーを使ってボラティリティが高まりそうなタイミングを把握しますが、1回のセッションの中で資産の長期的な価値が問題になることはほとんどありません。

本質的価値と市場価格の違いは何ですか？

市場価格とは、需給によって決まる直近の取引価格です。本質的価値とは、将来のキャッシュフローなどの要因に基づいてアナリストが推定した資産の価値であり、その信頼性は背後にある前提の信頼性を超えません。

ファンダメンタルズ分析は暗号資産にも使えますか？

部分的には使えます。ほとんどのトークンにはキャッシュフローがないため、伝統的なバリュエーションは当てはまりませんが、供給のスケジュール、ネットワークの利用状況、流動性、マクロ環境は実際に価格を動かす要因であり、アナリストは代わりにそれらを研究しています。

教育目的のコンテンツです。本サイトの内容は、金融・投資・法律・税務に関する助言ではありません。トレードには大きな損失リスクがあり、レバレッジ商品では入金額を超える損失が生じることがあります。ルール、手数料、プラットフォームの条件は変わります。取引の前に、ご利用の証券会社、取引所、規制当局で最新の条件をご確認ください。
