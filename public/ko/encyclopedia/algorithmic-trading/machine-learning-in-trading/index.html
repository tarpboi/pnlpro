트레이딩과 머신러닝

트레이딩에서의 머신러닝(ML)은 알고리즘 트레이딩의 한 분야로, 사람이 직접 쓴 규칙을 따르는 대신 데이터에서 패턴을 학습하는 알고리즘을 이용해 가격을 예측하거나, 시장 상황을 분류하거나, 뉴스 같은 텍스트를 처리합니다. 퀀트 펀드에서 널리 쓰이지만, 금융 데이터는 노이즈가 많고 끊임없이 변하기 때문에 ML 모델은 존재하지 않는 패턴을 찾아내기 유난히 쉽습니다. 신중하게 쓰면 유용한 도구이지만, 부주의하게 쓰면 실전에서 실패하는 그럴듯한 백테스트를 만드는 가장 빠른 길 중 하나입니다.

핵심 요약

  • 트레이딩 ML 대부분은 지도학습으로, 오늘 알려진 피처로 미래의 수익률이나 방향을 예측합니다.
  • 어떤 알고리즘을 고르느냐보다 레이블을 어떻게 정의하고 모델을 어떻게 검증하느냐가 더 중요합니다.
  • 시장은 비정상적(non-stationary)이고 신호 대 잡음비가 매우 낮으므로, 작은 정확도 향상도 의미가 있을 수 있고 큰 향상은 의심스럽습니다.
  • 표준 교차검증은 시계열에서 미래 정보를 누출합니다. 워크포워드 검증이나 퍼징(purging) 검증을 쓰십시오.
  • 대규모 언어 모델(LLM)은 텍스트를 읽고 분류하는 데 유용하지만, 이를 쓰는 백테스트는 테스트 날짜 이후 사건에 대한 지식으로 오염될 수 있습니다.

ML이 할 수 있는 것과 없는 것

ML은 여러 약한 신호를 결합하고, 비선형 관계를 포착하고, 수천 건의 뉴스 기사나 공시처럼 사람이 대규모로 읽을 수 없는 데이터를 처리하는 데 강합니다. 데이터에 없는 예측 가능성을 만들어 낼 수는 없습니다. 자산 가격은 대부분의 기간에서 대체로 예측할 수 없으며, 존재하는 예측 가능성도 상당 부분은 경쟁으로 사라집니다. 잘 알려진 2020년 연구에서 Gu, Kelly, Xiu는 트리 앙상블과 신경망 같은 유연한 방법이 전통적인 선형 모델보다 미국 주식의 월간 수익률을 더 잘 예측한다는 것을 발견했지만, 수익률 중 예측 가능한 부분은 작았습니다.

신호를 위한 지도학습

문제 유형

  • 회귀: 5일 수익률처럼 다음 수익률의 크기를 예측합니다.
  • 분류: 상승 또는 하락, "손절 전에 익절 목표에 도달" 같은 범주를 예측합니다.
  • 순위화: 기대수익률 순으로 자산을 정렬해 상위는 매수하고 하위는 공매도합니다. 횡단면 종목 선정에서 흔한 접근입니다.

흔히 쓰는 모델

모델 계열 장점 단점
선형 회귀와 정규화 회귀(릿지, 라쏘) 단순하고 안정적이며 해석 가능 비선형 효과를 놓침
트리 앙상블(랜덤 포레스트, 그래디언트 부스팅) 비선형성과 혼합 피처를 잘 다루고, 정형 데이터에 강함 노이즈에 과적합될 수 있고, 예측이 덜 매끄러움
신경망 유연하며 시퀀스, 텍스트, 이미지를 다룸 데이터가 많이 필요하고 해석이 어려우며 과적합되기 가장 쉬움

일반적인 정형 트레이딩 데이터에서는 정규화 선형 모델과 그래디언트 부스팅 트리가 흔한 출발점입니다. 더 복잡한 모델을 정당화하려면 더 많은 데이터가 필요합니다.

피처

피처(feature)는 모델이 사용하는 입력값입니다. 예측하는 순간에 알려져 있는 값이어야 합니다.

  • 가격 기반: 여러 기간의 과거 수익률, 변동성, 이동평균선과의 거리, RSI 같은 기술적 지표.
  • 거래량과 주문 흐름: 상대 거래량, 호가 불균형, 체결 방향.
  • 횡단면: 섹터나 시장 대비 자산의 수익률.
  • 펀더멘털: 밸류에이션 비율, 어닝 서프라이즈. 데이터는 공시일 이후부터만 사용합니다.
  • 대체 데이터: 텍스트 감성, 웹 트래픽, 위성 데이터나 거래 데이터.
  • 시장 맥락: 변동성 지수, 금리, 펀딩비 같은 심리 지표.

롤링 z-점수처럼 과거 데이터만으로 피처를 정규화해, 모델이 미래에서 계산된 통계를 절대 보지 못하게 하십시오. 데이터 조달과 타임스탬프는 시장 데이터에서 다룹니다.

레이블링

레이블(label)은 모델이 예측하도록 학습하는 대상이며, 이를 잘 고르는 것이 문제의 절반입니다.

  • 고정 기간 레이블: 다음 N개 봉 동안의 수익률 부호나 크기. 단순하지만 가격 경로와, 실제 거래를 어떻게 관리할지를 무시합니다.
  • 트리플 배리어 레이블: Marcos López de Prado가 2018년 저서 Advances in Financial Machine Learning에서 설명한 방식입니다. 각 표본은 위쪽 배리어(익절 목표), 아래쪽 배리어(손절), 시간 제한 중 무엇에 먼저 닿는지로 레이블이 붙습니다. 실제 거래가 청산되는 방식과 맞아떨어집니다.
  • 메타 레이블링: 1차 모델이나 규칙이 방향을 정하고, 2차 ML 모델이 각 1차 신호가 성공할지를 예측합니다. 이를 이용해 거래를 걸러 내거나 포지션 규모를 정할 수 있습니다.

매일 계산한 5일 수익률처럼 서로 겹치는 레이블은 정보를 공유합니다. 이 점은 검증 단계에서 처리해야 합니다.

비정상성과 노이즈

금융 시장의 관계는 변합니다. 저금리 시기에 유지되던 패턴이 금리가 오르면 사라질 수 있고, 많은 트레이더가 쓰기 전에 통하던 피처가 그 뒤에는 통하지 않을 수 있습니다. 신호 대 잡음비는 매우 낮습니다. 일간 방향을 52~53% 맞히는 모델은 유용할 수 있지만, 일간 방향 정확도가 70%라면 거의 언제나 버그나 데이터 누출을 의미합니다.

이는 규칙 기반 평균회귀 시스템과 추세 시스템을 괴롭히는 것과 같은 국면(regime) 문제입니다. 실무적인 대응으로는 롤링 윈도우로 재학습하기, 더 단순한 모델 선호하기, 여러 약한 신호 결합하기, 실전 성과의 쇠퇴 여부 모니터링하기가 있습니다.

누출 없는 검증

표준 k-폴드 교차검증은 데이터를 무작위로 섞기 때문에, 모델이 미래로 학습하고 과거로 테스트하게 됩니다. 트레이딩에서는 다음을 쓰십시오.

  • 워크포워드 검증: 과거 데이터로 학습하고, 다음 기간으로 테스트한 뒤, 앞으로 굴려 나갑니다.
  • 간격과 퍼징: 레이블이 테스트 기간과 겹치는 학습 표본을 제거하고, 테스트 기간 뒤에 엠바고 간격을 둡니다.
  • 최종 홀드아웃: 개발 과정에서 한 번도 건드리지 않은 최근 기간.
import numpy as np
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.model_selection import TimeSeriesSplit

def walk_forward_accuracy(X, y, horizon=5, n_splits=5):
    """X: 시점 t에 알려진 피처, y: t -> t+horizon 구간의 레이블. 행은 시간 순서."""
    splitter = TimeSeriesSplit(n_splits=n_splits, gap=horizon)  # gap으로 레이블 중첩을 피한다
    scores = []
    for train_idx, test_idx in splitter.split(X):
        model = GradientBoostingClassifier(max_depth=3, n_estimators=200)
        model.fit(X[train_idx], y[train_idx])
        scores.append((model.predict(X[test_idx]) == y[test_idx]).mean())
    return np.mean(scores), np.std(scores)

학습하고 평가하는 모델 하나하나가 또 하나의 시행이므로, 과최적화와 데이터 스누핑에서 다루는 다중 검정 문제가 더 강하게 적용됩니다.

뉴스와 시장 심리 분석을 위한 LLM

대규모 언어 모델은 뉴스, 실적 발표 컨퍼런스 콜 녹취록, 공시, 소셜 미디어 게시물을 읽고 이를 긍정·부정 논조, 이벤트 유형, 언급된 기업, 사람 트레이더를 위한 요약 같은 구조화된 신호로 바꿀 수 있습니다. 실무적인 용도로는 뉴스 흐름 필터링, 이벤트 태깅, 사람보다 빠르게 대량의 텍스트를 선별하는 일이 있습니다.

중요한 주의 사항:

  • 미래 참조 오염. 최근 날짜까지의 인터넷 텍스트로 학습한 모델은 과거 기사 날짜 이후에 기업이나 시장이 실제로 어떻게 되었는지 "알고" 있을 수 있습니다. 그래서 과거 뉴스에 대한 LLM 기반 감성 백테스트가 실전 매매보다 훨씬 좋아 보일 수 있습니다. 가능하면 학습 데이터 기준일(cutoff)이 테스트 기간보다 앞서는 모델을 쓰거나, 기준일 이후의 데이터로만 테스트하십시오.
  • 오류와 환각. LLM은 숫자를 잘못 읽거나, 기업을 혼동하거나, 세부 사항을 지어낼 수 있습니다. 출력, 특히 추출한 수치를 검증하십시오.
  • 지연시간과 비용. 모델이 헤드라인을 처리할 즈음이면 빠른 트레이더들은 이미 움직였을 수 있습니다. LLM 신호는 더 느린 시간대에 맞는 경향이 있습니다.
  • 쏠림. 누구나 쓸 수 있는 모델을 누구나 볼 수 있는 뉴스에 적용해서는 그것만으로 지속적인 엣지를 얻기 어렵습니다.

에이전트가 시뮬레이터 안에서 시행착오로 매매 정책을 학습하는 강화학습은 활발한 연구 분야이지만, 시뮬레이터의 현실성과 과최적화에 특히 민감합니다.

계산 예시: 정확도가 곧 수익은 아닙니다

어떤 분류기가 주가지수 펀드의 다음 날 방향을 워크포워드 테스트에서 53% 정확도로 예측한다고 합시다. 평균 상승일과 하락일의 변동폭은 모두 약 1.0%라고 가정합니다.

  • 거래당 기대 총수익 = 0.53 × 1.0% − 0.47 × 1.0% = 0.06%.
  • 왕복 비용이 0.05%라면 순엣지는 거래당 0.01%이며, 매일 매매한다면 연간 대략 252 × 0.01% ≈ 2.5%입니다(복리 무시).
  • 왕복 비용이 0.10%라면 순엣지는 거래당 −0.04%, 연간 대략 −10%입니다.

게다가 이 모델은 앞으로도 53% 정확도를 유지해야 하는데, 비정상성 때문에 이는 불확실합니다. ML 신호는 비용이 작은 엣지를 덜 갉아먹는 저회전 전략과 결합할 때 가장 잘 통하는 경우가 많습니다.

흔한 실수

  • 시계열을 무작위로 학습/테스트 분할합니다. 미래가 학습 데이터로 새어 들어갑니다.
  • 미래 데이터로 계산한 피처를 씁니다. 전체 표본 정규화나 수정된 경제 지표가 그 예입니다.
  • 높은 정확도를 좇습니다. 수익률 예측에서 매우 높은 정확도는 대개 데이터 누출의 신호입니다.
  • 작은 데이터에 복잡한 모델을 씁니다. 몇 년치 일봉으로 학습한 심층 신경망은 쓸모 있는 관측치보다 파라미터가 훨씬 많습니다.
  • 비용과 회전율을 무시합니다. 모델이 너무 자주 매매하면 작은 엣지는 사라집니다.
  • 학습 데이터 오염 문제를 해결하지 않고 오래된 뉴스에 대한 LLM 백테스트를 믿습니다.

자주 묻는 질문

머신러닝으로 주가를 예측할 수 있나요?

머신러닝은 수익률에서 약하지만 통계적으로 유용한 패턴을 찾을 수 있지만, 가격을 신뢰성 있게 예측하지는 못합니다. 연구에 따르면 수익률 중 예측 가능한 부분은 작고, 패턴은 시간이 지나며 변합니다.

트레이딩에 가장 좋은 머신러닝 모델은 무엇인가요?

최고의 모델 하나는 없습니다. 정형 데이터에서는 정규화 선형 모델과 그래디언트 부스팅 트리가 흔한 출발점이며, 대개 알고리즘보다 레이블, 피처, 검증 방법의 선택이 더 중요합니다.

ChatGPT나 다른 LLM으로 매매할 수 있나요?

LLM은 뉴스 요약, 감성 분류, 코드 작성과 검토를 도울 수 있지만, 미래 가격에 대한 신뢰할 만한 통찰은 없습니다. 출력은 검증해야 할 입력 중 하나로 다루고, 모델의 학습 데이터로 오염되었을 수 있는 백테스트를 경계하십시오.

머신러닝 트레이딩 전략은 왜 실패하나요?

흔한 이유는 노이즈에 대한 과최적화, 검증 과정의 데이터 누출, 변하는 시장 상황, 그리고 작은 예측 엣지를 넘어서는 거래비용입니다.

교육 목적의 콘텐츠입니다. 이곳의 어떤 내용도 금융, 투자, 법률 또는 세무 조언이 아닙니다. 트레이딩은 손실 위험이 크며, 레버리지 상품은 입금액보다 큰 손실이 날 수 있습니다. 규칙, 수수료, 플랫폼 조건은 바뀔 수 있으니 거래 전에 브로커, 거래소 또는 감독기관에서 최신 조건을 확인하십시오.
