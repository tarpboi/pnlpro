  • 시장 데이터

시장 데이터(market data)는 거래소와 기타 거래 장소에서 생성되는 가격, 호가, 체결, 호가창 활동의 기록입니다. 모든 알고리즘 전략은 시장 데이터에 두 번 의존합니다. 리서치와 백테스트를 위한 과거 데이터, 그리고 매매를 위한 실시간 데이터입니다. 데이터의 종류, 출처, 타임스탬프 방식, 정제 방식은 전략 로직 자체만큼이나 전략의 측정 성과를 바꿀 수 있습니다.

핵심 요약

  • 틱 데이터는 모든 체결이나 호가 변경을 기록하고, 봉 데이터는 1분이나 1일 같은 기간 단위로 활동을 요약합니다.
  • 레벨 1은 최우선 매수·매도호가를, 레벨 2는 가격대별 잔량을, 레벨 3은 개별 주문을 보여 줍니다.
  • 과거 데이터는 분할, 배당, 선물 롤오버를 반영해 수정해야 하며, 상장폐지된 종목을 포함해야 합니다.
  • 전문 데이터는 라이선스 대상이며, 요금은 사용자가 누구이고 어떻게 쓰는지에 따라 달라집니다.
  • 타임스탬프, 시간대, 시계 동기화는 백테스트와 실전매매에서 미묘한 오류를 많이 일으킵니다.

틱 데이터 vs 봉 데이터

틱 데이터는 개별 이벤트 하나하나를 기록합니다. 모든 체결(가격, 수량, 시각, 때로는 공격 측 방향)과 모든 호가 갱신(매수·매도호가와 잔량)입니다. 가장 상세한 형태의 데이터로, 일중 체결 연구, 주문 흐름 분석, 현실적인 체결 시뮬레이션에 필요합니다. 용량이 크고 저장과 처리도 더 어렵습니다.

봉 데이터는 활동을 기간 단위로 요약합니다. 봉 하나는 1분, 1시간, 1일 같은 각 구간의 시가, 고가, 저가, 종가와 거래량(OHLCV)을 기록합니다. 봉은 간결하며 대부분의 스윙 전략과 포지션 전략에 충분합니다.

봉 유형 봉이 만들어지는 방식 비고
시간 봉 고정된 시간 간격 표준이지만, 장 시작과 한낮의 활동량이 크게 다름
틱 봉 고정된 체결 건수 시장이 붐빌 때 봉이 더 많이 생김
거래량 봉 고정된 주식 수나 계약 수 활동량 기준으로 표본을 추출
거래대금 봉 고정된 거래 금액 긴 기간의 가격 변화를 보정

봉은 정보를 숨깁니다. 일봉은 고가가 저가보다 먼저 나왔는지 알려 주지 않으므로, 손절가와 목표가가 같은 날 둘 다 닿았다고 가정하는 백테스트는 무엇이 먼저 일어났는지 추측해야 합니다.

레벨 1, 레벨 2, 레벨 3

이 용어들은 피드가 호가창을 얼마나 보여 주는지를 나타냅니다.

레벨 내용 주요 용도
레벨 1 최우선 매수·매도호가(잔량 포함), 직전 체결가, 거래량 대부분의 개인 매매, 차트, 단순한 봇
레벨 2(가격별 호가) 양쪽 여러 가격대 각각의 총잔량 호가 깊이 분석, 체결, 단기 전략
레벨 3(주문별 호가) 추가, 변경, 취소를 포함한 모든 개별 주문 대기열 순번 모델링, 마켓 메이킹, 리서치

미국 주식에는 모든 거래소의 호가를 합쳐 전국 최우선 매수·매도호가(NBBO)를 만드는 통합 피드와, 각 거래소가 직접 제공하는 더 빠르고 상세한 전용 피드의 구분도 있습니다. 크립토 거래소는 보통 WebSocket으로 레벨 2 스냅샷과 증분 업데이트를 제공하며, 일부는 주문 단위 데이터도 제공합니다.

유형별 과거 데이터 출처

출처 유형 제공하는 데이터 예시 고려 사항
거래소 직접 공식 과거 체결, 호가, 호가창 데이터 가장 권위 있지만 대개 비싸고 복잡함
상용 데이터 업체 정제된 다자산 과거 데이터, 기업 행위, 펀더멘털 품질과 범위가 제각각이므로 생존 편향 처리를 확인할 것
브로커·플랫폼 API 제공하는 종목의 최근 봉과 틱 편리하지만 기간이 제한적이고 브로커마다 다를 수 있음
크립토 거래소 API 무료 체결, 봉, 때로는 호가창 스냅샷 장애 기간에 공백이 생기고 거래소마다 다름
학술 데이터베이스 미국 주식의 CRSP, 미국 체결·호가의 TAQ처럼 길고 생존 편향 없는 데이터 보통 대학을 통해 접근
무료 웹사이트 주요 자산의 일봉 학습용으로는 괜찮지만 수정 여부, 공백, 상장폐지 종목을 확인할 것

주식 리서치에는 상장폐지 기업과 시점별 지수 구성 정보를 포함한, 생존 편향 없는 데이터를 찾으십시오. 펀더멘털에는 나중의 정정 공시가 아니라 각 날짜에 알려져 있던 내용을 보여 주는 시점별(point-in-time) 데이터를 쓰십시오.

외환에는 중앙 거래소가 없으므로, 개인 외환 데이터의 "거래량"은 대개 한 브로커나 한 플랫폼의 활동만 반영합니다. 크립토에서는 일부 거래소가 보고한 거래량에 역사적으로 자전거래(wash trading)가 포함되어 있었으므로, 여러 출처를 비교하십시오. 거래량 분석을 참고하십시오.

비용과 라이선스

시장 데이터는 거래소에게 중요한 사업입니다. 핵심은 다음과 같습니다.

  • 가입자 분류. 많은 거래소가 비전문 개인 사용자에게 전문 사용자보다 훨씬 낮은 요금을 받습니다. 정의는 거래소마다 다르며, 규제 당국에 등록되어 있는지나 남을 위해 매매하는지에 따라 달라질 수 있습니다.
  • 디스플레이 vs 논디스플레이 사용. 거래소는 화면에 표시되는 데이터와 자동 시스템이 사용하는 데이터(논디스플레이)에 요금을 따로 매기는 경우가 많습니다.
  • 재배포. 대부분의 라이선스는 웹사이트에 게시하거나 데이터에서 직접 파생된 신호를 재판매하는 것을 포함해 데이터를 남에게 넘기는 것을 금지합니다.
  • 지연 데이터. 약 15분 지연된 데이터는 무료이거나 저렴한 경우가 많지만, 실전매매에는 쓸모가 없습니다.

요금표는 바뀌므로 이용하는 브로커, 업체, 거래소의 현재 약관을 확인하십시오.

타임스탬프와 시계 동기화

시간은 가장 흔한 오류 원인 중 하나입니다.

  • 어떤 타임스탬프인가? 체결 하나에 거래소의 매칭 시각, 데이터 발행 시각, 내 시스템의 수신 시각이 함께 붙을 수 있습니다. 백테스트에서 신호는 실제로 데이터를 받았을 시점 기준의 데이터만 사용해야 합니다.
  • 시간대와 서머타임. 모든 것을 UTC로 저장하십시오. 서머타임 전환은 나라마다 다른 날짜에 UTC 대비 현지 거래 시간을 바꾸므로, 여러 시장의 데이터가 어긋날 수 있습니다.
  • 일봉 정의. 외환과 크립토는 24시간 거래되므로 "일간 종가"는 제공자가 정한 마감 시각에 따라 달라집니다.
  • 시계 동기화. 실전 시스템은 NTP로 시계를 동기화하는데, 인터넷을 통해 보통 밀리초 이내의 정확도를 냅니다. 또는 적합한 네트워크에서 마이크로초 수준까지 도달할 수 있는 PTP를 씁니다. 일부 지역의 규제 당국은 매매 회사에 시계 정확도 요건을 두며, 고빈도 트레이더에게 가장 엄격한 허용 오차를 적용합니다. 트레이딩 봇 만들기에서 언급했듯이, 시계가 동기화되지 않으면 거래소 API가 서명된 요청을 거부할 수도 있습니다.

데이터 정제

어떤 데이터셋이든 쓰기 전에 다음을 점검하십시오.

  • 잘못된 틱: 주변 가격과 동떨어진 체결 기록으로, 흔히 오류나 특이한 체결 유형에서 생깁니다.
  • 누락 데이터와 공백: 거래소 장애, 휴장일, 거래 정지.
  • 중복 레코드와 순서가 뒤바뀐 레코드.
  • 기업 행위: 분할, 병합, 배당, 분사(스핀오프), 종목 코드 변경.
  • 선물 롤오버: 만기가 다가오는 계약들을 이어 붙인 연속 계약은 일관된 수정이 필요합니다.
  • 0 또는 음수 가격: 대개 오류이지만, 2020년 4월의 WTI 원유 선물처럼 실제로 0 아래에서 거래된 종목도 있습니다.

필터는 문서화해 두고, 리서치 데이터와 실시간 데이터에 똑같이 적용해야 합니다.

계산 예시: 데이터 수정

주식 분할

600달러에 거래되던 주식이 4대 1로 분할되어, 1주가 4주가 되고 가격은 약 150달러가 됩니다. 수정하지 않은 데이터에서는 이 시계열이 하룻밤 사이에 75% 하락한 것처럼 보입니다. 백테스트는 이를 폭락으로 처리해, 실제로는 존재하지 않았던 손절과 평균회귀 매수 신호를 발생시킬 것입니다.

분할 수정 데이터는 분할 이전의 모든 가격을 4로 나누고(거래량은 4를 곱해) 분할 전 600이 150이 되므로 시계열이 연속적으로 이어집니다.

선물 롤오버

어떤 트레이더가 분기물 선물로 연속 시계열을 만듭니다. 롤오버 날짜에 만기 계약은 4,000, 다음 계약은 4,020에 거래됩니다. 수정 없이 이어 붙이면 20포인트짜리 가짜 점프가 생깁니다. 백 어저스트(back-adjusted) 시계열은 이전 모든 가격에 20포인트를 더해 점프를 없앱니다. 다른 방법인 비율 수정은 이전 가격에 4,020 / 4,000 = 1.005를 곱하며, 퍼센트 수익률을 보존합니다.

데이터 용량

미국 주식 한 종목의 정규장(하루 390분) 1분봉은 252거래일 동안 390 × 252 = 98,280개로, 1년치를 저장하기 쉽습니다. 같은 종목의 틱·호가 데이터는 거래가 활발한 종목이라면 하루 수백만 건에 이를 수 있으며, 그래서 틱 단위 리서치에는 제대로 된 저장소와 도구가 필요합니다.

흔한 실수

  • 주식 백테스트에 수정되지 않은 가격을 씁니다.
  • 현재 상장된 종목만 써서 결과에 생존 편향을 심습니다.
  • 데이터 출처 간에 시간대를 섞어 씁니다.
  • 24시간 시장에서 일간 종가가 어디서나 같다고 가정합니다.
  • 틱 단위 체결이 필요한 전략을 봉 데이터로 백테스트합니다.
  • 데이터를 공유하거나 게시할 때 라이선스 조건을 무시합니다.

자주 묻는 질문

레벨 1 데이터와 레벨 2 데이터는 무엇이 다른가요?

레벨 1은 최우선 매수호가, 최우선 매도호가, 직전 체결가만 보여 줍니다. 레벨 2는 호가창 양쪽의 여러 가격대에 걸린 수량을 보여 주므로 시장 깊이를 볼 수 있습니다.

과거 시장 데이터는 어디서 구할 수 있나요?

거래소, 상용 데이터 업체, 브로커와 플랫폼 API, 크립토 거래소 API, 학술 데이터베이스 등이 있습니다. 무료 출처는 학습용으로는 괜찮지만, 의존하기 전에 수정 여부, 공백, 생존 편향을 확인하십시오.

백테스트에 틱 데이터가 필요한가요?

대부분의 일간 전략이나 스윙 전략에는 필요 없으며, 깨끗한 봉 데이터로 충분합니다. 틱이나 호가 데이터는 일중 전략, 체결과 슬리피지의 현실적인 모델링, 그리고 호가창에 의존하는 모든 것에 중요합니다.

시장 데이터는 왜 그렇게 비싼가요?

거래소와 데이터 업체는 데이터 수집, 배포, 라이선스에 요금을 받으며, 전문적인 용도와 자동화된 용도는 보통 더 비쌉니다. 비전문 개인 사용자는 브로커를 통해 실시간 데이터를 훨씬 싸게 받을 수 있는 경우가 많습니다.
