铁鹰与蝶式价差

铁鹰（iron condor）和蝶式价差（butterfly）是风险有限的期权策略，只要标的在到期前停留在某个区间内就能获利。铁鹰把牛市看跌价差和熊市看涨价差组合在一起，在较宽的区间上收取权利金。蝶式价差在三个行权价上组合期权，价格收在某个目标附近时获利最多。两者在平静的区间震荡市以及隐含波动率高企时都很受欢迎，但收益有上限，一次剧烈波动就可能亏掉全部风险金额。

要点总结

  • 铁鹰由一个卖出看跌价差加一个卖出看涨价差组成，最大收益等于收取的权利金。
  • 蝶式价差使用三个行权价，标的恰好收在中间行权价时回报最高。
  • 两种策略的最大亏损和盈亏平衡点都是已知的，可以在建仓前算出。
  • 它们属于做空波动率的交易：受益于时间衰减和隐含波动率下降，大幅波动则对其不利。
  • 到期时卖出行权价附近的钉住风险可能留下意料之外的股票头寸，因此许多交易者会在到期前平仓。

铁鹰的构建

铁鹰有四条腿，到期日全部相同：

  1. 卖出一张虚值看跌期权。
  2. 买入一张更虚值的看跌期权（起保护作用的“翼”）。
  3. 卖出一张虚值看涨期权。
  4. 买入一张更虚值的看涨期权。

第 1、2 条腿构成牛市看跌价差；第 3、4 条腿构成熊市看涨价差，两者详见垂直价差。该头寸收取净权利金。

实例：铁鹰

某股票现价 $100。期权价格仅作示例，每张合约对应 100 股。

腿 行权价 价格 现金流
卖出看跌 $90 $1.20 +$1.20
买入看跌 $85 $0.50 -$0.50
卖出看涨 $110 $1.10 +$1.10
买入看涨 $115 $0.40 -$0.40
净收入 +$1.40
  • 最大收益：$1.40，即 $140，到期时股价在 $90 和 $110 之间。
  • 最大亏损：单侧宽度减去收取的权利金 = $5.00 - $1.40 = $3.60，即 $360。发生在股价低于 $85 或高于 $115 时。到期时只有一侧可能亏损，因为股价不可能同时在两处。
  • 下方盈亏平衡点：$90 - $1.40 = $88.60。
  • 上方盈亏平衡点：$110 + $1.40 = $111.40。
到期股价 看跌价差价值 看涨价差价值 盈亏
$80 $5.00 $0 -$360
$88.60 $1.40 $0 $0
$95 $0 $0 +$140
$105 $0 $0 +$140
$111.40 $0 $1.40 $0
$120 $0 $5.00 -$360

盈亏等于 $1.40 的权利金减去到期时处于实值的那个价差的价值，再乘以 100。这笔交易冒 $360 的风险去赚 $140。这个比例很典型：铁鹰往往赢多输少，但每次亏损都大于每次盈利。

蝶式价差的构建

买入看涨蝶式价差使用三个等距的行权价：

  1. 买入一张低行权价看涨期权。
  2. 卖出两张中间行权价看涨期权。
  3. 买入一张高行权价看涨期权。

同样的形态也可以用看跌期权构建。该头寸通常只需支付少量权利金。

实例：买入看涨蝶式价差

股价为 $100 时：

腿 行权价 价格 现金流
买入 1 张看涨 $95 $7.00 -$7.00
卖出 2 张看涨 $100 每张 $4.00 +$8.00
买入 1 张看涨 $105 $2.00 -$2.00
净支出 -$1.00
  • 最大亏损：$1.00，即 $100，股价等于或低于 $95，或等于或高于 $105。
  • 最大收益：单翼宽度减去支付的权利金 = $5.00 - $1.00 = $4.00，即 $400，到期时股价恰好为 $100。
  • 下方盈亏平衡点：$95 + $1.00 = $96.00。
  • 上方盈亏平衡点：$105 - $1.00 = $104.00。

到期时股价为 $100，$95 看涨期权价值 $5.00，其余看涨期权作废，因此头寸价值 $5.00，成本为 $1.00。股价为 $102 时，$95 看涨期权价值 $7.00，两张卖出的 $100 看涨期权各值 $2.00（共 $4.00），$105 看涨期权作废：$7.00 - $4.00 = $3.00，盈利 $2.00。在中间行权价两侧，利润逐步递减。

相对于最大回报，蝶式价差很便宜，但最大回报只在一个很窄的区域内才能实现，所以大多数持有到期的蝶式价差最终拿不到全部回报。

铁蝶式

铁蝶式（iron butterfly）是卖出的看跌期权和卖出的看涨期权使用同一行权价（通常是平值）的铁鹰。

实例

股价为 $100 时：以 $4.00 卖出 $100 看涨期权，以 $3.80 卖出 $100 看跌期权，以 $1.00 买入 $110 看涨期权，以 $1.00 买入 $90 看跌期权。

  • 净收入：$4.00 + $3.80 - $1.00 - $1.00 = $5.80，即 $580。
  • 最大收益：$580，股价恰好收于 $100。
  • 最大亏损：$10.00 - $5.80 = $4.20，即 $420，股价低于 $90 或高于 $110。
  • 盈亏平衡点：$100 - $5.80 = $94.20 和 $100 + $5.80 = $105.80。

与铁鹰相比，铁蝶式收取的权利金多得多，风险回报比也更好，但盈利区间更窄，并且只在单一价格达到峰值。

断翼蝶式

断翼蝶式（broken-wing butterfly）两翼宽度不等，从而把风险偏向一侧。它通常可以收取少量权利金开仓，因此股价朝某一方向远离时不会亏损。

实例：看涨断翼蝶式

以 $7.00 买入 $95 看涨期权，以每张 $4.00 卖出两张 $100 看涨期权，以 $0.80 买入 $110 看涨期权。

  • 净额：-$7.00 + $8.00 - $0.80 = +$0.20 的净收入，即 $20。
  • 低于 $95：所有看涨期权作废；利润为收取的 $20。
  • 在 $100：$95 看涨期权价值 $5.00；利润 = $5.00 + $0.20 = $5.20，即 $520。
  • 高于 $110：头寸价值为 (S - 95) - 2 x (S - 100) + (S - 110) = -$5.00；亏损 = $5.00 - $0.20 = $4.80，即 $480。
  • 上方盈亏平衡点：在 $100 和 $110 之间，头寸价值为 $105 - S，因此盈亏平衡点满足 $105 - S + $0.20 = 0，即 $105.20。

这笔交易到期时没有下行风险，但在强劲上涨中的亏损比标准蝶式更大。看跌版本则把风险移到下行一侧。

交易者何时使用这些策略

市场条件 为何适合铁鹰和蝶式
区间震荡市 盈利取决于价格停留在某个区域内
隐含波动率高 卖出的期权能收取更多权利金，IV 回落也有帮助
事件之后 一些交易者会在 IV 仍高但事件风险已过时卖出铁鹰
有明确目标价 蝶式价差可以表达对价格最终落点的看法

这些都是做空波动率的头寸，在卖出行权价附近具有负 Gamma 和正 Theta；参见期权希腊字母和隐含波动率。

持仓管理

  • 止盈目标：许多交易者在赚到权利金的某个预定比例后就平掉铁鹰，而不是在风险仍高的情况下等最后几美分。
  • 止损限额：事先决定，例如亏损达到权利金的某个倍数时平仓。
  • 调整：一种常见的调整是把未受考验的一侧向价格方向移仓，以收取更多权利金。调整会增加成本，也可能扩大风险，因此需要规则。
  • 到期前平仓：相对于剩余的权利金，最后几天的 Gamma 风险最大。

钉住风险

如果到期时股价收在某个卖出行权价上或非常接近它，你就无法确定那张期权是否会被行权。你可能在卖出的期权上被指派，而起保护作用的买入期权却作废，导致你在周末持有一笔多头或空头股票头寸。盘后波动可能让这代价高昂。参见期权到期与指派。

常见错误

  • 把高胜率当作安全。一个大多数月份都赚钱的铁鹰，可能一次亏损就吐回好几个月的收益。
  • 为省佣金把翼设得太窄，或为多收权利金设得太宽。宽度直接决定最大亏损。
  • 持仓过财报或重大消息。一次跳空可能让股价一夜之间越过翼。
  • 忽视买卖价差。四条腿意味着开仓和平仓时都要跨越四个买卖价差。
  • 没有计划就调整。反复移仓可能把一笔风险有限的交易变成规模大得多的交易。

常见问题

铁鹰是怎么赚钱的？

它通过卖出虚值看跌价差和虚值看涨价差收取权利金。如果股价在到期前一直位于两个卖出行权价之间，所有期权都会作废，交易者保留全部权利金。

铁鹰和铁蝶式有什么区别？

铁鹰的两个卖出行权价是分开的，形成一个宽而平的盈利区间。铁蝶式在同一行权价上卖出两张期权，收取更多权利金，但只在单一价格达到峰值。

铁鹰的最大亏损是多少？

单个价差的宽度减去收取的净权利金，再乘以 100。一个宽 $5、以 $1.40 卖出的铁鹰，每张合约最大亏损为 $360。

什么时候应该平掉铁鹰？

许多交易者会在到期前很早就平仓，即在赚到权利金的目标比例或达到预设亏损时。持有到最后几天会增加 Gamma 风险和钉住风险。
