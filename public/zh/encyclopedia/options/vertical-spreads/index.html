垂直价差

阅读约 5 分钟 · 更新于 2026年11月23日

垂直价差（vertical spread）是这样一种期权头寸：在同一标的、同一到期日上，买入一份期权，同时卖出另一份同类型（同为看涨或同为看跌）但行权价不同的期权。卖出的期权抵消了买入期权的部分成本或风险，因此这笔交易从一开始就有固定的最大收益和固定的最大亏损。垂直价差是用期权表达方向性观点、同时保持风险有限的最常用方式之一。

要点总结

  • 基本的垂直价差有四种：牛市看涨价差和熊市看跌价差需要付钱建仓（借方，debit），牛市看跌价差和熊市看涨价差则收取权利金（贷方，credit）。
  • 最大收益、最大亏损和盈亏平衡点都可以在建仓前算出来。
  • 两个行权价之间的距离称为价差宽度，它决定了最大收益与最大亏损之和。
  • 信用价差（贷方价差）往往胜率更高，但每次赢的钱少于所承担的风险；借方价差往往胜率较低，但每次赢的钱更多。
  • 与单一期权相比，价差降低了对时间衰减和隐含波动率的敞口，但并没有消除它。

四种垂直价差

价差 构建方式 市场观点 借方或贷方
牛市看涨价差（Bull call spread） 买入低行权价看涨，卖出高行权价看涨 看涨 借方
熊市看跌价差（Bear put spread） 买入高行权价看跌，卖出低行权价看跌 看跌 借方
牛市看跌价差（Bull put spread） 卖出高行权价看跌，买入低行权价看跌 看涨或中性 贷方
熊市看涨价差（Bear call spread） 卖出低行权价看涨，买入高行权价看涨 看跌或中性 贷方

以下所有例子都假设股票现价 $100，期权到期日相同，采用美国标准乘数，即每张合约 100 股。期权价格仅作示例。

公式

对于两个行权价相隔固定宽度的价差：

借方价差 贷方价差
最大亏损 支付的净权利金 宽度 - 收取的净权利金
最大收益 宽度 - 支付的净权利金 收取的净权利金
盈亏平衡点（看涨价差） 低行权价 + 支付的净权利金 低行权价 + 收取的净权利金
盈亏平衡点（看跌价差） 高行权价 - 支付的净权利金 高行权价 - 收取的净权利金

注意，最大收益加最大亏损总是等于价差的宽度。

牛市看涨价差

以 $4.00 买入 $100 看涨期权，以 $1.50 卖出 $110 看涨期权。

  • 净支出：$4.00 - $1.50 = $2.50，即每组价差 $250。
  • 最大亏损：$250，到期时股价等于或低于 $100。
  • 最大收益：($110 - $100) - $2.50 = $7.50，即 $750，股价等于或高于 $110。
  • 盈亏平衡点：$100 + $2.50 = $102.50。
到期股价 $100 看涨价值 $110 看涨价值 价差价值 盈亏
$95 $0 $0 $0 -$250
$102.50 $2.50 $0 $2.50 $0
$105 $5.00 $0 $5.00 +$250
$110 $10.00 $0 $10.00 +$750
$120 $20.00 $10.00 $10.00 +$750

与单独以 $4.00 买入 $100 看涨期权相比，这个价差便宜 $1.50，盈亏平衡点也更低（$102.50 而不是 $104.00）。作为交换，它放弃了 $110 以上的全部收益。

熊市看跌价差

以 $3.80 买入 $100 看跌期权，以 $1.30 卖出 $90 看跌期权。

  • 净支出：$3.80 - $1.30 = $2.50，即 $250。
  • 最大亏损：$250，股价等于或高于 $100。
  • 最大收益：($100 - $90) - $2.50 = $7.50，即 $750，股价等于或低于 $90。
  • 盈亏平衡点：$100 - $2.50 = $97.50。

牛市看跌价差（贷方）

以 $2.00 卖出 $95 看跌期权，以 $0.80 买入 $90 看跌期权。

  • 净收入：$2.00 - $0.80 = $1.20，即 $120。
  • 最大收益：$120，到期时股价等于或高于 $95。
  • 最大亏损：($95 - $90) - $1.20 = $3.80，即 $380，股价等于或低于 $90。
  • 盈亏平衡点：$95 - $1.20 = $93.80。

股价可以横盘、上涨，甚至下跌不超过 $5，这个价差仍能赚到全部 $120。代价是冒 $380 的风险去赚 $120。对于贷方价差，券商通常会把最大亏损 $380 作为保证金冻结。

熊市看涨价差（贷方）

以 $2.10 卖出 $105 看涨期权，以 $0.90 买入 $110 看涨期权。

  • 净收入：$2.10 - $0.90 = $1.20，即 $120。
  • 最大收益：$120，股价等于或低于 $105。
  • 最大亏损：($110 - $105) - $1.20 = $3.80，即 $380，股价等于或高于 $110。
  • 盈亏平衡点：$105 + $1.20 = $106.20。

借方与贷方：胜率的取舍

借方价差 贷方价差
典型胜率 较低 较高
盈利与亏损的大小 盈利往往大于亏损 盈利通常小于亏损
需要股价 朝你的方向运动 不要朝不利方向走得太远
时间衰减 处于虚值时通常对你不利 处于虚值时通常对你有利

两者并无天然优劣。期权价格已经反映了市场的概率估计，所以一个 70% 时间都能赢的贷方价差，其定价会让偶尔的大额亏损抵消众多小额盈利（不计成本）。长期结果取决于你的判断是否优于市场，以及成本高低。参见风险回报比与期望值。

选择行权价

  • 宽度：价差越宽，成本越高（借方）或风险越大（贷方），潜在收益也越大。窄价差能把风险控制得很小，但佣金所占比例更大。
  • 价值状态：在平值附近买入的借方价差比单一期权便宜，但仍然需要行情运动。卖得更虚值的贷方价差成功率更高，收取的权利金更少。
  • 以 Delta 作参考：交易者常按 Delta 选择卖出腿的行权价。Delta 约为 0.30 的卖出行权价，常被理解为到期时处于实值的概率大约是 30%。参见期权希腊字母。
  • 隐含波动率：IV 高时，贷方价差能收取更多权利金；IV 低时，借方价差更便宜。参见隐含波动率。
  • 流动性：每条腿的买卖价差过宽会吃掉大部分优势，所以要选择交投活跃的期权，并以净价格下限价单。

管理垂直价差

  • 提前止盈：许多交易者在贷方价差赚到最大收益的某个预定比例后就平仓，而不是为了最后几美分持有到期。
  • 止损：事先设定止损水平，例如固定金额或收取权利金的某个倍数。
  • 到期风险：如果到期时股价位于两个行权价之间，一条腿可能以实值到期，另一条以虚值到期。你可能在卖出腿上被指派，最后持有 100 股的股票头寸。只要有任何疑虑，就在到期前平掉价差；参见期权到期与指派。
  • 提前指派：美式期权中深度实值的卖出腿可能被提前指派，尤其是在除息日之前。你的买入腿仍然限制着风险，但你必须处理由此产生的股票头寸。

常见错误

  • 只比较胜率而不看盈亏比。贷方价差即使有 75% 的胜率，如果亏损是盈利的三到四倍，照样可能亏钱。
  • 分腿建仓（legging in）。先建一条腿、等一等再加第二条，会让你暴露在中间这段时间的不利行情中。
  • 股价贴近卖出行权价时持有到期。钉住风险（pin risk）可能把一笔风险有限的交易变成意料之外的股票头寸。
  • 忽视窄价差的佣金。四笔佣金（开仓两条腿、平仓两条腿）可能占小价差利润的很大一部分。
  • 以为风险有限就是风险低。最大亏损是已知的，但它往往会被全额兑现。

常见问题

借方价差和贷方价差有什么区别？

借方价差开仓需要花钱，股价朝你选择的方向运动时获利。贷方价差开仓时你会收到钱，股价停留在卖出行权价有利的一侧时获利。

贷方价差的最大亏损怎么算？

用行权价宽度减去收取的净权利金，再乘以 100。一个宽 $5、以 $1.20 卖出的价差，最大亏损为每股 $3.80，即每张合约 $380。

垂直价差会亏得比最大亏损更多吗？

如果两条腿都持有到期，就不会。意外风险来自提前指派，或者一条腿以实值到期，这可能留下一笔在收盘后还会继续波动的股票头寸。

牛市看涨价差比直接买看涨期权更好吗？

它更便宜、盈亏平衡点更低，但收益以高行权价为上限。它适合有目标价位的温和看涨观点，而单一看涨期权适合押注大幅上涨。
