期权希腊字母

希腊字母（Greeks）是一组指标，描述在其他条件不变时，某一个输入变量变化会让期权价格如何变动。Delta 衡量对标的价格的敏感度，Gamma 衡量 Delta 本身的变化速度，Theta 衡量时间衰减，Vega 衡量对隐含波动率的敏感度，Rho 衡量对利率的敏感度。有了它们，期权就不再是一张彩票，而是一个风险可以量化、比较和管理的头寸。

要点总结

  • Delta 大致告诉你标的每变动 $1，期权价格会变动多少；它也可以看作等效股数敞口。
  • Gamma 是 Delta 的变化率，平值且临近到期的期权 Gamma 最大。
  • Theta 是持有期权每天付出的成本，越接近到期，衰减越快。
  • Vega 衡量对隐含波动率变化的敞口，即使股价不动，隐含波动率也能推动期权价格变化。
  • 把所有头寸的希腊值加总，就得到持仓希腊值，这是最能清楚概括一个组合实际风险敞口的指标。

参考期权

下面的例子始终使用同一份期权。某股票现价 $100。一张行权价 $100、30 天后到期的看涨期权价格为 $3.50，隐含波动率约为 30%。其希腊值经四舍五入，大致如期权定价模型给出的结果：

希腊字母 数值 通俗含义
Delta 0.52 股价上涨 $1，看涨期权每股约涨 $0.52
Gamma 0.046 股价上涨 $1，Delta 约增加 0.046
Theta -0.06 看涨期权每股每天因时间衰减约损失 $0.06
Vega 0.11 隐含波动率上升 1 个百分点，看涨期权每股约涨 $0.11
Rho 0.04 利率上升 1 个百分点，看涨期权每股约涨 $0.04

美国标准股票期权每张对应 100 股，因此每个数值乘以 100，就是每张合约的美元影响。Theta 为 -0.06，意味着每张合约每天约损失 $6。希腊值是模型给出的估算值，而且会持续变化；合约机制参见期权基础。

Delta

Delta 是标的变动 $1 时期权价格的预期变化。看涨期权的 Delta 为正，介于 0 和 1 之间；看跌期权的 Delta 为负，介于 0 和 -1 之间。

Delta 能告诉你什么

  • 价格敏感度：Delta 为 0.52 时，股价上涨 $1，看涨期权约涨 $0.52，即每张合约 $52。
  • 等效股数：一张 Delta 为 0.52 的合约，在小幅波动时大致相当于 52 股。
  • 粗略概率：交易者常把 Delta 当作期权到期时处于实值的粗略概率估计。Delta 为 0.30 的期权常被理解为大约有 30% 的机会。这只是经验法则，并非精确概率。
价值状态 典型看涨 Delta 典型看跌 Delta
深度实值 接近 1.00 接近 -1.00
平值 约 0.50 约 -0.50
深度虚值 接近 0 接近 0

Gamma

Gamma 是标的变动 $1 时 Delta 的变化。买入的期权（无论看涨还是看跌）Gamma 总是为正；卖出的期权 Gamma 为负。

实例：Delta 与 Gamma 结合

股价从 $100 涨到 $101。

  • 新的 Delta 约为 0.52 + 0.046 = 0.566。
  • 由于 Delta 在上涨过程中不断增大，用平均 Delta 估算价格变化更准确：0.52 + (0.5 x 0.046) = 0.543。
  • 新的看涨期权价格约为 $3.50 + $0.543 = $4.04。

如果股价反而下跌 $1，Delta 降到约 0.474，看涨期权约下跌 0.52 - 0.023 = $0.497，至约 $3.00。正 Gamma 意味着在同样幅度的波动下，看涨期权上涨时赚的比下跌时亏的略多。期权卖方的情况正好相反：股价朝不利方向走时，亏损会加速扩大。

Gamma 如何变化

平值期权的 Gamma 最高，并且随着到期日临近急剧上升。一张当日到期的平值期权，小幅波动就可能让 Delta 从约 0.50 摆动到接近 1 或 0。这就是 0DTE 期权如此敏感的原因，也是做市商对冲 Gamma 的行为可能影响标的市场的原因，详见Gamma 敞口与做市商对冲。

Theta

Theta 是在其他条件不变时，过去一天期权价格的变化。买入的期权 Theta 为负；卖出的期权 Theta 为正。Theta 是你持有期权所赋予权利的成本。

实例

在股价不动、波动率不变的情况下，持有参考看涨期权 5 天的成本约为 5 x $0.06 = $0.30 每股，即每张合约 $30，看涨期权从约 $3.50 降至约 $3.20。现实中 Theta 并不恒定：越接近到期，它越大。

Theta 如何变化

  • 时间：平值期权的外在价值起初流失得慢，在最后几周流失得快。一张 90 天的期权每天可能只损失几美分，同一行权价在只剩一周时，每天的损失可能是那时的好几倍。
  • 价值状态：以美元计，平值期权的 Theta 最大，因为它们包含的外在价值最多。深度实值和深度虚值期权可损失的部分较少。

期权卖方的目标是赚取 Theta。他们之所以能拿到这笔钱，是因为同时承担了负 Gamma，也就是大幅波动的风险。

Vega

Vega 是隐含波动率每变化 1 个百分点时期权价格的变化。买入的期权 Vega 为正；卖出的期权 Vega 为负。

实例

财报发布前，参考看涨期权的隐含波动率从 30% 升至 36%，股价不变。看涨期权约上涨 6 x $0.11 = $0.66，至约 $4.16。财报发布后，如果隐含波动率回落到 30%，这 $0.66 就会消失，即使股价几乎没动。这被称为 IV 压缩（IV crush，俗称“波动率塌陷”）。

Vega 如何变化

平值期权和期限较长的期权 Vega 最大，因为波动率有更多时间发挥作用。同一行权价下，一年期期权的 Vega 远高于一周期期权。

Rho

Rho 是利率每变化 1 个百分点时期权价格的变化。看涨期权的 Rho 为正，看跌期权的 Rho 为负，因为利率越高，持有看涨期权相对于直接买入股票就越有吸引力。短期期权的 Rho 很小，对散户交易者来说通常是最不重要的希腊字母，但对 LEAPS 等长期期权而言很重要。

希腊字母如何共同变化

希腊字母 平值 深度实值 深度虚值 临近到期（平值）
Delta 约 ±0.50 接近 ±1.00 接近 0 保持在 ±0.50 附近，但变得不稳定
Gamma 最高 低 低 急剧上升
Theta 衰减最大 较小 较小 衰减加速
Vega 最高 较低 较低 下降

持仓希腊值

持仓希腊值（Position Greeks）是把每个期权和股票头寸的各项希腊值，乘以合约数量和乘数后加总得出的。股票每股 Delta 为 1，没有 Gamma、Theta 或 Vega。

实例：一个小型组合

某交易者持有：

  • 买入 5 张参考看涨期权（Delta 0.52，Gamma 0.046，Theta -0.06，Vega 0.11）
  • 卖空同一股票 200 股
希腊字母 看涨期权：5 x 100 x 希腊值 股票 持仓合计
Delta 5 x 100 x 0.52 = +260 -200 +60 股
Gamma 5 x 100 x 0.046 = +23 0 每 $1 +23
Theta 5 x 100 x -0.06 = -$30 0 每天 -$30
Vega 5 x 100 x 0.11 = +$55 0 每个波动率点 +$55

解读：这个头寸目前相当于做多 60 股。如果股价上涨 $1，Delta 升至约 +83。如果行情不动，该头寸每天约亏 $30；隐含波动率每上升 1 个点，约赚 $55。这是一个多 Gamma、多 Vega 的头寸，为此付出 Theta 作为代价。大多数券商平台都会显示持仓希腊值，在每笔交易前后查看一下是个好习惯。

常见错误

  • 把 Delta 当成固定值。Delta 会随价格、时间和波动率变化。现在中性的头寸，行情一动可能就不再中性。
  • 忽视买入期权的 Theta。方向判断正确，但行情来得太晚，照样可能亏损。
  • 忽视事件前后的 Vega。在隐含波动率高位买入期权，然后眼看它崩塌，是看对方向却亏钱的常见方式。
  • 低估负 Gamma 风险。临近到期卖出期权能快速赚取 Theta，但一次剧烈波动就可能迅速造成巨额亏损。
  • 盲目相信模型希腊值。希腊值来自带有假设的模型。大幅波动、跳空和波动率跳升，恰恰会在最关键的时候让它们失准。

常见问题

买期权选多大的 Delta 比较好？

没有唯一最佳的 Delta。Delta 较高的实值期权表现更接近股票，按百分比计衰减更少；Delta 较低的虚值期权更便宜，但到期时处于实值的可能性更小。

为什么临近到期时 Theta 会变大？

外在价值必须在到期时归零。对平值期权来说，剩余的时间价值要在越来越少的天数里流失，所以越接近到期，每日衰减越大。

负 Gamma 是什么意思？

负 Gamma 来自卖出期权，意味着标的波动时你的 Delta 会朝不利方向变化：价格下跌时你的多头敞口变大，价格上涨时空头敞口变大。大幅波动时亏损可能加速。

哪个希腊字母最重要？

取决于策略。方向型交易者关注 Delta，短期合约交易者关注 Gamma 和 Theta，围绕财报或其他事件交易的人最关注 Vega。
