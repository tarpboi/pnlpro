股指期货

阅读约 6 分钟 · 更新于 2026年11月23日

股指期货是价值跟踪某一股票市场指数的期货合约，比如标普500（S&P 500）、纳斯达克100（Nasdaq-100）、道琼斯工业平均指数、DAX或日经225。它让交易者可以通过一笔交易表达对整个市场的看法，每天近24小时可交易，并具备中央清算和高杠杆。CME的E-mini和微型E-mini（Micro E-mini）合约是全球交易最活跃的期货之一，也是日内交易者的常见选择。

核心要点

  • 股指期货以现金交割，通过固定的美元乘数跟踪指数，例如E-mini S&P 500为每点$50。
  • 微型E-mini合约的规模是E-mini的十分之一，这让小账户的仓位管理容易得多。
  • 期货价格通常高于或低于现货指数，差额由利率和预期股息决定，称为公允价值。
  • 工作日几乎全天候交易，因此美股交易时间之外的重大新闻会首先反映在期货价格中。
  • 吸引日内交易者的杠杆，同样会让亏损来得又快又大。

主要的美国股指期货

CME Group挂牌交易着最活跃的美国合约。“E-mini”指的是电子交易的合约，它们取代了更早期、规模更大的场内交易版本。CME于2019年推出的“微型E-mini”合约，规模是E-mini的十分之一。

合约 代码 乘数 最小变动价位 每跳价值
E-mini S&P 500 ES $50 x 指数 0.25点 $12.50
Micro E-mini S&P 500 MES $5 x 指数 0.25点 $1.25
E-mini Nasdaq-100 NQ $20 x 指数 0.25点 $5.00
Micro E-mini Nasdaq-100 MNQ $2 x 指数 0.25点 $0.50
E-mini Dow（$5） YM $5 x 指数 1点 $5.00
Micro E-mini Dow MYM $0.50 x 指数 1点 $0.50
E-mini Russell 2000 RTY $50 x 指数 0.10点 $5.00
Micro E-mini Russell 2000 M2K $5 x 指数 0.10点 $0.50

以上合约均按季度挂牌，分别在3月（H）、6月（M）、9月（U）和12月（Z）到期，并以现金交割。合约规格可能调整，交易前请在交易所网站上确认。合约的一般机制参见期货交易入门。

名义价值

名义价值等于指数点位乘以乘数。无论你缴纳的保证金有多少，它才是仓位的真实规模。

合约 示例指数点位 名义价值
ES 5,000 $250,000
MES 5,000 $25,000
NQ 18,000 $360,000
MNQ 18,000 $36,000

在上述点位下，持有一张NQ合约的交易者，其指数敞口比持有一张ES合约的交易者更大，尽管NQ的乘数更小，这是因为纳斯达克100的指数点位要高得多。纳斯达克100的百分比波动通常也更大，因此NQ头寸每天的美元盈亏波动通常更大。

国际股指期货

大多数主要市场都有股指期货。

  • DAX（德国）： Eurex挂牌交易每指数点€25的标准DAX期货，以及每指数点€5的Mini-DAX。
  • Euro Stoxx 50（欧元区）： Eurex的Euro Stoxx 50期货为每指数点€10，最小变动价位为1点，是欧洲交易最活跃的股指期货之一。
  • 日经225（日本）： 大阪交易所挂牌交易多种规模的日元计价日经225期货，CME也挂牌交易日元和美元计价的日经合约，其中包括一张每指数点$5的美元计价合约。
  • 其他： 富时100（FTSE 100）期货在ICE Futures Europe交易，恒生指数期货在香港交易所交易，许多其他国家的指数也有各自的合约。

这些合约常与现货指数配合用于套期保值，并有助于在本地股票交易所开盘前为市场定价。指数的编制和加权方法参见股指交易。

交易时间与夜盘

CME股指期货在Globex电子平台上交易，时间为美国时间周日晚间至周五下午，每天从美国东部时间下午5:00开始有一小时的休市。与美国股票交易所交易时间（美东时间上午9:30至下午4:00）相对应的时段，通常称为常规交易时段（RTH）。其余时间称为夜盘或电子交易时段（ETH）。

夜盘之所以重要，有三个原因：

  1. 新闻首先在期货上反应。 收盘后公布的财报、海外央行的决议以及地缘政治事件，会在美股开盘前数小时就反映在ES和NQ的价格中。
  2. 流动性更薄。 ES的点差通常仍为一跳，但订单簿上的合约更少，因此大额订单对价格的影响更大。参见买卖价差与流动性。
  3. 跳空出现在现货市场，而不一定出现在期货上。 股票指数可能在开盘时“跳空”，而期货在夜盘中已经逐步消化了这一走势。

Eurex和大阪交易所有各自的交易时段，包括延长的晚间时段。交易时段的细节会变化，请查看交易所当前的时间表，概览参见市场交易时间与时段。

公允价值与现货指数

期货价格并不等于指数点位。两者之间的差额称为基差（basis）。理论上，期货应当以公允价值交易，公允价值反映的是今天买入指数中所有股票并持有至到期的成本：

  • 你需要为买入股票的资金支付利息，这会把公允价值推到指数之上。
  • 持有期间你能收到股息，这会把公允价值推到指数之下。

简化公式为：

Fair value = Index x (1 + (interest rate - dividend yield) x days to expiry / 365)

（公允价值 = 指数 x (1 + (利率 - 股息率) x 距到期天数 / 365)）

计算示例

假设S&P 500现货指数为5,000，短期利率为年4.5%，指数股息率为1.3%，距到期还有90天。

  • 净持有成本率：4.5% - 1.3% = 3.2%
  • 时间比例：90 / 365 = 0.2466
  • 持有成本：3.2% x 0.2466 = 0.789%
  • 公允价值：5,000 x 1.00789 = 约5,039.45

因此期货“应当”在5,039.45附近交易，比现货指数高约39.45点。如果期货价格远高于公允价值，套利者可以卖出期货、买入股票；如果远低于公允价值，则反向操作。这种指数套利使基差在大部分时间里都接近公允价值。随着到期日临近，基差会向零收缩，这也是为什么下一季度合约的交易价格与近月合约不同。两者之间的展期参见期货升水、贴水与展期。

盘前电视节目说“期货上涨20点”时，有时指的是原始期货价格，有时指的是期货相对于公允价值的涨幅。当距到期还有几个月时，这两个数字可能相差几十点。

到期与交割

美国股指期货按季度到期，以现金交割。对于E-mini S&P 500，最终结算价基于合约月份第三个星期五的指数特别开盘报价（special opening quotation），该报价根据指数成分股的开盘价计算。大多数交易者会在到期前约一周展期到下一个合约，此时成交量会转移到新的近月合约。

为什么日内交易者青睐股指期货

特点 实际意义
流动性深厚 美股交易时段内，ES和NQ的点差通常为一跳
近24小时可交易 欧洲和亚洲的交易者可以在自己的白天交易美国指数
不受“日内交易者规则”约束 美国的模式日内交易者（PDT）规则适用于股票保证金账户，而不适用于期货账户
中央清算 合约履约不依赖交易商自身的资产负债表
规模可灵活调整 微型合约允许以每个标普点$5为单位调整仓位
美国的税务处理 收益通常按第1256条（Section 1256）的60/40规则征税；参见期货与其他金融工具对比

这些特点同样有代价。在上述点位下，一张ES合约代表着二十五万美元的指数敞口，而一些经纪商的日内交易保证金远低于交易所的初始保证金。ES出现20点的不利波动，在很多交易日都很平常，这就是每张合约$1,000的亏损。多个国家针对零售日内交易者的研究一致发现，绝大多数人长期来看都在亏钱，而杠杆会让这一结果来得更快。

计算示例：用MES代替ES确定仓位

一位账户为$10,000的交易者，希望每笔交易的风险不超过1%，即$100。他的止损距入场价8点。

  • 用ES：8点 x $50 = 每张合约$400的风险。即使只做一张，也是风险上限的四倍。
  • 用MES：8点 x $5 = 每张合约$40的风险。做两张合约的风险为$80，在上限之内。

这正是微型合约存在的主要原因。一般方法参见仓位管理。

常见错误

  • 混淆点和跳。 ES的一点等于四跳。ES中“10跳止损”只有2.5点，即$125。
  • 把NQ当成ES来做。 NQ的指数点位和波动率都更高，意味着每张合约的美元波动更大。
  • 交易即将到期的合约。 展期之后，旧合约的流动性会枯竭，点差和滑点都会变差。
  • 忽视已排期的新闻。 CPI、就业报告和央行决议可能在几秒钟内让股指期货波动几十点。参见新闻交易与财经日历。
  • 没有计划就持仓过周末。 市场从周五下午到周日晚间休市，开盘价可能远离周五的收盘价。

常见问题

ES和MES有什么区别？

两者都跟踪S&P 500，最小变动价位都是0.25点，但ES为每指数点$50，MES为每指数点$5。一张MES在规模、风险和保证金上都是一张ES的十分之一。

NQ一个点值多少钱？

E-mini Nasdaq-100（NQ）一个点值$20，每个0.25点的最小变动价位值$5。Micro E-mini Nasdaq-100（MNQ）一个点值$2，一跳值$0.50。

为什么期货价格与S&P 500指数不同？

期货价格包含了为指数成分股融资至到期的成本，再减去这些股票支付的股息。这个差额称为公允价值或基差，到期时会收缩为零。

E-mini期货什么时候交易？

CME股指期货从美国时间周日晚间到周五下午，每天近24小时交易，每天从美国东部时间下午5:00开始有一小时的休市。节假日安排请查看交易所公告。
