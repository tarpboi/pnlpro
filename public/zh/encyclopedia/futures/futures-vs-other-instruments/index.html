期货与股票、差价合约及永续合约对比

阅读约 7 分钟 · 更新于 2026年11月23日

期货、股票、差价合约（CFD）和加密货币永续合约都可以让你获得同一个市场的敞口，但它们在杠杆、成本、交易背后由谁担保、监管方式和税务处理上各不相同。例如，对于一位想要获得S&P 500敞口的交易者来说，指数ETF、指数CFD、E-mini期货和加密货币交易所上的永续合约，在相同的持有期内可能表现得截然不同。选择合适的工具是一个匹配度的问题，而不是哪个“最好”的问题。

核心要点

  • 场内交易的期货实行中央清算，消除了CFD和离岸加密衍生品中存在的大部分交易对手风险。
  • 期货的杠杆内嵌于合约之中，没有每日融资费用，而且通常远高于股票保证金所允许的水平。
  • 在美国，受监管的期货通常按第1256条（Section 1256）的60/40规则征税，并且不受股票的模式日内交易者规则约束。
  • CFD灵活，在美国以外广泛可得，但有融资成本和交易商对手风险，且不向美国零售交易者提供。
  • 加密永续合约永不到期，但持有者需要支付或收取资金费，交易平台自身关于强平和保险基金的规则也很重要。

杠杆与保证金

对于股票，杠杆来自借款。在美国的保证金账户中，T规则（Regulation T）通常把初始借款限制在购股金额的50%，即隔夜约2比1的杠杆。符合条件的账户日内购买力可以更高。

对于期货，合约本身就带有杠杆。你缴纳的履约保证金只占名义价值的一小部分，并且不需要为其余部分支付利息。融资成本依然存在，但它以基差的形式内含于期货价格之中，详见股指期货。

CFD的杠杆由经纪商在当地规则范围内设定。在欧盟，监管机构对零售CFD杠杆设有上限，例如主要货币对为30比1，主要股票指数为20比1，并要求经纪商披露零售账户中亏损账户的比例。这些披露通常显示，大多数零售CFD账户都在亏钱。

加密永续合约在某些平台上可以提供非常高的杠杆。高杠杆会把距离强平（爆仓）的空间压缩到很小的价格波动。

成本

计算示例：持有$50,000敞口30天

假设一位交易者想要持有约$50,000的股指多头敞口30天。以下数字仅用于说明；实际费率因经纪商、平台和市场状况而异。

  • 期货： 在指数点位5,000时，两张MES合约提供 2 x 5,000 x $5 = $50,000 的敞口。成本是每张合约的双边佣金和交易所费用（通常只有几美元），外加点差。融资成本内含于基差之中，而不是作为单独一项收取。
  • CFD： 假设经纪商收取基准利率加2.5%，合计年化7%。30天的融资费用为 $50,000 x 7% x 30 / 365 = 约$287.67，外加点差。
  • 加密永续合约： 假设资金费率平均为每8小时0.01%，由多头支付。即每个周期 $50,000 x 0.0001 = $5，每天三次，所以每天$15，30天共$450，外加交易手续费。资金费率不断变化，也可能转为负值，因此这个数字可能高得多，也可能低得多。参见资金费率。

关键区别在于：CFD融资费和永续合约资金费是明确的、持续发生的费用，而期货则把持有成本折算进你的成交价格之中。在较短的持有期内，点差和佣金通常最重要；在较长的持有期内，融资成本占主导。参见交易成本与费用。

清算与交易对手风险

交易受监管的期货时，由清算所担保履约。它向每家会员公司收取保证金，每日对头寸进行盯市，并持有违约基金。在美国受监管的期货经纪商处，客户资金必须存放在隔离账户中。

交易CFD时，你的交易对手是经纪商。如果经纪商倒闭，你能追回多少取决于当地的客户资金规则和任何赔偿计划。在加密货币交易所，你依赖的是交易所的偿付能力和诚信，2022年FTX的崩溃就说明了这一点。永续合约平台还可能使用自动减仓（auto-deleveraging，ADL），即在保险基金无法覆盖亏损时，强行平掉盈利头寸来弥补。

美国的模式日内交易者规则

在美国，FINRA的模式日内交易者（PDT）规则曾要求在五个工作日内进行四次或以上日内交易的保证金账户，必须保持至少$25,000的权益。FINRA已以日内保证金标准取而代之，自2026年6月4日起生效，经纪商可以在2027年10月之前逐步实施这一变化，因此请查看你的经纪商当前的规则。无论哪种情况，这都是一条证券规则。它不适用于期货账户，这也是美国小账户日内交易者转向微型股指期货的原因之一。参见股票日内交易。

美国税务：第1256条

美国纳税人交易的大多数受监管期货，都属于《国内税收法典》（Internal Revenue Code）中的“第1256条合约”。概括来说：

  • 60/40处理： 无论持仓多久，盈亏都按60%长期资本利得和40%短期资本利得处理。
  • 年末盯市： 未平仓头寸被视为在当年最后一个工作日按公允市场价值卖出。

计算示例

一位美国交易者通过每次只持有几分钟的期货日内交易，净赚$10,000。根据第1256条，其中$6,000被视为长期资本利得，$4,000被视为短期资本利得。作为说明，以20%和37%分别作为联邦长期资本利得和普通所得的最高税率，混合最高税率为 0.6 x 20% + 0.4 x 37% = 12% + 14.8% = 26.8%，而如果全部按短期处理则为37%。实际税率取决于收入、申报身份、州税和现行法律。

持有一年或以下的股票按短期资本利得征税。CFD、点差交易和加密衍生品的税务处理取决于所在国家，并会随时间变化。例如，在英国，点差交易对大多数个人而言历来免征资本利得税。本节仅为一般性信息，不构成税务建议；参见交易税务概览，并咨询合格的专业人士。

常见错误

  • 比较保证金而不是名义价值。 保证金越低意味着杠杆越高，而不是风险越低。
  • 忽视CFD和永续合约的融资成本。 每日费用在数周和数月内会不断累积。
  • 以为所有“期货”都一样。 受监管的CME合约和离岸永续合约在清算、监管和客户保护方面都不相同。
  • 凭记忆套用税务规则。 各国规则不同且会变化；在据此做规划之前，请核实现行法律。
  • 仅凭杠杆选择工具。 大多数使用高杠杆的零售交易者都在亏钱；杠杆放大的是交易者拥有的优势，或者优势的缺失。

常见问题

期货比CFD更好吗？

总体而言两者无所谓谁更好。期货提供中央清算、透明的交易所定价，且没有明确的融资费用；CFD则提供更小的交易规模，并能在一个账户中接触众多市场，但存在经纪商对手风险和每日融资费用。

模式日内交易者规则适用于期货吗？

不适用。美国PDT规则适用于证券保证金账户，而不适用于受CFTC和NFA监管的期货账户。

期货的60/40规则是什么？

根据美国第1256条，受监管期货的盈亏无论持有期长短，都按60%长期资本利得和40%短期资本利得处理。税务规则会变化，请核实现行法律并寻求专业建议。

期货和永续合约有什么区别？

传统期货有到期日，并在到期时向现货收敛。永续合约永不到期，通过多空双方之间定期支付的资金费，使其价格保持在现货附近。
