钱包安全是指防止加密资产丢失或被盗的一整套习惯和工具。在加密世界，通常没有银行能替你撤销欺诈交易，所以一个失误，比如在假网站上输入助记词或签署了恶意授权，就可能在几秒钟内清空钱包。活跃交易者面临的风险更大，因为他们要连接很多应用、签署很多交易，还要把资金放在交易所和热钱包里。

要点

  • 在交易所，私钥由交易所掌控；自托管时则由你掌控，一旦私钥丢失或被盗，没有人能帮你找回资金。
  • 助记词是万能钥匙：绝不要把它输入任何网站、应用、聊天窗口或云端文档。
  • 如今大多数盗币是通过签名而非窃取助记词实现的：恶意授权和 permit 签名让盗币程序能够转走你的代币。
  • 把资金分散在冷钱包、日常使用的热钱包，以及金额与活跃交易量相匹配的交易所余额之间。
  • 用于机器人的交易所 API 密钥应禁用提现权限，并限定特定 IP 地址。

托管与自托管

托管（交易所） 自托管（你自己的钱包）
谁掌握私钥 交易所 你
主要风险 交易所倒闭、被盗、账户冻结、账户被盗用 私钥丢失、钓鱼、恶意签名、恶意软件
找回 重置密码和客服支持 没有，除非你事先设置了恢复方式
最适合 活跃交易余额、法币入金 长期持仓、使用 DeFi

2022年11月的 FTX 崩盘展示了托管风险；见 CEX 与 DEX。自托管消除了这种风险，但你自己就成了安全团队。

在交易所，请用独立的密码保护账户，使用身份验证器应用或硬件安全密钥进行双重验证（不要用短信，短信容易遭受 SIM 卡劫持攻击），并在有提供的情况下开启提现地址白名单和防钓鱼码。

助记词

自托管钱包由助记词（也称恢复短语）生成，通常为 12 或 24 个单词。任何拿到这些单词的人，都能控制由它们派生出的所有账户。

实用规则：

  • 把它写在纸上或刻在金属板上，把副本分别存放在不同的安全地点。
  • 绝不要拍照、存在云笔记里、通过电子邮件发送，或保存在联网的密码管理器中，除非你完全理解其中的取舍。
  • 绝不要在网站、浏览器插件弹窗或表单中输入助记词。任何正规客服、空投或“钱包验证”都不会向你索要它。
  • 在依赖一个新钱包之前，先用小额资金测试恢复流程。

可选的密码短语（有时称为第 25 个单词）能在助记词被人找到时多一层保护，但如果你忘了它，资金就会丢失。

硬件钱包

硬件钱包把私钥保存在专用设备上，并在设备内部签署交易，因此私钥永远不会接触你的电脑。它能防止恶意软件窃取私钥，但无法阻止你自己批准一笔恶意交易。

正确使用：

  • 直接从制造商或授权经销商处购买，绝不要买二手的。
  • 确认之前先看清设备屏幕上显示的内容。如果显示的是一串看不懂的十六进制数据（“盲签”），要当作警告信号，金额较大时尤其如此。
  • 通过官方应用及时更新固件。

2025年2月交易所 Bybit 被盗约 15 亿美元，FBI 将其归咎于朝鲜黑客。此次攻击是通过一个被入侵的网页界面实现的：界面向签名者展示了一笔看似正常的交易，而底层交易实际上交出了钱包的控制权。如果签名者批准的是他们无法核实的内容，即便是配合硬件钱包使用的多签方案也可能被攻破。

代币授权及其撤销

要让 DEX 或协议能动用你的代币，你需要为其智能合约签署一项授权（allowance）。许多应用会请求无限额授权，这样你就不必再次授权。如果该合约后来被攻击，或者你授权的本身就是恶意合约，你的代币可能随时被转走，而无需你再次签名。

有些代币还支持 permit 签名，通过链下签名消息而非链上交易来授予授权。盗币程序很喜欢这种方式，因为签名不花 Gas 费，看起来也人畜无害。

实例：一笔陈年授权

某交易者两年前授权一个 DeFi 协议无限额动用 USDC，之后再也没用过它。钱包里现在有 25,000 USDC。如果该协议的合约被攻击，攻击者可以转走全部 25,000 USDC。如果当初交易者只授权了那笔交易所需的 2,000 USDC，交易完成后风险敞口就是零，最多也只有 2,000 USDC。

良好习惯：

  • 在界面允许的情况下，只授权你需要的金额。
  • 定期使用区块浏览器的授权查询工具或信誉良好的撤销工具，检查并撤销旧授权。撤销需要支付少量 Gas 费。
  • 用一个单独的钱包来试用新应用。

盗币程序与钓鱼

盗币程序（drainer）是一种恶意工具包，一旦你连接钱包并签名，它就会把你的代币和 NFT 转给攻击者。它们通过以下途径传播：

  • 仿冒真实 DEX、钱包和发射平台的假网站，通常借助搜索广告推广。
  • 项目方和网红被盗的社交媒体账号，发布“铸造”或“领取”链接。
  • 以提供客服、工作机会或合作为名的私信。
  • 假冒的浏览器插件和钱包应用。

防范措施：

  • 把常用网站加入书签，并通过书签访问。
  • 把任何催促你“立即领取”或“你的钱包已被入侵，请在此验证”的消息都视为恶意。
  • 仔细阅读签名请求。越来越多的钱包会模拟交易，显示哪些资产将离开你的钱包。如果模拟结果显示有你意料之外的资产流出，就拒绝签名。
  • 绝不要签署你看不懂的消息，尤其是 permit 和 “setApprovalForAll” 请求。

假空投

不明代币有时会出现在你的钱包里。其中很多是诱饵：代币名称或网址会把你引导到一个网站，当你尝试卖出或领取时，它就会清空你的钱包。不要与来路不明的代币交互，在钱包界面中把它们隐藏起来即可。真正的空投如何运作，见空投与积分撸毛。

地址投毒

攻击者会从一个看起来像你常用地址的地址发起极小额或零金额转账，让首尾几位字符都对得上。例如，你真正的交易对象可能是 0x7a3F...9c21，而攻击者的地址是 0x7a3E...9c21。这个假地址随后就会出现在你的交易记录中。如果你从记录里复制地址，资金就可能被转给攻击者。

防范措施：

  • 从已保存的地址簿或原始来源复制地址，而不是从交易记录中复制。
  • 核对完整地址，而不只是开头和结尾。
  • 大额转账前先发一笔小额测试交易。

交易者的冷热钱包分配

对于一位拥有 40,000 美元加密资产组合、交易活跃的人，一种实用的结构如下：

存放位置 金额 用途
硬件钱包（冷钱包） $30,000 长期持仓；很少连接
交易所账户 $7,000 活跃交易和保证金
热钱包 $2,500 DeFi 和链上交易
一次性钱包 $500 测试新应用、铸造和不明网站

这样做的目的是：一个钱包被盗或一家交易所倒闭，不会让你失去全部资产。定期把利润从热钱包转到冷钱包。根据你自己的交易活动调整比例。

API 密钥安全

交易机器人和资产追踪工具通过 API 密钥连接交易所。一个带有提现权限的密钥一旦泄露，就可能清空整个账户。

  • 为每个机器人或服务创建单独的密钥。
  • 在每个交易密钥上禁用提现权限。
  • 在交易所允许的情况下，将密钥限定于特定 IP 地址。
  • 把密钥存放在环境变量或密钥管理工具中，绝不要写进你分享的代码或提交到公开代码仓库。
  • 删除不再使用的密钥。
  • 对要求获取宽泛权限密钥的第三方机器人或“跟单”服务保持警惕。见构建交易机器人。

保管你私钥的 Telegram 交易机器人也存在类似风险；见 Meme 币交易机器人。

如果出了问题

  • 立即把剩余资金转移到一个使用新助记词的全新、干净的钱包。
  • 如果被盗钱包中还有资产，撤销其上的授权。
  • 向警方报案，并在相关情况下通知资金流入的交易所。
  • 不要理会任何声称收费即可追回被盗加密资产的人。追款骗局专门在被盗后立即瞄准受害者。见交易骗局。

常见错误

  • 以电子方式存储助记词。
  • 不看内容就签署交易。
  • 在旧合约上保留无限额授权。
  • 所有操作都用同一个钱包。
  • 从交易记录中复制地址。
  • 给 API 密钥开启提现权限。

常见问题

存放加密货币最安全的方式是什么？

对于长期持仓，标准做法是使用从制造商处购买的硬件钱包，并把助记词离线备份在安全地点。交易所和热钱包里只放你正在活跃交易的资金。

如何撤销代币授权？

使用区块浏览器的代币授权查询工具或信誉良好的撤销工具，连接钱包，撤销你不再需要的授权额度。每次撤销都是一笔链上交易，需要支付少量手续费。

什么是盗币程序（drainer）？

盗币程序是一种恶意脚本，通常藏在假网站上，诱骗你签署授权或转账，把你的资产转给攻击者。仔细阅读签名请求、只通过书签访问网站，是主要的防范手段。

什么是地址投毒？

这是一种骗局：攻击者从一个看起来像你常用地址的地址发起小额转账，希望你从交易记录中复制它。务必从可信来源复制地址，并核对完整的字符串。
