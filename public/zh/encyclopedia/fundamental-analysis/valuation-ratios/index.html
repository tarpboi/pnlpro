估值比率

阅读约 6 分钟 · 更新于 2026年11月23日

估值比率把公司的市场价格与其业务的某个衡量指标进行比较，例如盈利、销售额、账面价值或现金流。它们提供了一种快速判断方法：相对于自身历史、竞争对手或整个市场，一只股票看起来是便宜还是昂贵。它们是捷径，而不是答案：低比率可能意味着捡到便宜，也可能意味着企业正在衰退；高比率可能意味着快速增长，也可能意味着过度乐观。

要点速览

  • 每个比率把价格与不同的基本面指标比较，因此各有盲点；分析师会同时使用多个比率。
  • 基于企业价值的比率考虑了债务和现金，因此在比较资产负债表不同的公司时，比市盈率更好用。
  • 比率只有放在背景中才有意义：要把公司与同行业公司及其自身历史比较，而不是与整个市场比较。
  • 低比率可能反映了真实存在的问题（即“价值陷阱”），而高比率可能因强劲增长而合理。
  • 估值几乎无助于把握短线时机；昂贵的资产可能在数年内变得更加昂贵。

主要比率

下表全程使用同一家示例公司：

  • 股价：$50.00；流通股：1亿（100 million）股；因此市值为50亿美元（$5.0 billion）。
  • 过去12个月EPS：$2.50（净利润2.5亿美元，$250 million）。分析师对明年EPS的预测：$3.00。
  • 预期EPS年增长率：15%。
  • 营收：20亿美元（$2.0 billion）。账面价值（股东权益）：25亿美元（$2.5 billion）。
  • 债务：15亿美元（$1.5 billion）。现金：5亿美元（$0.5 billion）。
  • EBITDA：6亿美元（$600 million）。自由现金流：2.5亿美元（$250 million）。年度股息：每股$1.00。
比率 公式 计算示例 结果
市盈率（P/E，滚动） 股价 / 过去12个月EPS 50.00 / 2.50 20.0x
远期市盈率 股价 / 明年预测EPS 50.00 / 3.00 16.7x
PEG 市盈率 / 预期EPS增长率（以%计） 20.0 / 15 1.33
市销率（P/S） 市值 / 营收 5.0bn / 2.0bn 2.5x
市净率（P/B） 市值 / 账面价值 5.0bn / 2.5bn 2.0x
EV/EBITDA (市值 + 债务 − 现金) / EBITDA (5.0 + 1.5 − 0.5)bn / 0.6bn = 6.0 / 0.6 10.0x
自由现金流收益率（FCF yield） 自由现金流 / 市值 0.25bn / 5.0bn 5.0%
股息率 每股年度股息 / 股价 1.00 / 50.00 2.0%

市盈率（P/E）

市盈率告诉你，投资者为每一美元的年利润支付了多少美元。市盈率为20，意味着市场按当前盈利的20年来给公司估值。它的倒数，即盈利收益率（这里是1 / 20 = 5%），可以让你把股票与债券收益率进行粗略比较。当盈利为负时，市盈率没有意义；当盈利暂时被压低或抬高时，市盈率会失真。

远期市盈率使用分析师的预测而不是过去的盈利。由于市场为未来定价，它更有参考价值，但它的好坏取决于预测，而对较远年份的预测往往偏乐观。

PEG比率

PEG用市盈率除以预期增长率，因此一家高市盈率但增长迅速的公司可能看起来估值合理。PEG约为1常被认为是合理的，不过这只是经验法则，而不是定律。PEG高度依赖一个未必能实现的增长预测，而且忽略了债务和风险。

市销率（P/S）

市销率把市值与营收进行比较。它适用于尚未盈利的年轻公司，以及利润率暂时被压低的企业。它的弱点是营收不等于利润：利润率很薄的公司，理应比利润率很高的公司享有低得多的市销率。

市净率（P/B）

市净率把市值与会计上的股东权益进行比较。它最适用于银行、保险公司和工业企业等重资产行业，因为这些企业的资产负债表能比较好地反映业务价值。对于软件公司或消费品牌，它就没那么有用了，因为这些公司的主要资产——代码、客户和声誉——大多不会出现在资产负债表上。

企业价值倍数（EV/EBITDA）

企业价值（EV）是整个企业对股东和债权人合计的价值：市值加债务减现金。EBITDA是息税折旧摊销前利润，可以粗略代表经营性现金利润。EV/EBITDA被广泛用于比较债务水平和税务状况不同的公司，也用于收购分析。EBITDA忽略了资本支出，因此会美化那些必须不断再投资的企业，例如电信公司或航空公司。

自由现金流收益率

自由现金流收益率显示企业产生的自由现金相对于其市值有多少。5%的收益率意味着公司每年产生相当于其市值5%的现金，可用于支付股息、回购或减债。许多投资者认为它比市盈率更诚实，因为现金比会计利润更难调整。自由现金流如何计算，见财报与财务报表。

股息率

股息率是年度股息除以股价。高股息率可能意味着一家成熟、现金充裕的企业，也可能意味着股价已经暴跌，因为市场预期股息会被削减。要检查自由现金流是否足以覆盖股息。

实例演算：为什么债务很重要

把示例公司与一家竞争对手比较：两者市值相同、EBITDA相同，但竞争对手的债务多得多。

示例公司 竞争对手
市值 $5.0bn $5.0bn
债务 $1.5bn $4.0bn
现金 $0.5bn $0.0bn
企业价值 $6.0bn $9.0bn
EBITDA $0.6bn $0.6bn
EV/EBITDA 10.0x 15.0x

如果两者净利润相同，它们的市盈率也会相同，用市盈率筛选会把它们评为同样便宜。实际上，买下竞争对手的整个企业要多花50%的钱，因为买方要多承担30亿美元（$3.0 billion）的净债务（40亿美元对10亿美元，$4.0 billion 对 $1.0 billion）。竞争对手的股东也承担着更大的风险，因为债权人优先受偿。这就是为什么在资产负债表不同时，分析师更喜欢使用基于EV的比率。

行业背景

由于增长、利润率、资本需求和风险各不相同，典型的估值比率在不同行业之间差异很大。

行业类型 分析师倚重的比率 原因
银行和保险公司 市净率、市盈率、股息率 资产负债表就是业务本身
软件和高成长科技公司 市销率、EV/销售额、远期市盈率、自由现金流收益率 利润可能很少或被用于再投资
公用事业和电信 股息率、EV/EBITDA 现金流稳定，债务沉重
能源和矿业 EV/EBITDA、自由现金流收益率、跨周期市净率 盈利随大宗商品价格大幅波动
房地产投资信托（REIT） 股价与运营现金流（FFO）之比、股息率 折旧会扭曲净利润

对于周期性公司，市盈率往往在周期顶部、盈利处于峰值时看起来最低，在周期底部、盈利低迷时看起来最高。从历史上看，因为市盈率低而买入周期股，是一种常见的在高点附近接盘的方式。

国家和指数背景同样重要。科技公司较多的市场，例如美国，平均估值比率往往高于以银行、能源和工业为主的市场，例如欧洲大部分地区、英国或香港。这种差距有一部分反映的是行业构成不同，而不是“便宜”与否。

估值不是择时工具

与一般的基本面分析一样，估值可以告诉你预期的长期回报可能是高还是低，但从历史上看，它对接下来几周或几个月会发生什么的指导作用很弱。由经济学家Robert Shiller推广的周期调整市盈率（CAPE）等全市场指标，与十年或更长时间的回报显示出一定关系，然而按这些指标衡量，市场曾经一连数年保持“昂贵”或“便宜”。因为一只股票看起来被高估就去卖空的交易者，可能在市场持续上涨时遭受巨额亏损。

在交易中，许多人把估值当作过滤器，例如避开EV/EBITDA高于某个水平的公司，然后依靠价格行为、催化剂或技术分析来把握时机。选股器让这种筛选变得很容易。

常见错误

  • 在不相关的行业之间比较比率， 例如拿银行的市盈率和软件公司的比。
  • 把低比率自动当作便宜。 盈利下滑、债务沉重或行业萎缩都可能让低比率合情合理。
  • 在盈利为负或被一次性项目扭曲时使用市盈率。
  • 盲目相信远期预测。 随着时间临近，预测常常被下调。
  • 用估值来把握短线时机， 或者仅仅因为一只股票看起来贵就做空它。

常见问题

多少市盈率算好？

没有唯一的好市盈率。它取决于公司的增长、风险、所属行业和利率水平，所以要把它与同类公司以及公司自身的历史进行比较。

市盈率和EV/EBITDA有什么区别？

市盈率把股价与每股净利润进行比较，忽略了公司有多少债务。EV/EBITDA把整个企业的价值（包括债务、扣除现金）与折旧前的经营利润进行比较，因此更适合比较资产负债表不同的公司。

低市盈率的股票一定值得买吗？

不一定。低市盈率可能反映了预期的盈利下滑、高负债、法律问题或市场萎缩。有充分理由显得便宜的股票被称为价值陷阱。

PEG比率为1是什么意思？

它意味着市盈率等于预期的年盈利增长率，常被用作估值合理的粗略标志。它高度依赖增长预测，而预测可能出错。
