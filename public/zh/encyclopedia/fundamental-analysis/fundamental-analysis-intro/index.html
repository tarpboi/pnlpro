基本面分析

基本面分析（fundamental analysis）研究的是资产价格背后的经济力量：对公司来说是盈利和现金流，对货币来说是利率和经济增长，对大宗商品来说是供求关系。它的核心观点是：资产有一个可以根据这些驱动因素来估算的价值，而市场价格会随着时间推移趋向这个价值。它对交易者很重要，因为持续数周乃至数年的最大、最持久的价格波动，通常都可以追溯到基本面的变化，或者市场对基本面预期的变化。

要点速览

  • 基本面分析根据资产的底层驱动因素估算它应值多少，再把这一估值与市场价格比较。
  • 价格变动取决于新信息与原有预期之间的差距，而不是消息本身的绝对好坏。
  • 不同资产的相关基本面各不相同：股票看现金流，货币看利率，大宗商品看库存，加密货币看采用率和代币供应。
  • 估值对假设极为敏感，折现率或增长率的微小变化，就可能让“合理价值”大幅变动。
  • 单靠基本面很难把握时机，所以许多交易者会把它与技术分析或严格的风险规则结合使用。

内在价值与价格

资产的价格就是最近一笔交易中买卖双方达成一致的价格。内在价值则是根据资产未来能产出什么或者它有多稀缺而得出的价值估计。两者可能长期背离。基本面分析者寻找的是那些差距很大、且有理由收敛的情况。

对于一家企业，其价值来自它未来将为所有者创造的现金，再折现到今天。十年后收到的一美元不如今天的一美元值钱，因为现在的钱可以赚取利息，而且未来充满不确定性。用来缩减未来现金流的比率就是折现率，当利率上升或现金流看起来风险更大时，折现率就会上升。

实例演算：“合理价值”有多敏感

折现现金流模型的一个简化版本是永续增长公式：

价值 = 明年每股自由现金流 / (折现率 − 增长率)

假设一家公司明年预计每股产生$5.00的自由现金流，此后每年永续增长4%，投资者要求的回报率为9%。

情景 折现率 增长率 每股价值
基准情景 9% 4% $5.00 / 0.05 = $100.00
利率上升一个百分点 10% 4% $5.00 / 0.06 = $83.33
增长率高一个百分点 9% 5% $5.00 / 0.04 = $125.00

仅仅一个假设变动一个百分点，估值就会下降约17%或上升25%。这就是为什么基本面估值总是以区间的形式给出，为什么现金流在遥远未来的成长股会在利率上升时大跌，也是为什么两位同样严谨的分析师可能得出相差甚远的结论。

自上而下与自下而上

组织基本面研究大致有两种方式。

自上而下（top-down）的分析从全球经济入手，逐步收窄范围。分析师首先判断经济增长、通胀和利率的走向，然后判断哪些国家和货币会受益，再看哪些行业，最后才落到具体资产。一位自上而下的交易者可能会得出结论：欧洲通胀回落将促使欧洲央行降息，然后通过债券、欧元或对利率敏感的股票来表达这一观点。

自下而上（bottom-up）的分析从单个公司或资产入手，向外延伸。一位自下而上的选股者会研究公司的财务报表、竞争地位和管理层，如果这家企业看起来被低估，无论经济背景如何都可能持有它。

自上而下 自下而上
出发点 全球宏观：增长、通胀、利率 单个公司或资产
主要工具 经济指标、央行政策、资本流动 财务报表、估值比率、行业分析
典型使用者 宏观基金、外汇和利率交易者、资产配置者 选股者、价值型和成长型投资者
主要风险 宏观判断正确，却选错了交易工具 在下跌的市场中持有一家好公司

大多数从业者会把两者结合起来。即便是纯粹的选股者，也需要知道利率何时变动到足以让整个市场重新定价。

不同资产类别的基本面有何不同

股票

股票的基本面分析是最成熟的。分析师研究营收、利润率、现金流、债务和增长，并用市盈率等比率把股价与这些数字进行比较。季度或半年度财报（视国家而定）是最主要的预定事件。从长期来看，股票回报在历史上一直跟随盈利增长加股息，而估值的变化则在其间带来大幅波动。

货币

货币没有盈利，所以它的基本面是宏观经济层面的。最重要的是其央行设定的利率相对于其他央行的水平，此外还有通胀、经济增长、贸易和资本流动，以及危机期间的避险需求。当数据或央行决议改变了市场对未来利率路径的预期时，外汇市场往往波动最大。完整清单见影响汇率的因素。

大宗商品

大宗商品的基本面关乎实物供求：产量、天气、库存、仓储成本和期货曲线的形态。每周的美国原油库存数据或每月的农作物产量预估等预定报告，可能会引发价格剧烈波动。大宗商品交易一文对这些驱动因素有详细介绍。

债券

债券价格取决于利率、通胀预期和发行人的信用质量。大型经济体的政府债券主要对央行政策和通胀数据作出反应。见债券与利率交易。

加密货币

大多数加密资产不产生现金流，所以经典估值方法无法直接套用。分析师转而关注网络使用量、手续费、代币供应和解锁时间表、区块链上可见的持有者行为，以及流动性状况。代币经济学和链上分析是加密货币领域中最接近基本面分析的方法。自加密货币进入主流投资组合以来，全球流动性和利率也已成为重要的驱动因素。

预期比消息本身更重要

市场是前瞻性的。等到一条消息发布时，交易者通常已经对它的内容形成了看法，价格也已经反映了这种看法。真正推动价格的是意外：实际数字与预期之间的差距。

这就是为什么一家公司公布创纪录的利润，股价却可能下跌；或者一份疲软的就业报告发布后，如果它没有担心的那么差，货币反而可能上涨。基本面交易者必须问两个问题：会发生什么？市场已经认为会发生什么？只有当第二个问题的答案是错的时候，优势才存在。

基本面与技术分析相结合

基本面分析告诉你什么可能被错误定价，却很少告诉你错误定价何时会修正，而市场保持“错误”的时间，可能比加杠杆的交易者保持偿付能力的时间更长。技术分析研究价格和成交量，用来判断时机和趋势。

一种常见的结合方式：

  1. 用基本面选择方向或候选清单。例如，某种货币的央行加息速度可能快于市场预期。
  2. 用价格行为或趋势工具把握入场时机，等待市场开始印证这一观点。
  3. 根据交易逻辑明显出错的位置设定止损，并调整仓位大小，使亏损在可承受范围内。

也有交易者反其道而行之：他们交易技术形态，但会查看经济日历，避免在重大数据发布期间持仓。

证据怎么说

学术研究的结论喜忧参半，但颇具启发性。规模大、流动性好的市场很难持续战胜，从历史上看，扣除费用后，大多数主动型基金经理在长期内跑输低成本的指数基金。与此同时，研究者也记录了一些与基本面相关、长期存在的收益规律，例如较便宜的股票（价值股）和盈利能力更强的公司在非常长的时间跨度内倾向于跑赢大盘，不过这些效应会伴随漫长的失效期。基于基本面的短线交易更难，因为专业交易台会在几毫秒内消化预定发布的消息。

对散户交易者来说，实际的教训是：主要用基本面来理解市场为何变动，避免站在重大转变的错误一边，而不是指望在每一个数据点上都比机构分析得更好。

常见错误

  • 把合理价值当作目标价。 正如上面的例子所示，估值依赖的假设可能错得离谱。
  • 忽视预期。 只看标题交易（“好消息，所以买入”），而不去核实哪些已经被市场消化。
  • 用基本面把握短线时机。 便宜的资产可能在数年内变得更便宜。
  • 把股票式的估值方法硬套到没有现金流的资产上， 例如许多加密代币。
  • 执着于单一叙事。 建立在单一变量（例如利率）之上的投资逻辑，可能被另一个变量（例如经济衰退或信用事件）压倒。

常见问题

基本面分析比技术分析更好吗？

两者都不是在所有情况下都更好。基本面分析更适合较长的时间周期，以及理解价格为何变动；技术分析则更多用于把握时机和控制风险，许多交易者会两者结合使用。

基本面分析可以用于日内交易吗？

只能在有限程度上使用。日内交易者主要利用经济日历和财报日历来了解什么时候可能出现波动，但在单个交易时段内，资产的长期价值很少起作用。

内在价值和市场价格有什么区别？

市场价格是最近的成交价，由供求决定。内在价值是分析师根据资产未来现金流或其他驱动因素对其价值的估计，它的可靠程度完全取决于背后的假设。

基本面分析适用于加密货币吗？

部分适用。大多数代币没有现金流，所以传统估值方法并不适用；但供应时间表、网络使用量、流动性和宏观环境都是真实的驱动因素，分析师会转而研究这些。
