配对交易与统计套利

配对交易（pairs trading）是一种市场中性策略：当两个密切相关资产之间的价格关系异常拉大时，买入其中一个、做空另一个，押注差距会收窄。统计套利（statistical arbitrage，简称 stat arb）把这一思路扩展到用统计模型挑选出的大型持仓组合。两者都是把均值回归应用于相对价格而非单一价格，也都依赖于可能减弱或破裂的价格关系。

核心要点

  • 配对交易从两个资产之间价差的变化中获利，而不是从大盘的方向中获利。
  • 协整（即价差本身倾向于回到稳定水平）比相关性更重要。
  • 对冲比率决定每个资产各交易多少，使价差保持平衡。
  • 进出场通常由价差的Z值来定义，并在价格关系破裂时设置止损。
  • 已公开的配对交易收益随时间推移不断下降，而拥挤的统计套利仓位可能会剧烈平仓，例如2007年8月。

配对交易的原理

经典例子是同一行业、业务相似的两家公司，比如两家大型石油生产商、两家支付网络公司，或同一公司的两类股票。它们的价格受许多相同因素驱动。当其中一只在没有明确原因的情况下相对另一只大幅上涨时，配对交易者会做空表现较强的一只，买入表现较弱的一只。如果关系维持不变，差距收窄，无论大盘涨跌，这笔交易都能获利。

配对交易通常被追溯到1980年代华尔街交易部门的量化团队，人们常把功劳归于摩根士丹利的一个团队。在2006年一项被广泛引用的研究中，Gatev、Goetzmann 和 Rouwenhorst 在美股上测试了一条简单规则：把标准化价格走势最接近的股票配成对，在它们分化时进行交易。他们发现了历史超额收益，但也发现样本后期的收益较低，后续研究同样报告了这种规律。

相关性与协整

相关性和协整经常被混淆，而两者的区别很重要。

概念 衡量什么 对配对交易是否有用？
相关性 两个序列的收益在每一期是否同涨同跌 单靠它不够。两只高度相关的股票也可能永久性地分道扬镳
协整 两个价格序列的某种组合（价差）是否平稳，即是否倾向于回到稳定的均值 有用。这才是配对交易真正押注的东西

两只股票的日收益可以高度相关，而其中一只多年来一直比另一只增长得稍快。这时价差会呈趋势性变化，做空“贵”的那只的交易者会持续亏损。反过来，协整的序列可能日相关性只是中等，却仍保持稳定的长期关系。

Engle 和 Granger 于1987年提出的 Engle-Granger 两步法是一种常用检验：先用一个价格对另一个价格做回归以估计关系，再检验残差价差是否平稳。Johansen 检验可处理两个以上的资产。关于相关性在投资组合中的表现，参见相关性与组合风险。

构建价差

对冲比率

对冲比率 β 表示需要多少单位的资产 B 来抵消一单位的资产 A。它通常通过在回看窗口内用 A 的价格对 B 的价格（或对数价格）做回归来估计：

Spread = Price_A − β × Price_B

美元中性的配对持有等金额的多头和空头。贝塔中性的配对则会针对市场敏感度的差异进行调整。对冲比率会漂移，因此许多交易者在滚动窗口上重新估计，或用卡尔曼滤波连续更新。

半衰期

半衰期估计价差通常需要多长时间才能把偏离均值的幅度收回一半。它来自用价差的变化量对其前一期水平做回归。5到20天的半衰期适合波段交易；以月计的半衰期会占用资金，并增加关系先行破裂的可能。

import numpy as np
import statsmodels.api as sm
from statsmodels.tsa.stattools import coint

def pair_stats(a: np.ndarray, b: np.ndarray):
    """a, b：对齐的价格数组（通常使用对数价格）。"""
    beta = sm.OLS(a, sm.add_constant(b)).fit().params[1]
    spread = a - beta * b
    coint_p = coint(a, b)[1]          # Engle-Granger 检验；p 值小表明存在协整
    lagged = spread[:-1]
    delta = np.diff(spread)
    lam = sm.OLS(delta, sm.add_constant(lagged)).fit().params[1]
    half_life = -np.log(2) / lam if lam < 0 else np.inf
    return beta, coint_p, half_life

进出场规则

大多数配对系统交易的是价差的Z值，即价差偏离其滚动均值多少个标准差。

  • 入场： 当 z 升至约+2以上时做空价差（做空 A，做多 β 单位的 B）；当 z 跌至约−2以下时买入价差。
  • 离场： z 回到0附近时平仓。
  • 止损： 若 z 达到±4这样的极端值，或交易持续时间达到半衰期的数倍，则平仓。
  • 重新检验： 如果用近期数据做的协整检验不再通过，就停止交易这一配对。

从配对交易到统计套利

统计套利把同样的逻辑规模化。统计套利基金持有的不是一个配对，而可能是数百乃至数千个小额多空仓位。常见方法包括：

  • 用每只股票对冲其同行业股票组成的一篮子。
  • 用因子模型或主成分分析剔除市场和行业的波动，再交易预期会回归的残差收益。Avellaneda 和 Lee 在2010年的一篇论文中描述了这种针对美股的方法。
  • 将回归信号与订单流和成交量信息相结合的短周期模型。

尽管名字里有“套利”，统计套利并不是套利策略中所说的无风险套利。它依赖的是在大量仓位上平均成立的概率。

衰减与拥挤

优势衰减

随着越来越多的交易者运行类似的模型，他们瞄准的价差收敛得更快，机会也随之减少。速度更快的竞争者会抢走最干净的信号。过去持仓数周的策略，如今可能需要在几分钟内行动，甚至根本无利可图。

2007年8月量化地震

在2007年8月6日那一周，许多量化股票市场中性基金突然遭受了巨额亏损。在一项著名的分析中，Khandani 和 Lo 认为，可能的导火索是一家或多家大型基金迅速平仓，或许是为了筹集现金或削减其他地方的风险。由于许多基金持有相似的多空组合，被迫抛售让价格同时对所有基金不利，进而引发进一步的降风险操作。大部分亏损在几天内就回补了，但在底部减仓的基金把亏损锁定了。教训是：一个策略即使是市场中性的，也可能承担集中的拥挤风险。

实例

两只股票的估计对冲比率为1.2。从历史上看，价差 A − 1.2 × B 的均值为2.00美元，标准差为0.50美元。

  • 今天 A 的价格为51.50美元，B 为40.00美元。价差 = 51.50 − 1.2 × 40.00 = 51.50 − 48.00 = 3.50美元。
  • z = (3.50 − 2.00) / 0.50 = 3.0，高于+2的入场水平，因此交易者做空价差：做空1,000股 A（51,500美元），买入1,200股 B（48,000美元）。
  • 两周后 A 为51.00，B 为40.75。价差 = 51.00 − 48.90 = 2.10美元，z = 0.2，交易者离场。
  • 做空 A 的盈利：(51.50 − 51.00) × 1,000 = 500美元。做多 B 的盈利：(40.75 − 40.00) × 1,200 = 900美元。合计1,400美元。
  • 验算：价差从3.50降至2.10，变化1.40美元，乘以1,000单位价差 = 1,400美元。

还要从中扣除四条腿的佣金、每条腿付出的买卖价差，以及做空股票的借券费。做空的机制与成本参见卖空。

常见错误

  • 只按相关性挑选配对。 高相关性并不意味着价差会回归。
  • 挖掘数千个配对，然后交易回测最好的那些。 候选足够多时，总有一些配对会偶然看起来协整。参见过拟合与数据窥探。
  • 忽视结构性变化。 合并、分拆、新的监管规定或业务结构变化，都可能永久性地破坏价格关系。
  • 价差没有止损。 破裂的配对可能连续几个月持续分化。
  • 低估空头端成本。 借券费、召回和卖空限制都可能吞掉微薄的优势。

常见问题

配对交易是无风险的吗？

不是。两个资产之间的关系可能破裂，价差可能在收窄前进一步扩大，拥挤的仓位也可能突然平仓。配对交易降低了对市场方向的敞口，但带来了其他风险。

协整和相关性有什么区别？

相关性衡量两个资产的收益在每一期是否同向变动。协整则是指它们价格的某种组合构成一个倾向于回到稳定均值的价差，而这正是配对交易所依赖的。

配对交易应该用多大的Z值？

许多交易者在约±2入场、在0附近离场，并在±4这样更大的数值处止损。最佳阈值取决于成本、价差的半衰期以及配对本身，应在样本外检验。

配对交易现在还有效吗？

学术研究发现，随着这一策略广为人知，简单配对交易规则的收益随时间推移而下降。机会仍然存在，但与过去相比，往往规模更小、速度更快、竞争更激烈。
