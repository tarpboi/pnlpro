交易中的机器学习

交易中的机器学习（machine learning，ML）是算法交易的一个分支，它使用能从数据中学习规律的算法，而不是遵循人工编写的规则，来预测价格、划分市场状态或处理新闻等文本。量化基金广泛使用机器学习，但金融数据噪声大、变化不断，这让机器学习模型格外容易找到并不存在的规律。谨慎使用时，机器学习是有用的工具；草率使用时，它是做出一份令人信服、却在实盘中失效的回测的最快途径之一。

核心要点

  • 交易中的机器学习大多是监督学习：根据今天已知的特征预测未来的收益或方向。
  • 如何定义标签和验证模型，比选择哪种算法更重要。
  • 市场是非平稳的，信噪比极低，因此微小的准确率提升可能就有意义，而大幅提升则值得怀疑。
  • 标准的交叉验证在时间序列中会泄露未来信息；应使用滚动前推验证或清除式（purged）验证。
  • 大语言模型适合阅读和分类文本，但使用它们的回测可能被测试日期之后事件的知识所污染。

机器学习能做什么、不能做什么

机器学习擅长组合大量弱信号、捕捉非线性关系，以及大规模处理人类无法读完的数据，比如数以千计的新闻报道或公告文件。它无法创造数据中本不存在的可预测性。在大多数时间尺度上，资产价格基本上是不可预测的，而现存的可预测性大多也会在竞争中消失。在2020年一项著名研究中，Gu、Kelly 和 Xiu 发现，树集成模型和神经网络等灵活方法预测美股月度收益的效果优于传统线性模型，但收益中可预测的部分很小。

用监督学习生成信号

问题类型

  • 回归： 预测下一期收益的大小，例如5日收益。
  • 分类： 预测一个类别，比如涨或跌，或者“先触及止盈还是先触及止损”。
  • 排序： 按预期收益对资产排序，买入排名靠前的、做空排名靠后的，这是横截面选股的常用方法。

常用模型

模型类别 优点 缺点
线性回归与正则化回归（岭回归、Lasso） 简单、稳定、可解释 无法捕捉非线性效应
树集成模型（随机森林、梯度提升） 能很好地处理非线性和混合类型特征；在表格数据上表现强 可能过拟合噪声；预测不够平滑
神经网络 灵活；能处理序列、文本和图像 需要大量数据；难以解释；最容易过拟合

对于典型的表格型交易数据，正则化线性模型和梯度提升树是常见的起点。更复杂的模型需要更多数据来证明其合理性。

特征

特征是模型使用的输入。它们必须在预测时点就已知。

  • 基于价格： 多个时间尺度上的过去收益、波动率、与均线的距离，以及RSI等技术指标。
  • 成交量与订单流： 相对成交量、订单簿失衡、成交方向。
  • 横截面： 资产相对于其所在行业或大盘的收益。
  • 基本面： 估值比率、业绩超预期幅度，且只使用其发布日期之后的数据。
  • 另类数据： 文本情绪、网站流量、卫星或交易流水数据。
  • 市场环境： 波动率指数、利率，以及资金费率等情绪指标。

只用过去的数据对特征做归一化，例如滚动Z值，这样模型就永远不会看到用未来数据计算出的统计量。数据来源与时间戳参见市场数据。

标签

标签是模型要学习预测的目标，选好标签就解决了一半的问题。

  • 固定周期标签： 未来 N 根K线收益的正负或大小。简单，但忽略了价格路径以及真实交易会如何管理。
  • 三重障碍标签： 由 Marcos López de Prado 在其2018年的著作《Advances in Financial Machine Learning》中提出。每个样本按哪个条件先被触发来打标签：上障碍（止盈目标）、下障碍（止损）或时间上限。这与交易实际离场的方式相吻合。
  • 元标签（meta-labeling）： 由一个主模型或规则决定方向，再由一个次级机器学习模型预测每个主信号能否成功，可用于过滤交易或确定仓位规模。

相互重叠的标签，比如每天计算一次的5日收益，彼此共享信息。这一点必须在验证中加以处理。

非平稳性与噪声

金融关系会变化。在低利率时期成立的规律，可能在利率上升后消失；一个在众多交易者使用之前有效的特征，可能在那之后失效。信噪比极低：一个预测日度方向准确率达到52%至53%的模型就可能有用，而日度方向准确率达到70%几乎总是意味着程序有错误或存在数据泄露。

这与困扰基于规则的均值回归和趋势系统的市场状态问题是一样的。实际的应对办法包括：在滚动窗口上重新训练、优先选择更简单的模型、组合大量弱信号，以及监控实盘表现是否衰减。

无泄露的验证

标准的 k 折交叉验证会随机打乱数据，于是模型在未来数据上训练、在过去数据上测试。在交易中，应使用：

  • 滚动前推验证： 用过去的数据训练，在下一时期测试，然后向前滚动。
  • 间隔与清除： 剔除标签与测试期重叠的训练样本，并在测试期之后留出一段禁用间隔（embargo）。
  • 最终保留集： 一段在开发过程中从未动用过的近期数据。
import numpy as np
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.model_selection import TimeSeriesSplit

def walk_forward_accuracy(X, y, horizon=5, n_splits=5):
    """X：t 时刻已知的特征；y：t -> t+horizon 的标签。各行按时间顺序排列。"""
    splitter = TimeSeriesSplit(n_splits=n_splits, gap=horizon)  # gap 避免标签重叠
    scores = []
    for train_idx, test_idx in splitter.split(X):
        model = GradientBoostingClassifier(max_depth=3, n_estimators=200)
        model.fit(X[train_idx], y[train_idx])
        scores.append((model.predict(X[test_idx]) == y[test_idx]).mean())
    return np.mean(scores), np.std(scores)

你训练和评估的每一个模型都是又一次试验，因此过拟合与数据窥探中的多重检验问题在这里更加突出。

用大语言模型分析新闻与情绪

大语言模型（LLM）可以阅读新闻、业绩电话会议记录、公告文件和社交媒体帖子，并把它们转化为结构化信号：正面或负面语气、事件类型、提及的公司，或供人工交易者参考的摘要。实际用途包括过滤新闻流、给事件打标签，以及以远超人工的速度筛查大量文本。

重要的注意事项：

  • 前视污染。 一个用截至近期的互联网文本训练的模型，可能“知道”某家公司或某个市场在一篇历史文章发表之后的实际表现。因此，用过去的新闻回测基于 LLM 的情绪策略，结果可能远好于实盘交易。尽可能使用训练截止日期早于测试期的模型，或只在截止日期之后的数据上测试。
  • 错误与幻觉。 LLM 可能读错数字、混淆公司或编造细节。要验证输出，尤其是提取出的数字。
  • 延迟与成本。 等模型处理完一条新闻标题，快速交易者可能早已行动。LLM 信号往往更适合较慢的时间尺度。
  • 拥挤交易。 用人人可得的模型去分析人人可得的新闻，单靠这一点不太可能提供持久的优势。

强化学习（reinforcement learning）是一个活跃的研究领域，即让智能体在模拟器中通过反复试错学习交易策略，但它对模拟器的真实程度和过拟合尤其敏感。

实例：准确率不等于利润

某分类器在滚动前推测试中预测某股指基金次日方向的准确率为53%。假设平均上涨日和下跌日的幅度都约为1.0%。

  • 每笔交易的预期毛收益 = 0.53 × 1.0% − 0.47 × 1.0% = 0.06%。
  • 如果每个来回的成本为0.05%，净优势为每笔0.01%；若每天交易，每年约为252 × 0.01% ≈ 2.5%（不计复利）。
  • 如果每个来回的成本为0.10%，净优势为每笔−0.04%，每年约−10%。

同一个模型还必须在未来保持53%的准确率，而非平稳性让这一点充满不确定性。机器学习信号往往与低换手率策略结合使用效果最好，因为这样成本对微小优势的侵蚀更少。

常见错误

  • 对时间序列随机划分训练集和测试集。 这会把未来信息泄露到训练中。
  • 用未来数据计算特征，比如全样本归一化或使用修订后的经济数据。
  • 追求高准确率。 对收益预测的准确率极高，通常是数据泄露的迹象。
  • 在小数据上使用复杂模型。 用几年日K线训练的深度网络，其参数数量远远多于有效观测值。
  • 忽视成本和换手率。 模型交易过于频繁，微小的优势就会消失。
  • 相信用旧新闻做的 LLM 回测，却不处理训练数据污染问题。

常见问题

机器学习能预测股价吗？

机器学习能在收益中找到微弱但在统计上有用的规律，但无法可靠地预测价格。研究表明，收益中可预测的部分很小，而且规律会随时间变化。

哪种机器学习模型最适合交易？

没有唯一最好的模型。对于表格数据，正则化线性模型和梯度提升树是常见的起点，而标签、特征和验证方法的选择通常比算法更重要。

我能用 ChatGPT 或其他大语言模型来交易吗？

LLM 可以帮助总结新闻、分类情绪以及编写或审查代码，但它们对未来价格并没有可靠的洞察。把它们的输出当作一项有待检验的输入，并警惕可能被模型训练数据污染的回测。

机器学习交易策略为什么会失败？

常见原因包括对噪声过拟合、验证中存在数据泄露、市场环境变化，以及交易成本超过了预测出的微小优势。
