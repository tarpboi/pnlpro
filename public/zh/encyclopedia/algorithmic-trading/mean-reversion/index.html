均值回归交易

均值回归（mean reversion）是指价格或价差在大幅偏离近期均值后，有向均值回归的倾向。均值回归策略在异常急跌后买入、在异常急涨后卖出，押注这一波动是过度反应或暂时的供需失衡。这类策略往往赢得多、输得少，但一输就输得很重，因此在平静的市场中颇具吸引力，一旦趋势形成就非常危险。

核心要点

  • 均值回归押注短期的价格极端会部分反转；趋势跟踪押注的恰恰相反。
  • Z值以标准差为单位衡量价格偏离均值的程度，是定义“极端”的标准方法。
  • 布林带系统和短周期 RSI 系统是同一思路在散户中流行的版本。
  • 收益通常呈负偏态：胜率高，但偶尔会有大额亏损。
  • 主要风险是市场状态转变：被拉伸的价格没有回弹，而是继续沿原方向运动。

价格为什么会回归

有几种机制可以在短期内把价格推回均值附近：

  • 流动性需求。 急于离场的大卖家会把价格压到合理价值以下。承接这些卖盘的交易者要求获得补偿，这份补偿在价格回升时兑现。
  • 过度反应。 交易者有时会对消息、情绪或剧烈波动反应过度，价格随后部分修正。
  • 买卖价跳动（bid-ask bounce）。 成交在买价和卖价之间交替发生，使记录的价格出现统计上的反转，但这种反转实际上无法捕获。基于成交价的回测可能会把它误认为可交易的优势。
  • 结构性锚定。 有些价差，比如两个密切相关资产之间的价格差，受经济关系约束而联系在一起，这正是配对交易的基础。

短期反转

1990年前后的学术研究，包括 Jegadeesh 和 Lehmann 的研究发现，过去一周或一个月收益最差的美股，往往在接下来的一周或一个月跑赢，而表现最好的股票往往落后。这种短期反转效应与中期动量效应并存，后者是指过去3至12个月的赢家往往继续赢。两者并不矛盾：它们作用于不同的时间尺度。

研究中的短期反转收益很大一部分来自小盘、流动性差的股票，并且对交易成本很敏感。计入贴近现实的成本后，简单版本的吸引力远不如原始数字所显示的那样。

衡量“拉伸”程度：Z值

Z值（z-score）表示当前价格相对于其近期历史有多么异常：

z = (价格 − 移动平均) / 同一窗口内价格的标准差

Z值为−2表示价格比均值低两个标准差。一套典型的规则：

  • z 跌破−2时开多；z 升破+2时开空。
  • z 回到0（均值）时离场，或触发时间止损时离场。
  • 可选：若 z 达到±4这样的极端值，再加一道止损。
import pandas as pd

def zscore_positions(close: pd.Series, lookback=20, entry=2.0, exit=0.0) -> pd.Series:
    mean = close.rolling(lookback).mean()
    std = close.rolling(lookback).std()
    z = (close - mean) / std
    pos, out = 0, []
    for zt in z:
        if pos == 0 and zt < -entry:
            pos = 1
        elif pos == 0 and zt > entry:
            pos = -1
        elif pos == 1 and zt >= -exit:
            pos = 0
        elif pos == -1 and zt <= exit:
            pos = 0
        out.append(pos)
    return pd.Series(out, index=close.index)

仓位是根据收盘价计算的，因此应将其应用于下一根K线的收益，以避免前视偏差，详见回测。

常见的散户系统

布林带回归

布林带在移动平均线上下各两个标准差处画出轨道。在下轨买入、在中轨离场，本质上就是一个在−2入场、在0离场的Z值系统。

短周期 RSI

RSI通常使用14个周期，但均值回归交易者常用短得多的参数。由交易员兼作者 Larry Connors 推广的2周期 RSI，可以标记出极短期的极端。常见做法是：当价格位于200日均线之上、且2周期 RSI 跌破10时买入，在 RSI 回升或价格收于短期均线之上时离场。长期过滤条件旨在只在上升趋势中逢低买入，降低“接飞刀”的风险。

趋势过滤与时间止损

许多回归系统会加入一个过滤条件，避免逆强趋势交易，再加一个时间止损：如果预期的反弹在几根K线内没有出现就离场。没有迅速回归的交易，往往说明情况已经变了。

负偏度

均值回归策略的胜率通常很高，大多数被拉伸的价格确实会小幅反弹。但亏损的交易恰恰是价格继续运动的那些：一只股票因利空下跌10%，然后又跌了30%；或者一种货币突破了长期区间。

这种模式会产生负偏度：左侧有一条由罕见大额亏损构成的长尾。净值曲线可以连续多年看上去很平滑，然后在几天之内吐出几个月的收益。它与趋势跟踪正好是镜像关系。

均值回归何时失效

  • 市场状态转变。 区间震荡的市场变成趋势市场，通常发生在基本面冲击之后。
  • 消息驱动的行情。 业绩超预期、收购、财务造假曝光和央行政策转向，都可能让资产永久性地重新定价。看似过度反应的走势，可能是市场在消化新信息。
  • 流动性危机。 在全面抛售中，许多资产会同时保持被拉伸的状态，而通常提供流动性的交易者也被迫卖出。
  • 跳空。 价格可能在隔夜跳过任何止损位。
  • 拥挤交易。 当许多基金运行类似的回归策略时，它们同时离场会让拉伸更加严重，2007年8月股票市场中性基金就遭遇了这种情况。

实例

一笔Z值交易

某股票20日平均收盘价为100美元，20日标准差为2美元。今天收于95美元。

  • z = (95 − 100) / 2 = −2.5，低于−2的入场阈值，因此系统在下一个开盘价买入200股，假设为95.20美元。
  • 四天后价格收于99.80美元，接近均值（假设均值和标准差不变，z ≈ −0.1），因此继续持仓。
  • 次日收于100.30美元，z 转正，于是在接下来的开盘价100.10美元卖出。
  • 毛利润 = (100.10 − 95.20) × 200 = 980美元，未扣除成本。

负偏度陷阱

某回归系统75%的交易盈利，平均盈利1%，平均亏损2.5%。

  • 期望值 = 0.75 × 1% − 0.25 × 2.5% = 0.75% − 0.625% = 每笔+0.125%。
  • 一笔没有保护、因跳空亏损15%的交易，就会抹掉15 / 0.125 = 120笔平均交易的预期利润。

这就是为什么对均值回归而言，仓位上限和应对跳空风险的预案比对大多数策略都更重要。

常见错误

  • 无限制地摊低成本。 在亏损的回归交易上不断加仓，可能把小亏变成灾难性亏损。
  • 没有止损或时间止损。 “它一定会回来的”不是风险计划。
  • 用成交价回测目标极小的策略。 买卖价跳动和点差可能让毫无价值的信号看起来有利可图。
  • 忽视消息。 重大公告后被拉伸的价格，与没有消息时被拉伸的价格截然不同。
  • 只看胜率。 不知道亏损的大小，80%的胜率什么也说明不了。

常见问题

交易中的均值回归是什么？

均值回归是指大幅偏离均值的价格倾向于回到均值附近。交易者利用这一点，在急跌后买入、在急涨后卖出，通常会设定明确的离场规则。

均值回归比趋势跟踪更好吗？

总体上没有哪个更好。均值回归往往在区间震荡市中有效，趋势跟踪则在趋势市中有效，二者的收益模式也不同：均值回归是频繁的小赚加罕见的大亏，趋势跟踪则正好相反。

均值回归应该用多大的Z值？

常见做法是在约±2个标准差处入场、在接近零处离场。合适的数值取决于市场、回看周期和成本，应在样本外检验，而不是精细优化。

均值回归策略为什么会爆仓？

它们经常在趋势、危机或消息冲击中持有越来越不利的仓位。如果再叠加杠杆或摊低成本，几笔这样的交易就可能抹掉多年积累的小额收益。
