如何回测交易策略

回测（backtesting）是把一套交易规则应用到历史数据上，以估算策略过去会有怎样的表现。它是算法交易最主要的研究工具，也是最容易自欺欺人的地方。严谨的回测会贴近现实地模拟数据、成本和时序；草率的回测则会给出亮眼的数字，而这些数字一旦动用真金白银就会消失。

核心要点

  • 回测的质量取决于数据；幸存者偏差和前视偏差（未来函数）是危害最大的两种错误。
  • 对手续费、点差和滑点要保守建模，因为成本往往决定了策略到底能否盈利。
  • 保留一段策略从未见过的数据做样本外测试；对需要定期重新调参的策略，使用滚动前推分析。
  • 综合多个指标评判策略：夏普比率、索提诺比率、最大回撤、盈利因子和交易次数。
  • 好的回测能增强信心，但永远无法保证未来的结果。

回测的原理

最简单的回测会逐根K线遍历历史。在每一步，它都会问：仅使用当时可获得的信息，规则会怎么做？然后记录模拟的订单和成交，并跟踪账户净值。

常见的设计有两种：

设计 原理 优点 缺点
向量化 用数组运算一次性计算整个序列的信号和收益 速度极快，适合早期研究 容易引入前视偏差；难以模拟订单成交、止损和仓位限制
事件驱动 像实盘系统那样，把每根K线或每个 tick 作为事件处理 订单处理贴近现实；代码往往可直接复用于实盘 速度较慢，开发工作量更大

许多研究者先用向量化测试筛选想法，再在事件驱动模拟器中确认有潜力的那些。

数据质量

糟糕的数据会产生看似可信、实则毫无意义的结果。至少要检查以下几点，更多内容参见市场数据一文：

  • 公司行为。 股价必须经过拆股和分红调整，否则回测会看到虚假的暴跌，并漏掉股息收入。
  • 期货换月。 连续期货序列必须以一致的方式在合约到期之间拼接。
  • 错误报价和缺口。 错误成交记录、缺失的K线和重复记录都会产生虚假信号。
  • 时区与时间戳。 混用交易所时间、本地时间和 UTC，可能让信号偏移数小时。
  • K线构建。 不同数据商的日线收盘时间可能不同，在全天候交易的外汇和加密货币市场尤其如此。

毁掉回测的偏差

幸存者偏差

如果测试范围只包含今天仍然存在的资产，就会出现幸存者偏差。破产、退市或被收购的公司，在许多免费数据集中都消失了。只在当前指数成分股上测试的策略，等于只在赢家身上测试，这会夸大收益，对买入超跌股票的策略尤其如此。加密货币也有同样的问题：成千上万个已经崩盘的代币并不在当前币种列表里。解决办法是使用无幸存者偏差的数据集，其中包含已消亡的品种，并保留时点准确（point-in-time）的指数成分。

前视偏差

前视偏差（俗称“未来函数”）是指使用了交易当时还无法获得的信息。常见例子：

  • 用某日收盘价生成信号，同时又假设你在同一个收盘价买入。
  • 在报告期末日期就使用财务报表数据，而不是在其实际发布的日期。
  • 用整个样本（包括未来）计算的统计量（均值、最大值）对数据做归一化。
  • 使用修订后的经济数据，而不是交易者当时实际看到的首次公布值。

一个有用的习惯是把每个信号都向后推一根K线，使在第 t 根K线计算出的信号最早在第 t+1 根K线执行。

其他偏差

  • 选择偏差： 只在你已经知道上涨了的市场上测试。
  • 数据窥探： 测试大量变体，然后只报告最好的那个。详见过拟合与数据窥探。
  • 流动性偏差： 假设你能在清淡的市场中按报价成交大额订单。

成本与滑点建模

每笔模拟交易都应支付贴近现实的成本：

  • 佣金和交易所费用，包括加密货币交易平台的挂单/吃单（maker/taker）费率。
  • 点差。 在卖价买入、在买价卖出，每个来回都要付出完整的买卖价差。
  • 滑点与市场冲击。 市价单和止损单的成交价往往比最新价更差，在快速行情和大额订单中尤其如此。
  • 融资成本。 隔夜掉期费、永续合约资金费，以及做空股票的借券费。

合理的做法是尽可能根据真实成交估算成本，然后把成本翻倍再跑一次回测。如果策略只在乐观的成本水平下有效，那它很可能根本无效。

样本内、样本外与滚动前推

开始之前就先切分历史数据。在样本内部分构建和调优策略，然后在样本外部分只测试一次。如果你不断回到样本外数据去微调规则，它就不再是样本外了。

滚动前推分析（walk-forward analysis）是沿时间轴重复这一过程。例如：在2015年至2018年上优化参数，在2019年测试；在2016年至2019年上优化，在2020年测试；依此类推。把各测试期拼接起来，就得到一条样本外净值曲线，反映策略在实时重新调参情况下的表现。样本内结果与滚动前推结果差异很大，说明存在过拟合。

绩效指标

没有任何单一数字能全面刻画一个策略，要综合使用多个指标。

指标 公式 含义
CAGR (期末净值 / 期初净值)^(1 / 年数) − 1 年复合增长率
夏普比率 Mean(R − Rf) / StdDev(R − Rf)，乘以 √(每年期数) 进行年化 每单位总波动带来的收益
索提诺比率 (Mean(R) − T) / 下行偏差，以相同方式年化 仅以下行波动衡量的单位收益
最大回撤 净值从峰值到谷底的最大跌幅，以峰值的百分比表示 历史上最痛的时刻
盈利因子 总盈利 / 总亏损（绝对值） 每亏一美元能赚回多少美元
胜率与期望值 盈利交易占比；每笔交易平均盈利 收益的分布方式

其中 R 是策略每期收益，Rf 是每期无风险利率，T 是目标收益（通常为零）。下行偏差是对所有期取 min(0, R − T)² 的平均值再开平方，因此高于目标的期计为零。对于日度数据，把日度比率乘以 √252，约为15.87。回撤与回本的数学参见回撤与破产风险，期望值参见风险回报比与期望值。

下面的函数根据收益序列、净值曲线和交易盈亏列表计算这些指标。

import numpy as np

def sharpe(returns, rf_per_period=0.0, periods_per_year=252):
    excess = np.asarray(returns) - rf_per_period
    return np.sqrt(periods_per_year) * excess.mean() / excess.std(ddof=1)

def sortino(returns, target=0.0, periods_per_year=252):
    r = np.asarray(returns)
    downside = np.minimum(r - target, 0.0)
    downside_dev = np.sqrt(np.mean(downside ** 2))
    return np.sqrt(periods_per_year) * (r.mean() - target) / downside_dev

def max_drawdown(equity):
    equity = np.asarray(equity, dtype=float)
    peaks = np.maximum.accumulate(equity)
    return ((peaks - equity) / peaks).max()

def profit_factor(trade_pnls):
    pnl = np.asarray(trade_pnls, dtype=float)
    gross_loss = -pnl[pnl < 0].sum()
    return pnl[pnl > 0].sum() / gross_loss if gross_loss > 0 else np.inf

实例

某策略以10,000美元起步，进行了十笔交易，结果如下（单位：美元）：+300、−200、+150、−100、−250、+400、−150、+200、−300、+250。

  • 总盈利： 300 + 150 + 400 + 200 + 250 = 1,300。
  • 总亏损： 200 + 100 + 250 + 150 + 300 = 1,000。
  • 盈利因子： 1,300 / 1,000 = 1.30。
  • 净利润： 300美元，因此期望值为每笔30美元，胜率50%。
  • 净值路径： 10,300；10,100；10,250；10,150；9,900；10,300；10,150；10,350；10,050；10,300。
  • 最大回撤： 从10,300的峰值跌到9,900的谷底，跌幅为400 / 10,300 ≈ 3.9%。

对于风险调整比率，假设一段更长的测试得出日均收益0.05%、日标准差1.0%、下行偏差0.7%，无风险利率为零。年化夏普比率为0.05 / 1.0 × 15.87 ≈ 0.79，索提诺比率为0.05 / 0.7 × 15.87 ≈ 1.13。

十笔交易远远不足以让这些数字可信。粗略来说，许多研究者希望至少有几百笔分布在不同市场环境中的交易，才会认为这些统计量有意义。

常见错误

  • 在产生信号的那根K线上成交。 由收盘价计算出的信号，不可能同时以该收盘价成交。
  • 使用当前的指数成分股。 这会把幸存者偏差带进每一个结果。
  • 成本假设为零或过低。 高换手率策略对此尤其敏感。
  • 重复使用样本外数据。 每偷看一次，它就变成了样本内数据。
  • 交易次数太少。 少数几笔大赚的交易就能造就一份惊艳却毫无意义的回测。
  • 忽视策略容量。 一个策略可能用1,000美元有效，到100,000美元就失效，因为订单会推动价格。

常见问题

回测中多高的夏普比率算好？

许多从业者认为，单一策略的年化夏普比率高于1就值得关注。回测值过高，例如日度策略高于3，往往说明存在错误、前视偏差或过拟合，而不是真正的优势。

回测需要多少历史数据？

要足以涵盖不同的市场状态，例如上涨、下跌和横盘市场，以及至少一段压力时期。对日度策略来说，这通常意味着十年或更长；对日内策略来说，如果包含大量交易，较少的年数也可能足够。

回测和模拟交易有什么区别？

回测是回放历史数据，而模拟交易是在实时价格上运行策略，但不动用真钱。模拟交易能发现回测无法发现的执行和软件问题。

为什么实盘结果与回测结果不同？

常见原因包括低估了成本和滑点、对历史噪声过拟合、数据存在偏差，以及市场行为发生变化。存在一些差距是正常的；差距很大则说明回测有缺陷。
