交易中的过拟合与数据窥探

过拟合（overfitting）是指交易策略被调整得与历史数据贴合得过于紧密，以至于捕捉到的是随机噪声，而不是可重复的规律。数据窥探（data snooping）是与之相关的问题：在同一份数据上测试大量想法并保留最好的那个，从而让运气看起来像是实力。二者共同解释了为什么那么多回测漂亮的策略一上实盘就亏钱。

核心要点

  • 每多一条规则、一个过滤条件和一个参数，策略拟合噪声的自由度就更大。
  • 只要测试的随机策略足够多，总有一些会纯粹凭运气显得非常出色。
  • 稳健的策略在很宽的参数范围内都表现尚可；脆弱的策略只在一个尖峰上有效。
  • 紧缩夏普比率和更严格的显著性阈值会根据所做的试验次数对结果进行调整。
  • 最好的防御手段是：更少的参数、经济学上的逻辑、从未动用过的样本外数据，以及如实记录每一次测试。

过拟合是什么样子

市场价格中只有少量信号和大量噪声。一个足够灵活的模型可以完美解释过去的任何价格路径，但它解释的大部分是噪声，而噪声不会重复。

过拟合策略的典型迹象：

  • 条件繁多，例如“当 RSI 低于27、成交量是平均值的1.3倍、当天是周二，且17日均线正在上升时买入”。
  • 参数值看起来很古怪，显然是因为得分最高才被选中。
  • 参数稍有变动，表现就崩溃。
  • 样本内净值曲线平滑，样本外却走平或下跌。
  • 结果由少数几笔大额交易驱动。

一条简单的经验法则：策略的自由度（参数、过滤条件、规则选择）越多，就需要越多的交易和越长的历史来证明其合理性。

多重检验与数据窥探

假设你测试了100个完全没有真实优势的策略。使用标准的5%显著性阈值，你应该预期其中约有5个纯粹出于偶然而显得统计显著。如果你随后只报告这5个，你就“发现”了五个根本不存在的优势。

即使没有恶意，这种情况也会发生。一位研究者尝试均线交叉策略，快线取10种周期、慢线取10种周期（100种组合），再加上三种止损设置（300种）和两个市场（600种）。每一种都是一次独立的检验，即使最终报告里只出现最好的那一个。

数据窥探也会在人与人之间发生。成千上万的交易者在挖掘同样热门的数据集。书籍和论坛上发表的策略，往往是一场庞大而看不见的搜索中的幸存者。

运气能有多大？

从回测中估计出的夏普比率噪声很大。对于没有真实优势的策略，估计的年化夏普比率的标准误约为1 / √(数据年数)。用5年的日度数据，约为1 / 2.24 ≈ 0.45。

N 个相互独立的零优势策略中，预期的最佳结果会随 N 增大。对于100次试验，100个标准正态抽样的期望最大值约为2.5个标准差，因此最好的回测会显示约2.5 × 0.45 ≈ 1.1的夏普比率。对于1,000次试验，期望最大值约为3.2个标准差，对应的夏普比率约为1.45。1.1到1.5的夏普比率是许多交易者乐于实盘部署的数字，而在这里它完全来自噪声。

你可以自己验证：

import numpy as np

rng = np.random.default_rng(0)
years, n_strategies = 5, 100
# 真实优势为零、日波动率为1%的日收益
daily = rng.normal(0.0, 0.01, size=(n_strategies, 252 * years))
sharpes = np.sqrt(252) * daily.mean(axis=1) / daily.std(axis=1, ddof=1)
print(f"Best Sharpe among {n_strategies} random strategies: {sharpes.max():.2f}")
print(f"Median Sharpe: {np.median(sharpes):.2f}")

真实的策略变体之间是相关的，而不是相互独立的，这会减少有效试验次数，但原理依然成立。

参数稳定性

稳健的策略应在一片参数邻域内都有效，而不只是在某一个点上。常见的检验方法是绘制两个参数下的绩效热力图，例如均线策略以快线周期为一个坐标轴、慢线周期为另一个坐标轴。

热力图上的形态 解读
大片表现尚可的平台区 这个想法很可能捕捉到了真实的东西；在平台中间选一个值
单个亮点被糟糕的结果包围 很可能是噪声；“最佳”参数纯属偶然
相邻格子之间结果正负翻转 策略与该参数之间没有稳定的关系

在不同时期和不同市场上的稳定性同样重要。如果一个趋势系统用同一组参数在20个期货市场中的15个上都有效，那远比只在一个市场上、用定制参数才有效的系统更有说服力。

统计调整

更严格的阈值

策略平均收益的 t 统计量大约等于其年化夏普比率乘以 √(年数)。5年期间夏普比率为1.0，得到 t ≈ 2.24，超过了约为2的传统阈值。在2016年一篇关于因子研究的论文中，Harvey、Liu 和 Zhu 认为，由于已被检验过的因子太多，新因子应达到约3的 t 统计量。在夏普比率为1.0时，这需要约9年的数据（√9 = 3）。

紧缩夏普比率

Bailey 和 López de Prado 于2014年提出了紧缩夏普比率（deflated Sharpe ratio）。其思路是追问：考虑到尝试了多少个策略、各次试验之间差异多大、回测有多长，以及收益的偏度和厚尾程度，观察到的最佳夏普比率反映真实优势、而非选择运气的概率有多大？随着试验次数增加，这一调整会抬高门槛。如实使用它，需要记录你测试了多少种变体，而这本身就是一种宝贵的纪律。这两位作者及其合作者还提出了一个名为“回测过拟合概率”的指标，其依据是在多次数据切分中比较样本内与样本外的排名。

如何避免过拟合

  1. 从理由出发。 有经济学或行为学解释支撑的策略，不太可能是统计上的偶然。
  2. 保持简单。 优先选择少量参数，并取整齐、合理的数值。
  3. 记录每一次测试。 统计试验次数，包括失败的那些。
  4. 留出数据。 预留一段样本外时期，并只在最后使用一次。
  5. 对需要重新调参的策略使用滚动前推测试。
  6. 跨市场、跨时期测试。 真实的效应通常会在相关品种中显现。
  7. 对结果进行压力测试。 把成本翻倍、把入场延迟一根K线、剔除最好的5%交易，看看还剩下什么。
  8. 先模拟交易，再小规模实盘。 实盘表现是最终的样本外检验。

使用机器学习时，过拟合的风险更大，因为灵活的模型能非常高效地记住噪声。它还有心理层面的因素：确认偏误会让研究者在找到想要的结果后就停止搜索。

实例

一位交易者用8年数据，在一个股指期货上测试趋势跟踪突破系统。入场回看周期从10天到100天、步长为5（19个值），离场回看周期从5天到50天、步长为5（10个值），共190种组合。最佳组合为入场65、离场15，夏普比率为1.3。

  • 用8年数据，零优势夏普比率的标准误约为1 / √8 ≈ 0.35。
  • 如果这190次试验像独立的抛硬币一样，预期的最佳结果约为2.7个标准误，即仅凭运气就能得到约0.95的夏普比率。
  • 观察到的1.3高于这一水平，略微令人鼓舞，但这些试验并不独立，而且结果只来自一个市场。

交易者随后查看热力图，发现除了65天那个单独的峰值之外，入场周期从40天到90天的夏普比率都在0.6到1.0之间，而且同样的参数在其他几个股指期货上也有效。现实的预期应以这个平台区为准，而不是1.3的峰值。选择平台中间的数值，并预期实盘夏普比率在0.5到0.8附近，才是更诚实的计划。

常见错误

  • 只报告胜出的变体。 试验次数本身就是结果的一部分。
  • 优化到小数点后第二位。 精细调参拟合的是噪声。
  • 添加过滤条件以剔除过去的亏损交易。 每一个专门修补某笔亏损的过滤条件，很可能都是在拟合历史。
  • 把样本外数据当作可重复使用的。 一旦你看过它之后又调整了规则，它就成了样本内数据。
  • 相信夏普比率很高的短期回测。 短样本很容易产生极端的估计值。

常见问题

交易中的曲线拟合是什么？

曲线拟合是指不断调整策略的规则和参数，直到它们与历史价格高度吻合。这样做出的回测很亮眼，但通常在实盘中失效，因为策略学到的是噪声，而不是可重复的规律。

怎么判断我的策略是否过拟合？

警示信号包括：参数很多、参数稍有变动表现就崩溃、样本内与样本外结果差距很大，以及结果依赖少数几笔交易。在从未动用过的数据和其他市场上测试，是最直接的检验方法。

什么是紧缩夏普比率？

它是 Bailey 和 López de Prado 提出的一个统计量，会根据尝试过的策略数量、回测长度和收益的非正态性对观察到的夏普比率进行调整。它估计的是结果反映真实优势、而非选择运气的概率。

参数优化一定是坏事吗？

不是。选择合理的参数是构建任何策略的一部分。问题在于自由选择太多、数据太少的过度优化，以及没有考虑到测试了多少种变体。
