外汇经纪商是为散户交易者提供货币市场接入服务的公司：它负责报价、保管交易者的资金，并且要么充当每笔交易的对手方，要么把交易转给更大的流动性提供商。经纪商的商业模式、监管机构和账户类型，决定了交易者要付多少钱、订单如何成交，以及经纪商倒闭时客户资金会怎样。选择经纪商主要关乎安全和成本，而不是赠金或营销宣传。

要点速览

  • 零售外汇经纪商要么充当客户交易的对手方（做市商或 B-book，俗称B仓），要么把交易转给流动性提供商（STP、ECN 或 A-book，俗称A仓），许多经纪商两者兼做。
  • 经纪商的收入来自点差、佣金、隔夜利息加价，对于B仓订单流，还来自客户的亏损。
  • 各地监管差别很大：严格的监管机构会强制执行客户资金隔离、杠杆上限和负余额保护，而一些离岸司法管辖区几乎不加监督。
  • 交易总成本 = 点差 + 佣金 + 隔夜利息，所以要三者一起比较，而不是只看宣传的点差。
  • 入金之前，务必直接在监管机构自己的登记系统中核实经纪商的牌照。

零售外汇经纪商如何运作

外汇是场外市场，所以散户交易者并不会把订单发往交易所。经纪商报出买价和卖价，交易的对手要么是经纪商本身，要么是经纪商接入的流动性提供商。经纪商、交易商和交易所之间的一般区别见经纪商与交易所。

做市商（有交易室，DD）

做市商，也叫有交易室（dealing desk，DD）的经纪商，根据银行间报价自行定价，并充当客户交易的对手方。如果客户买入 EUR/USD，经纪商就持有 EUR/USD 空头。经纪商可能会用其他客户的反向交易来抵消这部分风险，并对冲剩余的净敞口。

  • 典型特点： 固定或浮动点差，不另收佣金，最小交易规模较小。
  • 利益冲突： 当经纪商把客户风险留在自己账上时，客户亏钱它就赚钱。

STP 与 ECN 经纪商（无交易室，NDD）

直通式处理（STP） 经纪商把客户订单转给一家或多家流动性提供商，如银行或非银行做市商，通常会在点差上加价。ECN 类经纪商则让客户接入由多家提供商报价组成的价格池，通常是原始点差加单独收取的佣金。

  • 典型特点： 浮动点差，主要货币对在活跃时段可接近零；按手收取佣金；价格反映更广泛的市场。
  • 局限： "ECN"一词在营销中用得很随意，经纪商不必真正提供多方交易场所也可以自称 ECN。

A仓与B仓

这两个业内术语描述的是经纪商如何处理每个客户的风险：

术语 交易如何处理 经纪商如何赚钱
A-book（A仓） 转出，并与流动性提供商对冲 点差加价和佣金
B-book（B仓） 留在经纪商自己的账上 点差，加上客户亏损减去客户盈利
混合模式 部分客户或交易走A仓，其余走B仓 两者皆有

大多数大型零售经纪商采用混合模式。它们通常把小额或短线账户放进B仓，因为这类客户整体上倾向于亏钱；而把大额或持续盈利的账户放进A仓，以免自掏腰包向他们赔付。在大多数司法管辖区，只要进行披露并按利益冲突规则管理，混合模式就是合法的。2017年，美国商品期货交易委员会（CFTC）认定一家大型美国零售外汇经纪商误导客户，隐瞒了自己在充当客户交易对手方的做市商中拥有利益。此案以罚款和该公司退出美国市场告终，常被引为应仔细阅读执行披露文件的理由。

经纪商如何赚钱

  • 点差： 买卖价之差，或在原始银行间点差之上的加价。
  • 佣金： 原始点差账户按手收取的固定费用。
  • 隔夜利息加价： 隔夜融资费率比纯粹的利差更不利于客户。见套息交易。
  • 客户亏损： 对于B仓订单流，客户亏损的交易就是经纪商的收入。
  • 其他费用： 部分公司收取不活跃账户费、入金货币兑换费和出金手续费。

点差账户与佣金账户

许多经纪商提供两种账户类型。哪种更便宜，取决于交易规模和风格。

计算示例：比较一次往返交易的成本

一位交易者开仓并平仓1标准手 EUR/USD，每点价值 $10。

账户 点差 每次往返佣金 总成本
标准账户（仅点差） 1.2点 = $12.00 $0 $12.00
原始点差账户（收佣金） 0.2点 = $2.00 $7.00 $9.00

按这些数字计算，原始点差账户每手便宜 $3.00。一位每月做100手往返交易的交易者，每月可节省 $300。对只交易几个微型手的人来说，差别只有几美分，其他因素更重要。以上数字仅作说明，点差和佣金因经纪商、货币对和时段而异。交易成本与费用一文展示了这些成本对活跃交易者如何累积。

固定点差与浮动点差

固定点差看起来可预测，但平均通常更宽，而且在极端新闻行情中，经纪商仍可能扩大点差或拒绝订单。浮动点差在正常情况下更窄，但会在新闻发布、展期和流动性不足的时段扩大。

监管等级

各监管机构的要求和执法力度各不相同。下表描述的是截至2026年的大致情况；规则会变化，请查看最新要求。

监管机构 国家或地区 说明
CFTC 和 NFA 美国 零售外汇交易商必须注册；资本要求高；主要货币对杠杆上限50:1；不向美国散户提供差价合约
FCA 英国 杠杆上限、负余额保护、客户资金规则，符合条件的索赔可获赔偿计划保障
由各国监管机构执行的 ESMA 规则（例如塞浦路斯的 CySEC、德国的 BaFin） 欧盟 杠杆上限、负余额保护、保证金强平规则、亏损比例披露；公司可凭"护照"在全欧盟展业
ASIC 澳大利亚 自2021年起根据产品干预令实施杠杆上限和负余额保护
FSA 日本 散户外汇杠杆上限25:1
其他如 FINMA（瑞士）、MAS（新加坡）、SFC（香港） 多地 监管体系总体严格
部分小型司法管辖区的离岸监管机构 多地 规则较宽松，往往杠杆高、追索手段弱；有些当局明确表示根本不监管外汇交易

在某个国家注册成立公司，并不等于获得了该国金融监管机构的牌照。交易监管概览概括介绍了各监管机构的职能以及赔偿计划的运作方式。

负余额保护

负余额保护是指散户客户的亏损不会超过账户里的资金。欧盟和英国分别于2018年和2019年对散户差价合约客户强制实施这一保护，澳大利亚则在2021年实施。它的价值在2015年1月显露无遗：瑞士央行取消欧元汇率下限后，瑞郎突然暴涨，许多散户账户出现负余额。多家经纪商损失惨重，至少有一家英国经纪商进入破产程序。见杠杆风险与黑天鹅。

离岸经纪商的风险

只在监管宽松地区持牌的经纪商，往往提供500:1甚至更高的杠杆、大额入金赠金和快速开户。风险包括：

  • 客户资金可能没有与公司自有资金隔离；
  • 出金被拖延或拒绝，有时以赠金条款为借口；
  • 操纵价格或无故取消交易；
  • 没有像样的投诉处理流程或赔偿计划；
  • 公司一旦消失，几乎无从追索。

有些离岸经纪商是正规的，但使用这类经纪商的交易者应当默认自己的资金受到的保护更少。外汇风险与骗局一文介绍了危险信号以及如何核查牌照。

交易平台

大多数零售外汇经纪商提供 MetaTrader 4 或 MetaTrader 5（由 MetaQuotes 开发）、cTrader（由 Spotware 开发）、自家的网页版和手机应用，或接入图表服务。平台只是前端：它不会改变谁保管你的资金，也不会改变订单如何执行。见交易平台与工具。

简要核查清单

  1. 找到牌照号码，并在监管机构自己的网站上核实，不要通过经纪商提供的链接。
  2. 确认你的账户将在哪个法律实体开立，因为许多集团同时拥有一个严格监管的实体和一个离岸实体。
  3. 阅读订单执行政策和利益冲突披露。
  4. 比较总成本：你交易的货币对的点差、佣金和隔夜利息。
  5. 先用小额资金测试入金和出金。
  6. 警惕大额赠金、催你追加入金的客户经理，以及保证收益的说法。

常见错误

  • 按最高杠杆选平台。 高杠杆是风险，不是卖点。
  • 相信网站上的监管机构标志。 克隆公司会盗用真实的牌照号码。请独立核实。
  • 只比较宣传的点差。 佣金和隔夜利息加价可能更重要。
  • 不看条款就接受赠金。 赠金条件往往会限制出金。
  • 忽视账户由哪个实体持有。 同一个品牌在不同国家提供的保护可能截然不同。

常见问题

ECN 经纪商和做市商经纪商有什么区别？

做市商充当客户交易的对手方并自行报价，而 ECN 类经纪商把订单转给外部流动性提供商组成的价格池，通常收取佣金。许多经纪商两种方式兼用。

外汇经纪商会和你对赌吗？

把客户订单流放进B仓的经纪商就是这些交易的对手方，所以客户亏钱时它们获利。在许多国家，只要进行披露并按利益冲突规则管理，这种做法既普遍又合法。

怎么知道一家外汇经纪商是否受监管？

在监管机构的官方登记系统中查询该公司及其牌照号码，例如英国的 FCA 登记册或美国 NFA 的 BASIC 数据库。核对网站地址和联系方式是否与登记信息一致。

我的钱放在外汇经纪商那里安全吗？

这取决于监管机构和法律实体。严格的监管体系要求客户资金与公司自有资金分开存放，并可能提供赔偿计划，而离岸经纪商往往几乎不提供保护。

仅供学习参考。本站内容不构成任何金融、投资、法律或税务建议。交易具有很高的亏损风险，杠杆产品的亏损可能超过你投入的本金。规则、费用和平台细节会变化，交易前请向你的券商、交易所或监管机构核实最新条款。
