交易平台与工具

交易平台是用来查看价格、分析图表并向经纪商或交易所发送订单的软件。围绕平台，大多数交易者还会配备一套工具：看盘图表、筛选器、新闻资讯、交易日志，有时还有自动化或数据服务。工具可以让良好的交易更容易执行、运行成本更低，但工具本身无法创造优势，而且订阅费是实实在在的支出，会侵蚀收益，对小账户来说尤其如此。

要点速览

  • 平台只是前端；谁保管你的资金、订单如何执行，取决于平台背后的经纪商或交易所。
  • 不同平台适合不同市场：MetaTrader 和 cTrader 适合外汇和差价合约，NinjaTrader 之类适合期货，券商平台适合股票和期权，专用终端适合加密货币。
  • 根据你的市场、交易周期、数据需求、自动化需求和预算选择工具，而不是看谁最流行。
  • 相对于小账户，实时数据、插件和各种订阅加起来可能是一笔可观的年度开支。
  • 对待平台安全，尤其是 API 密钥和登录凭证，要像对待交易本身一样认真。

平台类别

类别 示例 典型用户
图表平台 TradingView、券商自带图表 各个市场的大多数散户
外汇和差价合约平台 MetaTrader 4、MetaTrader 5、cTrader 外汇和差价合约交易者
期货平台 NinjaTrader、Sierra Chart、其他期货交易前端 期货日内交易者
股票和期权券商平台 thinkorswim（Charles Schwab）、Interactive Brokers Trader Workstation、其他券商应用 股票和期权交易者
加密货币交易所界面与终端 交易所网页版和手机应用、多交易所终端、链上交易终端 加密货币交易者
手机应用 大多数经纪商和交易所 盯盘和简单交易

此处列出这些产品并不代表推荐，只是因为它们使用广泛。还有许多替代选择。

看盘图表

图表软件显示价格数据，让交易者可以画出关键价位，并加载移动平均线、RSI和VWAP等指标。TradingView 是一款广泛使用的网页版图表服务，拥有名为 Pine Script 的脚本语言和庞大的社区指标库。许多经纪商也提供内置图表，有些还直接对接 TradingView 下单。

要关注什么： 你需要的市场和数据、数据源质量、指标和画线工具、价格提醒、多周期布局，以及能否直接在图表上交易。

外汇和差价合约平台

  • MetaTrader 4（MT4）和 MetaTrader 5（MT5） 由 MetaQuotes 开发，是最常见的零售外汇和差价合约平台。它们支持名为 EA（Expert Advisor）的自动化策略，使用 MQL4 和 MQL5 语言编写。MT5 是较新的平台，周期更多、订单类型更多，部分经纪商还支持在 MT5 上交易场内市场。
  • cTrader 由 Spotware 开发，提供市场深度显示、细致的订单类型以及用 C# 编写的自动化交易。

同一个平台在不同经纪商那里的表现可能不同，这取决于经纪商的定价、执行模式和服务器位置。见外汇经纪商。

期货平台

期货交易者往往需要市场深度阶梯（DOM）、快速下单以及足迹图等订单流工具。NinjaTrader 和 Sierra Chart 等平台很常见，期货经纪商也会提供其他平台。大多数平台需要另外订阅交易所的行情数据，有些还收取授权费或按合约收费。订单流分析背后的工具见订单流交易。

股票和期权平台

大型券商提供功能齐全的桌面平台，集成图表、期权链、风险分析和扫描功能。例子包括现已归属 Charles Schwab 的 thinkorswim，以及 Interactive Brokers 的 Trader Workstation（TWS），后者还提供用于自动化交易的 API。期权交易者往往看重能显示头寸希腊字母和盈亏图的工具。

加密货币终端

加密货币交易者会直接使用交易所界面、通过 API 密钥连接的多交易所终端，以及用于去中心化交易所的链上终端或机器人。关键风险在于资产托管和密钥安全。除非绝对必要，永远不要给工具的 API 密钥开启提币权限；尽可能用 IP 地址限制密钥；对于持有私钥的工具要格外小心。见加密钱包安全和Meme 币交易机器人。

交易日志、筛选器与新闻

  • 交易日志： 电子表格或专门的日志软件，可以导入交易记录，并计算胜率、平均 R 值和回撤等统计数据。见交易日志。
  • 筛选器与扫描器： 按价格、成交量、基本面或技术条件，从成千上万只股票或币种中筛选。见选股器与扫描器。
  • 新闻资讯与经济日历： 实时头条、预定的数据发布和市场一致预期。免费和付费服务在速度上差别很大。见新闻交易与经济日历。
  • 行情数据服务： 用于分析和回测的历史及实时数据。见行情数据来源。

自动化

许多平台支持自动化交易：MetaTrader 上的 EA、cTrader 上的 cBot、NinjaTrader 上的 NinjaScript、TradingView 上可通过第三方服务触发订单的 Pine Script 提醒，以及供自定义代码使用的经纪商或交易所 API。自动化可以强化纪律、提高速度，但也会带来程序漏洞、连接故障和过度拟合的风险。搭建交易机器人一文介绍了系统架构和紧急停止开关等安全措施。

有些交易者会在靠近经纪商服务器的虚拟专用服务器（VPS）上运行平台，以便在自己电脑关机时自动化策略仍能运行。

工具要花多少钱

价格差别很大且经常变化，所以下面的数字是假设的。重点在于比例。

计算示例：每月工具预算

项目 每月费用
图表订阅 $30
交易所实时数据 $15
日志软件 $20
用于自动化的 VPS $25
合计 $90

年度费用：$90 × 12 = $1,080。

  • 对一个 $10,000 的账户来说，工具每年要花掉资金的10.8%。交易者必须赚到这么多才能覆盖工具成本，这还没算交易成本和税收。
  • 对一个 $100,000 的账户来说，同样的工具只占1.08%。

对小账户来说，免费的券商平台和免费版图表工具通常就够用了。在拥有一个真正需要这些工具、经过检验的策略之前，花钱买工具很少划算。工具费用应当和其他开支一起计入交易成本与费用。

如何选择

  1. 从你的市场和风格出发。 股票波段交易者和期货剥头皮交易者需要的工具截然不同。
  2. 检查与经纪商的兼容性。 有些平台只能与特定经纪商配合使用。
  3. 检查数据。 是否包含实时数据，还是延迟数据，或者需要单独付费？交易所费用是否另计？
  4. 用模拟账户测试。 大多数平台都提供模拟账户。
  5. 检查稳定性和客服支持。 在行情剧烈时宕机代价高昂。
  6. 检查安全性。 双重身份验证、API 密钥权限控制以及良好的安全记录。
  7. 看清费用结构。 留意平台费、按笔收费、数据费和不活跃账户费。

常见错误

  • 还没有策略就先买工具。 指标和插件不会创造优势。
  • 指标堆砌。 图表上的线越多，往往越看不清。
  • 忽视数据差异。 外汇和差价合约价格因经纪商而异，加密货币价格因交易所而异。
  • API 密钥安全薄弱。 开启提币权限的密钥是重大的被盗风险。
  • 频繁换平台。 不停地更换平台，会浪费本可用于检验和复盘的时间。

常见问题

新手最适合用什么交易平台？

没有唯一最好的平台。新手通常用自己经纪商的平台，或者一款广泛使用、带模拟账户的图表服务就足够了，选择适合自己想交易的市场的那一个即可。

MT4和MT5有什么区别？

两者都是 MetaQuotes 的平台，主要用于外汇和差价合约。MT5 更新，周期更多、订单类型更多，并支持部分场内市场；而 MT4 仍被广泛使用，尤其是运行较老的 EA。

我需要为 TradingView 或其他图表工具付费吗？

许多交易者从免费版开始，免费版提供基本的图表和指标功能。付费套餐增加了每张图可加载更多指标、更多提醒以及部分实时数据等功能，这些功能对你的交易可能重要，也可能不重要。

把交易工具连接到我的交易所账户安全吗？

如果你使用仅有交易权限的 API 密钥、禁用提币、尽可能用 IP 地址限制密钥并使用信誉良好的工具，就可以做到相当安全。永远不要把密码或助记词交给任何工具。

仅供学习参考。本站内容不构成任何金融、投资、法律或税务建议。交易具有很高的亏损风险，杠杆产品的亏损可能超过你投入的本金。规则、费用和平台细节会变化，交易前请向你的券商、交易所或监管机构核实最新条款。
