K线形态

K线形态是价格图表上由一根、两根或三根连续K线构成的、有特定名称的形状。交易者用它们来描述买卖压力似乎发生转变的时刻，例如下跌之后出现的长下影线，或一根把前一根K线完全"吞掉"的大K线。K线形态是技术分析中传授最广的工具之一，但单独使用时信号很弱：它们是否有用，很大程度上取决于出现的位置以及随后的走势。

要点速览

  • K线形态描述的是一到三个周期内买卖力量对比的短期变化。
  • 同一个形态，出现在区间中部时意义不大，出现在交易者已经在关注的价位时意义更大。
  • 大多数交易者会等待确认，例如下一根K线突破该形态的高点或低点，然后才采取行动。
  • 对K线形态的系统性检验普遍发现，其预测价值很弱或不稳定，扣除交易成本后尤其如此。
  • 形态最实际的用途，往往是界定交易在哪里被证明是错的，从而给出合乎逻辑的止损位置。

如何阅读本文

下面的每种形态都由K线图怎么看中介绍的K线组成部分构成：实体（从开盘价到收盘价）和影线（实体之外的极值）。不同书籍和软件的定义不尽相同，因此请把下面的比例视为常见惯例，而不是固定规则。

本文中的"看涨"和"看跌"，描述的是传统上认为某形态所暗示的方向，而不是预测。

单根K线形态

十字星

十字星（doji）的开盘价与收盘价相等或非常接近，因此实体只是一条细线。它表明价格在该周期内有所波动，但最终回到了起点。

  • 标准十字星： 上下影线都较短。
  • 长腿十字星： 上下影线都很长；振幅大，没有净进展。
  • 蜻蜓十字星（T字线）： 下影线长，几乎没有上影线。
  • 墓碑十字星（倒T字线）： 上影线长，几乎没有下影线。

十字星通常被解读为犹豫不决。在一波强劲上涨之后，它可能暗示动能正在减弱；但在清淡的市场里十字星很常见，往往没有任何意义。

锤子线与上吊线

两者都是小实体位于区间上端，下影线长度至少约为实体的两倍，几乎没有上影线。

  • 锤子线出现在下跌之后。它被解读为卖方把价格打低，而买方在收盘前又把价格拉了回来。
  • 上吊线是出现在上涨之后的同样形状。它被解读为一种警示：尽管收盘价守住了，但该周期内出现了抛压。

流星线与倒锤子线

这两种是镜像形态：小实体位于区间下端，上影线很长。

  • 流星线出现在上涨之后，被解读为买方未能守住更高的价格。
  • 倒锤子线出现在下跌之后，被解读为买盘兴趣的早期迹象。

Pin Bar

"Pin Bar"（源自Pinocchio bar，即"匹诺曹K线"）是价格行为交易中的术语，指一端有长影线、另一端是小实体的任何K线。锤子线和流星线都属于Pin Bar。使用这个术语的交易者通常不太在乎名称，更在意长影线是否刺穿了某个关键价位后又被打回。参见价格行为交易。

光头光脚K线

光头光脚K线（marubozu）实体很大，两端几乎没有影线：价格从一个极值开盘，在另一个极值收盘。它表明该周期内是一边倒的控制。

两根K线形态

看涨吞没与看跌吞没

  • 看涨吞没： 一根阴线之后跟着一根阳线，后者的实体完全覆盖前一根K线的实体。
  • 看跌吞没： 一根阳线之后跟着一根阴线，后者的实体完全覆盖前一根。

示例。 第1天开盘$45.00，收盘$44.00（阴线）。第2天开盘$43.80，收盘$45.40。第2天的实体从$43.80到$45.40，完全包含了第1天从$44.00到$45.00的实体。这就是一个看涨吞没形态。

在外汇和加密货币这类24小时市场中，每根K线通常在前一根收盘价附近开盘，所以带缺口的严格"吞没"很少见。许多交易者在这些市场会放宽定义。

孕线

孕线（harami）与吞没相反：一根大K线之后跟着一根小K线，后者的实体位于前一根K线的实体之内。"Harami"在日语中意为"怀孕"，形容其形状。它被解读为动能暂停。第二根K线是十字星的孕线，称为十字孕线。

平头顶与平头底

两根K线的最高价相同或几乎相同（平头顶），或最低价相同或几乎相同（平头底）。它们被解读为价格两次测试同一价位，均未能突破。

三根K线形态

早晨之星与黄昏之星

  • 早晨之星（启明星）： 一根大阴线，接着一根小实体K线（在股票市场中常常跳空低开），然后是一根大阳线，收盘价深入第一根K线的实体。它被解读为抛售衰竭、买方接管。
  • 黄昏之星： 看跌的镜像形态，出现在上涨之后。

红三兵与三只乌鸦

  • 红三兵（three white soldiers）： 连续三根大阳线，每根都在前一根实体内开盘，并收在接近最高价的位置。
  • 三只乌鸦（three black crows）： 连续三根大阴线，每根都收在接近最低价的位置。

它们描述的是持续的一边倒压力。在一波延续已久的行情之后，它们也可能标志着短期衰竭，这正是它们单独使用时不可靠的原因之一。

位置比形状更重要

出现在横盘区间中部的锤子线，携带的信息很少。同样的锤子线，如果出现在一个价格此前多次转向的价位，伴随高于平常的成交量，并且是在长期下跌之后，那就是另一回事了。交易者通常会权衡：

  • 位置： 该形态是否位于支撑或阻力、某条移动平均线或此前的波段转折点？
  • 趋势： 它与更大级别的趋势一致，还是相悖？
  • 成交量： 信号K线上的参与度是否上升？参见成交量分析。
  • 时间周期： 日线图上的形态所反映的成交量，远多于1分钟图上的形态。

计算示例：以明确风险交易锤子线

一只股票从$24跌到$19.50左右，正在接近一个去年曾两度反弹的价位。下一根日K线开盘$20.10，最高$20.25，最低$19.20，收盘$20.20。

  • 实体 = $20.20 - $20.10 = $0.10
  • 下影线 = $20.10 - $19.20 = $0.90，是实体的九倍
  • 上影线 = $20.25 - $20.20 = $0.05

这符合支撑区域锤子线的条件。交易者可以这样计划：

  • 入场： 只有第二天价格交易到锤子线最高价之上，即$20.26时才买入（确认）。
  • 止损： 设在锤子线最低价下方一点，即$19.19。
  • 每股风险： $20.26 - $19.19 = $1.07。
  • 目标： 前期阻力$22.40，潜在回报为$22.40 - $20.26 = $2.14。
  • 回报风险比： $2.14 / $1.07 = 2.0。

如果第二天价格始终没有超过$20.26，就不交易。如果超过了，随后又跌到$19.19，这笔交易每股亏损$1.07，而这种结果在相当一部分情况下是预料之中的。该形态并没有预测反弹；它提供的是一个具体的、可检验的、亏损已知的计划。如何根据这$1.07来确定仓位大小，请参见仓位管理。

实证研究怎么说

学术界和从业者已在股票、期货和外汇市场中对K线形态进行了大量检验。总体结论是：在计入交易成本和多重检验之后，大多数形态几乎没有稳定的预测能力；在某个市场或时期看似强劲的结果，换到另一个市场或时期往往就失效了。有少数研究报告了某些形态在特定条件下有一定效果，但并不存在一份公认可靠有效的形态清单。

困难部分在于定义："小实体"和"长影线"必须转换成精确的数字才能检验，而阈值稍有不同，结果就会不同。如果你想依赖某个形态，请精确定义它，并在你所交易的市场和时间周期上，计入真实成本进行回测。

常见错误

  • 脱离背景交易形态。 位置和趋势比K线形状更重要。
  • 在K线收盘前就行动。 一天进行到一半时的锤子线，收盘时可能变成一根普通阴线。
  • 跳过确认。 仅凭形态入场，意味着要做很多根本没有后续走势的交易。
  • 死记几十种形态。 许多有名称的形态只是同一思路的变体：拒绝某个价格区域，或一方取得控制。
  • 止损设得太紧。 止损仅比长影线多出几美分，可能被正常的噪音打掉。参见止损策略。

常见问题

最可靠的K线形态是哪一种？

没有任何一种K线形态被证明能在不同市场和时期都可靠地预测走势。使用K线形态的交易者，往往只关注少数几种简单形态，比如吞没形态和Pin Bar，并且只在重要价位使用，行动前还要等待确认。

锤子线是什么意思？

锤子线的小实体位于顶端，下影线很长，出现在下跌之后。它表明卖方在该周期内把价格打低，但买方在收盘前又把价格拉了回来。

十字星和纺锤线有什么区别？

两者都表示犹豫不决。十字星的开盘价与收盘价几乎相等，而纺锤线有一个较小但清晰可见的实体，上下都有影线。

K线形态在加密货币和外汇中有用吗？

同样的形状会出现在所有市场，但24小时交易意味着K线很少出现缺口，这会改变吞没形态和早晨之星等形态的形成方式。在加密货币或外汇市场中，这些形态的实证依据并不比其他市场更强，因此请在你交易的市场上检验任何形态。
