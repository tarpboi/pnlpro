RSI（相对强弱指数）

相对强弱指数（Relative Strength Index，RSI）是一种动量震荡指标，它比较近期涨幅与近期跌幅的大小，并把结果表示在0到100的刻度上。读数接近100表示近期以上涨为主；接近0表示以下跌为主。RSI由J. Welles Wilder Jr.提出，发表于他1978年的著作《技术交易系统新概念》（New Concepts in Technical Trading Systems），是所有看盘平台上最受欢迎的指标之一。它衡量的是近期上涨与下跌之间的力量对比，读数偏高或偏低本身并不意味着价格即将反转。

要点速览

  • RSI = 100 - 100 / (1 + RS)，其中RS是回溯周期内平均涨幅除以平均跌幅，默认周期为14。
  • 按惯例，读数高于70称为超买，低于30称为超卖；但在强劲趋势中，RSI可能长时间停留在这些极端区域。
  • 在上升趋势中，RSI常在大约40至80的区域内摆动；在下降趋势中，则大约在20至60之间，这有助于判断市场状态。
  • 价格与RSI之间的背离显示动能正在减弱，但很多背离最终并未导致反转。
  • RSI是收盘价的一种变换，因此并不能为价格图表增加独立的信息。

RSI如何计算

RSI考察回溯周期（通常为14根K线）内相邻收盘价之间的变化：

  1. 对每根K线，记录涨幅（若收盘价上涨）或跌幅（若下跌，记为正数）。上涨的K线跌幅记为零，反之亦然。
  2. 计算该周期内的平均涨幅和平均跌幅。Wilder使用了一种平滑方法：每个新的平均值等于(前一平均值 x 13 + 当前值) / 14。它的表现类似于指数平均，意味着过去的每一根K线仍保有微小的影响。
  3. 计算RS = 平均涨幅 / 平均跌幅。
  4. 计算RSI = 100 - 100 / (1 + RS)。

其中的直觉很简单。如果平均涨幅与平均跌幅相等，RS为1，RSI为50。如果涨幅是跌幅的两倍，RSI约为67。如果完全没有下跌，RSI就是100。

请注意，RSI与"相对强度"（把一只股票与指数作比较的那种含义）并不是一回事。后者有时被称为比较相对强度，是另一种计算方法。

计算示例

某股票的14日平均涨幅为$1.20，平均跌幅为$0.60。

  • RS = 1.20 / 0.60 = 2.00
  • RSI = 100 - 100 / (1 + 2) = 100 - 33.33 = 66.67

第1天： 股价上涨$2.00。

  • 新平均涨幅 = (1.20 x 13 + 2.00) / 14 = (15.60 + 2.00) / 14 = 17.60 / 14 = 1.2571
  • 新平均跌幅 = (0.60 x 13 + 0) / 14 = 7.80 / 14 = 0.5571
  • RS = 1.2571 / 0.5571 = 2.2564
  • RSI = 100 - 100 / 3.2564 = 69.29

第2天： 股价上涨$3.00。

  • 平均涨幅 = (1.2571 x 13 + 3.00) / 14 = 1.3816
  • 平均跌幅 = (0.5571 x 13 + 0) / 14 = 0.5173
  • RS = 2.6706，因此RSI = 72.76。现已高于70，进入"超买"区域。

第3天： 股价下跌$1.50。

  • 平均涨幅 = (1.3816 x 13 + 0) / 14 = 1.2829
  • 平均跌幅 = (0.5173 x 13 + 1.50) / 14 = 0.5875
  • RS = 2.1836，因此RSI = 68.59。

两个强势上涨日把RSI从约67推到约73，一个温和的下跌日又把它拉回70以下。这个读数告诉你，近期涨幅大于跌幅。它并没有告诉你那波$3的上涨"涨过头了"，也没有说下跌即将到来。

超买与超卖

惯用的阈值如下：

读数 惯用标签 实际含义
高于70 超买 近期涨幅远大于近期跌幅
30至70 中性 没有明显失衡
低于30 超卖 近期跌幅远大于近期涨幅

有些交易者使用80和20来获得更严格的信号，在波动较大的资产上尤其如此。

这些标签具有误导性。"超买"听起来像是价格必然下跌，但它描述的只是近期强劲的动能。强劲的动能往往会延续。一只处于强势上升趋势中的股票，可能在RSI高于70的状态下持续上涨好几周；如果每次RSI上穿70就卖出，意味着一次又一次地过早离场或过早做空。

逆着极端读数交易，在价格于支撑与阻力之间来回摆动的震荡市场中往往效果更好。在趋势市场中，这样做的代价可能很高。

趋势中的RSI：市场状态视角

一个被广泛使用的观察是，RSI的典型区间会随趋势而移动：

  • 在上升趋势中，RSI往往大致在40到80之间摆动。回调常常在40到50附近止步，而不会跌到30。
  • 在下降趋势中，RSI往往大致在20到60之间摆动。反弹常常在50到60附近停滞，而不会涨到70。

交易者以两种方式利用这一点：

  • 判断市场状态。 如果RSI在回调时始终守在40之上，这与上升趋势相符。如果它在反弹时开始无法触及60，趋势可能正在走弱。
  • 回调入场。 在已确立的上升趋势中，RSI回落到40至50区域（而不是30），可以作为买入区，止损设在回调的波段低点下方。

这些区间是经验法则，而不是固定边界。不同资产和时间周期的表现各不相同。

背离

当价格与RSI的走向不一致时，就出现了背离：

  • 顶背离（看跌背离）： 价格创出更高的高点，但RSI形成更低的高点。最近一波上涨的动能弱于前一波。
  • 底背离（看涨背离）： 价格创出更低的低点，但RSI形成更高的低点。最近一波下跌的动能减弱。

有些交易者还关注隐性背离，它被解读为趋势延续信号：在上升趋势中，价格形成更高的低点，而RSI形成更低的低点。

背离描述的是动能减弱，这往往发生在反转之前。但动能可能在趋势延续的同时减弱，在强劲趋势中，背离可能连续出现好几次而不发生任何反转。交易者通常会等待价格本身给出确认，例如一次结构突破或收盘跌破支撑位，然后才根据背离采取行动。

参数设置

参数 效果 典型用途
14（默认） 均衡 通用，适用于任何时间周期
2至7 非常灵敏；频繁触及极端值 短线均值回归系统，尤其用于股指
20至25 更平滑；极端值罕见 较长期的趋势背景

周期越短，RSI触及70和30的频率就越高。2周期RSI可以在几天之内从10以下摆到90以上。短周期参数因用于在上升趋势的股指中买入短暂下跌的均值回归策略而流行起来。和任何系统一样，这些策略应计入真实成本进行检验，因为它们每笔交易的平均盈利很小，对点差和佣金很敏感。

常见错误

  • 把70当成卖出信号。 在上升趋势中，超买读数很正常。做空它们就是在逆势而行。
  • 在暴跌中把30当成买入信号。 在整个急跌过程中，RSI可能一直低于30。"超卖"并不是底部。
  • 交易每一次背离。 背离很常见，而且很多都会失败。没有价格确认，它们就是过早的信号，而过早往往意味着错误。
  • 把RSI与类似的震荡指标组合使用。 RSI、随机指标（KDJ/Stochastics）和MACD都由收盘价衍生而来。当它们一致时，大多只是同一信息被重复计算了几次。
  • 在历史数据上优化阈值。 因为回测表现最好而选用RSI 11、阈值73和27，是通往过拟合的经典路径。
  • 忽视时间周期。 5分钟图上RSI为80，对日线趋势几乎说明不了什么。

实证研究怎么说

基于RSI的规则已被检验过很多次，结果不一。在单一资产上采用"低于30买入、高于70卖出"的简单规则，扣除成本后普遍没有表现出可靠的盈利，而且不同市场和时期的结果差异很大。短周期RSI系统试图捕捉的短期反转效应，已在部分股票市场中得到记载，但每笔交易的收益很小，对交易成本高度敏感。与此同时，更广泛的动量研究表明，过去的强势表现往往会在中期内延续，这也是对自动逆着高RSI读数交易保持谨慎的理由。

常见问题

RSI参数设多少比较好？

默认的14周期最常用，也是一个合理的起点。较短的参数会让RSI更灵敏、更频繁地触及极端值，较长的参数则让它更平滑；任何改动都应在你所交易的市场和时间周期上进行检验。

RSI高于70就意味着要卖出吗？

不一定。RSI高于70意味着近期涨幅远大于近期跌幅，在强劲的上升趋势中，RSI可能长时间保持在70以上，同时价格持续上涨。

什么是RSI背离？

背离是指价格与RSI朝不同方向运动，例如价格创出更高的高点而RSI形成更低的高点。它暗示动能正在减弱，但很多背离并不会导致反转，所以交易者通常会等待价格确认。

RSI比MACD更好吗？

两者没有优劣之分；它们由同样的收盘价构建，以不同方式衡量动能。RSI的取值限定在0到100之间，极端值一目了然；MACD则没有上下限，侧重于两条移动平均线之间的关系。
