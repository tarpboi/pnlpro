移动平均线（Moving Average，MA，简称均线）是最近若干个周期的平均价格，每出现一根新K线就重新计算一次，因此它会沿着图表"移动"。它能平滑短期噪音，让趋势方向更容易看清。移动平均线是使用最广泛的技术指标，也是MACD、布林带等许多其他指标的基础构件。它的根本局限在于滞后：由于它是对过去价格求平均，所以总是在价格已经变动之后才做出反应。

要点速览

  • 简单移动平均线（SMA）对每个周期一视同仁；指数移动平均线（EMA）和加权移动平均线（WMA）则给予近期价格更大的权重。
  • 常用周期有20（短期）、50（中期）和200（长期），它们之所以流行，部分原因在于自我强化。
  • 金叉（50日均线上穿200日均线）和死叉（50日均线下穿200日均线）被广泛报道，但信号迟缓，在横盘市场中会反复打脸。
  • 每一条移动平均线都是在灵敏度与平滑度之间做取舍；不存在既快速又没有虚假信号的参数。
  • 均线规则是系统化趋势跟踪的核心组成部分，历史上在部分市场中有效，但伴随着漫长的亏损期。

移动平均线的类型

简单移动平均线（SMA）

SMA把最近N个收盘价相加，再除以N。20日SMA就是最近20个交易日收盘价的平均值。每新增一天，最早的一天就被剔除。

由于每一天的权重相同，当一次大幅波动移出计算窗口时，即使当天价格毫无变化，SMA也可能突然跳动。这有时被称为"剔除效应"。

指数移动平均线（EMA）

EMA给最新价格最大的权重，对越早的价格权重越小，而且没有硬性截断。每个新值的计算方式为：

  • 今日EMA = 昨日EMA + k x (今日收盘价 - 昨日EMA)
  • 其中 k = 2 / (N + 1)

对于20周期EMA，k = 2 / 21，约为0.095。对于5周期EMA，k = 2 / 6，约为0.333。EMA需要一个初始值，通常用SMA，早期数值取决于这个初始值。

加权移动平均线（WMA）

WMA采用线性权重：在5周期WMA中，最新收盘价乘以5，前一个乘以4，依此类推直到1，再把总和除以权重之和（15）。它的反应比SMA更快。

此外还有其他变体，包括赫尔移动平均线（Hull MA）、双重和三重EMA，以及Wilder平滑法（用于RSI和ATR的计算中）。它们都试图以不同方式在平滑度和速度之间取得平衡。

计算示例：SMA、EMA与WMA对比

五个日收盘价：$10、$11、$12、$13、$14。

  • 5日SMA = (10 + 11 + 12 + 13 + 14) / 5 = 60 / 5 = $12.00
  • 假设此时5日EMA也是$12.00（以SMA作为初始值）。

第二天收盘价为$16，涨幅比平时大。

  • 新SMA： 剔除$10，加入$16。(11 + 12 + 13 + 14 + 16) / 5 = 66 / 5 = $13.20
  • 新EMA： k = 2 / 6 = 1/3。EMA = 12.00 + (1/3) x (16 - 12.00) = 12.00 + 1.33 = $13.33
  • 新WMA： (11 x 1 + 12 x 2 + 13 x 3 + 14 x 4 + 16 x 5) / 15 = (11 + 24 + 39 + 56 + 80) / 15 = 210 / 15 = $14.00

三者都低于最新价格$16，这就是滞后。WMA最接近价格，因为它给最新一根K线的权重最大；SMA变动最小。

常用周期及其用法

周期 典型用途
9或10 非常短期的趋势；在日内图表上常用EMA
20或21 短期趋势；大约相当于一个月的交易日。也是布林带的中轨
50 中期趋势；在股票日线图上备受关注
100 中期偏长；较少使用
200 长期趋势；股指最受关注的均线

这些周期并没有什么特殊的数学性质。它们只是成了惯例，而正因为流行，许多交易者都盯着同样的线。例如，财经媒体经常报道主要股指突破或跌破200日均线的消息。这种关注可能在这些均线附近引发短期反应，部分属于自我实现效应。

移动平均线可以在任何时间周期上计算。5分钟图上的50周期均线覆盖的是大约四个小时，而不是50天。

如何使用移动平均线

趋势过滤

最简单的用法是判断方向：价格位于向上倾斜的200日均线之上，被视为长期上升趋势；位于向下倾斜的均线之下，则为下降趋势。许多交易者只在价格位于某条选定均线之上时做多，只在其下方时做空。斜率与位置同样重要：走平的均线意味着震荡。参见趋势与市场结构。

均线交叉

交叉系统使用两条均线，一快一慢。快线上穿慢线时产生买入信号，下穿时产生卖出信号。

  • 金叉： 50日均线上穿200日均线。
  • 死叉： 50日均线下穿200日均线。

金叉和死叉天生就是慢信号。等到50日均线穿过200日均线时，价格通常已经走出很长一段。在横盘市场中，两条均线可能反复来回交叉，产生一连串被称为"来回打脸"（whipsaw）的小额亏损。价格穿越单条均线（例如收盘站上50日均线）是同一思路的更快但噪音更多的版本。

动态支撑与阻力

在稳定的趋势中，价格经常回调到某条移动平均线附近，然后继续原有方向。交易者把均线视为一种移动版的支撑与阻力。在股票中，20日和50日均线常被这样使用。与水平价位一样，均线是一个区域而不是一条精确的线，而且它经常失效，尤其是在趋势即将结束时。

其他指标的基础构件

MACD是两条EMA之差。布林带是一条移动平均线加减若干倍标准差。肯特纳通道（Keltner Channels）使用EMA和ATR。理解了移动平均线，解读这些工具就更容易。

滞后的取舍

所有移动平均线都存在滞后。在稳定的直线趋势中，N周期SMA大约落后价格(N - 1) / 2根K线。20日SMA大约落后9.5天；200日SMA大约落后100天。

在稳定趋势中，N周期EMA的平均滞后大致相同。它的优势在于，当价格突然转向时它反应更早，因为最新一根K线的权重更大。代价是它对随机尖峰的反应也更大。

选择 好处 代价
较短周期 信号更早，更贴近价格 虚假信号和来回打脸更多
较长周期 更平滑，虚假信号更少 入场和离场更晚，回吐利润更多
用EMA或WMA替代SMA 对拐点反应更快 对一次性尖峰更敏感

没有任何参数能消除这种取舍。在历史数据上优化周期以找到"最佳"参数，往往会得到拟合过去、在未来失效的设置。参见过拟合。

实证研究怎么说

均线规则是研究最多的技术工具之一。Brock、Lakonishok和LeBaron（1992）发现，在很长的历史样本中，简单均线规则对道琼斯指数具有预测能力；但后来对数据窥探进行调整的研究发现，这种效应在较近期的数据中并未延续。更广泛地看，关于时间序列动量的学术研究支持这样一种观点：趋势跟踪规则（通常由移动平均线构建）在历史上长期在多元化期货组合中获得了收益。这种成功伴随着漫长的横盘或亏损期，并且依赖于交易众多市场并严格控制风险。参见趋势跟踪。

对于单只股票或单一加密资产，交叉规则是跑赢还是跑输买入持有，取决于所测试的时期。结果对周期、资产和成本都很敏感。

常见错误

  • 指望均线能预测。 移动平均线是对过去的总结。交叉确认的是已经发生的行情。
  • 在震荡中使用交叉信号。 横盘市场会反复打脸，造成一连串小额亏损。
  • 过度优化周期。 去年表现最好的47日均线，明年不太可能还有什么特别之处。
  • 堆叠多条均线。 一张图上的五条移动平均线，只是同一信息的五个版本。
  • 把200日均线当成一堵墙。 价格可以而且确实会直接穿过备受关注的均线。

常见问题

SMA和EMA有什么区别？

SMA对窗口内每个周期赋予相同权重，EMA则给最近的价格更大权重。EMA对突然变化反应更快，但对一次性尖峰也更敏感。

日内交易用哪条均线最好？

没有最佳参数。日内交易者常在1分钟至15分钟图上使用较短的EMA，如9周期或20周期，并结合VWAP等日内基准，但具体选择应在所交易的市场和时间周期上进行检验。

什么是金叉？

当50日均线上穿200日均线时，就形成了金叉。它被广泛报道为看涨信号，但它是一个慢信号，往往在大部分行情已经走完之后才出现。

为什么200日均线很重要？

它是最受关注的长期趋势线，在股指中尤其如此，所以许多交易者和媒体都会关注价格在它之上还是之下。这种关注可能在它附近引发反应，但它只是一种惯例，而不是定律。
