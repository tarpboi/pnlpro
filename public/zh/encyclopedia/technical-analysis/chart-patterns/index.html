图表形态

图表形态是价格在多根K线上反复画出的形状，例如头肩形、双顶、三角形和旗形。交易者把它们分为反转形态和持续形态：前者据称标志着趋势的结束，后者据称标志着趋势中的暂停。每种形态都有一个约定俗成的入场点（通常是突破某条边界）和一个"量度涨幅"目标。它们有助于规划交易，但失败频繁、事后很容易看出来，而且在严格检验中获得的支持很有限。

要点速览

  • 图表形态只有在价格突破其关键边界（例如头肩形的颈线）之后才算完成。
  • 量度目标是从突破点投射形态的高度；它只是粗略的参考，而不是预测。
  • 许多形态其实是支撑与阻力和趋势结构的组合，只是被冠以一个名称。
  • 形态失败很常见，而失败的形态可能引发反方向的急剧行情。
  • 形态具有主观性，因此精确定义并加以检验，是了解它们对你是否有价值的唯一途径。

如何交易图表形态

大多数形态的交易逻辑是相同的：

  1. 识别： 在形态形成过程中，借助波段高点和低点辨认其形状。
  2. 等待确认： 通常是一根K线收在形态边界（颈线、趋势线或区间边缘）之外。在突破之前，它只是一个潜在形态。
  3. 入场： 在突破时入场，或在回踩被突破的边界时入场。
  4. 设置止损： 设在形态内部，即突破思路明显被证伪的位置。
  5. 设定目标： 用量度涨幅计算，并根据附近的价位进行调整。

成交量常被用作辅助检验：经典著作描述的是形态形成过程中成交量萎缩、突破时成交量放大。参见成交量分析。

反转形态

头肩形

头肩顶形成于上升趋势之后。它有三个峰：左肩、一个更高的峰（头部）和一个较低的右肩。颈线连接各峰之间的低点。当价格收于颈线之下时，形态完成。

从结构上看，右肩是一个更低的高点，而跌破颈线是一个更低的低点，这就是一次结构突破。头肩底（倒头肩）则是出现在下降趋势末端的镜像形态。

双重顶底与三重顶底

双顶是两个价格大致相同的峰，中间夹着一个谷。当价格收于谷底之下时，形态完成。双底则相反。三重顶和三重底多了第三次测试。它们描述的都是价格在同一价位屡次失败，随后突破区间的另一侧。

圆弧底

一种从下跌缓慢过渡到上涨的U形形态。它比大多数形态更主观，通常跨越数周乃至数月。

持续形态

旗形与三角旗形

旗形出现在一段陡峭、近乎垂直的行情（旗杆）之后。随后价格在一个与行情方向相反倾斜的小矩形中漂移。三角旗形思路相同，只是小矩形换成了小型对称三角形。据称朝旗杆方向的突破意味着趋势恢复。这些都是短期形态，在日线图上通常只持续几天。

矩形

价格在水平的支撑与阻力之间横向运行。矩形其实就是一个震荡区间；形态视角额外加入了对突破的预期，而且突破方向更常与此前趋势一致。

杯柄形态

价格先呈圆弧状下跌并回升（杯身），回到接近前期高点的位置，随后出现一次浅幅回调（杯柄），然后向上突破杯口。这种形态在成长股交易者中很受欢迎。

方向不定的形态

三角形

  • 上升三角形： 阻力水平，低点抬高。常被解读为看涨，因为买方不断在更高位置入场。
  • 下降三角形： 支撑水平，高点降低。常被解读为看跌。
  • 对称三角形： 高点降低、低点抬高，两者收敛。在突破之前方向不明。

三角形反映的是波动率收窄。突破方向并不像名称暗示的那样可以预测，这也是交易者要等待突破的原因。

楔形

两条边界朝同一方向倾斜并逐渐收敛。

  • 上升楔形： 更高的高点和更高的低点，但低点抬升得更快。传统上被解读为看跌，因为动能正在衰退。
  • 下降楔形： 传统上被解读为看涨。

计算示例：量度目标

头肩顶

一只股票形成左肩$54、头部$60、右肩$54.50。颈线水平位于$50。

  • 形态高度 = 头部 - 颈线 = $60 - $50 = $10
  • 量度目标 = 颈线 - 高度 = $50 - $10 = $40

一位在收盘价$49.60入场的卖空者，可能会把止损设在右肩上方的$55.00。风险 = $55.00 - $49.60 = $5.40。到$40目标的回报 = $49.60 - $40 = $9.60。回报风险比 = $9.60 / $5.40，约为1.8。

如果把止损收紧到颈线上方一点，比如$51.50，风险会降到$1.90，但如果价格回踩颈线（这很常见），止损被触发的可能性就大得多。

双底

两个低点分别为$30.00和$30.20，中间的峰为$34.50。

  • 高度 = $34.50 - $30.00 = $4.50
  • 目标 = $34.50 + $4.50 = $39.00

上升旗形

旗杆从$20涨到$26，涨幅$6。旗形回落至$24.80，价格在$25突破。

  • 目标 = $25 + $6 = $31

这些目标只是惯例。价格常常在前期阻力位提前止步，有时又会走得远得多。许多交易者会在量度目标处部分止盈，其余仓位用移动止损跟踪。

失败率与确认

图表形态经常失败。"失败"通常是指价格突破后很快又反向穿回边界，或者始终未能到达目标。对数千个形态进行归类统计的从业者研究报告称，失败率因形态、市场以及"失败"的定义不同而差异很大，而且许多形态的表现达不到量度涨幅的预期。

有几点已被广泛认同：

  • 未经确认的形态只是猜测。 许多潜在的双顶最终只是上升趋势中的普通回调，因为价格始终没有跌破中间的谷底。
  • 失败的形态也可能提供信息。 当一个备受关注的头肩形跌破颈线后又急剧反转向上时，在跌破时做空的交易者被迫买回，这可能加剧上涨。有些交易者专门交易这类失败形态。参见价格行为交易。
  • 趋势背景很重要。 顺着较高周期强劲趋势方向的持续形态，通常被认为比逆势的反转形态更可靠。

实证研究怎么说

Lo、Mamaysky和Wang（2000）构建了一种算法，用于在美股价格中识别头肩形、双顶双底、三角形和矩形等形态。他们发现有几种形态对后续收益带有一定的增量信息，这表明这些形状并非纯粹的噪音。但他们的研究并没有证明按这些形态交易在扣除成本后能够盈利。其他研究得出的结论有的不一，有的是否定的，而且结果对形态的定义方式很敏感。

主要障碍在于主观性。两位交易者看同一张图，常常会在形态是否存在、颈线在哪里、何时被突破等问题上意见不一。把形态转化为精确的规则并进行回测，是衡量它的唯一途径，而要做好这一点，还需小心避免过拟合。

常见错误

  • 在突破前就交易。 预判形态意味着要在许多最终并未完成的形状上交易。
  • 在随机数据中看到形态。 随机价格序列经常会产生令人信服的头肩形和三角形。
  • 把目标当成承诺。 量度涨幅只是粗略参考，附近的价位往往更重要。
  • 止损设得太紧。 回踩突破价位很常见，往往会触发恰好设在边界上的止损。
  • 忽视更大级别的趋势。 在强劲的周线上升趋势中出现的小型看跌形态，是在逆主流而动。
  • 形态失败后挪动形态。 为了不承认形态失败而重画颈线，是一种确认偏差。

常见问题

最可靠的图表形态是哪一种？

没有任何形态能单独做到可靠；所有形态的失败率都不低，并且因市场和定义而异。对于收盘价确认突破边界、与较高周期趋势一致、并伴随成交量放大的形态，交易者一般更有信心。

如何计算图表形态的目标价？

大多数形态使用量度涨幅：取形态的高度，例如头部到颈线的距离或旗形的旗杆长度，再从突破点投射出去。把结果视为粗略参考，并对照附近的支撑和阻力进行核对。

头肩形是看涨还是看跌？

出现在上升趋势末端的标准头肩顶，传统上在跌破颈线后被解读为看跌。出现在下降趋势末端的头肩底（倒头肩），则被解读为看涨。

旗形和三角旗形有什么区别？

两者都是急剧行情之后的短暂停顿。旗形在一个倾斜的小矩形中整理，三角旗形则在一个逐渐收敛的小三角形中整理。
