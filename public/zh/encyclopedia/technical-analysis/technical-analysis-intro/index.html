技术分析（Technical Analysis，TA）是通过研究历史价格和成交量来为未来交易做决策的方法。技术分析师不问一项资产"值多少钱"，而是关注买卖双方过去如何行动，以及这些行为对下一步走势可能意味着什么。技术分析广泛用于股票、外汇、期货、加密货币乃至预测市场，覆盖从几秒到几年的各种周期。它之所以流行，是因为图表免费、直观；但关于它在扣除成本后能否带来盈利，实证结论并不一致。因此，既要了解它能告诉你什么，也要清楚它在哪里会失灵。

要点速览

  • 技术分析把价格和成交量视为供求关系与群体行为的记录，并从中寻找反复出现的结构。
  • 同一个市场，在折线图、美国线（OHLC柱状图）、K线图、Heikin-Ashi图或砖形图（Renko）上看起来可能截然不同；在5分钟图和周线图上也是如此。
  • 学术研究在许多市场中证实了动量效应和趋势效应，但很多经典图表形态和指标信号在计入交易成本、剔除数据窥探偏差后便站不住脚。
  • 技术分析最有用的地方在于作为规划交易和管理风险的框架，而不是用来确定无疑地预测价格。
  • 每一条技术分析规则都可以用历史数据检验，未经检验的规则值得怀疑。

技术分析的基本前提

技术分析建立在几条工作假设之上。它们都不是自然规律，每一条都有反对者。

  1. 价格反映可得信息。 财报、利率、新闻和传闻，最终都通过成交体现在图表上。因此，技术分析师盯着价格本身，而不是试图为每一个输入变量建模。这一点与有效市场假说有重叠，但并不相同：有效市场假说认为，如果价格已反映全部信息，那么历史价格就不应有助于预测未来价格。
  2. 价格以趋势方式运动。 由于信息传播缓慢、仓位逐步建立以及交易者的从众行为，市场可能长时间朝一个方向漂移。对趋势与市场结构的研究正是建立在这一前提之上。
  3. 行为会重复。 恐惧、贪婪、对过去价格的锚定以及不愿止损卖出，都是根深蒂固的人性特征。技术分析师认为，这些特征会留下反复出现的痕迹，例如交易者记得此前拐点所在的支撑位与阻力位。

这门学问由来已久。几个世纪前，日本的米市商人就使用了早期形式的蜡烛图；在美国，查尔斯·道（Charles Dow）19世纪后期的报刊文章成为今天所谓"道氏理论"的基础，其核心是由更高的高点和更高的低点所确认的趋势。

技术分析与基本面分析

基本面分析依据盈利、现金流、经济数据或代币供应量来估算价值；技术分析则直接研究市场行为。许多交易者将两者结合：用基本面决定交易什么、做多还是做空，用技术面决定何时入场、止损设在哪里。

图表类型

图表是把大量成交压缩成一幅图像的方式。选择哪种图表，会改变你看到的东西。

图表类型 每个单位显示的内容 优点 缺点
折线图 每个周期一个价格，通常是收盘价 整体走势一目了然 隐藏了周期内的波动区间和波动性
美国线（OHLC） 每个周期的开盘价、最高价、最低价和收盘价 区间信息完整 不易一眼看懂
K线图（蜡烛图） 与美国线数据相同，实体带颜色 方向和区间一目了然 容易让人过度解读单根K线
Heikin-Ashi 由平均值构建的平滑K线 让趋势更容易辨认 显示的并非真实成交价
砖形图（Renko） 固定大小的砖块，不考虑时间 过滤小幅波动 高度依赖砖块大小；存在滞后

折线图、美国线与K线图

折线图把收盘价连起来，适合观察长期走势和比较多种资产。美国线和K线图都显示每个周期的开盘价、最高价、最低价和收盘价（OHLC）。两者数据完全相同，K线只是给开盘价与收盘价之间的区域上了色，大多数交易者觉得这样读起来更快。具体的K线形状和组合，详见K线形态。

Heikin-Ashi

Heikin-Ashi（日语意为"平均K线"）并不是直接根据成交绘制的，而是计算出来的：

  • HA收盘价 = (开盘价 + 最高价 + 最低价 + 收盘价) / 4
  • HA开盘价 = (前一根HA开盘价 + 前一根HA收盘价) / 2
  • HA最高价 = 最高价、HA开盘价、HA收盘价三者中的最大值
  • HA最低价 = 最低价、HA开盘价、HA收盘价三者中的最小值

计算示例。 假设前一根Heikin-Ashi K线的HA开盘价为100，HA收盘价为102。当前真实K线的开盘价为102，最高价105，最低价101，收盘价104。

  • HA收盘价 = (102 + 105 + 101 + 104) / 4 = 412 / 4 = 103
  • HA开盘价 = (100 + 102) / 2 = 101
  • HA最高价 = max(105, 101, 103) = 105
  • HA最低价 = min(101, 101, 103) = 101

真实K线收于104，而Heikin-Ashi K线显示的是103。这个差别很重要：你无法按Heikin-Ashi价格下单，假设按这些价格成交的回测结果会比现实好看。Heikin-Ashi是辅助观察趋势方向的工具，而不是价格记录。

砖形图及其他与时间无关的图表

砖形图（Renko）只有在价格较上一块砖移动固定幅度（例如$1或10个点）时才画出一块新砖。它不考虑时间，所以平静的一天可能一块砖都没有，而剧烈波动的一小时可能出现十块。砖形图能过滤噪音，但图形完全取决于砖块大小，而且砖块只有在行情走完之后才会形成。

时间周期

每张图表都有一个时间周期，即每根柱线或K线所代表的时长。常见的有1分钟、5分钟、15分钟、1小时、4小时、日线和周线。时间周期的选择通常取决于你的交易风格：

风格 典型持仓时间 常用图表周期
剥头皮（Scalping） 几秒到几分钟 Tick图、1分钟
日内交易 几分钟到几小时 1分钟至15分钟
波段交易 几天到几周 1小时、4小时、日线
头寸交易（中长线） 几周到几个月 日线、周线

同一资产可能在日线图上处于上升趋势，在15分钟图上却处于下降趋势。两种看法都没错，它们回答的是不同的问题。依次查看多个时间周期的交易者，使用的就是所谓的多周期分析。

周期越短，噪音相对于波动幅度就越大，交易成本在每笔交易中所占的比例也越高。这也是为什么在针对散户日内交易者的研究中，短线散户交易的结果尤其糟糕。

主要工具类别

技术分析是一大类方法的统称，大多可归入以下几组：

  • 价格结构： 趋势、波段高点与低点、支撑与阻力，以及三角形、头肩形等图表形态。主要依据裸K图交易的人，把这称为价格行为交易。
  • 技术指标： 应用于价格或成交量的公式，例如移动平均线、RSI、MACD、布林带和ATR。指标并不会增加新信息，只是以另一种形式概括价格。
  • 成交量与订单流： 成交量分析、VWAP、成交量分布和订单流关注的是成交了多少、在什么价位成交。
  • 结构性理论： 例如艾略特波浪与威科夫、斐波那契工具和聪明钱概念（SMC）。这些框架往往更依赖主观解读，也更难客观检验。

实证研究怎么说

对于"技术分析到底有没有用"，诚实的回答是：其中一部分在某些市场和时期似乎有过价值，很多部分则没有；而且曾经存在的优势，一旦公开发表，往往会逐渐缩小。

支持部分技术分析观点的证据：

  • 动量效应。 Jegadeesh和Titman（1993）发现，过去3到12个月表现强劲的美股，在随后几个月往往继续跑赢。这种横截面动量效应已在许多国家和资产类别中被发现。
  • 时间序列动量与趋势跟踪。 Moskowitz、Ooi和Pedersen（2012）发现，在数十个期货市场中，一项资产自身过去12个月的收益往往能预测其下个月的收益。这是趋势跟踪和管理期货（CTA）行业的学术支柱。历史上，该策略曾出现过很长的横盘或亏损期。
  • 早期数据中的简单交易规则。 Brock、Lakonishok和LeBaron（1992）发现，在很长的历史样本中，移动平均线规则和区间突破规则对道琼斯指数具有预测能力。Sullivan、Timmermann和White（1999）的后续研究对数据窥探进行了调整，发现表现最好的规则在之后的数据中并未持续有效。
  • 含有一定信息量的形态。 Lo、Mamaysky和Wang（2000）对美股进行自动化形态识别，结论是部分经典形态带有少量增量信息。但他们并没有证明，按这些形态交易在扣除成本后能够盈利。

不利于技术分析的证据：

  • 许多流行的形态和指标信号，在精心挑选的图表上看起来很有说服力，但在系统性检验中却会失效，尤其是在计入佣金、点差和滑点之后。
  • 结果很脆弱。参数稍作改动，或换一个时期、换一个市场测试，优势往往就消失了。这就是过拟合与数据窥探问题。
  • 市场会适应。一条规则一旦广为人知且易于自动化，速度更快、资金更雄厚的交易者往往会把其中的利润竞争殆尽。
  • 散户结果很差。针对散户日内交易者的研究，包括Barber、Lee、Liu和Odean对台湾市场的研究，以及Chague、De-Losso和Giovannetti对巴西市场的研究，都发现绝大多数人亏钱，能够年复一年盈利的人寥寥无几。这些交易者大多使用某种形式的图表交易。

技术分析还存在自我实现的成分。如果很多交易者都盯着同一条200日均线或同一个整数关口，订单就会在那里聚集，价格可能出现反应，至少是短暂的反应。这种反应是真实的，但它并不等同于一种可靠、可利用的优势。

计算示例：为什么"好"形态照样会亏钱

假设某个图表形态据称胜率为55%。每笔盈利赚$100，每笔亏损亏$100。佣金、点差和滑点每次开平仓合计成本为$8。

  • 每笔交易期望值 = (0.55 x $100) - (0.45 x $100) - $8 = $55 - $45 - $8 = +$2

100笔交易下来是+$200，优势非常微薄。现在假设，在新数据上诚实测得的真实胜率是52%而不是55%：

  • 每笔交易期望值 = (0.52 x $100) - (0.48 x $100) - $8 = $52 - $48 - $8 = -$4

100笔交易下来是-$400。胜率估计偏差3个百分点，就能把一个小赚的策略变成持续亏损的策略。这就是为什么成本和诚实的度量比形态本身更重要。完整框架请参阅风险回报比与期望值。

如何负责任地使用技术分析

  • 用技术分析来界定风险，而不只是找入场点。 支撑位或波段低点为止损提供了合乎逻辑的位置。知道自己在哪里会被证明是错的，往往比入场信号更有价值。参见止损策略。
  • 把规则写下来。 "看起来走强就买"无法检验；"日线收盘价高于50日均线且RSI高于50时买入"则可以。
  • 先检验，再交易。 先用历史数据进行计入真实成本的回测，再进行模拟交易，能以很低的代价淘汰许多想法。
  • 优先选择参数少的简单规则。 一个系统的"旋钮"越多，就越容易拟合到过去的噪音上。
  • 寻找独立的确认。 两个都由收盘价计算出来的指标，并不构成相互独立的证据。
  • 做好记录。 交易日志能告诉你，你的读图能力是否真的带来了价值，而不是依赖往往偏向记住盈利交易的记忆。
  • 记住基础概率。 大多数散户交易者都在亏钱，在短周期和使用杠杆时尤其如此。技术分析不能让任何人例外。

常见错误

  • 处处看到形态。 人类很擅长在随机数据中找出形状。一条随机游走的价格序列，也会偶然出现头肩形、三角形和双顶。
  • 事后画图。 事后给形态贴标签很容易。问题在于，你能否在结果出现之前、实时地把它识别出来。
  • 指标堆叠。 叠加更多由同一价格数据衍生的指标，增加的是复杂度，而不是信息。
  • 忽视成本。 一条每笔交易毛利很小的规则，在扣除点差、佣金和滑点后可能是亏钱的，在短周期上尤其如此。
  • 把技术分析当作预测。 图表描述的是概率和背景。一个形态失败是正常结果，不能证明市场被操纵了。
  • 购买承诺高准确率的课程。 宣称80%或90%胜率却没有经过验证的记录，是一种常见的营销手段。参见课程、大师与喊单。

常见问题

技术分析真的有用吗？

其中一部分有学术支持，尤其是在许多市场中都存在的动量效应和趋势跟踪效应；但很多图表形态和指标信号在扣除成本后，经不起严格检验。技术分析最适合作为规划交易和控制风险的框架，而不是预测工具。

新手最适合用哪种图表？

K线图是最常见的起点，因为它清楚地显示开盘价、最高价、最低价和收盘价，也是大多数平台的默认图表。折线图则适合在不受干扰的情况下看清大局。

做技术分析应该用哪个时间周期？

让时间周期与你打算的持仓时间相匹配：持仓几分钟的交易用1分钟至15分钟图；持仓几天或几周的交易则用4小时图、日线图或周线图。周期越短，相对于预期波动的噪音越多、成本越高。

技术分析比基本面分析更好吗？

两者没有绝对的优劣，它们回答的是不同的问题。基本面分析估算一项资产可能值多少钱，技术分析研究它如何交易，很多交易者会把两者结合起来使用。

仅供学习参考。本站内容不构成任何金融、投资、法律或税务建议。交易具有很高的亏损风险，杠杆产品的亏损可能超过你投入的本金。规则、费用和平台细节会变化，交易前请向你的券商、交易所或监管机构核实最新条款。
