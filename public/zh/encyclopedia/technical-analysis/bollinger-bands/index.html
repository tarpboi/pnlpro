布林带

布林带（Bollinger Bands，又称布林线、BOLL）是一种由三条线构成的波动率指标：中间是一条移动平均线，上下两条轨道与中轨相距若干倍标准差。价格波动加剧时轨道变宽，波动平缓时轨道收窄，因此布林带既能显示价格相对于近期均值所处的位置，也能显示市场当前的波动程度。布林带由John Bollinger于1980年代提出，既用于均值回归交易，也用于突破交易，而这两种方法对同一次触轨的解读恰恰相反。价格触及轨道只是描述了价格所在的位置，本身并不是信号。

要点速览

  • 标准参数是20周期简单移动平均线，上下轨距离中轨各2倍标准差。
  • 轨道宽度反映波动率："收口"（squeeze，轨道收窄）描述的是异常低的波动率，此后往往会出现较大的行情，但方向无法预测。
  • 在强劲趋势中，价格可能"沿轨运行"，连续多根K线收在上轨或下轨处或附近。
  • %B显示价格在轨道内所处的位置，带宽则衡量轨道相对于中轨的宽度。
  • 肯特纳通道（Keltner Channels）用平均真实波幅代替标准差，因此更平滑，对单根大K线的反应也更小。

布林带如何构成

使用默认参数时：

  • 中轨 = 收盘价的20周期简单移动平均线（SMA）。
  • 上轨 = 中轨 + 2 x 收盘价的20周期标准差。
  • 下轨 = 中轨 - 2 x 20周期标准差。

标准差衡量最近20个收盘价围绕其平均值的分散程度。收盘价紧密聚集时，标准差小，轨道靠近中轨；收盘价大幅摆动时，轨道就会张开。在计算标准差时，各平台除以N还是N - 1略有不同；在20个周期下，差别很小。

有一种说法是，约95%的价格会落在2倍标准差的轨道之内。这个数字来自正态分布，但价格并不服从正态分布，而且该计算使用的是价格的滚动窗口而非收益率。实践中，收盘价落在轨道之外的情况比这个数字所暗示的更常见，其比例也因市场和时期而异。

%B与带宽

两个衍生指标把布林带转换成数字：

  • %B = (价格 - 下轨) / (上轨 - 下轨)。数值为1表示价格位于上轨，0表示位于下轨，0.5表示位于中轨。高于1或低于0表示价格位于轨道之外。
  • 带宽 = (上轨 - 下轨) / 中轨。它把轨道宽度表示为价格的一个比例，从而可以在不同时间和不同资产之间进行比较。

%B适用于需要用单一数字表示价格"偏离程度"的系统。带宽则是识别收口的标准方法。

计算示例

某股票最近20个日收盘价的平均值为$50.00，标准差为$1.50。

  • 中轨 = $50.00
  • 上轨 = 50.00 + 2 x 1.50 = $53.00
  • 下轨 = 50.00 - 2 x 1.50 = $47.00
  • 带宽 = (53.00 - 47.00) / 50.00 = 6.00 / 50.00 = 0.12，即12%

如果今天收盘价为$52.40：

  • %B = (52.40 - 47.00) / (53.00 - 47.00) = 5.40 / 6.00 = 0.90。价格接近上轨。

如果收盘价为$53.60：

  • %B = (53.60 - 47.00) / 6.00 = 6.60 / 6.00 = 1.10。价格收在上轨之外。

一次收口。 几周后，这只股票交投清淡，20日标准差降到$0.50，均值仍在$50.00附近。

  • 上轨 = 50.00 + 2 x 0.50 = $51.00；下轨 = 50.00 - 2 x 0.50 = $49.00
  • 带宽 = 2.00 / 50.00 = 4%

带宽从12%降至4%，只有之前水平的三分之一。如果4%接近过去几个月的最低带宽读数，交易者就会把这描述为一次收口。

收口

波动率有聚集性：平静时期之后往往还是平静，活跃时期之后往往还是活跃；但随着时间推移，波动率也倾向于回归其长期水平。收口突显了一段异常低波动的时期。关注收口的交易者预期波动最终会扩张，即出现一波朝某个方向的较大行情。

难点在于，收口完全不说明方向，而且收口后的第一波行情有时是会反转的假突破。交易者通常会把收口与其他因素结合起来选择方向：

  • 更大级别趋势的方向。
  • 收盘价突破附近的支撑或阻力价位。
  • 突破时成交量放大。参见成交量分析。

收口也可能持续得比预期久得多，轨道可能连续几周保持狭窄。

沿轨运行

在强劲的上升趋势中，价格可能连续多根K线收在上轨处或上轨之上，而中轨成为回调遇到买盘的区域。在强劲的下降趋势中，则会沿下轨出现相反的情形。这被称为沿轨运行（walking the bands）。

沿轨运行是"每次触及上轨就卖出"之所以危险的主要原因。在趋势中，收在上轨之外往往反映的是强势，而不是即将反转。Bollinger本人也强调，触及轨道本身并不是买入或卖出信号。

均值回归与突破两种用法

同一个事件——价格收在轨道之外——会因方法不同而得出截然相反的解读：

方法 对收在上轨之上的解读 最适用的环境 主要风险
均值回归 价格偏离过度；预期回到中轨附近 震荡、来回拉锯的市场 趋势启动，价格沿轨运行
突破 / 趋势 波动率和动能正向上扩张；考虑顺势跟进 新兴趋势、收口后的突破 突破失败，价格回到轨道之内

均值回归交易者常把触轨与RSI等震荡指标结合使用，并加上避免逆强势趋势交易的过滤条件。突破交易者则常要求事先出现收口，并且收盘价突破关键价位。两种方法都不是在所有情况下都正确；难点在于判断市场处于哪种状态，而这种判断往往只有事后才清楚。

均值回归策略往往胜率高，但偶尔会出现大额亏损；突破策略往往胜率较低，但偶尔会有大额盈利。两者扣除成本后都可能亏钱，这就是为什么期望值比胜率更重要。

布林带与肯特纳通道

肯特纳通道看起来与布林带相似，但衡量波动率的方式不同。其现代版本（也是大多数平台的默认版本）使用：

  • 中线： 一条指数移动平均线，通常为20周期。
  • 上下轨： 中线加减若干倍平均真实波幅（ATR），常用1.5倍或2倍。
特征 布林带 肯特纳通道
中线 20 SMA EMA，通常为20
波动率度量 收盘价的标准差 平均真实波幅，包含跳空缺口和K线内振幅
对单根大K线的反应 轨道急剧变宽 更平滑，逐渐变宽
典型形状 时而鼓起、时而收紧 更稳定，更接近平行

由于标准差对大幅波动反应更强烈，布林带的扩张和收缩更为剧烈。有些交易者把布林带收缩到肯特纳通道之内的那一刻定义为收口。

示例。 沿用上面的股票，假设20周期EMA约为$50.00，ATR为$1.20。2 x ATR的肯特纳通道位于50.00 +/- 2.40，即$47.60和$52.40，宽度为$4.80。在早先的高波动时期，布林带（$47.00至$53.00，宽度$6.00）位于肯特纳通道之外。在收口期间，布林带（$49.00至$51.00，宽度$2.00）位于肯特纳通道之内，这些交易者就会称之为收口。实际上，ATR在平静时期也会有所收缩；只要标准差下降得比ATR快，这种比较就成立。

实证研究怎么说

布林带是一种衡量波动率以及价格偏离近期均值程度的方法，这些量是真实存在的，对设置止损和确定仓位很有用。在已发表的检验中，"下轨买入、上轨卖出"或交易每一次突破这类简单规则，结果不一，表现在很大程度上取决于市场、时期和成本。波动率聚集本身在金融收益率中有充分记载，这支持了收口背后的思路，但这并不意味着下一波行情的方向可以预测。

常见错误

  • 把触轨当成信号。 触轨只显示价格相对于近期波动率所处的位置。
  • 逆强势趋势交易。 在沿轨运行时卖出上轨，是反复亏钱的常见方式。
  • 假定95%的价格都在轨道内。 价格并不服从正态分布，收盘价落在轨道之外很常见。
  • 猜测收口后的方向。 收口描述的是低波动率，而不是价格将向哪里突破。
  • 过度优化参数。 为拟合历史数据而修改周期和倍数，不太可能在未来的数据中有所帮助。

常见问题

布林带参数设多少最好？

默认的20周期均线加2倍标准差是迄今使用最广的设置，也是一个合理的起点。较短的周期会让轨道反应更快，任何改动都应在你所交易的市场和时间周期上进行检验。

布林带收口意味着什么？

收口是指轨道收窄到异常小的宽度，显示出一段低波动时期。这类时期之后往往会出现较大的行情，但收口并不能说明行情会朝哪个方向走。

价格触及布林带上轨是卖出信号吗？

单凭这一点不是。在震荡中，价格常常从上轨回落；但在强劲的上升趋势中，价格可能连续多根K线收在上轨处或上轨之上。

布林带和肯特纳通道有什么区别？

布林带使用围绕简单移动平均线的收盘价标准差，肯特纳通道则使用围绕指数移动平均线的平均真实波幅。肯特纳通道更平滑，布林带的扩张和收缩更为剧烈。
