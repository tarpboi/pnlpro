MACD（指数平滑异同移动平均线）

MACD是Moving Average Convergence Divergence的缩写，中文常称"指数平滑异同移动平均线"，是一种由两条价格指数移动平均线之差构成的趋势与动量指标。它由三部分组成：MACD线（国内软件中常称DIF）、对其进行平滑的信号线（常称DEA），以及显示两者差距的柱状图（MACD柱）。MACD由Gerald Appel在1970年代后期创立，因其在单一窗口中同时呈现趋势方向和动能而成为使用最广泛的指标之一。与构成它的移动平均线一样，MACD滞后于价格，描述的是已经开始的行情。

要点速览

  • MACD线是12周期EMA减去26周期EMA；信号线是MACD线的9周期EMA；柱状图是MACD线减去信号线。
  • MACD线位于零轴之上，意味着短期均线高于长期均线，这与上升趋势相符。
  • 信号线交叉频繁且噪音大；零轴交叉较慢，等同于一次均线交叉。
  • 柱状图显示MACD线与信号线之间的差距是在扩大还是收窄，交易者将其解读为动能在增强还是减弱。
  • MACD以价格单位计量，因此不同价格水平的资产之间，其数值无法直接比较。

MACD如何构成

MACD由三步计算构成，默认参数为12、26和9：

  1. MACD线 = 收盘价的12周期EMA - 收盘价的26周期EMA。
  2. 信号线 = MACD线的9周期EMA。
  3. 柱状图 = MACD线 - 信号线。

这个名称描述的正是MACD线所追踪的内容：两条移动平均线的收敛（相互靠近）与发散（相互远离）。当价格稳步上涨时，较快的12周期EMA会向上拉开、远离较慢的26周期EMA，MACD的正值越来越大。当涨势放缓时，两条均线收敛，MACD向零轴缩小。

柱状图并不是最初设计的一部分；它是后来由其他分析师加入的，如今已成为大多数平台的标准配置。

解读三个组成部分

组成部分 显示的内容 常见解读
MACD在零轴之上 12 EMA高于26 EMA 短期趋势相对中期向上
MACD在零轴之下 12 EMA低于26 EMA 短期趋势向下
MACD上升 均线向上发散或从下方收敛 上行动能增强
MACD上穿信号线 近期动能转而向上 短期看涨信号（金叉）
MACD下穿信号线 近期动能转而向下 短期看跌信号（死叉）
柱状图放大 MACD与信号线的差距扩大 动能加速
柱状图缩小 差距收窄 动能放缓；可能随后出现交叉

计算示例

某一天，一只股票的12日EMA为$105.40，26日EMA为$103.90。昨日信号线为1.20。

  • MACD = 105.40 - 103.90 = 1.50
  • 信号线的平滑系数 k = 2 / (9 + 1) = 0.2。
  • 信号线 = 1.20 + 0.2 x (1.50 - 1.20) = 1.20 + 0.06 = 1.26
  • 柱状图 = 1.50 - 1.26 = 0.24

第二天，涨势放缓，MACD回落至1.40。

  • 信号线 = 1.26 + 0.2 x (1.40 - 1.26) = 1.26 + 0.028 = 1.288
  • 柱状图 = 1.40 - 1.288 = 0.112

第三天，MACD跌至1.20。

  • 信号线 = 1.288 + 0.2 x (1.20 - 1.288) = 1.288 - 0.0176 = 1.2704
  • 柱状图 = 1.20 - 1.2704 = -0.0704

柱状图已经转负：MACD下穿了信号线。然而MACD本身仍远在零轴之上，意味着12日均线仍高于26日均线，中期趋势依然向上。交易者会把这解读为上升趋势中的动能减弱，而不是下降趋势已获确认。第二天缩小的柱状图，比交叉更早发出了警示。

为什么不同资产之间的数值不可比

MACD以价格单位计量。$104股票上1.50的MACD，与$10.40股票上0.15的MACD，代表的比例差距相同。为了在资产之间作比较，有些交易者使用价格百分比震荡指标（PPO），即用EMA之差除以较慢的EMA。在本例中，PPO = 1.50 / 103.90 x 100，约为1.44%。出于同样的原因，对于一只价格变化很大的资产，多年前的MACD读数也无法与今天的直接比较。

交易者如何使用MACD

信号线交叉

最常见的用法：MACD上穿信号线时买入，下穿时卖出。这些信号频繁且反应迅速，但在横盘市场中会产生大量来回打脸。许多交易者只做与更大趋势方向一致的交叉，例如只在MACD位于零轴之上或价格位于200日均线之上时才做看涨交叉。

零轴交叉

当MACD穿越零轴时，就是12 EMA在穿越26 EMA。这恰恰就是一次均线交叉，比信号线交叉更慢，虚假信号也更少。有些交易者把零轴用作趋势过滤器，而不是触发信号。

柱状图动能

柱状图会在交叉发生之前改变方向。柱状图出现峰值，意味着MACD与信号线之间的差距已停止扩大。有些交易者把柱状图拐头用作提前离场或收紧止损的依据。信号越早，误报也越多。

背离

与RSI一样，背离是价格与指标之间的不一致：

  • 顶背离（看跌背离）： 价格创出更高的高点，而MACD（或其柱状图）形成更低的高点。
  • 底背离（看涨背离）： 价格创出更低的低点，而MACD形成更高的低点。

背离显示的是动能减弱。它常常出现在反转之前，但也会在持续进行的趋势中反复出现。由于MACD没有上下限且依赖于价格水平，跨越较长时期或价格大幅变动的背离可能会失真。大多数交易者会等待价格确认，例如出现一次结构突破。

参数设置

12/26/9的默认参数，是该指标早期用于日线图时形成的惯例。在大多数平台上，它被原封不动地应用于所有时间周期。

参数 效果
较短（例如5/35/5或8/17/9） 信号更快，噪音更多
默认12/26/9 使用广泛；信号与其他交易者看到的一致
较长（例如19/39/9） 更平滑，信号更少、更晚

没有证据表明哪种参数普遍更好。为拟合历史数据而调整这三个参数，很容易导致过拟合。参见过拟合与数据窥探。

滞后问题

MACD由移动平均线构建，而它的信号线是"均线之差"的均线。每多一层，就多一分延迟：

  • 只有在12 EMA追上并越过26 EMA之后，才会发生零轴交叉，而那时价格通常已经走出相当一段距离。
  • 信号线交叉更快，但仍然落后于价格的拐点。
  • 在快速反转中，比如消息面引发的急跌，MACD可能在行情接近底部时才给出卖出信号。

这种滞后是平滑的代价。它使MACD更适合识别并跟随持续性行情，而不是捕捉精确的拐点。在来回拉锯的横盘市场中，滞后加上频繁交叉，会导致反复的小额亏损。

实证研究怎么说

MACD规则已在许多市场中被检验，结果不一。由于MACD本质上是一个额外加了平滑的均线交叉系统，它继承了同样的特征：能够捕捉持续性趋势（趋势跟踪研究表明，这类趋势在历史上存在于许多市场中），同时在震荡中回吐收益。在单一资产上单独使用信号线交叉的系统，扣除成本后普遍没有表现出稳定的盈利。与其把MACD当作独立的优势来源，不如把它视为描述趋势和动能的一种方式。

常见错误

  • 交易每一次信号线交叉。 在震荡中，大多数交叉都是噪音。
  • 跨资产或跨年代比较MACD数值。 如果需要比较，请使用PPO等基于百分比的版本。
  • 把MACD和RSI算作两次确认。 两者都来自同样的收盘价。
  • 指望MACD能预测顶部和底部。 它天生就是滞后的；它是在拐点开始之后才加以确认。
  • 忘记零轴。 在强劲上升趋势中、远在零轴之上的看跌交叉，与零轴之下的看跌交叉含义不同。

常见问题

MACD参数12、26、9是什么意思？

MACD线是12周期EMA减去26周期EMA，信号线是MACD线的9周期EMA。这些默认值源于MACD早期在日线图上的应用，至今仍是大多数平台的标准设置。

什么是MACD交叉？

信号线交叉是指MACD线穿越其信号线：上穿被解读为看涨，下穿被解读为看跌。零轴交叉是指MACD穿越零轴，这等同于12 EMA穿越26 EMA。

MACD柱状图显示的是什么？

柱状图显示MACD线与信号线之差。柱状图放大意味着该方向的动能在加速，缩小则意味着动能在减弱，可能随后出现交叉。

MACD是领先指标还是滞后指标？

MACD是滞后指标，因为它由过去价格的移动平均线构建。柱状图和背离可以给出更早的提示，但伴随着更多的虚假信号。
