K线图（又称蜡烛图）针对每个时间周期，显示开盘价、期间达到的最高价和最低价，以及收盘价。每个周期画成一根"蜡烛"：开盘价与收盘价之间是粗的实体，延伸到最高价和最低价的是细的影线。K线是大多数交易平台的默认图表，因此会看K线是所有看盘者的基本功。一根K线是对已发生事情的总结，而不是对接下来走势的预测。

要点速览

  • 每根K线包含四个价格：开盘价、最高价、最低价和收盘价（OHLC）。
  • 实体显示开盘价与收盘价之间的距离；影线显示价格在该周期内超出这一区间走了多远。
  • 收盘价在K线区间中的位置，简单描述了周期结束时是哪一方占据主导。
  • 同样的价格走势在不同时间周期上看起来差别很大，因为一根K线不过是若干根更小K线的合成。
  • K线与OHLC柱状图（美国线）包含的数据完全相同，区别只在于视觉呈现。

K线的构成

每根K线都由该周期的四个数字构成：

  • 开盘价： 该周期第一笔成交的价格。
  • 最高价： 最高的成交价。
  • 最低价： 最低的成交价。
  • 收盘价： 最后一笔成交的价格。

它们被画成两个部分：

  • 实体。 开盘价与收盘价之间的矩形。收盘价高于开盘价时，K线为阳线，通常画成绿色或空心；收盘价低于开盘价时，K线为阴线，通常画成红色或实心。颜色是平台设置项，一些地区采用相反的惯例（例如在中国和其他一些东亚市场，红涨绿跌很常见），所以请检查你的图表设置。
  • 影线（也叫"影子"或"尾巴"）。实体上方和下方的细线。上影线从实体顶端延伸到最高价；下影线从实体底端延伸到最低价。
组成部分 计算方式 描述的内容
实体大小 收盘价减开盘价的绝对值 该周期的净进展
上影线 最高价减开盘价与收盘价中较高者 价格在被打回之前上冲了多远
下影线 开盘价与收盘价中较低者减最低价 价格在被拉回之前下探了多远
振幅区间 最高价减最低价 该周期内的总波动

没有实体（开盘价与收盘价相等或几乎相等）的K线叫十字星（doji）。这类有名称的形状，详见K线形态。

K线反映的买卖压力

一根K线并不显示是谁在买、谁在卖，也不显示买卖了多少。它显示的是价格路径的起点、终点和极值。不过交易者仍把它当作对买卖双方力量对比的粗略描述：

  • 大实体、短影线。 价格朝一个方向稳步运行，并收在极值附近。一方在整个周期内都占据主导。
  • 小实体、长影线。 价格波动很大，但最终收在起点附近。双方都没能掌控局面，交易者常把这称为犹豫不决。
  • 长下影线。 卖方在周期内把价格打低，但价格在收盘前收复失地。交易者称之为对低价的拒绝。
  • 长上影线。 买方把价格推高，但价格又回落。交易者称之为对高价的拒绝。

这些描述是有用的简便说法，但终归是解读。在流动性稀薄的市场中，一根长下影线可能只是一笔大卖单砸穿了空荡的订单簿，而不是市场情绪的普遍转变。在新闻发布前后和开盘时段，流动性较弱，影线往往也更长。

背景比K线本身更重要。在一个备受关注的支撑位出现的长下影线，与在区间中部出现的同样形状，含义并不相同。成交量提供了另一个维度：成交量异常放大的大实体K线，通常被认为比缩量时的同类K线更有意义。参见成交量分析。

计算示例：测量一根K线

某股票的日K线开盘价$50.00，最高价$52.40，最低价$49.20，收盘价$51.80。

  • 收盘价高于开盘价，所以这是一根阳线。
  • 实体 = $51.80 - $50.00 = $1.80
  • 上影线 = $52.40 - $51.80 = $0.60
  • 下影线 = $50.00 - $49.20 = $0.80
  • 振幅区间 = $52.40 - $49.20 = $3.20
  • 验算：实体 + 上影线 + 下影线 = $1.80 + $0.60 + $0.80 = $3.20。

常用两个比率来客观描述一根K线：

  • 实体占区间比例 = $1.80 / $3.20 = 56.25%。当天超过一半的波动区间是净进展。
  • 收盘位置 = (收盘价 - 最低价) / (最高价 - 最低价) = ($51.80 - $49.20) / $3.20 = $2.60 / $3.20 = 81.25%。该股收在当日区间的上方五分之一以内。

合理的描述是：买方取得了扎实的进展，并把大部分涨幅保持到收盘，早盘曾小幅跌破开盘价。这描述的是当天的情况，并不能说明明天是涨是跌。

时间周期的影响

一根K线可以代表一分钟、一小时、一天或一周。较长周期的K线只是较短周期K线的组合：

  • 开盘价是第一根子K线的开盘价。
  • 最高价是所有子K线中最高的最高价。
  • 最低价是最低的最低价。
  • 收盘价是最后一根子K线的收盘价。

计算示例。 四根1小时K线：

小时 开盘价 最高价 最低价 收盘价
1 100.0 102.0 99.0 101.0
2 101.0 103.0 100.0 102.5
3 102.5 102.8 98.5 99.0
4 99.0 100.5 98.8 100.2

合并成一根4小时K线：开盘价100.0，最高价103.0，最低价98.5，收盘价100.2。这是一根实体很小（实体0.2）而振幅很大（4.5）的K线。在4小时图上，它看起来像犹豫不决；而在1小时图上，它其实是一波上涨，随后急跌，再部分反弹。

两种画面都没错，它们以不同的分辨率描述同一批成交。这就是为什么5分钟图上的一根"看涨"K线可能位于一根看跌的日K线之内，也是为什么交易者常常查看不止一个时间周期。参见多周期分析。

K线什么时候"收盘"？

日K线取决于一天从何时开始。对股票而言，日K线通常覆盖常规交易时段，盘前和盘后成交是否计入，因平台而异。对外汇而言，很多平台在纽约时间下午5点收出日K线。加密货币全天候交易，日K线通常在UTC 00:00收盘，但也有平台使用当地时间。因此，两位交易者看的"同一张"日线图，K线可能并不相同。参见交易时间与交易时段。

还要注意，最新一根K线在其周期结束前尚未走完。一根在小时中途看起来像强烈拒绝的K线，收盘时可能变成完全不同的样子。

美国线与K线图

OHLC柱状图（美国线）使用同样的四个价格。每根柱线是一条从最低价到最高价的竖线，左侧的小横线表示开盘价，右侧的小横线表示收盘价。

特征 OHLC美国线 K线
显示的数据 开盘价、最高价、最低价、收盘价 开盘价、最高价、最低价、收盘价
方向提示 左右小横线的位置 实体颜色
一眼可读性 较低 较高
视觉分量 较轻；适合密集的图表 较重；实体抓人眼球
传统使用者 西方交易者、许多期货交易者 起源于日本；现已在全球占主导

由于数据完全相同，在K线上能做的任何分析都可以在美国线上做。一些经验丰富的交易者偏爱美国线，恰恰是因为K线实体会让单个周期显得比实际更重要。

K线图传统上与日本米市商人联系在一起，并于1990年代初在西方交易者中流行开来。

常见错误

  • 把未走完的K线当成定局。 当前K线在收盘前可能完全改变。
  • 忽视时间周期。 1分钟图上的一根强势K线，在日线图上可能根本看不出来。
  • 以为各平台的K线都一样。 不同的交易时段设定和数据源会产生不同的OHLC值，外汇和加密货币的日K线尤其如此。
  • 在流动性稀薄的市场中过度解读影线。 冷清时段的一根长影线可能只反映一笔订单，而不是市场情绪。
  • 把颜色当成信号。 绿色K线只说明收盘价高于开盘价。如果市场跳空低开，一根绿色K线的收盘价仍可能远低于前一根K线的收盘价。

常见问题

K线上的影线代表什么？

影线显示该周期内超出开盘价和收盘价范围的最高和最低成交价。长影线意味着价格朝那个方向走了很远，但在周期结束前被打了回来。

绿色或红色K线是什么意思？

绿色（或空心）K线表示收盘价高于开盘价，红色（或实心）K线表示收盘价低于开盘价。颜色是平台设置项，有些市场采用相反的惯例，所以请检查你的图表设置。

K线图比美国线更好吗？

两者显示的开盘价、最高价、最低价和收盘价数据完全相同。K线更便于快速阅读，所以大多数平台默认使用K线；也有些交易者偏爱美国线，觉得画面更简洁。

为什么不同平台上的日K线看起来不一样？

各平台对交易日起止时间的定义不同，外汇和加密货币几乎或完全全天候交易，差异尤其明显。不同的交易时段设定和数据来源会产生不同的开盘价、最高价、最低价和收盘价。
